## 選んだ改善

| 観察・狙い | 変更 |
| --- | --- |
| 辞書の不足で緊張が上がる | 未分類・判断保留の数値変化を0にする |
| 否定や曖昧語の部分一致 | 指定の否定形と一部の混在・伝聞等を限定的に保留 |
| 入力にない語の引用 | 引用に依存しない返答にし、状態・直前の行動で変化 |
| 同じ文を連打すると成功 | 会話内の正規化済み同文は再加点しない |
| 失言後も試せる展開 | 直後に新しい謝罪をすると緊張-1・信頼+1 |
| 目標・操作の分かりにくさ | 到達値、コスト、実際の変化、入力ヘルプ、4/5区画のメーター |
| 次に試す言葉を考えたい | 追加実験「会話のふり返り」で実際の行動数と助言を表示 |

新しいモデル・外部APIは不要と判断し、3つの小さな処理へ分離した。辞書レビューの144件の表現・理由・出典は取込コミットとの構造比較で同一と確認した。
