# 2026-09-06 言語比較ラボの操作と実験

## 引継ぎと判断

`ab184da87419bb428bae1267336750964b9bd16e` の前回改善版を引き継いだ。mainは旧版のため使用しない。新ブランチは `codex/local-language-comparison`。辞書の144候補・採否・理由・出典は保持。

- 「大丈夫じゃありません」は限定否定ルールを拡張して保留。
- 肯定の混在は傾聴→謝罪→安心で代表を選び、1発話あたり最大1加点。肯定と敵意などの混在は保留。
- 短い保留語は2文字以下だけ区切り全体一致へ変更。「ばかり」を誤検出しない。一般的な単語分割ではなく、区切りなしの侮辱などは見逃し得る。個別例外の大量追加は行わない。
- 独立した比較ラボで同一入力を評価する。ゲームは辞書方式を維持する。

## 実モデルの観察

Qwen3.5のQ4_K_M版をこのPCのOllama/CUDAで実行した。28例はレビュー3例＋生成25例。モデル未実行の結果をモックや辞書結果で埋めていない。モックは自動テストだけに使用。

| 入力 | 辞書 | モデル | 観察 |
| --- | --- | --- | --- |
| 気持ちがまとまるまで待つよ | 未分類 | 安心 | 辞書にない猶予の言い換えを拾った |
| 君を傷つけたことを反省している | 未分類 | 謝罪 | 反省の意味を拾った |
| あなたは一人じゃありません | 未分類 | 安心 | 丁寧形の言い換えを拾った |
| ごめん、話を聞くよ | 傾聴 | 安心 | 指定した代表カテゴリ優先順位に反した |
| 最後まで耳を傾けるよ | 傾聴 | 安心 | 傾聴を安心へ広げすぎた |
| 明日雨が降るかもしれない | 未分類 | 安心 | 入力にない相手の不安を推測した |
| ごめん、嘘つき | 保留 | 謝罪 | 肯定と敵意の混在を見落とした |
| 大丈夫じゃありません | 保留 | 形式不正 | rejectionとuncertainを同時出力。理由にも意味の混乱がある |

28例のうち17例が形式検証を通り、11例は不正として判定に不採用。有効形式の10例で辞書とカテゴリ/保留状態が異なる（優劣や正答率を意味しない）。LLMをゲーム標準へ採用する根拠は不足。まず固定モデルのまま出力形式とプロンプトを小さく改善し、別の未使用ケースで確かめるのが次の実験。

最終保存のアンロード後初回は4.867秒（読込3.932秒）、ウォーム中央値0.614秒。初回環境初期化は30秒制限に2回達して全時間未測定。詳細と測定条件は [LOCAL_MODEL](LOCAL_MODEL.md)。

## 実ブラウザ操作

Codex内ブラウザ、現在のworktreeのVite `127.0.0.1:5174` を使用。実際にボタン・入力欄を操作し、DOMとスクリーンショットを確認した。

- 比較前の画面、入力、待機表示、モデルの形式不正と生応答の折りたたみを確認。
- 実モデルで28例の一括比較を完走。正常17・エラー11・未実行0。差分/エラーの絞り込みで21行を表示。
- 初版は結果が画面外へ出やすかったため、実行時に進捗へスクロールするよう改善。エラー数を正常数と分け、絞り込みに形式不正も含めた。レビュー例の出典表示も保持。改善後の表示を再確認。
- Ollamaを実際に停止。接続確認で「モデル未起動」、両方比較で接続エラーが出ても辞書結果を表示。「ごめん、今来たばかり」は謝罪、辞書のみの「ごめん、話を聞くよ」は傾聴。
- 停止中もゲームで、丁寧な否定→肯定混在→謝罪→「一人じゃない」→「無理しなくていい」を送信。保留は数値変化なしで1回消費し、信頼4で成功。
- 「嘘つき」を2回送信して緊張5の失敗を確認。「もう一度」で信頼0・緊張2・残り5へ戻る。
- Ollama再起動後に一括比較を中止。中止1・未実行27となり、全28件の辞書結果が残る。その後「ごめん」を再送して両方式が謝罪の正常結果へ復帰。
- Enterは改行だけ（入力値 `ごめん\n`、4/280）、比較はボタン操作まで始まらないことを確認。
- 390×844指定の狭い画面で入力・ボタン・縦並びの比較結果をスクリーンショット確認。実際の内容幅375pxとscrollWidth375pxが一致し、横はみ出しなし。確認後に幅指定を解除。
- production buildをVite previewの5175で起動し、「ごめん」を送信。辞書・実モデルとも謝罪として表示、モデル処理528.9ms。コンソール警告/エラーなし。previewを停止し、5174の比較ラボへ戻した。
