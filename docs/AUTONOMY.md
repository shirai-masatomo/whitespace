# WhiteSpace 自律運用

各プロジェクトは開始時に自律モードを選ぶ。

## 完全自律型

「完全自律型」を選んだ場合は、個別に0から指示せず、次を標準設定とする。

```text
Codex
実装 → テスト → 自己レビュー → 改善 → GitHub更新
                         ↓
                  GitHub定期監視
                         ↓
                    AIレビュー
                         ↓
              人間判断が必要？
                NO ↓      ↓ YES
                  継続    人間へ通知
```

### 標準ルール

- 実装が1つ終わっただけでは人間確認を求めない。
- Codexは最低1回、自己レビューと改善まで行う。
- GitHubを状態の受け渡し場所にする。
- 定期監視は原則 **1時間ごと**。
- 更新がなければ何もしない。
- 更新があってもAI側で判断できる場合は人間へ通知しない。
- 人間へ上げるのは、ゲームの核、プレイ感、重大な創作判断、Vertical Slice、ほぼ完成版、Release Candidate、契約・支払い・権利・公開判断など。
- 各PJ固有の例外だけ、そのPJの `AUTONOMY.md` に書く。
