# C：初手「どうしたの？」から

[カップにぶつかった友人の初手一覧](C.md) / [入口](../COFFEE_PLAYER_FLOW.md)

あなたがカップにぶつかり、友人のコーヒーが机に広がった。二人とも、その瞬間を見ていた。手元にはティッシュがある。

## 初手と、その直後

```mermaid
flowchart TB
  start["場面の始まり"]
  start --> pick["発言：どうしたの？"]
  pick --> reply["相手「さっきのコーヒーのこと。まず机を拭きたいんだ。」<br/>新たな動作・情景の記録なし"]
```

ここから下は、同じ初手の直後から選べる**別々の2手目**。上から順に押す手順ではない。発言も行動も選べる。

## 2手目：どうしたの？

```mermaid
flowchart TB
  from["初手『どうしたの？』の反応の後"]
  from --> pick["発言：どうしたの？"]
  pick --> reply["相手「さっきのコーヒーのこと。まず机を拭きたいんだ。」<br/>新たな動作・情景の記録なし"]
  reply -->|"同じ選択を繰り返すと、同じ反応"| pick
```

<details>
<summary>この地点で引き継ぐこと（他の枝とは合流しない）</summary>
