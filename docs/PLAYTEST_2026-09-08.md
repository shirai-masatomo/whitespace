# 2026-09-08 低ポリゴンの対話相手

## 作業範囲と判断

開始時a3a23a6、未コミット変更なし、fetch後のorigin/codex/local-language-comparisonとの差0/0。442701d以降のサブエージェント制限も保持し、`codex/reactive-low-poly-bust` へ分岐。全作業を主エージェントが直接行った。

追加依存はThree.js 0.185.1だけ。Vite/Reactと共存させ、3D側を動的importにした。外部モデル・人物画像・追加LLMは使わない。参考は公式 [WebGLRenderer](https://threejs.org/docs/#api/en/renderers/WebGLRenderer) と [資源の解放](https://threejs.org/manual/en/cleanup.html)。

- コード生成の頭・首・肩・胸を灰白色のマット材質で構成。三角面を独立させ、わずかな面のずれと胸の光を追加した。
- 信頼は顔の向きと光、緊張は肩の高さと揺れへ独立接続。高信頼・高緊張も表現する。
- 持続姿勢と2秒の一時反応を分け、同じ発言IDでは再生し直さない。再挑戦で描画・反応・プレビューを初期化。
- 通常時は揺れを小さく限定。動き軽減では揺れ・呼吸・面の動き・首かしげ/肩下げを抑え、静的姿勢と説明で伝える。成功/失敗は揺れと面の動きが収まる。
- 表示確認は得点・履歴を変えない。ゲーム判定は辞書のまま。

## 画面を見て修正したこと

1. 初版は入力の自動フォーカスで頭が画面外に出た。初回自動フォーカスを外し、送信後はフォーカスを保って胸像先頭へスクロール。人物・返答・入力が同時に見えることを再確認。
2. 肩が独立した部品に見えたため、胸との重なりと形状を調整。光を灰白色寄りへ変更した。
3. 顔の向きが読み取りにくかったため、目口を増やさず小さな中央の稜線を追加。
4. 開発パネルが会話を押し下げたため、PCでは人物横、狭い画面では人物下へ配置。狭い画面で開いている間は人物が見えるよう固定。
5. 会話中も得点を見られるよう、胸像足元に信頼/緊張/残り発言数を表示。遊び方と履歴を折りたたんだ。
6. 手動の動き軽減が再挑戦で解除されないようApp側へ設定を移した。
