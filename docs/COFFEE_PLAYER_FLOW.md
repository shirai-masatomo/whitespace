# コーヒー場面：プレイヤーの選択から読む分岐図

まず、自分がどう居合わせたかを選んでください。**初期状態 → 初手 → 相手の台詞・動作 → 2手目 → 反応**の順で、現在の実装を読めます。

- [A：後から来た友人](coffee-player-flow/A.md)
- [B：近くにいた見知らぬ人](coffee-player-flow/B.md)
- [C：カップにぶつかった友人](coffee-player-flow/C.md)

各入口には初手9個を、実際の文言と反応で掲載。各初手の詳細ページには、発言6個・行動3個の**2手目すべて**と結果を載せています。長大な横並びを避け、一つの選択と反応を縦に読む小さな図へ分割しました。図を上から全部実行する手順ではなく、同じ地点から選べる別々の枝です。

## 図の範囲と読み方

- 3条件 × 初手9個 = **27初手**、それぞれに2手目9個 = **243通りの2手の組合せ**をアプリの処理へ渡して生成。相手の発話と、動作主付きのト書きを区別します。動作が記録されていない場合は、その旨を明記します。
- 2手目まででは紙の受け渡しまで到達します。受取直後に無効になる「渡す」と、変わる操作名「拭くのを見守る」も各枝の続行候補に明記。[受取後の共通の続き](coffee-player-flow/CONTINUE.md#受け取った直後)では、3手目の拭き取りまで追えます。
- 2手目までの通常候補はすべて実行可能です。無効な操作を実行した架空の反応や、検証パネル専用の経路は混ぜません。自由入力の解釈の揺れはこの図の対象外です。
- 同じ返答でも枝を合流しません。「この地点で引き継ぐこと」を開くと、知識・同意・謝罪・拒否・確認要求・所持品・距離等を読めます。ループ矢印は、同じ選択を再度行って発話・動作・更新状態が全部同じ場合だけ。別の選択へ移る際に過去を消す意味ではありません。
- **3手目以降の全返答は未展開**。各地点の通常候補を示し、必要な後続部分だけ別の図へ進める構成です。全履歴の数を有限のルート数として数えていません。
- 全状態を調べる場合は、従来の[内部状態図・規則表](COFFEE_TRANSITIONS.md)と[A](COFFEE_STATES_A.md)・[B](COFFEE_STATES_B.md)・[C](COFFEE_STATES_C.md)の全状態表へ。これらは詳細検証資料として維持しています。

## 議論の起点にしやすい枝

- [A「ティッシュいる？」の次](coffee-player-flow/A-offer_tissue.md)：受諾後にも6種類の発言が残り、渡すとさらに「見守る」が必要。
- [B「手伝おうか？」の次](coffee-player-flow/B-offer_help.md)：一度断られても具体的な援助なら受け入れられる。
- [C「ごめん」の次](coffee-player-flow/C-apologize.md)：再謝罪と、次の援助へ移る選択の差。
- [A「どうしたの？」の次](coffee-player-flow/A-ask_event.md)：情報を得た後も選択肢の文言はほとんど変わらない。

## 改善候補 — 以下は未実装の提案

現行図には混ぜていません。今回、ゲームの判定・状態更新規則は変更していません。内部で段階を保持することと、各段階でプレイヤーにボタンを押させることは別に検討します。

| 現在の流れ | 改善候補と理由 | 残したい判断・確認 |
| --- | --- | --- |
| 相手が受け取る → プレイヤーが「拭くのを見守る」 → 相手が拭く | 受け取った相手が短い間を置いて自動で拭く。自分で拭くという本人の意思を実行するためだけのクリックを省ける | 受取・拭き取りは内部で別の出来事として保持。途中で話しかける余地が必要か検討 |
| 「ティッシュいる？」→受諾→「ティッシュを渡す」 | 「ティッシュを差し出して尋ねる」という一連の操作を候補にする。受諾時だけ物を渡す | 自動化すると渡さずに引き下がる選択が失われるため、まず上の拭き取り自動化と分けて比較 |
| 「どうしたの？」や「大丈夫？」を再度押すと同じ情報を繰り返す | 既知の質問を通常候補で弱く表示するか、文脈に合う追質問へ置換 | 気まずい発言を一律に削らず、検証用の反復も維持 |
| 「机を拭きたい」「自分で拭く」と聞いても候補はほぼ同じ | 「じゃあ、これを使って」「分かった、任せる」等、聞いた情報に応じる言い方を試す | 新しい台詞が必要なのか、新しい行為が必要なのかを分ける。現在の図に存在する操作ではない |

最初に試すなら「受取後の自動拭き取り」。受諾・受け渡しという主人公の関与を残したまま、相手が自分で動く自然さを比較できます。
