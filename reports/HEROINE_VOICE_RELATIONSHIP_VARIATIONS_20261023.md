## 人物像の核

ヒロインは20歳以上の大学生。おしとやかで穏やか、後輩にも敬語で接しやすい。親しくなると本音や冗談、甘え、反論も出る。これらは別人格ではなく、同じ女性が相手によって見せる側面。以下は全て新規創作。

## 1. 関係別の基本的な話し方

| 段階 | 口調 | 例文 |
| --- | --- | --- |
| あまり親しくない | 丁寧、距離がある | 「あ、お疲れさまです。今日は早いんですね」 |
| 顔見知り | 丁寧で雑談が増える | 「ふふ。そんなに慌てなくても大丈夫ですよ」 |
| 気の置けない仲 | 敬語を維持しつつ小言も言える | 「それはずるいです。……もう、知りません」 |
| 恋心が芽生える | 言い直しや照れが増える | 「もう少しお話しできたら……嬉しいです」 |
| 恋人 | 二人きりならタメ口が混ざる | 「ねえ、今日もう少し一緒にいられる？」 |
| 深い信頼 | 素直に甘え、怒りや弱音も見せる | 「……遅いよ。心配したんだから」 |
| すれ違い | 丁寧さが距離になる場合も | 「その言い方は、少し悲しかったです」 |

## 2. おしとやかな女性が見せる8つの側面

お題は全て「来てくれて嬉しい」。ベースの品のよさを維持しつつ、言葉を変える。

| 側面 | 台詞例 |
| --- | --- |
| 上品で控えめ | 「来てくださって、ありがとうございます。……安心しました」 |
| おっとり | 「あ……来ていたんですね。気づくのが遅くなっちゃいました」 |
| 恥ずかしがり | 「待っていたわけじゃ……いえ、少しだけ待っていました」 |
| 世話焼き | 「寒くなかったですか？ まず温かいものを飲みませんか」 |
| 芯が強い | 「嬉しいです。でも、次は時間を守ってくださいね？」 |
| 茶目っ気 | 「遅刻一分です。……冗談ですよ。ふふ」 |
| 甘えん坊（親しい相手だけ） | 「……遅い。会いたかったんだよ？」 |
| 気持ちが溢れる | 「……よかった。本当に来てくれた。心配したんだから」 |

## 3. 同じ質問への返答比較

### 「隣、座ってもいい？」

- 距離あり：「ええ、どうぞ。こちら、空いていますので」
- 顔見知り：「もちろんです。ちょうどお話ししたかったんですよ」
- 仲良し：「毎回聞かなくても大丈夫ですよ。……律儀ですね」
- 片思い：「……はい。あの、できれば近くに」
- 恋人：「うん。こっちに来て？ ……少しくっついてもいい？」
- 深い仲：「だめ、なんて言うと思った？ ほら、早く」

### 「俺のこと、どう思う？」

- 距離あり：「いつも周りに気を配ってくださる方だと思います」
- 顔見知り：「話しやすい方ですよ。……それでは、だめですか？」
- 仲良し：「困った人です。でも、嫌いとは言っていませんよ」
- 片思い：「……今、答えないといけませんか？ 顔、見ないでください」
- 恋人：「好きです。……あの、ちゃんと聞こえました？」
- 深い仲：「好きだよ。何度も聞かないで。……何度でも言うけど」

### 「今日はもう帰る？」

- 距離あり：「はい。そろそろ失礼しようと思います」
- 顔見知り：「少し片づけてから帰ります。手伝いましょうか？」
- 仲良し：「帰りますけど……駅まで一緒なら、嬉しいです」
- 片思い：「……まだ帰らなくてもいいですか？」
- 恋人：「もう少し一緒にいたいな。明日も会えるのに、変だね」
- 深い仲：「帰るよ。でも、その前にもう少しだけ、こうしてたい」

### 「他の男子と仲良いね」

- 距離あり：「同じサークルですから、皆さんとお話ししますよ」
- 顔見知り：「そう見えましたか？ 相談を受けていただけなんです」
- 仲良し：「……気になります？ いえ、からかってはいませんよ」
- 片思い：「……あなたにも、もう少し気にしてほしかったです」
- 恋人：「心配させたならごめん。でも、私の話も聞いてほしいな」
- すれ違い：「疑われ続けるのはつらいです。私の言葉も信じてください」

## 5. 台詞作りの注意

- おしとやかさを保つとは、いつも受け身になることではない。冗談、反論、拒否、怒りも自然に描く。
- 全場面で「あの」「ふふ」「……」を使うと人物が単調になる。安心している場面では簡潔に言い切らせる。
- 親密になれば必ずタメ口ではなく、『恋人にも敬語』『二人きりだけタメ口』という差分も用意できる。
- 主人公との会話だけでなく、男子A、男子B、女子友人、サークル全体で声色を変える。
- 酒に弱い設定は、判断力・返答の間・集中力などで自然に示す。飲酒と長期の関係性は区別する。
- 実装時は相手、場所、関係段階、感情、場にいる人、画像・表情IDを台詞ごとに記録する。
