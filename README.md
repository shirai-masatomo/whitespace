## HTMLの操作画面を使う

GitHub上ではMarkdown・画像・GIFを閲覧できます。採否比較や素材の試し重ねなどHTMLの操作には、このブランチの **Code → Download ZIP** で一式を取得し、展開後の **index.html** を開いてください。HTMLファイルのGitHub表示では操作できません。

- [統合素材一覧のHTML](materials/index.html)：人物・文字・効果の試し重ね
- [表情の比較・採否HTML](expressions/index.html)：視線・赤み・眉・口で絞り込み、最大4枚比較
- [ComfyUI初回ガイド](manuals/COMFYUI_FIRST_STEPS.md) ／ [衣装・構図プロンプト](manuals/COMFYUI_PROMPT_COOKBOOK.md) ／ [保存区分](manuals/COMFYUI_STORAGE.md)

採否はブラウザーごとの保存です。端末間ではJSONを書き出して取り込んでください。素材の候補掲載は採用・ゲーム実装の完了を意味しません。
