このブランチはシーン検討用です。製品は当面、特定背景＋人物＋表情＋文字・効果を重ねる構成とし、参考画像は一枚絵でも構いません。**製品CG用 `assets/scene` へは、ユーザーの明示指定なしに画像を入れません。** 今回製品CGは送信していません。

GitHubでは場所別のMarkdown・画像・GIFを閲覧できます。場所選択のHTMLは **Code → Download ZIP** で取得・展開して `index.html` を開いてください。GitHub Pagesは有効化していません。旧版01・02の重複一覧を削除し、改訂03と室内絨毯版を現行の検討対象にまとめました。固有の比較・失敗記録、依存素材は保持しています。
