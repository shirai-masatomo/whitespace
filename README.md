# Coffee — WhiteSpace 会話・意味の実験

**[世界観・ゲーム仕様（ここだけ読めばOK）](SPEC.md)**

同じ出来事や言葉が、関係・事情・本人にとっての大切さによって別の意味になるかを、短い場面で検証する試作です。

## 試す

`prototypes/001-nadameyo` に移動し、`npm.cmd ci` → `npm.cmd run dev -- --host 127.0.0.1 --port 5174 --strictPort`。

ブラウザの `http://127.0.0.1:5174/#coffee` でコーヒー場面を試せます。宥めよ・言語比較ラボも同じ試作環境にあります。

技術・検証の資料は [開発者向け](docs/README.md)、進行状況は [開発状態](docs/STATUS.md) に分離しています。ユーザーが更新する世界観やゲーム仕様は `SPEC.md` に集約してください。
