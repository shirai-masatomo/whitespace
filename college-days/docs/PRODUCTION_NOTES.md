# 画像制作と本体の分担

この文書は制作方針です。ゲーム世界の設定・登場人物の性格とは分けて扱います。

## 役割と目標

【確定発言／U00】画像labはゲーム本体用の素材を制作する場所です。ユーザー一人で、GPT内蔵画像生成を使わずに、ポーズ・表情・衣装を効率的に変え、変更対象以外を保つ制作環境を目指します。原本は保持します。

| 対象 | パスと役割 |
| --- | --- |
| 現行ゲーム本体 | `projects/university-circle-renpy`。会話、分岐、画面表示、採用素材の組み込み |
| 画像lab | `projects/local-ai-image-lab`。人物・背景・表情等の制作と採否・版の管理 |

【資料由来暫定／L04–L06】labにはComfyUIの手順、人物参照、局所編集、ポーズ制御、LoRAの学習・使用記録があります。ただし、全身ポーズや衣装を自在に変えながら人物と画風を保つことが、あらゆる条件で達成済みという意味ではありません。

## 旧資料と現在の目標を分ける

【資料由来暫定／L04】過去のworkshop資料は、内蔵画像編集で差分を作り、ComfyUIで補修する分担を提案しています。これは当時の結果に基づく記録です。

【確定発言／U00】現在の目標はGPT内蔵生成なしの自力制作です。過去に内蔵生成した素材が存在することと、今後も同方式を使うことを混同しません。今回の資料整理では過去の画像や手順を削除・書換えせず、今後の目標との差を記録します。

## 保全と品質の意味

【資料由来暫定／L04、L05、A03】原本は上書きせず、差分を別ファイル・別版で管理します。人物参照・画風参照・構図参照を分け、候補と明示採用を区別します。

【資料由来暫定／L04、L05】マスク外を元画像から合成して画素を保持できることと、生成モデルだけで同一人物・画風・自然な人体を再現できることは別です。ポーズ変更では描き直す範囲が大きくなります。小さな表情修正の成功を、大幅なポーズ変更の保証にしません。

【提案】次の制作では、変更箇所、保持箇所、原本、採用基準を先に記録し、少数の候補を比較します。表情の素材ラベルからゲーム内の性格・恋愛傾向を決めません。

## 本体へ渡す際の確認

【資料由来暫定／G01、G03、G07】本体の表示確認で使うlab人物は仮使用です。lab内の採用状態、本編人物としての正式採用、本体での実機表示確認はそれぞれ別です。

【提案】本体へ採用する時点で、人物対応、素材の役割、版・パス・ハッシュ、採否と利用条件を照合します。生成・制作済み、組み込み済み、ゲーム内で検証済みを分けて記録します。

【未決】内蔵生成なしでどの編集を合格水準まで行えるか、ユーザーが繰り返し扱いやすい操作方法、人物固定・衣装・ポーズ・表情それぞれの受入条件は今後の検討対象です。今回モデル取得、学習、生成、ツール起動、画像加工は行いません。
