## ヒロインの性格：確定できる範囲

以下は【資料由来暫定／U01】として追加された、別会話「アイディア」の要約由来の参考設定です。ユーザーへの直接確認や、原文全体を照合した設定とは区別します。

| 参考設定 | 今回記録できる範囲 |
| --- | --- |
| 基本おしとやか | 普段の性格の参考。内気、消極的、清楚など別の性質まで自動で付けない |
| 後輩の男の子にも敬語で接する | 話し方の参考。具体的な一人称・語尾・呼び方は未確認 |
| 男性経験が豊富ではない | 経験の多寡についての参考。具体的な経験内容・人数・交際歴は不明 |
| お酒に弱い | 体質の参考。飲酒量や反応を数値化せず、意思や同意の代替条件にしない |

【未決】参考設定を正式採用する範囲と、親しい相手の前での態度・変化は要確認です。「お酒に弱い」ことから「押しに弱い」等の性格や、他者の意図へ従う性質を導きません。

【資料由来暫定／G04、G06】試作の葵は、主人公をサークルへ案内し、会話や準備の手伝いに応じる台詞を持ちます。これは試作場面での発言の事実であり、全場面での性格を保証しません。

【資料由来暫定／L01】「穏やかな微笑み」「照れ笑い」「戸惑い」等は表情素材のラベルです。表情の採用・候補状態と、人物の恒常的な性格は別です。衣装、赤面、飲み会用差分、裕福な家庭という情報から、恋愛傾向や貞操観念を推測しません。

【提案】参考設定の先を決める際は、普段の話し方、自分から行動する場面、相手との距離感、断るときの態度、サークルでの役割を、ユーザーの言葉または明示された資料で確認します。未確認の回答は補いません。

## 他の男性・サークルの人物

【確定発言／U00】ヒロインと他の男性との親密度も持ち、主人公だけに閉じない関係変化を考えます。

【資料由来暫定／U01】「アイディア」の要約では、主人公とまっすぐ恋愛する場合も、サークルの他の男子と親しくなる場合もあるとされています。また「一年は男子が多い」と伝達されています。具体的な人数・男女比・人物名は未確認です。

【未決】男性の人数、名前、年齢、学年、性格、ヒロインとの既存関係、主人公との関係、登場順は未定です。競争相手・恋人・悪役等の役割を自動で割り当てません。サークルの他のメンバーも、確認資料なしに増やしません。

## 人物について今後確認すること

1. ヒロインの正式名・年齢・三年生設定と、画像lab人物との対応。
2. 「おしとやかさ」等の参考設定の原発言・採用範囲、日常と親しい相手の前での違い。
3. 他の男性の人数・役割・関係の開始状態。
4. 主人公の「二浪／二年間留年」「20歳／20歳超」の整理、個性、外見、名前入力、家や生活の設定。

初期の親密度や性に関する状態値は未設定です。年齢以外の人物数値や性格評価値を新しく作っていません。
