# 関係とイベントの方針

## 一対一に閉じない関係

【確定発言／U00】主人公とヒロインの関係に加えて、ヒロインと他の男性との親密度も持ちます。会話の選び方と関係変化によるドキドキを重視します。

【資料由来暫定／U01】別会話「アイディア」の要約では、主人公とまっすぐ恋愛する場合と、サークルの他の男子と親しくなる場合の両方が挙がっています。片方だけを作品の唯一の進め方と決めません。ルート数や結末は未定です。

【提案】将来の設計では「誰と誰の関係か」を識別して記録します。主人公と親しくなることだけで、他の男性との親密度が自動的に下がる仕様にはしません。そのような連動を入れるか自体が未決です。

【未決】関係を片方向で持つか相互で持つか、主人公が全状態を知るか、数値を画面に出すか、主人公が不在の関係変化をどのように表現するかは未定です。

## 状態の候補

下記の用語は【確定発言／U00】として挙がった**候補**です。項目名が挙がったことと、定義・数値化が確定したことを分けます。

| 候補 | 設計時に確認すべき点【未決】 |
| --- | --- |
| 親密度 | 対象となる人物の組、友人関係と恋愛感情の扱い、相互性 |
| 性欲 | 一時的状態か継続的傾向か、変化する要因、他項目との違い |
| 淫乱度 | 用語の意味・表示名・独立項目にする必要性。性欲や行動履歴との区別 |
| 貞操観念 | 何についての価値観か、本人の意思や境界との関係、単純な高低で表せるか |
| 風紀 | 個人・サークル・場の雰囲気のどれを対象にするか、他項目との違い |

【確定発言／U00】これらの組み合わせで分岐を考えます。ただし、計算式、初期値、上下限、増減量、閾値、優先順位は未定です。

【提案】数値を決める前に、同じ会話でも相手や過去の関係によって反応がどう変わるかを文章で確認します。数値だけから人物の意思や性格を自動確定せず、場面での本人の反応と選択を記述します。今回は具体的な反応や分岐シナリオを新作しません。

## 現行試作との違い

【資料由来暫定／G06】現行ソースには `affection_aoi`、大学・部室の訪問回数、海への同行履歴があります。好感度初期値0、選択で+1、海の同行条件2という試作用の値が記述されています。

これらは**既存コードの値を記録したもの**です。上の複数状態設計の初期値・数式・閾値として採用しません。現行の簡易好感度と、将来の親密度が同じ意味かも未決です。他の男性を含む関係管理が実装済みとは説明しません。

## 場面例と役割

| 場面例【確定発言／U00】 | 検討できる役割【提案】 | 未決事項 |
| --- | --- | --- |
| サークルの飲み会 | 複数人の会話、相手との距離、周囲の反応 | 参加者・場所・発生時期 |
| 宅飲み | 親しい集まりの空気、少人数のやりとり | 誰の家か、参加条件・退出の扱い |
| 二人で出かける | 会話の選択と相手の反応を丁寧に描く | 行き先、誘う側、関係への影響 |
| 主人公宅 | 主人公の生活や関係の変化を見せる | 住まい自体の設定・素材 |
| ヒロイン宅 | 日常の生活空間と、距離感の変化を描く | labの住環境を本編へ採用するか |

場所や素材があるだけでは、その場面を完成イベントとして扱いません。飲酒量、酩酊、拒否のしにくさを利用する攻略条件や手順は新規作成しません。今回の範囲は非露骨な企画方針です。

## 臨場感を検討するための記録項目【提案】

- 場所、時間帯、同席者、その時点の関係と既に分かっている出来事。
- 会話で主人公が選べること、ヒロインや同席者が自分で選ぶこと。
- 台詞、間、視線、表情、立ち位置、環境音で伝える変化。
- 場面が終わったときに何が変化し、何が次の会話へ残るか。
- 使用素材の版と採否、実装状況、隔離内での実機確認状況。

これは今後の設計項目であり、イベントの発生式や確定シナリオではありません。初期基盤の確認を優先し、採用する場面から具体化します。
