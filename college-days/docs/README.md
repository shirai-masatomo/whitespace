## 設定の扱い

- **【確定発言】**：資料作成時に明示されたユーザー方向性。会話全文を直接照合したという意味ではありません。
- **【資料由来暫定】**：既存資料・試作ソース・別会話の要約に記載がある情報。資料内の採用状態と、本編への正式採用・ユーザーの再確認は区別します。
- **【提案】**：今回示す設計案。採用済みではありません。
- **【未決】**：根拠不足、矛盾、ユーザー確認が必要な点。

出典IDは [SOURCES.md](SOURCES.md) と対応します。資料の多さや新しさだけで、矛盾する設定を自動的に正本へ昇格させません。

## 今の重要事項

【確定発言／U00】大学生の恋愛と人間関係、会話選択による関係変化のドキドキ、イベントの臨場感を重視します。将来は成人向けを想定します。主人公とヒロインだけで関係を閉じず、ヒロインと他の男性との親密度も考えます。

【資料由来暫定／G01–G04】現行本体の主人公は二浪・20歳・一年生。本編導入の葵は三年・21歳の仮設定です。画像labの人物は名前未定・20歳で、表示確認シーンに仮使用されています。両者の正式な同一人物化は未決です。

【資料由来暫定／U01】別会話「アイディア」の要約では、ヒロインは「基本おしとやか」「後輩の男の子にも敬語で接する」「男性経験が豊富ではない」「お酒に弱い」と伝えられています。原文全体未照合の参考設定です。

【未決】ヒロインの正式名・正式年齢、主人公の「二浪／二年間留年」「20歳／20歳超」、状態候補の定義・数式・閾値は確認待ちです。`SCENARIO_MASTER` と別の関連会話本文は未確認です。
