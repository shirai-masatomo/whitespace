# ゲームの方向性

## 目指す体験

【確定発言／U00】仮題は **college days**。大学サークルを舞台に、大学生同士の恋愛と人間関係を描くゲームです。将来は成人向けを想定します。本資料は非露骨な企画概要としてまとめます。

【確定発言／U00】中心となる楽しさは、会話の選び方によって距離や関係が変わるドキドキと、イベントの場に居合わせているような臨場感です。主人公からヒロインへの一方向の攻略だけでなく、ヒロインと他の男性との関係も動く構成を考えます。

【未決】嫉妬、競争、すれ違い等をどの程度描くか、主人公が不在の出来事をどう知るか、どの関係を結末として扱うかは未定です。題材の方向性から特定のルートや展開を自動的に確定しません。

## 最初に完成を目指す範囲

【確定発言／U00】最初は、起動、背景と人物の表示、人物移動、表情切替、短い会話という最小基盤を優先します。

【資料由来暫定／G01–G03、G05】現行本体はRen’Pyのソース構成です。独立した「表示確認」シーンに図書館背景・仮人物、左／中央／右の移動、表示／非表示、通常／戸惑い、5行の会話が記述されています。これはソースの確認結果です。隔離ゲスト内での実機受入は未完了で、起動・描画・入力が成功したとする根拠にはしません。

【資料由来暫定／G06】既存試作には大学・部室・海と簡易好感度分岐、訪問履歴があります。ホテル外観や海の昼夜の導線も既存本体に記載があります。これらの存在を、完成した物語や成人向けイベントの実装と扱いません。

【提案】最小基盤の受入を終えてから、短い日常会話と関係変化を一場面ずつ検討します。複数状態の大規模な分岐表を先に完成させることは、最小基盤の前提にしません。

## 画面と文章の方針

【資料由来暫定／L03】画像labの2026-10-20要件は、背景・人物絵、画面下部の固定台詞とナレーション、BGM／SE、セーブ／ロード、バックログ、回想を中心にしています。選択肢、好感度、フラグ、条件分岐も想定します。プレイ中のLLM会話生成は要件に含めません。

【未決】回想等をいつ実装するか、最終UI、作品の長さ、日付・時間・行動回数の仕組みは未定です。古い要件にある「最終エンジン未選定」と、現行のRen’Py本体を区別します。最終採用の再確認が必要で、今回エンジンを変更・導入しません。

## 表現範囲

【確定発言／U00】今回は性行為の詳細や、同意不能な状態を利用する攻略手順を新規作成しません。飲み会や宅飲みは会話・人間関係の場面例として記録します。

【提案】臨場感は、会話の間、視線、表情、立ち位置、背景、環境音、相手の反応の組み合わせから検討します。成人向け想定というだけで、イベントの内容や人物の行動原理を決めません。
