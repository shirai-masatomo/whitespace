# 参考資料をGitHubへ保存する共有版

## 目的・合格条件

ユーザーの「gitに上げて見れるようにしたい」に対応する。素材・表情・組み合わせ・ComfyUI資料をPC外から参照できる形にし、既存ゲームの変更や実行環境を混ぜない。

## 入力と環境

2026-10-23。既存の統合159ファイル、表情比較30候補、室内の組み合わせ、ComfyUI初回ガイドを入力とする。新規画像生成0。既存原本の画像は同じバイナリーでコピーし、共有版のHTML／JSONを相対URLへ変換する。

ローカルの元作業ブランチはcodex/sporehollow-prototype。別の公開用Git checkoutをoutput内へ用意し、既存の公開リポジトリshirai-masatomo/whitespaceへ資料専用ブランチcodex/reference-libraryとしてpushする。ゲーム・SDK・Launcher・GPU・GUI自動操作は起動しない。VM隔離は未確認、実機テストは未実施。

## 作成と確認

- 原本ではなく共有版のパスを書き換える。モデル重み・実行環境・認証情報を同梱しない。PC固有パスはテキスト上で置換する。公開ブランチは505ファイル、約240MiB。静的ページ11、画像等435ファイル。画像の形式違いや比較画像を含む。
- 相対参照1537件を確認、欠損0。表情30、文字42を確認。3つのJavaScriptの構文、公開版データでの模擬DOM13項目を確認。元の読み取り対象515ファイルのハッシュ一致。実ブラウザーとゲーム表示は未検証。
- 既存Git認証はcredential helperからメモリー内で取得するだけとし、認証値をファイルや出力へ保存しない。GitHubのメタデータでリポジトリがpublicであることを確認し、公開ブランチへpushした。
- Pagesが未設定であることを読み取ったうえで有効化を試みたが、実行前の自動承認審査が「Gitへのアップロード承認だけでは一般公開URLへの追加配信まで明確に承認されていない」として拒否。回避や設定変更は行わず、一般公開の可否をユーザーへ質問した。
- 未影響の作業として、GitHubのREADMEに3資料本文と画像／GIFプレビューを追加し、GitHub内で読めるようにした。HTMLの操作機能はGitHubのファイル表示では動かないことを明記した。
