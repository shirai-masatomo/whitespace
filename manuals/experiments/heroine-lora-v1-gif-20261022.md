# ヒロインLoRA v1：構図を固定したGIF3種類

## 目的・合格条件

ユーザーは、指定画像の構図に完全一致できるかを確認し、GIFについて「まばたき」「小さな呼吸」「恋愛表情の変化」をすべて試したいと指定した。

今回は同一の基準画像を使い、各動作に必要な範囲だけを変更する。構図を毎回生成し直さない。PNGの編集範囲外が基準画像と同じであり、GIF復号後も編集範囲外がフレーム間で同一であることを機械的な合格条件にした。編集した目・口の自然さは別途目視確認する。

**この試験は任意の構図参照に全体生成で完全一致する実証ではない。** 固定部分を元画像から戻す合成を含む差分制作の試験である。

## 入力と環境

- 2026-10-22。継続中のComfyUI/LoRA実験として、承認済みの通常Windows上で実行。VM隔離・ゲーム内テストではない。
- 基準画像：追加18枚の`images/romance/06_shy_romance_42006_00001_.png`、832×1216。[元の実験](heroine-lora-v1-clothes-poses-romance-20261022.md)。ユーザー自身の原画を直接動かしたものではない。
- 元画像のSHA256は[入力記録](../../reports/COVERAGE.md#同梱しないもの)。元画像をRGBのPNGへ無変更複製し、フレームの基準とした。
- 人物・画風・構図・衣装の固定基準は同じ1枚。新しい衣装やポーズは持ち込んでいない。
- ComfyUI 0.42.1、Animagine XL 4.0 opt、配置済み800step LoRA。モデルのハッシュ・版は元の実験と同じ。LoRA model0.75 / CLIP0、内蔵VAE。RTX4070 SUPER12GB。
- IPAdapter、OpenPose、ControlNet、動画生成モデル、新規モデル・依存取得、再学習は使用していない。局所フレームは既存ComfyUIの標準inpaintノード、合成・GIFエンコードは既存Pillow/NumPy。
- 専用サーバー、入力、出力、ユーザープロファイル、ログを利用。既存ComfyUI本体、既存モデル、原画像を変更していない。

日本語の目的、Positive/Negative全文、実際のAPI DAG、生成履歴、時刻は[GIFフォルダー](../../reports/COVERAGE.md#同梱しないもの)の`source.json`、`validation/batch-plan.json`、`validation/workflows/`、`validation/executed/`、`validation/run-batch.json`へ保存した。

マスクは原寸座標で手動指定。目は2つの多角形、口は(367,460)〜(478,528)の楕円。形状の全座標は親フォルダー`prepare_gif.py`、マスクPNGは`gif/masks/`。VAEEncodeForInpaintのgrow_mask_byは6。合成マスクは半径3pxのGaussianぼかしで、値0の領域は元画像へ完全に戻した。クロップ・反転なし。生成範囲と合成範囲を区別した。

呼吸は下部の衣服を多角形で限定し、Gaussian12px、画像端を固定、暖色域を膨張して髪・肌・金色装飾を保護。0→3.2→0pxの局所的な縦変位を双線形補間した。これは生成動画や物理シミュレーションではない。パラメーター・マスク・PNGフレームを保存した。

ComfyUI起動・3枚生成・終了まで40.2秒。今回のVRAM/RAMピークは未測定。PNG24枚の変形やGIFエンコードは追加のCPU処理で、40.2秒に含めていない。

PNGでは合成マスク外のRGB差分0を確認。GIFでは共通256色パレット・ディザなしでエンコードし、全フレームを復号、許可領域外のフレーム間RGB差分0を確認した。**GIFと元PNGのRGB完全一致は主張しない。** GIFには256色化による色差がある。

元画像と閉じ目・笑顔の静止比較、呼吸最大変位フレーム、同時プレビューの代表フレームを目視した。ファイルを全フレーム復号して寸法・時間を検査した。実際のゲーム画面での再生は未実施。

新規AI静止フレーム3枚、使用2枚・不採用1枚。基準画像1枚を再利用。CPU変形24枚とフェード中間像をAI新規生成数に加算していない。成果物はGIF3本＋比較用プレビュー1本。製品用の自然さの最終採否は未決定。

## 観察・原因仮説・次の比較

目と口だけを差し替えることで体・背景を固定できる。固定は局所合成で達成しており、LoRA単独の画素一致能力とは異なる。閉じ目はdenoise変更で線の形が変わり、差分を選別する工程が必要だった。

呼吸は衣服を小さく動かす簡易表現にとどまる。身体全体の自然な呼吸、髪揺れ、連続したハグやキス、複数人物の相互運動は未検証。口のフェードは実際の口形の連続変形ではない。

厳密な構図を必要とする量産では、承認した構図を基準に固定領域を保持する方法を次の候補とする。別の構図参照を全体再生成して完全一致させることは、今回の結果から保証できない。
