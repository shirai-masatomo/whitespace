# 舌出し・酔い・参照表情と顔大アップ

## 目的・合格条件

2026-10-23。ユーザーは、イタズラっぽい舌出し、酔った表情、さらに顔へ寄った版、参照用素材の表情のいくつかを試すよう依頼。4表情を通常アップと顔大アップで用意し、前回の微笑みも顔大アップへ追加。合計9画像を制作した。

人物・髪・服装は既存ヒロインを基準にし、参照用素材からは表情の目・眉・赤み・口を取り入れる。姿勢・身体・衣装・背景は引き継がない。通常版と大アップを区別し、元のPNGと採否を保つ。

- 人物・衣装・画風の編集元：`assets/characters/heroine-01/portraits/closeups-20261023/01_smile.png`。成年20歳の既存ヒロイン。
- 表情参照：`sample/ヒロイン/まとまり/参照用素材/ref-01.png`、`ref-06.png`、`ref-08.png`。[参照とSHA256](../../reports/COVERAGE.md#同梱しないもの)。提供資料を依頼のため参照。権利の独立調査は未実施。

- 完成PNGはネイティブ出力とバイト同一。顔大アップは内蔵編集で画角を変更した別出力であり、CPUで単に切り抜いた画像ではない。表情や形状に微差があり、完全な画素固定は保証しない。
- 比較一覧・縮小表示はCPUのPillowで作成。VM／Sandboxは確認できず、ゲーム・SDK・GUI自動操作・Lint・ビルド・ComfyUIは起動していない。システム・共通ランタイム・GPU・既存プロセスの変更や追加取得なし。

## 試行と観察

| 表情 | 参照 | 出力の観察 |
| --- | --- | --- |
| イタズラ・舌先 | ユーザー指定 | 片目ウインク、片眉上げ、短い舌先、小さな笑み |
| 酔い | ref-06 | 半目・内側の上がる眉・頬鼻の強い赤み。口は小さな笑みへ調整 |
| 赤面と小口 | ref-01 | 左寄りの視線、強い赤み、困り眉、小さな丸い開き口 |
| 閉じ目の笑顔 | ref-08 | 両目を閉じ、赤みと開いた笑顔 |
| 微笑みの大アップ | 前回16の微笑み | 顔・眉・目・口・あごが大きく見える画角 |

通常アップ4枚は1037×1516または1517。顔大アップ5枚は1254×1254。RGBA透過PNGで、顔大アップは胸元を画面外へ寄せ、眉・目・口・あごを残す。髪の頭頂や長い毛先は画角外。通常版と大アップを同じ枠へ並べた5組の比較を用意した。

参照の表情を全てそのまま再現したとは扱わない。参照姿勢を維持せず、ヒロインの直立した顔角度へ適用した試作。特に酔いの口は参照の小口から笑みに変更した。
