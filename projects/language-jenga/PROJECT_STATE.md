## 運用モード: 完全自律実験

当面、このプロジェクトは Codex / AI による「ほぼ完全自律型」で進める。

- 企画、設計、実装、テスト、ブラウザ確認、改善、コミットまでを自律的に進める。
- 通常のゲームデザイン、UI、難易度、辞書採否、技術選定ではユーザー確認を待たず、自分で判断して前進する。
- 現在の「宥めよ」は出発点であり固定仕様ではない。必要なら構造を変更・縮小・置換してよい。
- 言語ジェンガの核は「言葉や意味の層を操作したとき、場面・関係・解釈が維持／変容／崩壊することを遊びとして観察する」。具体的なルールや表現は自律的に発明・検証してよい。
- 一度に大きく作り込まず、遊べる小さな版を作る → テストする → 自分で批評する → 改善する、を反復する。
- 各反復で test / lint / build を通し、可能ならブラウザで実操作も確認する。
- 文書は人間が読む前提で短く保つ。判断理由は後から追える最小限だけ残す。
- 作業は原則 `projects/language-jenga/` 内に閉じ、他プロジェクト固有の実装を勝手に変更しない。

### 人間に確認してよい例外

次の場合だけ停止して確認する。

1. 有料サービス、API課金、購入、外部アカウントや秘密情報が必要。
2. 復元困難な削除や、他プロジェクトを壊す可能性が高い変更。
3. 法務・公開・個人情報など、人間の承認が必要な判断。
4. プロジェクトの核そのものを捨てる必要があると判断した場合。

それ以外は「確認待ち」を作らず、仮説を置いて実装・検証してよい。
