# 遊び方と規則

## 雨の駅前（現行の最小版）

六層は場面・関係・傘の本数・申し出・次の行動・添える言葉。各層には元の内容/別の内容/抜いた状態がある。「抜く」は前提の未指定または発言の削除であり、「雨を抜く＝晴れ」とは扱わない。プレイヤーは場面の編集者で、表示される相手の返答は現在の組合せの試演。過去の会話を延々続けるゲームではない。

- 挑戦：3層以上抜き、一本の傘で一緒に駅へ向かう意味を維持する。
- 維持：相合傘が成立。変容：貸し借り・別行動・二本の傘等へ変わる。崩壊：相合傘の約束が矛盾するか、次の行動が決められない。「怒った」「人間関係が終わった」という意味ではない。
- 抜く/二案の差し替え/戻す。一手戻すは前の層と履歴へ戻る。同じ内容の再適用は履歴を増やさない。手数の上限・課金・通信はない。
- 確定後は編集とundoを共通更新処理でも拒否し、結果・記録と組み直しを残す。初期盤面のままの確定はUIで禁止。
- 状態はReact内のみ。試作切替では盤面を保持、再読込で初期化。動きを減らすOS設定に対応。

### 意味を支える組合せ

| 残ったもの | 解釈 |
| --- | --- |
| 一本の傘＋使って＋一緒に行こう | 明示的な相合傘。雨の情報や親しさが省略されても成立 |
| 雨＋一本＋友人＋一緒に行こう（申し出なし） | この場面では傘への招きを補って読む。初対面や関係未指定では補わない |
| 使って（同行なし） | 一本なら貸し借り。各自に傘があれば借りずに別行動 |
| 雨上がり＋一緒に行こう | 傘を差さず同行。本数より先に扱う |
| 二本＋一緒に行こう | 各自の傘で同行 |
| 雨＋一本＋使わないで＋一緒に行こう | 使用拒否と同行の誘いが衝突。待つ意思へ変えれば、別々に雨宿り |
| 申し出も行動もなし | 口調や状況だけでは次の一歩が決まらない |

細かな条件の優先順位と根拠は lib/layers.js のinterpretに集約。これは作者が書いた一解釈で、自然言語一般・全ての人間に対する正解ではない。親しさから架空の過去の相合傘経験を追加しない。添える言葉は口調に作用し、行動の成立を単独で決めない。

### 確認する境界

抜き方の違い、他層との交差、一手戻す、無効な操作、確定後の更新防止をテストする。729組合せの走査は返却形式と限定した不変条件の確認で、全台詞の自然さを保証しない。

## 旧試作：宥めよ

比較用に保持。緊張2、信頼0、5発言から開始。辞書のadoptedだけを正規化後に部分一致で走査し、最初のカテゴリを適用。謝罪/傾聴/安心は信頼+1、命令/未分類は緊張+1、拒絶/敵意は緊張+2。緊張5→失敗、信頼4→成功、残り0→失敗の優先順。再挑戦は全状態初期化。同じ謝罪だけでも成功する限界は既知で、新しい層操作の規則には持ち込まない。
