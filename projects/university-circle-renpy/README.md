# 大学サークル恋愛ADV — Ren'Py基盤試作

**状態**: Ren'Py用のスクリプト雛形。実機起動・Ren'Py Lintは未実施（SDKがあるWindows環境でCodexによる検証が必要）。

## 目的

成人の大学生を登場人物とする恋愛アドベンチャー。最初の縦切りは **タイトル画面 → オープニング → マップ選択 → 会話 → マップに戻る**。
主人公は男子大学生。ヒロイン「葵」は動作確認用の仮名（成人の大学生・21歳）。サークルの種類、正式な人物設定やゲーム名は未決定。
初期実装には露骨な性的描写や飲酒イベントを含めない。

仕様の起点: [現在のノベルゲーム要件](../local-ai-image-lab/GAME_REQUIREMENTS.md) （当ブランチの親ブランチにある文書）。

## 起動方法

1. [Ren'Py公式](https://www.renpy.org/latest.html)からRen'Py SDKを入手し、WindowsでLauncherを起動する。
2. Launcherの「Create New Project」で新しいプロジェクト（仮に `university-circle-romance`、1280×720）を作成する。
3. 生成されたプロジェクトの `game/script.rpy` を **バックアップの上で** このフォルダーの `game/script.rpy` に置き換え、`game/circle_map.rpy` を追加する。標準の `screens.rpy`、`gui.rpy`、`options.rpy` はRen'Py生成版を保持する。
4. Launcherから「Check Script (Lint)」→「Launch Project」を行う。Lintエラーは修正し、実際の挙動を確認する。
5. 起動後は「はじめから」→導入→マップ（大学・部室・海）を選び、各場所で会話した後マップに戻る。

**注意**: このリポジトリの内容だけではRen'Pyランチャーの生成する標準UI一式を同梱していない。「Launcherで新規プロジェクトを作ってスクリプトを上書きする」運用の雛形であり、スタンドアロンのビルド済みゲームではない。
