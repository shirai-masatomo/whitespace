## 保存先・配布

製品設定の保存先は `%APPDATA%\RenPy\WhiteSpace-UniversityCircle-Foundation-1`。
**これは実行したOS内の保存先です。ホストで起動してはいけません。** テストはゲスト内の独立したユーザープロファイルで行います。
アップデート時はこの保存先IDを維持し、変数・label変更後の互換性を別途テストします。

SDK・大量素材・キャッシュ・セーブ・配布ZIPはGitへ入れません。Gitにはソース、小容量の仮素材、権利情報、検証記録を保存します。
Windowsビルドの取得場所は**未提供（未作成）**です。[販売準備メモ](docs/DISTRIBUTION.md)はストア審査の通過を保証するものではありません。
