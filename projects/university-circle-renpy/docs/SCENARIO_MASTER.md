# 大学サークル恋愛ADV — シナリオ設定正本

更新日: 2026-10-21  
状態: **設定資料（実装指示ではない）**。本資料にはユーザー確定事項・既存試作の仮設定・未確定事項を区別して記録する。

## 1. 作品の概要

- **舞台**: 現代日本の大学と、主人公が所属する大学サークル。
- **ジャンル**: 成人の大学生を登場人物とする、男性主人公の恋愛アドベンチャー。
- **基本的な遊び**: オープニング → マップ選択 → キャラクターとの固定台詞による会話・選択肢 → イベント → マップへ戻る。好感度やイベントフラグによる分岐を想定する。
- **制作・販売**: Ren'Pyを採用。Windows向けを先行し、将来的なSteam・DLsite販売を想定。現在は一般向けの試作。成人向け要素の具体的な採否・内容は別途決定する。
- **本資料の範囲**: 物語・人物・サークル構成・導入の整合性。エンジン機能や実装手順は [プロジェクトREADME](../README.md)、[編集手順](EDITING.md)、[実行隔離規約](../../../docs/DEVELOPMENT_ISOLATION.md) を参照。

## 3. 学年と年齢の整理（要確認）

「20歳で2年留年した」という条件と大学の一般的な入学年齢を合わせて考えると、**20歳で1年次に在籍する**解釈が考えられる。ただし、以下の区別はユーザー未確認のため、**主人公の現在学年を確定しない**。

- **解釈A（大学入学後の留年）**: 18歳ごろ入学し、大学の1年次を2回進級できず、20歳時点でも1年次に在籍。大学には数年間通っている。
- **解釈B（入学前の浪人）**: 高校卒業後に2年間過ごし、20歳で大学に入学した1年生。厳密には「留年」ではなく「浪人」。
- **別解釈**: 入学年齢・学年歴が上記以外の場合はユーザー設定を優先する。

**現行の試作スクリプト** `game/script.rpy` には「大学二年、二十歳の春が始まった」とあるが、これは旧仮設定で、新しい「2年留年」の経歴を反映していない。Codexが実装を更新するときは、**現在学年と留年／浪人の意味を確認後**に修正すること。確認前にコードやセーブ変数を一方の解釈へ固定しない。

## 4. 登場人物・集団

### 主人公

- 男性、20歳、大学生。
- 2年にわたり進路・進級に停滞があり、その期間を遊んで過ごしたという経歴（時系列は未確定）。
- 女性との関係づくりに積極的なチャラい人物。
- サークルへ所属する。入部済みから開始するか、オープニングで入部するかは導入の最終調整で決定。
- 名前、外見、学部、具体的な過去、学年は未確定（開発版の表示名は「主人公」）。

### メインヒロイン

- 大学3年生の女性で、主人公と同じサークルに所属。
- 主人公にとっては先輩。
- 名前・年齢・容姿・性格・主人公との既往関係は、今後決定する。**既存試作の「葵・21歳」は仮設定**であり正式採用ではない。

### サークルの先輩たち

- 上級生側は女性が大多数という構図。
- 2年生・3年生・4年生それぞれの人数、ヒロイン以外の名前と関係性は未確定。
- サークル全体の人数や男女比を具体的な数字に固定しない。

### 1年生男子たち

- 1年生は男性が多数を占める。
- 男子の多くはチャラい。
- 主人公と同学年として行動するかは、主人公の現在学年が確定してから設定する。
- ライバル関係、友人関係、人数、個々の性格は未確定。自動的に対立関係を設定しない。

## 5. 導入から基本ゲームループまで（骨子）

これはプロットの細部を確定するものではなく、既存の最小Ren'Py基盤に新設定を反映するための整理。

1. **オープニング**: 20歳の主人公の大学生活を紹介する。「遊びまくった2年間」がどの時期かは要確認。サークルと3年生の女性先輩を登場させる。
2. **サークルを紹介**: 女性が多い先輩組と、チャラい男子が多い1年生組の対比が伝わるようにする。紹介方法・人数・キャラ台詞は未決。
3. **マップへ移動**: 大学・部室・海などの移動先を選択する。現行試作の3地点は**機能検証用の仮マップ**であり、海へいつ行けるか等のルールは未決。
4. **会話イベント**: 選択肢・サークル活動などを通じてヒロインとの関係を進める。好感度条件で一部の会話やイベントを分岐。
5. **イベント後**: マップへ戻り、別の場所や相手と接する。曜日・行動回数制は未実装・未確定。

## 6. 既存の会話で出た企画要素（採用範囲に注意）

- **提案済み**: ヒロインと会話する、サークル活動を共にすることで好感度が上昇する。
- **企画として言及**: 飲み会や宅飲みを企画できる。場所によって親密なイベントの起こり方が変わるという方向性。
- **まだ仕様未確定**: 飲み会・宅飲みの開催条件、飲酒の扱い、会話選択肢の具体的な効果、時間経過、その他キャラクターの行動AIや接触シミュレーション。
- 成人同士の恋愛や親密なイベントを扱う場合も、合意を前提とする。飲酒による判断能力の低下を同意の代替条件にしない。
- 現時点の初期Ren'Py基盤に、露骨な性的描写や成人向けCGを追加する指示ではない。
