# 隔離環境でのセットアップ・検証・ビルド

**現在は実行不可。Windows Sandboxまたは適切なVMを確認できていません。**
この文書のSDKコマンドはゲスト内専用です。ホストのPowerShellから実行しないでください。
[共通規約](../../../docs/DEVELOPMENT_ISOLATION.md)を優先します。

## 起動前に記録すること

1. 隔離方式・ゲストOS・VM名・専用ゲストユーザーを特定する。
2. 実行プロセス、ユーザープロファイル、設定、ディスクがゲストに属することを確認する。
3. ゲストのNICを無効化し、ネットワーク共有・ホストのホーム共有・クリップボード同期・ドラッグ＆ドロップを無効にする。
4. 専用の入力用フォルダだけを読み取り専用で渡す。SDKとソースをゲストの `C:\Work` へコピーし、コピー側で作業する。
5. スナップショット等の復元点を確保する。SDK・OS機能・VMソフトの導入が必要なら事前承認を得る。
6. テスト用ゲストプロファイルには本番・既存作品のセーブを置かない。
7. 出力を持ち帰る方式を決める。ホストのユーザーフォルダをゲストに書き込み共有しない。専用出力先を例外的に共有するなら範囲を先に承認する。

「VMを使う予定」「環境変数で保存先を変えた」だけでは起動条件を満たしません。
WSLが存在していても、このWindows GUI検証の隔離環境として確認されたことにはなりません。

既存の「ホイッスル牧場 製造」には、非対話Window Station上で描画し、ゲーム内部から実フレームを保存する独自方式と成功記録があります。
通常画面や入力への干渉を避ける設計は参考にできますが、確認した実装だけではファイル・設定・ネットワークのアクセス制限まで確認できません。
保存先変更を完全隔離とみなして流用せず、最新規約の不足条件を確認してから利用します。調査内容は`HOST_ENVIRONMENT_AUDIT.md`を参照してください。

## 使用SDK

- Ren'Py 8.5.3（実行記録: 8.5.3.26051504）
- 取得元: https://www.renpy.org/dl/8.5.3/renpy-8.5.3-sdk.zip
- SHA256: `ff57648f9c04f27e381c48af6d8e3ee3cdec296bed4d3831f47f09b0a71b505e`
- ZIPサイズ: 163,008,121 bytes
- 確認日: 2026-10-20。取得済み原本を読み取り専用でゲストへ渡す。今回は再ダウンロードしない。
- 新たな取得が必要なら、接続先・容量・実施場所を示し承認を得る。ゲストのネットワークを勝手に有効にしない。

SDKはGitへコミットしません。新規プロジェクトの標準UIは次の公式コマンドで生成したものを使用しています。
**再生成は通常の起動手順ではありません。カスタムファイルを上書きするため、必要時だけ隔離内の別フォルダで行います。**

```powershell
# 隔離確認済みのゲスト内だけで実行。ここでの C:\Work はゲストのディスク。
Set-Location C:\Work\renpy-8.5.3-sdk
.\lib\py3-windows-x86_64\python.exe renpy.py launcher generate_gui C:\Work\template-baseline --template gui --width 1280 --height 720 --accent '#67c9c1' --language japanese --start
.\lib\py3-windows-x86_64\python.exe renpy.py C:\Work\template-baseline gui_images
```

公式日本語フォント・GUI・共通翻訳を同梱済みです。通常はこのプロジェクトのコピーをそのまま使います。
フォントとランタイムのライセンスは残し、テンプレート更新は別コピーで差分を見て行います。

## 画面操作で確認する順序

1. タイトルの日本語・バージョン表示を確認し、スタートから導入を最後まで進める。
2. 好感度0で海へ行き、単独会話の後マップへ戻る。
3. 大学で「挨拶して別れる」を選び、好感度が変化しないことを確認する。
4. 大学で「サークルについて話す」を選び、笑顔・SE・好感度1を確認する。
5. 部室で「準備を手伝う」を選び、好感度2・海への言及を確認する。
6. マップでセーブし、海の初回会話を見る。再訪すると別の台詞になることを確認する。
7. 保存した状態をロードし、好感度2・海の初回フラグ未設定へ戻り、もう一度初回会話になることを確認する。
8. 会話中とマップ中の両方で標準メニュー、セーブ／ロード、履歴、設定、右クリック／Escを確認する。
9. 既読範囲をスキップし、未読と選択肢で止まることを確認する。オートで文章が進み、選択肢で入力待ちになることを確認する。
10. 好感度を上げる選択肢の後でロールバックし、選び直した結果だけが残ることを確認する。
11. BGM2種類・SEを再生し、ミキサーの消音・音量変更を確認する。聴感未確認を成功扱いにしない。
12. ウィンドウと全画面で日本語・改行・表情・マップ・標準UIの欠けを確認する。
13. 配布ZIPの新規起動とセーブ／ロードを別展開先で確認する。

スクリーンショットはゲスト内ゲーム画面だけを保存し、PC名・ユーザー名・他アプリを含めません。
終了後にゲストのゲーム／SDKプロセスが残っていないことを確認し、ゲストの一時プロファイルとコピーを整理します。
出力ファイルのハッシュ、結果、未検証事項、ホスト変更の有無を`ACCEPTANCE.md`へ記録します。

## 更新・バックアップ

ソースと小容量仮素材はGit、モデル・SDK・ビルドZIP・大量素材は別の専用保管先を使います。
作品の`config.version`を更新してビルドを区別します。保存先IDは製品の識別子として固定し、テスト用に変えません。
更新前のソース・素材台帳・SDKハッシュ・旧ZIPを保全し、古いセーブはゲスト内へコピーして互換性をテストします。
Gitで復元する際も既存ブランチをリセットせず、新しい作業ツリーへ取得し、実行は隔離内で行います。
