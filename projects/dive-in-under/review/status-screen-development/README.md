## 実装と範囲

町→ステータス→元の町。入場0.20秒、退場0.18秒。初期タブは毎回「装備」。中央に全身の静止絵、その左右に既存11枠を配置。頭・上半身・下半身・足・左手／右手・首・耳・目・指・腕。頭の選択説明にマントも同じ頭枠を使うことを記載した。今回、未決の初期装備5点や新アイテムは追加しない。

装備・能力・状態/耐性・プロフィールの4タブは同じControl内で中央を更新し、左のControl自体も保持する。選択時は右詳細を更新。装備クリックは閲覧のみで外さず、交換・修理は町の既存の別画面に残す。倉庫の一覧や操作、手動戦闘コマンドは表示しない。

主人公名/Lv/HP/SP/EXP、装備補正・個体耐久・成長内訳・到達/探索/死亡記録は実データから算出。状態の表示用アダプタは戦闘コアの毒/暗闇/麻痺・防御態勢の効果と自身行動機会の残数を読む。現在の入口は町なので状態は付与されておらず、その事実を表示する。能力上昇/低下は未導入、8属性の倍率は未設定。年齢・出身地・職業・人物紹介は未設定と区別。人物データの新JSONにはSPECで確認済みの種族「人間」だけを記録した。

最大6体の領域は、人間＋配下を1組とした3組。主人公以外の5枠を無効化し、加入・切替・仲間管理を先行実装しない。将来の人物差分をUIだけで捏造しない。

キーボードはTab/矢印/Enter、1〜4、Ctrl＋Tab/Shift＋Ctrl＋Tab、Esc。現在タブ・選択・ホバー・フォーカス・無効を区別。右詳細はScrollContainer、各項目はButton、詳細はVBoxContainer。タブは中央のみ0.10秒で切替。HP/SPの実データ更新用の0.15秒ゲージ補間も表示側へ分離。静止人物の待機・攻撃モーションなし。
