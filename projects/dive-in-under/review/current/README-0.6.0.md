# Dive In Under 0.6.0 — 通常EXEへ反映済み

通常の01入口で0.6.0が起動します。毎回の起動は新規開始。はじめる→冒険準備→出発→1F。準備からステータス・倉庫・装備へ。帰還や死亡後は準備へ戻り、同じ起動中の成長と所持品を保持します。旧保存の読込・書込・削除は行いません。
