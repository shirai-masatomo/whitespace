「01 ゲームを起動」は0.5.3を起動する。町で「ステータス」を選ぶと、新しい画面を確認できる。起動中の旧版はユーザーが閉じてから起動し直す。

顔横のHP/SP/EXP、能力アイコンと実値の内訳、状態アイコンと未付与時の説明、人物情報と立ち絵、下部の所持品/風呂敷の実枠数を反映。町からステータス・倉庫・装備/修理へ直接進める。装備クリックは情報表示のみ。

既存の成長・アイテム・進行を引き継ぐ。旧保存の原本は初回変更前に退避される。起動先切替はユーザーのセーブを変更しない。従来のEXE/PCKと旧ZIPも保持。入口の3項目とPlay.cmdの場所は同じ。

2026-10-19のユーザー指示により、0.4.6固定から通常版0.5.3へ更新した。別試作を提出して採否待ちにする運用は終了し、今後の許可された変更も必要な確認後に通常EXEへ反映する。モデル設定は変更しない。

画像の19歳/湖の村/職業/初期装備のサンプル、未実装能力の数値、属性0%、毒の最大HP10%は採用しない。仲間・印/強化・属性計算・人物設定の創作は今回の対象外。工程2全体の未完了項目は継続する。
