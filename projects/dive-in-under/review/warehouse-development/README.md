## 実装

左296px＝バックパック15枠と父親の風呂敷3枠、中央580px＝6列の倉庫、右348px＝選択品の詳細。風呂敷は紫色で保護対象を明示し、3枠を同時表示。中央の6カテゴリ、保管数、整理順（種別・名前・耐久）、下部固定5操作を実装した。倉庫ではステータスや装備着脱を表示せず、「戻る」から町の入口を経由して装備・修理や出発へ移る。

移動は1個体＝1枠、町で行う。バックパックへの受取は15枠、風呂敷へは3枠で制限。倉庫の正式上限は未決なので、現行の容量制限なしと実数を表示する。全移動・整理で個体IDと耐久を保持し、二重所有・古いリビジョン・満杯・支給品の預入を拒否する。支給品の配布自体は未実装。

詳細はアイコン・名前・種別・所持数（装備中も含む携行合計）・倉庫内数・説明・実効効果・使用回数・耐久・特殊効果・刻印。未定義項目は「—」。下部の余白と表示用カタログを分け、将来の追加能力・印・レア度を追加できる構成とした。これらのゲームシステムは追加していない。

既存の洞窟背景は原画不変。フレーム、アイコン、表示用カタログ、実操作UIは独立したファイルとし、最終文字はGodotが描画する。原画の透過素材へUIを焼き込んでいない。
