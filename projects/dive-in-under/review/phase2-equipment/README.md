# 工程2・最初の単位：装備耐久/破損/修理（0.5.0開発版）

工程1は[既存証拠で受入済み](../../docs/PHASE_01_ACCEPTANCE.md)。人間の試遊待ちを停止条件にせず工程2へ移行した。工程2全体の完成ではない。

## 今回動くもの

個体IDごとの現在/最大耐久、耐久比による実効装備ボーナス低下、0で破損/効果0、町の修理とGold消費、修理不能ボタン、装備一覧のスクロールを追加。キャラの成長基礎値や戦闘乱数は変更しない。消耗は解決した戦闘の終了時に1回のみで、現在戦闘の復元/再描画では消耗しない。仮値は独立した`data/v1/equipment-condition.json`で管理（最大100、1戦闘1消耗、欠損1につき1Gold）。

保存は形式4。旧1〜3を読み取り時は上書きせず、最初の保存で原本を別途退避。旧個体を満耐久で初期化し、成長設定・所持品・倉庫・装備・進行・戦闘途中入力を保持する。未知版を拒否する既存境界を維持する。
