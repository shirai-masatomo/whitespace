# Dive In Under 0.6.2 — 「旅立ちの支度」BGM導入

実装と技術的な再生確認を記録する。利用者による聴感・採用判断は未評価・未判断。音源原稿は変更しない。

## 変更内容

- 冒険準備に入ると0.35秒で再生開始。専用BGMバス **−16 dB**（元の約15.8%の振幅）。Masterや将来の効果音／UI音の設定は変更しない。
- ステータス4タブ・倉庫・装備・各画面からの戻る・町での表示更新は単一プレイヤー／同一再生位置を維持。
- 探索に出発すると0.7秒で無音へフェードして停止。タイトルへ戻る場合も同様。結果画面では停止し、帰還・死亡・攻略終了後に準備へ戻ったら再開。
- OGGをGodot `AudioStreamOggVorbis` の `loop=true`、`loop_offset=0`で直接ループ。終了シグナルから再生し直す処理なし。
- フェード中に準備へ戻った場合は古い停止Tweenを取り消して継続。再生の二重化を防止。
- ゲームの通常起動・戦闘・成長・アイテム・旧保存の扱いは維持。ダンジョン用曲は追加していない。

## 証拠

**実装・技術確認済み、通常入口へ0.6.2を反映済み。** 実行ソース `67bf4b2be45f37d1f315978fd212516e1ebd9cd7`、[成功CI39236684696](https://github.com/shirai-masatomo/whitespace/actions/runs/39236684696)。最終の隔離Windows EXEは1プロセス **15.483秒**、60秒タイムアウト付き。

画面別の再生位置は0.746→1.303→1.396→1.582→1.768→2.418→3.254秒と進み、プレイヤー／再生インスタンスは全画面で同一。OGGは75.789秒で、末尾74.292秒から先頭1.196秒へネイティブで折り返し、同じ再生を維持。取得2.694秒のPCMは44.1 kHzステレオ、ピーク0.12846（クリップなし）、最大隣接サンプル差0.03977、長い無音なし、キャプチャ欠損0。出発時の振幅は0.976→0.595→0へ減衰し停止。実際の帰還処理で再開、タイトルへの遷移、フェード中の戻りも確認。

core/dataは既存検証済みa5c3c692から変更なしのため、大量シミュレーションは再実施しない。旧保存番兵のSHAは不変。最終配布ZIPのEXE/PCKはこの隔離確認のハッシュと一致する。ローカルでのビルド・通常デスクトップでのゲーム起動・音声機器操作は行わない。

## 未確認・評価待ち

- 実PCのスピーカー／ヘッドホン・Windows実音声ドライバでの出力、機器別の聞こえ方。
- 効果音・UI操作音と重ねた聴感バランス。−16 dBは控えめな初期値であり、ユーザー評価後に `set_gain_db` から変更可能。
- 曲のつなぎ目の音楽的な自然さは利用者の試聴判断。技術検証の無音・急変・クリップ確認と混同しない。
- 全曲通しの長時間リスニング・繰り返し耐久は未実施。ループ境界の短時間確認に限定。
- 0.6.1のUIフィードバック01〜07の見た目の採否は引き続き未判断。今回はBGMの変更箇所だけを確認する。
