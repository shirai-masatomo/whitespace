## 機能と実測

本編とランナーは同じカタログ・戦闘コア・報酬処理を使用。新敵3種とFLOORS表を反映し、新旧戦闘の保存をencounter_versionで識別。既存設定.1〜.4と旧戦闘の乱数・HP・所持品を保持する。次の遭遇は新表で抽選する。

[遭遇/保存52チェック](encounter-tests.log)、[敵データ43チェック](enemy-pack-tests.log)成功。通常seed10000の12探索・死亡1回・10F突破を[実EXE269操作/3プロセス](campaign-complete.json)で再現し、倉庫・突破後再開も確認。[旧6F戦闘の移行/再起動](old-floor-migration.json)も成功。大量統計やバランス評価は行っていない。隔離実行は非対話Window Station内であり、通常デスクトップへの表示・OS入力・ユーザープロセス終了は行っていない。
