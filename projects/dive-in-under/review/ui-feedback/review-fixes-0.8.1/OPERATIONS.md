# 0.8.1 操作

- 左上のE主操作：潜る／宝箱を開ける／受け取って進む／単純イベントの実行。未選択の複数選択肢はEで確定しない。
- X／右クリック：画面に明記した見送り・取消。未開封宝箱の見送りは次の探索を1回進める。開封後はこの操作で品を捨てない。ドラッグ中はドラッグ取消だけ。
- 複数の利益や代償がある選択肢：クリックで決定。キーボードは↑↓・数字で選択してE。現行の利益／見送りだけのイベントは事前選択なし。
- I：所持品・装備。C：ステータス。既に開いている画面は再入場しない。
- Space：自動戦闘の停止／再開。詳細地図を開いても戦闘は停止しない。
- 詳細地図は右上クリックで開く。Esc／画面に記載の右クリックで閉じる。同じ階層・対象の閲覧位置は保持し、階層変更時は現在地へ。地図の到達済は過去の到達歴を含み、今回の足跡とは限らない。
- 装備：クリックで比較、ダブルクリック／適合部位へドラッグで直接交換。外した品の戻り先を確保する。数量1の代わりに装備の耐久が一覧に見える。
- 満杯報酬：獲得品の「所持品と入れ替える…」→手放す品をクリック→失う／得る品を確認→確定。Esc・X・右クリックで取消。Eで品を破棄しない。
- 終了で、この起動中の進行はリセット。保存なし。旧保存ファイルは使用・削除しない。

通常の戦闘ルール、報酬内容・公開範囲、初期装備や死亡喪失の正式仕様は、この修正で決めない。
