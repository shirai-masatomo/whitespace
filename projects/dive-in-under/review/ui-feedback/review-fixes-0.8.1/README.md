## 変更

1. 町ステータスのC再押下を無操作へ。準備／装備／倉庫の有効な元画面を保持、不正時は準備へ。
2. 既存の耐久計算を共通化し、同じUIDの現在性能を探索・装備・ステータス・倉庫へ反映。交換・修理比較も共通。ランダム個体性能は実装されていないため新設しない。
3. E主操作を左の固定位置へ。中央は出来事・選択・獲得品と結果に使用。
4. 現行の利益／見送りだけの場面はE・X／右クリック。比較選択はクリックで決定、キーボードは選択後E。ドラッグ取消を優先し、入力の長押し・反復・二重クリックの貫通を拒否。
5. 数値だけの更新は詳細Controlを維持。ラウンドの再構築でも同階層・同対象の詳細／地図スクロールを復元。対象撃破・階層変更は別に扱う。
6. 確認をモーダル化し、取消と確定を分離。失う／得る品の具体名と耐久を表示。取消で個体・未受領品・数量を変更しない。
7. 満杯報酬の入替ボタン→手放す品の選択→両品の確認。既存の原子的な入替・満杯1対1装備交換・空き部位への報酬装備を維持。
8. 装備説明／能力帯の下地、耐久表示、受け取り完了、対象別見出し、敵Lv、修理理由、到達済、自分の行動回数、終了でリセットの案内を整理。
9. 配布PLAYの旧自動保存案内と0.3.0固定版を履歴保全して置換。版は書出し時に自動挿入。project README・review/currentを最新の正本へ統一する。

## 確認の区別

- 新規セッションの通常経路：町C再押下→戻る／Esc／不正戻り先の安全復帰、1F出発、Space停止／再開。
- 固定データ：同じI02個体の耐久37/100、満杯15枠と報酬、未開封宝箱、イベント、選択肢、詳細スクロール、拡大地図、修理。通常の成長や報酬内容を変えず、隔離した確認用状態のみ。
- 一部の旧画像は通常プレイの別個体・別状態。新たに旧版を連続起動せず保存済み0.8.0を再利用。条件の違いを比較欄に明記。
- 実画像は実配布EXE/PCKをクラウドの非対話デスクトップで描画したもの。OSの物理入力を模倣せず、そのEXEのViewportへキーとマウスを送信。通常PC上でのゲーム起動・フリーズ再現・大量検証は行わない。
- 変更外の戦闘／バランス・イベント内容・報酬・BGM・保存コード・画像素材は保持。全10Fの再走は行わず既存の0.7.0全周回と0.8.0通常1〜4Fの証拠を参照。
