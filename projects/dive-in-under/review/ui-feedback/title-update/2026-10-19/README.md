# タイトルロゴ組込み — 0.6.3

## 今回の指示

最新mainへ採用ロゴを組込み、既存の英字フォントタイトルだけを置き換える。背景は元の町を保持し、背景とUIの間に黒10〜15%の独立レイヤーを置く。枠・ボタン・日本語副題を維持し、ロゴの比率・余白・下向き装飾を保つ。タイトル表示と「はじめる／終了」だけを確認し、実画面を `after/` へ保存。新規ブランチやBGM変更は行わない。

## 実装

- 採用画像：`assets/title/v1/dive-in-under-logo-gold-deep-shadow.png`、2172×724、最後が小文字rの透過原稿。SHA `eacfcc2ecb4e46458f193fd0d1c1e141f5816a93d9cf3df6a2c8586a87ad7f43`。
- 独立TextureRectを **540×180（3:1）** で配置。元画像を変更・切抜きせず、下向き装飾を含めて表示。
- 元の町背景 → **黒12%** の入力を遮らないColorRect → 枠・ロゴ・副題・ボタン。UIを親ごと暗くしない。
- 既存の枠、ボタンの見た目・ラベル・動作、日本語副題、説明の羊皮紙を再利用。縦長になったロゴの装飾のため見出しの高さを90px増やし、その下の説明・ボタンを同じ90px下げて間隔を保持。左右位置・幅は維持。
- 他画面、BGM、戦闘・アイテム・成長・保存コードは変更しない。参考画像全体をゲームへ読み込まない。
- 原素材・元のREADME／manifest／参考画像・旧配布物を保管。
