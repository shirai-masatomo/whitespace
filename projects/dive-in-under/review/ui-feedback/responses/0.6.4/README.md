## 撮影条件と検証の区別

- before：検証済み0.6.3の**配布PCKそのもの**を固定Godot4.7.2エンジンEXEで描画する。旧配布EXEには外部検証スクリプトを差し込めないため、エディタのスクリプト実行機能を利用。旧UIやゲームデータは変更しない。元PCKのSHAは0.6.3配布と照合。
- after：新しい**通常配布EXE/PCK**の明示的な検証フラグだけで実行。通常プレイから撮影・検証処理は起動しない。
- 同一エンジン版・1280×720・Compatibility/ANGLE・seed123・EXP90・Gold37・同じ個体順／敵E04 Lv1の固定撮影。撮影用ラウンドは0で固定し、実際のタイマーとキー入力の検証は別に行う。タイトルと未出発画像は本来の新規状態。
- 参考UIや生成画像ではなく、実ゲームの描画であることをbefore／after別のisolation.json、PCK SHAと画面監査に記録する。マントの色変種のみ画像制作機能で制作し、[出典・プロンプト](CLOAK_SOURCE.json)に記録。
- 検証は変更箇所のみ、隔離環境で順番に各60秒上限。PCでの描画・通常起動・大量seed・長期テストは実施しない。

- [初回の能力見出し](history/visual-first-pass/abilities-header-before-polish.png)で、見出しが数値列から左へずれていた。現在値／基礎＋装備を別Labelにして値と同じ右端へそろえ、行内上下を中央に修正。
