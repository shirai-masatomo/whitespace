最終CI39233227479で8枚を再取得。03以外の7枚は1回目とPNGのSHAが一致し、不要な再変更はしていない。

A 描画成立：7件の対象テキストと操作を実EXEで確認。エンジンエラー・タイムアウトなし。
B 画面の自然さ：元背景・人物・接地・奥行きは維持。03の装飾干渉を修正して再確認。05・06は小さな配置変更に限定し、見た目の好み・最終採否はユーザー判断に残す。
