## 今回追加採用された条件

ユーザーが「推奨セットを採用する」「この扱いで進める」と回答。毒消し草はバッグのみ・毒ダメージ前・HP3・麻痺中も解毒するが麻痺は残る。通常行動を消費しない。作戦は各人8行／AND2条件／8作戦、無料で次の未実行行動から切替。同速は固定seed、死亡候補除外・行動不能は手番消費・SPDは各選出時。前衛不在で後衛に届く。保存は起動中だけ。詳細は[TACTICS第10節](../../../docs/TACTICS.md)と[ITEMS](../../../docs/ITEMS.md)。

種類基礎値は固定。追加HP/SPの既存試作分布を維持し、特殊効果・付与技能・印の別配列と未評価の接続口を用意。例示された毒攻撃・二段攻撃を勝手に追加していない。基本／役割／上位系列を区別できるが、未使用の11F装備は作っていない。
