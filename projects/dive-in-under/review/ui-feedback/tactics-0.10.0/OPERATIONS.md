# 操作と範囲

- 準備／探索左メニュー「作戦」。複製して命名し、お気に入り、キャラ、前後衛、行動順、各行の技能・AND条件2つ・対象を編集。↑↓で優先順。保存／保存して適用。8作戦、各人8行。
- 戦闘中も作戦を変更できる。開いている間は計算を止め、閉じると元のSpace停止状態を維持。適用は次の未実行行動。コストなし、行動回数は戻さない。
- 左は適用中の作戦、右下は選択キャラの行動・不成立理由。複数編成は専用検証のみ、通常加入は主人公のみ。
- 毒消し草の自動使用ON/OFFは支給所・自動対策。バッグだけから使い、毒ダメージ前に解毒＋HP3。麻痺は残る。通常行動は消費しない。
- コインは999枚。倉庫のコイン詳細で全量／指定枚数移動、分割・結合。支払元は明示し遠隔倉庫払いなし。
- 5F居座り後は帰還できず、次は10F到着時。5Fの出来事を再抽選しない。
- 作戦も冒険進行も再起動では保持しない。既存保存は読み書きしない。
