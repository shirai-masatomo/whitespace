# ボスと作戦切替 — 調整案（未採用）

現B10の予告→強打→隙は0.9.0の試作維持。今回、行動単位を分離し、予告が確定した後に画面／Spaceから作戦を変えられる。予告対応セットはS105習得・SP2・DEF>0・CD明けの場合だけ防御し、攻撃1手を失う。テストでは防御消費とボス実強打・SPを確認。技能を所持していないセットは使えず、詳細に理由を残す。

調整案：予告中の待ち時間（現在1行動1.1秒）の長さ、視認性と初見の理解をユーザー試遊で評価し、必要なら伸ばす。自動停止や予告パターンの正式固定は今回追加しない。指定順で速い防御役を待たせる組み合わせ、行動不能・SP切れで防御できない場合を含めて、今後の数値調整を行う。必ず防御が間に合う隠し補正や、防御と攻撃の同時処理を導入しない。
