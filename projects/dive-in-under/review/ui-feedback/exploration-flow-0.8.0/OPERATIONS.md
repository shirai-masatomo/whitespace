# 操作とクリック数

数え方：意図したボタン押下を1操作とする。Eは1キー操作。ダブルクリックは1ジェスチャ／生クリック2回。画面往復は別の装備詳細画面などを開いて元へ戻る1往復。既存0.7.0コードと保存済み実画面を基準とし、比較用の旧EXE再起動はしない。値は実画面と公開導線を数えた操作数で、人間によるOS入力の所要時間測定ではない。

| 目的・前提 | 0.7.0 | 0.8.0 | 別画面往復 |
|---|---|---|---|
| イベント結果を読んで次の1回の探索へ | 戻る＋潜る＝2 | さらに潜る/E＝1 | 0→0 |
| 未受領1点をすべて持って次へ | 個別受領＋戻る＋潜る＝3 | 全受領して進む/E＝1 | 0→0 |
| 持てる未受領N点を全部持って次へ | N＋2 | 1 | 0→0 |
| 獲得装備を比較して装備し、次へ | 受領→装備画面→候補選択→交換→戻る→探索へ戻る→潜る＝7 | 選択済みなら直接装備→進む＝2（別の品を選ぶ場合3） | 1→0 |
| 所持品を交換（報酬画面） | 装備画面→候補→交換→戻る＝4 | ダブルクリック＝1ジェスチャ／2クリック | 1→0 |
| 装備画面内で候補を交換 | 候補選択＋交換＝2 | ダブルクリック＝1ジェスチャ／2クリック、またはドラッグ1 | 0→0 |
| イベント選択肢の決定 | 選択肢クリックで即決＝1 | 選択→決定/E＝2 | 0→0 |
| 受領済み報酬から帰還 | 探索へ戻る＋帰還＝2 | 町へ帰還＝1 | 0→0 |
| 地図を開く・閉じる | 左メニュー→閉じる＝2 | 右上地図→Esc/閉じる＝2 | 1→1（位置は固定） |

イベントの選択自体は意図確認のため1操作増える。一方で結果後の2段階移動を解消する。全ての操作が減ったとは評価しない。

- **E**：現在の強調主操作。未選択のイベントは決定しない。放棄・既存品を手放す入替には割り当てない。
- **I**：戦闘外の所持品・装備。**C**：主人公ステータス。**Space**：既存どおり自動戦闘の停止／再開。
- 左クリック：選択と詳細。ダブルクリック：適合する現在の1部位へ装備／交換。現行データは1品につき部位1つ。ドラッグ：装備部位へ交換、装備からバックパックへ解除。
- 満杯のバックパック同士の1対1交換は可能。未受領品から装備中の品へ交換する際は、外す品用の1枠が必要。空き装備部位への直接受領は、バッグ満杯でも可能。
- **整列**：その場でバックパックを種類順に並べる。アイテム・容量は増減しない。倉庫のShift移動や風呂敷の制限は既存処理を維持。
- ボタン遷移後360ms、E再押下には500msの間隔とキーを離す操作を要求する。長押しや遷移先へ貫通するダブルクリックを消費するための保護で、自動進行ではない。

結果・受領済み報酬では左の「町へ帰還」から直接帰還できます。10Fボス後は突破記録を保持して帰還します。未受領品・未決のイベント・戦闘中の帰還は無効です。
