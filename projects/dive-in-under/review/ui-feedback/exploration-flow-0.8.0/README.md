優先するのはクリック数と画面往復の削減。旧「全画面ロゴ共通化」は撤回しタイトル限定に変更。探索・戦闘・宝箱・イベントで左メニュー・右上縦地図・右下詳細を固定し、Eを主肯定、Iを所持品・装備、Cをステータスへ割当。イベント結果と報酬を一度の操作で次の1回の探索へ進め、直接装備と比較、周辺の状態表示を整える。破棄・放棄はEで無確認実行しない。

## 実装と確認範囲

番号別の実装内容と画像はSTATUS.jsonに記録。通常の新規開始→初回戦闘→宝箱→全受領→イベント→結果中の装備交換→次の4F戦闘を、公開ボタン・キーと通常Timerで確認済み。4F後の直接帰還→準備→2回目の出発まで確認済み。満杯・ドロップ・状態表示・10F地図は別の固定データで確認し、通常の成長・戦闘結果の証拠と混ぜない。

- 共通コア：全受領・イベント確認・次の1探索を1トランザクション化。事前に容量を確認し、古いrevisionや重複入力は変更しない。直接受領装備は1回だけ個体を作り、外す装備の行先を確保。最大HP/SP変更時は従来の上限クランプを維持。
- 入力：キーを離すまでEを再受付せず、echoと高速再押下を拒否。画面切替後360msの操作保護。通常画面の主肯定は1つ、詳細地図や破棄確認中はE主操作を停止。
- 所持品：共通15枠グリッドと11部位。クリックは選択、ダブルクリック／ドラッグは同じ装備処理。装備から袋への解除は空き枠が必要。無効ドロップは変更なし。現行装備データは1品1部位で、未実装の複数適合品を追加しない。
- マップ：階層だけを縦表示。未発見の敵・宝箱の種類は開示しない。現在地へスクロール、閉じてもイベント／未受領品を保持。地図を開くことで戦闘を停止する新仕様は導入しない。
- HP・詳細：人物本体を覆う大きな敵情報を除去。足元の小表示＋左の主人公HPを維持。選択した対象を右下へ表示し、長い状態説明・未受領品の説明は右下でスクロール。撃破時に旧情報を残さない。
- 状態：既存の毒・暗闇・麻痺・防御のみ。実Sprite位置へ追従する小アイコンと控えめな周辺表示、付与・解除時の更新。新たな状態ルール・戦闘計算は追加しない。

- 今回のGUI確認は変更箇所と初回1〜4Fに限定。10Fまでの全周回を重複起動していない。変更していない敵・配分・戦闘・成長・報酬表・BGM・保存の基盤には0.7.0の419操作の正常終了証拠を再利用し、コアの10F到達チェックは軽量で再確認。
