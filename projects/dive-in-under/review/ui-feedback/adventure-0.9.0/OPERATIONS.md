# 0.9.0 操作

通常：いつもの「01 ゲームを起動」→はじめる→冒険準備。保存しないため終了で進行をリセット。旧セーブは読み書きしない。

- E：左の主操作。5/10F到着時は居座る、未受領があれば受領、解決後は帰還／続行を選択。ポータルを受領ボタンだけで通過しない。
- 帰還：5/10Fの戦闘前または解決後。戦闘中、他の階、未受領が残る間は不可。
- I：所持品・装備。クリックで詳細、ダブルクリック／ドラッグで直接交換。C：ステータス。Space：自動戦闘停止／再開。
- 倉庫：クリックで選択、詳細の移動ボタン、Shift＋クリック、ドラッグは共通処理。コインも全量移動。コインを選択し「数量指定／分割・結合」で部分移動・分割・結合。画面上のGはバッグ内のコイン。風呂敷・倉庫残高は支払元の選択欄で確認。
- 支給所・個体・印・自動対策：不足部位の最低支給、薬の購入と自動ON/OFF、装備個体の確認、町で印の加工。コイン支払元を明示選択。ダンジョンから倉庫は使えない。出発時はバッグを支払元に戻す。
- 予防薬はバッグ内の実物だけ使用。印で防止できた場合は消費しない。破損中の印は無効。
- 無料一利益：Eで実行、X／右クリックで見送り。複数利益・費用付き：費用を読み、クリックで決定／↑↓・数字で選びE。対象装備・支払元は明示選択。
- 右上地図：クリックで拡大、Escで閉じる。詳細・装備へ寄り道しても未受領品を保持。
- 確認中のEsc／X／右クリック：取消。背後のC/I/Eを遮断。通常Eで破棄・放棄を即決しない。初突破保証品は整理・装備・入替で受け取る。

死亡ではバッグ・装備・その中のコイン・専用装備を失う。風呂敷・倉庫・EXP・レベルは保持。結果の左右欄を確認→冒険準備→支給所→再出発。支給品を風呂敷に置いても重複支給しない。

デバッグ：配布のDebug.cmd、または「04 デバッグで起動」。新しい専用セッションで常時デバッグ中と表示。専用パネルで次の一階の種類指定／いつでも帰還。通常の成果へ合流せず、保存も行わない。通常版に隠し帰還キーは追加していない。
