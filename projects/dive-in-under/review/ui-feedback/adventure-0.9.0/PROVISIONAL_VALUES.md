# 試作として採用した値

ユーザーが確定した方式と、ここに記す開発上の仮値を区別する。機械定義はdata/v1/adventure.json、項目別台帳はdocs/ITEMS・EVENTS・FLOORS・ENEMIES・SKILLS・COMBAT。変更値と理由は同じコミットで更新する。ユーザーの数値採用判断は未評価。

| 分野 | 今回の仮値と理由 |
| --- | --- |
| 通貨 | 1枚1G、99枚で1枠。15枠の持込判断と読みやすさ |
| 再支給 | 初期5点と同じ最低性能、不足部位のみ。所有を全収納で検出し、拾う価値と再挑戦を両立 |
| 装備 | 武器3役・服2役・指輪。主能力は小幅な整数均等、追加はなし70%／HP+2 20%／SP+1 10%。役割差を潰しにくい範囲 |
| 印・薬 | 1枠1状態、石1＋2G、予防薬各2G。確実な購入で低確率ドロップ依存を避ける |
| 5F | 戦闘30%・宝40%・イベント30%。帰還を学ぶ手前で内容に変化 |
| 敵 | 6F暗闇、8F毒、9F麻痺・強打。前段の5Fで対策可能。数値・Lv・ドロップは各台帳 |
| 自動防御 | SP2、DEF+100%、次の自分行動終了まで、再使用2自分行動。予告大技に攻撃1手と交換 |
| 石像 | 4行動周期。通常枠は通常:小強打3:1、HP35%以下1:2。詳細はENEMIESと機械定義 |
| 初突破 | G10門守の継ぎ輪、指、役割を残す性能。初回保証／再討伐100%、全損例外なし |
| イベント | 新6件を各型の代表に採用。EV16/17は候補。効果数値の重複転載は避け、EVENTSからID別機械定義を参照 |

固定seed10000で、意図的な初回5F帰還・10F前帰還を含む1本の方針を確認。初突破は11回目・Lv10、再討伐は12回目・Lv11。勝率や適正周回数を意味しない。統計調整・複数seedの難度検証はしておらず、長期バランスは利用者の遊び評価待ち。
