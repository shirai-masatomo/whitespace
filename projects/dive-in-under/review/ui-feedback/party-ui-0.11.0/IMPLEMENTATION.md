## 既存実装を維持した事項

コイン999枚、満杯でも既存スタックへ収納、風呂敷は3枠の実収納、死亡時保護、個体ID・固定追加効果・耐久、満杯1対1装備交換、5Fで居座った後の帰還禁止、Space停止／再開。再実装や別仕様化はしない。

倉庫は所有UID配列と位置表を分離。空マスに偽アイテムを入れない。絞り込みで対象外のマスも位置を維持し、無効表示。1ページの描画数を固定し、遠いマスのために大量の空UIを生成しない。

未取得品の入替取消は品を保持。通常右クリックでポータルの選択や未取得品放棄を実行しない。探索判定の巻き戻しは行わず、画面閲覧の履歴だけを戻す。
