# 操作と手数

- 装備：キャラ選択→所持品／倉庫を選ぶ。Shift左、ダブルクリック、部位へドラッグで交換。装備を収納へShift左／ドラッグで解除。旧装備の戻り先は選択中の収納。
- アイテム：Shift右で所持品⇔倉庫、Shiftドラッグで半分（切り捨て・1枚は1枚）。通常ドラッグは全量。倉庫は元のマス番号を保持してフィルタ、倉庫内ドラッグは手動配置。
- 風呂敷：選択品の右詳細下部から実収納へ移動。満杯理由を表示。
- 整理：収納と種別／名前／耐久順を選んで押す場合だけ詰め直す。コイン結合はコイン詳細の別操作。
- 戻る：右クリック。ドラッグ中は取消のみ、モーダル中は閉じるだけ。Shift右の移動時は戻らない。ポータル選択は右クリックで実行しない。
- 取得：Eまたは「入手する」。入る場合は即取得、入らない場合だけ手放す品→両方確認。取消しても未取得品は残る。取得後の次のEで潜る。帰還地点は自動通過しない。
- 作戦：部隊全体→キャラの行動設定／名前付き作戦の保存・選択。戦闘中も切替可能、既存の次未行動者反映・無料・再行動なしを維持。終了で保存内容はリセット。

## 手数の比較（UI経路による整理、時間計測ではない）

|目的・共通の開始条件|0.10.0|今回|
|---|---|---|
|装備画面から倉庫の品を装備|アイテム画面へ移り引出し、装備へ戻って装備。複数画面往復が必要|倉庫タブ→Shift左：2クリック、別画面往復0|
|表示中の収納から装備を交換|選択→交換ボタン：2クリック、またはダブルクリック2クリック|Shift左：1クリック。ドラッグも1ジェスチャー|
|装備を表示中の収納へ戻す|所持品解除後、倉庫へ移る必要あり|倉庫選択中はShift左1クリック、指定マスへドラッグ1ジェスチャー|
|空きのある宝箱の取得|開封→受領：2回|入手する：1回。次階への進行は別のE|
|戦利品の取得|全品受領は既に1回|1回を維持。不足時だけ入替へ|
|ステータスから同じキャラの装備確認|戻る→装備、主人公固定|装備ボタン1回、選択キャラ保持|

ダブルクリックは物理クリック2回であり、1クリックとは数えない。満杯時の不可逆な入替確認は省かない。
