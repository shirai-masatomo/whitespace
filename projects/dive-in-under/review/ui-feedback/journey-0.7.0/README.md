## 操作方法

- 倉庫：左クリックで詳細。詳細の「預ける／取り出す」またはEnterで1個体を移動。Shift＋左クリックで倉庫⇔バックパック。父の風呂敷からのShift操作は倉庫へ。ドラッグは薄青緑に光る収納へ離す。同じ収納内の並び替えはドラッグで行わず「整理」を使う。無効・画面外ドロップは取り消され、支給品等の制限も共通処理で判定する。
- 倉庫のFは風呂敷へ、Rは現在の整理順で整理。ボタンのキー表記と下部案内あり。**スタック未導入：数量×1、1個体＝1枠**。装備UID・耐久は結合しない。倉庫は既存どおり容量無制限、風呂敷整理は町のみ。
- 探索：戦闘外で「所持品・装備 [E]」。比較する→右側の現在・交換後・増減を見て「この装備へ交換」。Esc／戻るで同じ探索位置・受領画面へ。戦闘中は開けず、装備画面中にTimerは進まない。単なる選択では装備しない。町での回復は既存どおり、洞窟の着脱は現在HP/SPを増やさず、新上限を超える分だけ切り詰める。
- 戦闘：自動。**Spaceで停止／再開**、押しっぱなしのechoは無視。「戦闘を再開」ボタンも維持。停止で演出を片付け、既に確定したラウンドを再計算・二重適用しない。マップだけで戦闘停止する仕様は追加していない。
- 宝箱：開ける→品を選ぶ→受け取る→探索へ。戦闘ドロップも同じ受領画面。満杯なら装備を整理するか、左の所持品を選び「入替」→確認。手放す個体名を明示する。未受領品はEsc・画面切替だけでは消えず、受取り放棄は2段階の明示操作。
- イベント：選択→実際のHP／EXP変化・結果を見る→探索へ。品物は同じ受領処理へ。死亡・突破・帰還後は準備に戻り、地図・演出状態を次の出発へ残さない。

- 通常データ：[journey.json](../../../data/v1/journey.json)。ノード種別、敵の重みとLv、宝、イベント候補、背景キー／独立テクスチャパス、OGGパス、公開上限。
