# 制作順序：まず基幹フロー → 次に10Fまで

[全体仕様](../SPEC.md) | [実装範囲表](IMPLEMENTATION_STATUS.md) | [UIモック](UI_MOCKS.md)

## 直近（最小限の初期EXE試作）
**先に見た目と操作感を合わせる**。ゲーム開始→主人公単独探索→初回帰還不可→必ず死亡→結果→町→所持品・倉庫・装備整理→2回目以降は帰還可能、をひと続きで体験できるWindows EXEを目指す。現在はまだCodex未依頼。

今回の画像4枚はデザインモック。**新仕様で動くアプリではない**。旧ブラウザ試作ZIP（[参考用](../Dive-In-Under-10F-prototype.zip)）は過去仕様の別試作であり、今回の初回死亡・一人開始・人間配下編成を実装していない。

## 次の開発目標（10Fまで）
- 1〜9Fの階層別の敵・宝・イベント抽選と10Fボス。
- 深さによる報酬・EXPの増加、耐久と修理、持ち帰るか潜るかのリスク判断。
- 必要な時点で黄金像・支給所・人間の11装備枠などを拡張。
- 11Fに到達したら開始地点として解放（11Fそのものはこの段階の試作範囲外）。
- 最大6人、人間の連携・配下の忠実度は仕様として保持するが、最初の基幹フロー実装とは**分けて検討・実装**する。

## 実装の門番（進め方）
1. 見た目の方向性を今回の4画面からレビューし、操作導線を決定。
2. 最低限のデータ構造／画面遷移／セーブ／オート戦闘を作る。**戦闘コアはヘッドレスからも呼べる形にして、同時に単発戦闘シミュレーターを追加**（[要件](BATTLE_SIMULATION.md)）。
3. Windows EXEをビルドし、初回死亡から町・倉庫・再探索まで動作確認。
4. 画面・UXを改善し、必要に応じて遭遇内容と装備システムを充実。
5. その後に10Fまでを拡張し、**同じシミュレーターで階層連続探索も検証する**。**すべての詳細仕様を最初から作ろうとしない**。

## 気をつけること
- 旧モックのLv.5、金貨、倉庫上限、死亡後の戦利品移動表示は仮データ。
- 初回強制死亡の発生場所・理由はまだ未決定。プレイヤーが誤解しないよう導入の物語演出と連動させると良い。
- SteamではEXEと関連データの配布を想定する。最初はオフラインで完結する試作でよい。
