# 直近の目標 — 地下10Fプロトタイプ

[親仕様](../SPEC.md) | [試作を開く](../prototype/index.html)

## 目的
完成版を作るのではなく、**地上で準備 → 1Fから潜る → 途中で引き返すか決断 → 仲間や装備の損失を受け止める → ボス10Fへ挑む**が楽しいかを試す。数値・表示・テンポを更新するための試作品。

## 採用する試作範囲
- 1〜9Fの重み付きランダム（戦闘中心）と10Fボス。
- 地下では潜る・地上へ戻るのみ。オート戦闘の結果とターンログを表示。
- 地上の倉庫（預ける・引き出す）、支給所、黄金像。
- 3カテゴリの仲間、編成、死亡（例外含む）、レベル成長。
- 人間9部位の装備枠と耐久0破損・補修石。
- 主人公レベル別スキル解放と地上での選択。
- セーブ（ブラウザローカル）、10F突破後の11F解放表示。

## 検証シナリオ
1. 出発前に祈れる。地上で支給を受けて1Fに入る。
2. 1〜9Fでは敵・宝・イベントが三等分ではなく抽選される。敵・報酬候補が階層で変化する。
3. 10Fは必ずボス。到達11Fのチェックポイントが表示される（11F実プレイは対象外）。
4. 戦闘は自動。死亡した仲間は原則戻らず、例外特性の仲間は地上復帰する。
5. 装備は戦闘で劣化し、0なら効果が無い。地上で補修石を使うと直る。
6. 支給品は帰還時に失効し、倉庫へ預けられない。通常戦利品は整理できる。
7. レベルが上がると主人公スキル選択可能数が増える。地上で組み直せる。
8. 戻って再挑戦しても、到達階層・倉庫・成長が保存される。

## 今回の割り切り・未決定
- **10F後の深層そのものは未実装**。開始地点11Fは将来の機能で、試作では解放を示すだけ。
- 主人公戦闘不能は仮に強制帰還。**戦利品ロストや永続デスペナルティは未確定**。
- 戦闘はシンプルな1対複数の即時解決。敵パーティ・前後列・自動作戦編集は後続。
- 世界観・敵画像・演出・音・ゲームバランスは評価対象だが現時点の作り込みはしない。
