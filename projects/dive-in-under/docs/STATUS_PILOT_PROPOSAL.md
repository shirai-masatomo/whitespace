## 技術的な推奨案

| 論点 | 推奨する暫定契約 | 根拠・検証 |
| --- | --- | --- |
| 行動機会 | ラウンド開始に行動順を確定。各手番は、生存確認→開始時効果→HP0判定→行動不能／行動選択→行動・即時HP0判定→終了時の期限更新の順。麻痺でも生存者の行動機会は消費する | COMBATのSPD順とスキップ、SKILLSの本人行動機会。途中保存に処理段階も含め、再開で二重処理しない |
| 毒タイミング | 対象の行動機会開始時に1回。付与した攻撃の直後には追加tickしない。麻痺中も毒は処理し、致死ならその手番の攻撃を行わない | 初回tickの時点は未確定なので採用前に契約化。先攻／後攻双方、残り1回、毒HP0を固定seedで検証 |
| 毒の威力・丸め | 付与成功時の実効ATKと技の係数を記録し、各tickは同じ値。正の値は既存の `floor(x+0.5)` で整数化。追加の最低1補正や防御・会心・乱数・Lv補正は掛けない | 元ATKへの後続変化で毒が変動する曖昧さとLv二重適用を避ける。0へ丸まるケースを明示し、最低1にしたい場合は技正本の仮値変更として別判断 |
| 同種再付与 | 同じstatus_idは1枠、加算スタックなし。成功時に新しい付与者・技・威力・持続で置換し、reappliedイベントを1回出す。失敗時は残量を変更しない | stack_ruleをデータ化。強い毒が弱い毒で置換されることを含めて暫定案として比較。更新直後に同じ機会で期限を二重消費しない |
| 期限とCD | 効果ごとに開始／終了の消費点と付与機会IDを保存。S105は使用した当該手番末に消えず、次の本人行動終了で消える。CDは使用後N回の本人行動機会を禁止し、麻痺もその回数に含める | SKILLSの持続とCD定義。最後の暗闇機会は命中判定に適用後解除。麻痺はスキップして解除 |
| HP0 | 各HP変動の直後に死亡／勝敗を確定。致死攻撃後の状態付与は行わず、死亡イベント・報酬・結果遷移は各1回。毒で攻撃者が手番前に死亡したら行動しない | 同時一括tickをしないため通常処理で同時HP0を発生させない。復元入力が双方HP0なら曖昧な勝敗を創作せず不正状態として保全・拒否する案 |
| 技優先 | 使用条件・SP・CDを満たす候補のみ選び、防御／支援→攻撃→通常攻撃。候補選択後、行動確定時にSPを一度だけ消費。外れても消費、麻痺なら消費しない | 汎用処理に敵名分岐を置かず、台帳の優先リストを使う。E05は条件成立時S105→S104、E04は先行効果検証のためS102優先を推奨するが、S101との併用・優先は未採用 |
| 保存・演出 | 版付きの効果データ、技ID、付与者、威力、残回数、CD、処理段階、戦闘RNGを保存。表示はコアの確定イベントを読み、演出専用時間／乱数のみ使用 | 旧戦闘保存には空効果を補完する移行案。旧RNGを消費しない移行、効果あり／なし、途中再開とイベント一回性を比較 |

毒の開始時tick、威力の固定、同種置換は技術的な推奨であり、現時点の確定仕様ではない。防御態勢はSKILLSのDEF補正による軽減のみとし、独立した被ダメージ倍率を追加で掛けない案とする。プレイ感への影響は「状態あり／なし」の単発戦闘と1000seed反復探索で、勝率・死亡率・平均／中央値ラウンド・残HP・10F突破率を分けて比較する。

## 人間／親側で解決が必要な境界

- **主人公の取得・使用経路**：正本にS102〜S105の習得Lv、装備付与、購入、初期所持は定義されていない。共通コアが主人公に効果を処理できることと、プレイヤーが技を取得できることは別。まず敵が使い主人公が受ける実遭遇と、双方のテストfixtureを推奨する。新しい習得・購入・装備技・初期所持を創作して正式採用しない。プレイヤーが使用する要件にはゲーム設計判断が必要。
- **低層制約**：最新FLOORSはE03を2Fに配置したが、工程1／ENEMIESには「1〜2Fに状態異常を無理に追加しない」が残る。推奨はE03の出現を保ち、1〜2Fでは能動状態技を配らず3F以降から仮運用すること。遭遇側の技付与条件としてデータ化し、戦闘コアへ階層分岐を埋めない。これは**新しい制約案**で、既存の確定ルールと偽らず正本側で整合を取ってから適用する。
- **E06〜E08**：最新mainの追加要件。新敵・遭遇率・静止画・旧保存互換はまだ未実装。E06の防御、E07の麻痺、E08の強打は候補であり、状態4効果と新敵を一度に実装したものとして扱わない。画像の採否は既存の人間レビューを守る。
