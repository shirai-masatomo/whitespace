# スキルの正本 v0.9.0

## 2026-10-20 追記：設定可能なスキル優先順

[TACTICS.md](TACTICS.md)でキャラ別の「スキル・条件・対象」と優先順、および部隊セットの保存・戦闘中変更を採用。技能効果の定義は本台帳を維持し、対象指定によって射程を無視しない。以下の固定AI・自動防御の試作値を、ユーザー設定式作戦の完成仕様と混同しない。条件種類・行数・切り替え処理などは正本の未決事項として管理する。

> 2026-10-20 ユーザー指示A〜Hを現行とする。方式は今回のユーザー決定、具体数値・名称・配置は調整可能な試作採用値。0.8.1以前の仕様は[履歴](history/pre-adventure-0.9.0/)に保全し、現在の仕様として扱わない。実装／確認状態はIMPLEMENTATION_STATUSとレビューを参照。

既存S102毒牙・S103目くらまし・S104足止めの効果・持続・SP・付与確率はdata/v1/balance.jsonのrules.skillsを維持。今回の上書きだけadventure.json.skillsを参照し、既存の候補技一覧は履歴へ。S101強打を通常敵へ接続。技能効果を敵・階層に再定義しない。

S105はSP2、DEF+100%、自分の次行動終了まで、再使用まで2自分行動の試作値。攻撃1手を消費し、同時攻撃しない。予告された大技に対して、DEF>0・必要SP・防御未発動・クールダウン明けなら優先。通常時の低HPだけでは使用しない。理由：低HP時の無条件防御で攻撃を失う反復を避け、明確な予告対策として機能させる。SPD順により大技より前に自分の手番が回る必要がある。DEF0・SP不足・行動不能・弱い通常攻撃・敵の隙には役立たないため使用しない。

S101はSP3・倍率1.3、再使用まで3自分行動。命中・会心は共通。ボスの予告大技は固有行動パターンのheavy_multiplier/重み等をENEMIESが管理。アイテム・印の予防はITEMSを参照し、SPや行動を消費しない。

素早さは行動順のみ。複数敵・範囲攻撃・仲間や未実装の能力／属性を追加しない。
