# 起動・冒険準備画面 — 現段階の試遊仕様（2026-10-19）

[全体仕様](../SPEC.md) ｜ [UI参考](UI_MOCKS.md) ｜ [装備・収納](ITEMS.md) ｜ [実装状況](IMPLEMENTATION_STATUS.md)

> **ユーザーの最新確定指示**：現段階ではセーブ・ロード不要。ゲーム起動のたびに最初から始め、「開始」の後は**まず冒険の準備画面**を表示。そこで倉庫やステータス等の確認先を選べる。**今回の変更は試遊版の暫定スコープ**で、将来のセーブ復活は妨げない。**仕様更新とゲームコードへの反映は別**。

**2026-10-19 画風追加確定：タイトル・冒険準備・倉庫はすべて地上の屋外町。新しい参考UI3枚はチャットで一旦採用し、[UI_MOCKS](UI_MOCKS.md)に管理場所と最新実画面リンクを集約（原本画像のGitHub取込待ち）。以前の「洞窟内が地上町」のイメージは旧案。**

## 1. 起動・画面遷移（現在優先の仕様）

1. EXE起動 → シンプルなタイトル（「はじめる」「終了」程度。開発用単発戦闘は通常プレイヤーUIから外す）。
2. 「はじめる」 → **冒険準備ハブ**（必ず最初に表示。新規プロフィール／初期装備・所持品を新しく作成し、地上から始める）。
3. 冒険準備ハブから **「ステータス」／「倉庫・所持品」／「装備」**などの専用画面を選べる。準備ハブへの戻るボタンが必要。
4. 「探索に出発」 → 1Fから通常探索。以前から決まっている「潜る／帰還」、通常戦闘、宝・イベント、HP0敗北は維持。
5. 生還／死亡の結果 → 冒険準備ハブへ戻り、**同じ起動中であれば**アイテム整理・能力確認・再挑戦ができる。
6. アプリを終了し再起動したときは以前の進行を読み込まず、必ず新しい状態から開始する。

### セーブ機能を後回しにする意味

- **現段階の通常プレイではセーブ／ロードUIを提供しない**。「続きから」ボタン、「保存済み」等の表示を外す。
- **通常起動で古いセーブを読み込んで復帰しない**。プレイヤー操作のたびに保存する自動セーブも、この段階では使用しない。既存の保存データがある場合でも、初期化のために自動削除しない。
- ただし**同じ起動中の探索・帰還・倉庫・装備・ステータスはメモリ上で保持する**。セーブを省くことは探索ごとにすべて初期化する意味ではない。
- 将来セーブを導入するための内部設計や既存の保存コードは**復元可能な状態で残してよい**。今は正常なゲーム起動とUIの確認を優先する。
- デバッグ／CI用の検証用コマンドはプレイヤーの通常起動から分離。**通常起動に大量シミュレーション・負荷テスト・長い連続検証を含めない**。以前のPCフリーズ報告を受け、同じEXEでの無断の再現負荷テストは行わない。

## 2. 冒険準備ハブ（UI-07：新規）

**独立した行き先選択画面**。倉庫やステータスを同一画面へ無理に全部詰め込まない。

| UI | 内容・操作 |
| --- | --- |
| 上部 | 作品名／「冒険の準備」、主人公の名前（決まっていれば）、最低限のHP/SP・Lv・Gold表示 |
| メイン選択 | **ステータス**（能力・状態・プロフィール確認） |
| メイン選択 | **倉庫・所持品**（持ち物・父の風呂敷と倉庫の移動・アイテム詳細） |
| メイン選択 | **装備**（11部位・着脱・効果確認）。ステータス内の「装備」タブからも開ける形は許容 |
| 補助選択 | 支給所等の将来施設は機能が用意できた段階で追加。今は未実装ボタンの乱立を避ける |
| 主操作 | **探索に出発**（目立つ位置に配置） |
| 補助操作 | タイトルに戻る／終了。メニューから戻れる操作・キーボード対応 |

**見た目**は地上の屋外町（空・石畳・商店・家屋・暖色の街灯）＋現行2Dピクセル調の暗い石枠／羊皮紙／真鍮四隅。背景と操作UIを分離し、テキスト・数値・ボタンを実際に操作できるGodot Controlとする。

## 3. 専用画面の役割

- **ステータス**：倉庫から独立。主人公スプライト、HP/SP・基本能力、装備・能力・状態・プロフィールの4タブ構成を目標とする（未実装タブの取り扱いは後決め）。ユーザーの以前のステータスUI方針を維持。
- **倉庫・所持品**：以前の確定イメージ **左＝携行品＋父親の風呂敷／中央＝複数列の倉庫／右＝選択アイテムの詳細**。装備との預入・引出操作は実機能に接続。
- **装備**：11部位（右手・左手・頭・上半身・下半身・足・首・耳・目・指・腕）。初期5点（剣、青系マント＝頭枠、服、ズボン、靴）を活用。画像アイコンの見た目は別途採用判断。
- **冒険準備ハブ**：専用画面を選択するためのメニューであり、詳細な倉庫リストや全能力値を同時に押し込まない。

## 5. 実装境界

これは**最新UXの確定仕様**であり、**既存のゲーム本体に反映済みの意味ではない**。製造側へ取り込む際は既存戦闘・分岐・装備データの互換性を保ち、軽い起動・画面遷移テストだけ実施。PCへの負荷試験／大量シードの自動実行は行わない。
