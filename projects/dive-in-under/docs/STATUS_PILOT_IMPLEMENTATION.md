# 工程1・状態3種の暫定実装契約（0.4.9開発版）

2026-10-18。正本は[COMBAT](COMBAT.md)・[SKILLS](SKILLS.md)・[ENEMIES](ENEMIES.md)。技のSP・倍率・付与率・持続・CDはSKILLS S102〜S105の仮値をそのまま使用し、`data/v1/balance.json` に版付き実行データとして保持する。数値調整・高度な自動選択は行っていない。確認入口は0.4.6のまま。

## 今回の処理

- E03＝S103目くらまし、E04＝S102毒牙、E05＝S105防御→S104足止め。使用条件・SP・CDを満たすものをこの順で使い、不足時は通常攻撃。新たな3F制限は設けず、FLOORSの2F E03を維持する。新敵E06〜E08の候補技、S101強打はまだ割り当てない。
- 主人公と敵の同じコアが処理する。本編主人公の所有技は既存S105のみ。S102〜104の主人公取得・購入・装備付与は未決定のため追加しない。双方が技を使う固定fixtureで共通処理を検証する。
- 生存確認→自身の行動機会加算→開始時毒→HP0判定→麻痺ならスキップ→防御／攻撃技／通常攻撃→HP0・状態付与→自身の状態期限更新。麻痺も持続とCDの行動機会に数える。HP0後の攻撃・状態付与・追加SP消費は行わない。
- 毒は付与者の実効ATKを付与成功時に記録し、各tickの威力を固定。技係数を掛け正数四捨五入。防御・会心・乱数・追加Lv補正・最低1ダメージは掛けない。
- 暗闇は命中率から技の指定ポイントを減算し0〜1へ収め、最後の対象行動にも適用してから解除。麻痺は行動を飛ばし、その機会終了で解除。SPは行動成立時に一度だけ消費し、外れでも消費、麻痺では消費しない。
- 同種は1枠。成功時は付与元・威力・残回数を置換し、失敗時は更新しない。死亡・戦闘終了でも解除し理由をログへ出す。50ラウンド上限を維持。

**毒を対象の次の行動機会開始時に処理すること、威力のスナップショット、同種置換、戦闘終了時解除は、正本の空白を埋める技術的な試作用契約**。正式なバランス確定ではない。工程4で自動使用、工程7で強さを判断し、今回の進行を数値調整で止めない。

## 保存・表示

新戦闘は `rules_version:3`。旧版1/2の戦闘途中保存は敵の新技を追加せず復元し、終了後の次戦闘から新版を使う。保存形式schema3と既存成長設定を維持。保存は戦闘開始時の入力・seed・完了ラウンド数から共通コアで再構築するため、状態威力・残回数・CD・ログ・RNGを途中復元できる。UIはラウンド終了の原子的な保存点だけを扱い、途中演出でゲーム状態を変更しない。

緑の粒子／紫の局所暗転／黄色の短い電撃と、状態名・残行動機会・行動不能・ダメージ・解除ログを表示。既存の背景・静止キャラを動かさず、演出0.4秒は戦闘乱数を使わない。防御も両陣営の状態札へ表示。画面の自然さは既存構図を維持し、効果と札の可読性を別途確認する。
