# 現行の地図とポータル（0.9.0）

今回のユーザー決定A〜Hを優先。旧文書の全文は[履歴](history/pre-adventure-0.9.0/DUNGEON_MAP.md)に保全。旧「いつでも帰還」「全ノード種別固定」は現在の帰還・5F抽選を制約しない。

公開範囲は1〜10F。配置と出現は[FLOORS](FLOORS.md)、機械正本はadventure.jsonのnodes。1〜4・6〜9Fでは通常帰還不可。5・10Fは出来事開始前にポータルを表示し、帰還／居座るを選ぶ。5Fは戦闘・宝・イベント、10Fは居座ると石像戦。初回帰還で5F再出発を解放しない。

同じ階の実際の出来事を一度だけ決め、nodeに固定する。地図・装備の開閉・ポータル再表示で再抽選しない。報酬の受領後は帰還／続行の選択で止まり、自動でポータルを通過しない。戦闘中の通常帰還は不可。次の帰還地点をミニマップ見出しに表示。

左の主操作・中央の出来事・右上の縦地図・右下の詳細という0.8.1の配置を維持。地図は浅い階が上。現在地、今回の通過、過去の到達済を区別。未発見の内容を明かさず、クリックで詳細地図、Escで閉じる。地図を開くだけで戦闘を止める新仕様は追加しない。死亡・結果・町への遷移で開閉を解除。

枝分かれ・鍵による別ルート・仲間の情報察知は将来仕様として旧文書に保全し、今回未実装。通常の最高到達と5F開始解放は別。デバッグの一階限定置換は専用入口だけで、通常ルートの記録とは別セッション。
