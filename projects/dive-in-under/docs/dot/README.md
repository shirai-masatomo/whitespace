5. **工程1〜4は仲間システムなしで遊べることを必須**にする。仲間前提の戦闘バランス・進行条件は作らない。EV03の人間加入は工程5まで除外。黄金像の仲間排出も工程5までは利用不可。

**開発効率に関する優先ルール（2026-10-18）**：[TEST_POLICY.md](TEST_POLICY.md)に、工程1の機能テスト・工程4のAI行動改善・工程7の統計的難易度調整を分けて記録。**大量検証を小さな修正ごとに繰り返さない**。このルールは工程別ファイル内の古い「勝率・死亡率を比較」より優先する。
