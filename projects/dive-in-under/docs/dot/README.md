## 仕様の優先順位と実装境界

1. ユーザーの最新の明示指示・[SPEC.md](../../SPEC.md)の確定仕様。
2. **この工程一覧は実装順の正本**。個別資料に将来仕様が書かれていても、工程を前倒ししない。
3. 分野別の基礎データ／計算・条件はそれぞれ[FLOORS](../FLOORS.md)、[ENEMIES](../ENEMIES.md)、[COMBAT](../COMBAT.md)、[SKILLS](../SKILLS.md)、[ALLIES](../ALLIES.md)、[ITEMS](../ITEMS.md)、[EVENTS](../EVENTS.md)を正本にする。
4. [UIモック](../UI_MOCKS.md)は見た目の参考であり、画像内の数値・死亡時のアイテム処理は仕様ではない。旧ブラウザ試作は最新仕様の証拠ではない。
5. **工程1〜4は仲間システムなしで遊べることを必須**にする。仲間前提の戦闘バランス・進行条件は作らない。EV03の人間加入は工程5まで除外。黄金像の仲間排出も工程5までは利用不可。
6. **初回の強制死亡・帰還禁止は廃止**。最初から通常の1F探索・帰還・HP0敗北・再出発が可能。ソロ10F攻略を維持。[最新変更指示](CHANGE_2026-10-17_FIRST_EXPEDITION.md)が正本。
7. 未確定の数値は「仮」として記録し調整可能にする。権利・費用・公開・重大創作判断は人間へ確認する。
