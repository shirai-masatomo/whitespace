# 起動と冒険準備（0.9.0）

[現行入口](../review/current/README.md) / [全体仕様](../SPEC.md) / [装備・通貨](ITEMS.md) / [旧文書全文](history/pre-adventure-0.9.0/STARTUP_PREPARATION_UI.md)

通常起動→タイトル→はじめる→地上の冒険準備→探索に出発→1F。起動ごとに新規、同じ起動中の成長と収納を保持。保存・ロードを有効化せず、旧セーブを読み書き・移行・削除しない。終了でリセットと案内する。

準備にはステータス、倉庫・所持品、装備、探索に出発、支給所・個体・印・自動対策を配置。ステータスと倉庫は独立。4タブ・11部位、バッグ15・風呂敷3・中央複数列倉庫を維持。ロゴはタイトルだけ、タイトル背景フィルターは既存0.12の一枚だけ。町背景・0.6.4以降のUIと遅延破棄対策は維持。

支給所は不足部位に最低装備を受け取る。風呂敷を含む同じ支給品の全所有を調べ、重複受領・上書きを防ぐ。印と予防薬、支払元は同じ準備パネルで確認。性能・価格・加工条件の正本はITEMSとadventure.json。

帰還・死亡・突破の結果から準備へ戻る。死亡は装備・バッグを全損し、風呂敷・倉庫・EXP・レベルを保持。失った品と保持した品を別欄で示す。通常帰還は5・10Fのポータルのみ。未受領品の解決前には帰還せず、初突破保証装備は放棄で消さない。

通常版とデバッグは別の起動入口。配布のDebug.cmdは--debug-runで新しい専用セッションを起動し、常時表示で区別。通常入口には検証・シミュレーション・デバッグ帰還の操作を含めない。

確認済み／未確認はIMPLEMENTATION_STATUSと今回のレビュー記録を参照。見た目・遊びの採用はユーザー評価と分ける。
