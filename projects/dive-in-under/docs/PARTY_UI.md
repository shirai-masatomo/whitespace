# キャラ別UI・収納操作（2026-10-21）

仕様・実装範囲の正本は[今回の詳細](../review/ui-feedback/party-ui-0.11.0/IMPLEMENTATION.md)。数量／支給はITEMS、能力はALLIES・COMBAT・SKILLS、作戦ルールはTACTICSを参照する。本資料の数量・操作決定はユーザー承認済み。

Shift左：装備する／外す。装備画面の選択収納が旧装備・解除の戻り先。町の倉庫から装備する場合、旧装備も倉庫へ。満杯のバッグから一対一交換は可能。指定倉庫マスへ外す場合は空きマスが必要。倉庫同士のドラッグはマス交換で、所有数は変わらない。

Shift右：所持品と倉庫を移動し、戻るは発火しない。Shiftドラッグ：コインの半分切り捨て、1枚は1枚。装備品は1個体単位。風呂敷は詳細下部から実際に移動し、別収納と二重所有しない。

通常右クリック：前の閲覧画面。ドラッグ取消→モーダル取消→地図を閉じる→前画面の順。ポータルや未解決の出来事を勝手に決定しない。Xは明示された見送り・取消。

取得：まず「入手する」。既存スタックの余裕も含め全品が入れば一括取得、入らない場合だけ入替UI。取消は未取得品を保持。宝箱は開いた画像と取得完了を表示してから、次のEで進む。帰還地点は自動通過しない。

整理：実行ボタンを押したときだけ、選択収納を種別・名前・耐久順へ並べ、空きマスを詰める。コイン結合は別操作。画面更新やフィルタで手動配置を変えない。
