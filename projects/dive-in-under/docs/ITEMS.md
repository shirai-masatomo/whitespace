# アイテム・装備・支給品 台帳

[全体仕様](../SPEC.md) | [階層](FLOORS.md) | [実装範囲](IMPLEMENTATION_STATUS.md)

## 装備スロット（確定）
人間1名につき**合計11枠**。

| 系統 | 部位 | 枠数 |
| --- | --- | ---: |
| 武器・盾 | **右手、左手**（各手に武器または盾） | **2** |
| 防具 | 頭、上半身、下半身、足 | 4 |
| 装飾品 | 首、耳、目、指、腕 | 5 |

- 武器／盾も通常装備と同様に能力修正を持ち、装備で素早さ等の能力値は変化し得る。
- **耐久**は装備の現在値／最大値で管理。消耗で性能が低下、0で**破損マーク・性能0**。修理方法あり。
- 動物・魔物は今のところ装備なし。
- **両手武器の扱い、盾の重複、手の利き手、修復費用、持込重量制限**は未決定。

## 将来予定：装備の個体差・追加能力・印による強化

**導入予定／未実装**。同じ種類の装備でも、宝箱・敵ドロップ・黄金像ガチャで入手した**個体ごとに強さや追加能力、印を付けられる条件が異なる**ハクスラシステム。効果量・排出率・実装時期はまだ未決定。

| システム | 計画 |
| --- | --- |
| **基礎性能の個体差** | 同名装備でも基礎ATK・DEFなどのロール値が異なる |
| **ランダム追加能力** | 入手時に追加能力（Affix）が抽選される。種類・値・個数は後で決める |
| **印・印枠** | **印付き、あるいは印を受け入れられる装備**に、後から特殊効果を付与・交換できる仕組みを検討する |
| **装備強化** | 基礎値や追加能力の強化、印の付与などを後から行う加工システム（詳細未決定） |

- **アイテム個体データ案**：`template_id`（種類）／`instance_id`（個体）／`base_roll`（基礎性能）／`extra_affixes`（追加能力）／`seal_eligible`（印対応可否）／`seal_slots`（印枠）／`seals`（付与した印）／`current_durability`／`max_durability`／`origin`（入手経路）。**印が付いていることと印を後付けできることの関係は未決定**なので区別して保持できる構造にする。
- **抽選元の分離**：**装備品の種類が出る確率**は [FLOORS.md](FLOORS.md)（宝箱）、[ENEMIES.md](ENEMIES.md)（敵）、[SHRINE.md](SHRINE.md)（黄金像）が正本。**入手後の装備個体に付く基礎ロール／追加能力／印の候補と重み**は本資料で管理する構想。種別抽選と個体生成を混同しない。
- **確定済み耐久ルールは維持**：壊れたら装備性能0。破損中は基礎値・追加能力・印の効果も原則停止するが、個体データは保持して修理後に復元できるようにする。
- **未決定**：印枠上限・レアリティ・印の入手／装着／解除条件・必要な素材と費用・強化の成功率・強化値の上限・装備ごとの追加能力範囲・効果の重複ルール。
- **参考**：[風来のシレン6公式（印・合成）](https://www.spike-chunsoft.co.jp/pages/shiren6/system/)／[Diablo IV（装備特性・加工）](https://news.blizzard.com/en-us/article/24244465/vanquish-the-lesser-evils-in-season-of-divine-intervention)／[Dark and Darker（ランダム修飾値）](https://darkanddarker.com/news/83)。これらをそのまま複製するのではなく、独自仕様とする。
- **実装方針**：まず工程1のソロ探索、工程2の装備11枠・耐久、工程3の出現／報酬を完成させる。**本強化システムは別途導入工程を決めてから開発**し、既存のCodex作業へ突然追加しない。

## 倉庫と支給所（確定）
- **倉庫**：アイテム保管・移動・整理。
- **支給所**：探索で使う物資を支給。**支給品は倉庫へ預けられない**。
- 倉庫・携行容量や死亡時のロストの割合・保存先はまだ決めない。UIモックに表示される「100」「30」などの数字はサンプル。
