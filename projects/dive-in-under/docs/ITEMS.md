# アイテム・装備・支給品台帳

[親仕様](../SPEC.md) | [階層帯](FLOORS.md)

## 確定ルール
- **人間の防具4枠**: 頭 / 上半身 / 下半身 / 足。
- **人間の装飾品5枠**: 首 / 耳 / 目 / 指 / 腕。
- 全装備に耐久値。傷むと能力が弱まり、0で**破損（能力0）**。修理可能。
- 動物・魔物の装備は当面なし。
- 倉庫＝所持品の預け入れ・引き出し。**支給所の支給品は倉庫保存不可**。
- 武器スロットはユーザー未指定につき保留。試作では基本攻撃力と装飾品補正を使用。

## データ上の注意
個別アイテムは最大耐久とは別に現在耐久を保有。装備の付け外しや倉庫移動で耐久値は変化しない。試作では戦闘1回ごとに装備品の耐久が1減少。正式な耐久消費条件と修理コストは要検討。
