# 戦闘共通仕様 v0.1

[全体仕様](../SPEC.md)｜[スキル一覧（効果の正本）](SKILLS.md)｜[敵・固有AI](ENEMIES.md)｜[味方・固有AI](ALLIES.md)

> **確定**＝ユーザー指定。**仮**＝Codex実装前の初期バランス案。以下の式と数値は **Wizardry・B100系そのものの仕様ではなく、Dive In Under独自の試案**。現行ブラウザ試作・EXEには未反映。

## 1. 行動の基本

- **確定：完全自動のターン制（ラウンド制）**。各ラウンドで生存者が原則1回ずつ行動。
- **確定：素早さの高い順**に行動。装備・スキル・状態変化による素早さの補正も反映する。
- **仮：同速は戦闘用乱数で順位を決定**。行動順は各ラウンド開始時に確定。行動不能者は行動を消費してスキップ。
- 行動の種類：**通常攻撃／能動スキル／防御・支援／行動不能**。受動スキル・追撃・連携は、別の行動から派生する効果。
- 味方は最大 **人間3名＋各人間の配下1体＝6体**。初回探索は主人公1人。敵パーティ数・前衛後衛は別途検討。
- **確定：仲間HP0は即死亡（原則永久離脱）**。敵HP0は撃破。主人公死亡の帰還処理・ロスト内容は全体仕様に従う。

## 2. 攻防とダメージ計算（仮）

主な戦闘能力は **最大HP／攻撃 ATK／防御 DEF／素早さ SPD／スキルポイント SP** の5種。初期は物理攻撃のみ。魔法攻撃力・魔法防御力・回避力・属性は、必要になった段階で追加する。

- 実効能力＝**レベル反映後の基礎値＋装備・パッシブ補正**に強化／弱体倍率を適用。計算後 **ATK≥1、DEF≥0、SPD≥1、最大HP≥1、最大SP≥0** に丸める。
- 装備の耐久低下・破損による能力変化は [アイテム仕様](ITEMS.md) に従う。両手の武器・盾を持っても、基本は**1ラウンド1行動**（二刀流連続攻撃はまだ未決定）。
- 物理攻撃力を **A**、対象の物理防御力を **D** としたとき：

**基本威力 = A × (A + 4) ÷ (A + 4 + 2 × D)**

**最終ダメージ = max(1, 四捨五入［基本威力 × スキル倍率 × 乱数(0.95〜1.05) × 会心倍率］)**

- 命中率 **95%**、会心率 **5%**、会心時 **1.5倍**（すべて仮）。命中判定→会心判定→ダメージ→付随状態異常の順。命中しなければ0ダメージ・状態異常も不発。
- 仮の通常攻撃は **スキル倍率1.0**。会心しなかった場合の例：ATK10・DEF0→10、DEF5→約6、DEF10→約4、DEF20→約3（乱数1.0）。
- この式は、**防御0なら攻撃値を活かせ、防御が高くても最低1ダメージ**。攻防が同時に成長しても相対差が残る。状態異常などによる完全無敵・無限戦闘を避けるのが目的。
- 倍率の増減は**該当ステータスに加算してから1度だけ乗算**し、実効値を更新。強化と弱体の多重乗算による過大な増減を避ける。上限値・耐性はテストで見直す。

## 3. 状態異常・状態変化（仮）

| 状態 | 共通効果 | 持続 |
| --- | --- | --- |
| **毒** | 行動開始時に、付与時の攻撃値の**20%（四捨五入、最低1）の固定HPダメージ**を受ける | 3回の本人行動機会 |
| **暗闇** | 物理攻撃の命中率が**25ポイント低下**（通常95%→70%） | 2回の本人行動機会 |
| **麻痺** | **次の行動を1回失う**。その間にも毒の処理は実行 | 次の本人行動1回 |
| **衰弱** | 実効ATKを**25%低下** | 2回の本人行動機会 |
| **防御態勢**（有利効果） | 実効DEFを**30%上昇** | 次の本人行動終了まで |

**共通処理**：毒→行動不能判定→行動→持続残数の減算。付与したその瞬間は残数を減らさない。同種状態は重ね掛けせず**持続を長い方に更新**（毒の威力は高い方を保持）。異なる状態は同時に保持。HP0になれば直ちに死亡／撃破。

**状態付与**はスキルごとの基礎確率と対象の**状態別耐性（0〜100%）**から、`付与確率＝基礎確率×(1－耐性/100)` で決める。耐性の個体差・ボス固有値は敵／味方の台帳に記載。状態異常を生む**スキルの名称・発動条件・確率は [SKILLS.md](SKILLS.md) を正本**とする。

## 4. 汎用戦闘AI（仮）

各行動者は**自分の手番に1つの行動だけ**を選ぶ。状態異常・死亡によって行動できない場合はスキップ。

1. 使用条件・クールダウンを満たすスキルから、**回復→防御／支援→攻撃**の順に選択。
2. 使用可能なスキルがなければ**通常攻撃**。
3. 攻撃対象は**生存敵で残りHP割合が最も低い相手**、回復対象は**生存味方でHP割合が最も低い相手**を仮の標準とする。同率は編成順・ID順で決定。
4. 能動スキルごとの**閾値・消費SP・クールダウン・追加効果は [SKILLS.md](SKILLS.md)** に従う。**現在SPが不足するスキルは候補から除外**。パッシブは行動を消費しない。
5. 追撃／連携などの**派生行動は元の1行動につき各種最大1回**、派生行動から再び派生させない（無限連鎖防止）。

ボスの行動条件・ターゲット優先・特殊フェーズは [ENEMIES.md](ENEMIES.md)、味方の固有戦法・配下の挙動は [ALLIES.md](ALLIES.md) に書く。**汎用AIに固有キャラクターの例外を埋め込まない**。

## 5. 敵のレベル補正とSP（バランス検証用・仮）

**敵のLvは[FLOORS.md](FLOORS.md)が決定し、敵のLv1相当の基礎値は[ENEMIES.md](ENEMIES.md)が決定する。** 成長率を敵ごとに重複記載せず、次の共通式を適用する。Lvは1以上の整数、四捨五入は `floor(x+0.5)`（正数）、除算の切り捨ては `floor` とする。

| 項目 | Lv=L、n=L−1 のときの実値（仮） |
| --- | --- |
| 最大HP | `max(1, round(基礎HP × (1 + 0.10 × n)))` |
| ATK | `max(1, round(基礎ATK × (1 + 0.06 × n)))` |
| DEF | `基礎DEF + floor(n / 5)` |
| 最大SP | `基礎SP + floor(n / 3)` |
| SPD | **基礎SPDのまま**（レベル補正なし。装備・スキル等の補正は別） |
| 獲得EXP | `max(1, round(基礎EXP × (1 + 0.14 × n)))` |
| 獲得Gold | `max(0, round(基礎Gold × (1 + 0.12 × n)))` |

- **敵の強さと報酬は「敵種の基礎値×敵Lv補正」の1回だけ**で算出。これに**階層補正を二重に掛けない**。主人公・味方のLv成長係数は別途決定する。
- SP＝スキルポイント。**仮ルール**：能動スキル使用時に[SKILLS.md](SKILLS.md)の消費SPを引く。SP不足なら使わず別行動。敵は各戦闘で最大SPから開始、味方は探索開始時に最大SPへ回復し、フロア間で残量を持ち越す（帰還判断のリソースにする案）。**SP回復手段と採用可否は未確定**。
- 初期SPが0の敵は通常攻撃で行動可能。最大SPの増加だけではスキルを自動取得しない。SPの上限・スキル配布は個別台帳で管理する。

**試算の代表例**（乱数・装備・状態補正なし）：

| 敵とLv | HP | ATK | DEF | SP | EXP | Gold |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| E01 Lv1 | 8 | 3 | 0 | 0 | 4 | 2 |
| E04 Lv4 | 23 | 7 | 1 | 7 | 13 | 11 |
| E05 Lv6 | 36 | 9 | 4 | 7 | 20 | 19 |
| B10 Lv6 | 81 | 14 | 4 | 13 | 44 | 64 |

**初期バランス確認**：階層台帳の出現率・敵Lv範囲を使い、各Lv等確率・勝利前提で算出した平均EXP／戦闘遭遇は、1F **4.3** → 3F **6.4** → 4〜6F **8.9** → 7〜8F **14.9** → 9F **18.1** → 10Fボス **44**。成長に応じて強敵と報酬の両方が増える設計。ただし**クリア率、味方成長曲線、装備格差は未検証**であり、最終バランスではない。

## 6. 終了・検証項目

- 敵全滅で勝利／主人公HP0で探索失敗。仲間の即死亡は戦闘中にも判定。
- 仮の**50ラウンド上限**で膠着戦を打ち切り、引き分け／探索中断として記録（ペナルティは未決）。
- 戦闘ログには**行動順・攻撃対象・命中／会心・ダメージ・状態変化・死亡**を記録。乱数シードを保存して同じ戦闘を再現可能にする。
- **初回探索は必ず死亡**するが、これは導入シナリオのルールであり、通常のダメージ計算に「必ず負ける補正」を混ぜない。
- EXP配分・帰還時の所持品・仲間の復活例外は別仕様。敵1体の基礎EXP・Gold・ドロップは[ENEMIES.md](ENEMIES.md)、出現率・敵Lv・宝箱率は[FLOORS.md](FLOORS.md)を参照。前衛／後衛、属性・MP、B100X式の高度なスキル自動選択は**後日検討**。
