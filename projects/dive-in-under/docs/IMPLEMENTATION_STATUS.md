## 初期EXE試作のチェックリスト（受入条件案）

- [ ] 新規開始すると主人公1人で地下へ入る。地上施設はまだ選択できない。
- [ ] 進行・ランダム遭遇・速度順オート戦闘が表示される。
- [x] 戦闘コアをヘッドレスでも実行でき、同じシードの再現・基本指標の集計・変更前後の比較ができる。（単発通常攻撃版、472bc01）
- [ ] 初回の「帰還」は選べない。探索は必ず死亡して終わる（死亡する階はまだ未確定）。
- [ ] 死亡結果を見て町へ戻れる。
- [ ] 地上ではアイテムを整理し、倉庫へ預けたり取り出したりできる。
- [ ] 装備の変更が反映され、ステータスが更新される（細かな枠の採用範囲は実装前に選ぶ）。
- [ ] 再出発後は「潜る／地上へ戻る」を選べる。
- [ ] セーブ→EXE再起動で引き継げる。
- [ ] レビュー用スクリーンショットを4画面のモックと並べて比較できる。

**未確定のため勝手に決めないこと**：初回死亡の確定階、死亡時のアイテム持ち帰り／ロスト、初期能力値・初期通貨、倉庫容量、支給品ルールの序盤適用。
