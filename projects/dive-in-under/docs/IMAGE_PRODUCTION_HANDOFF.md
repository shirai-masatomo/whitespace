- 暗い地下洞窟の2Dドット調。青緑・黒い岩、水や鉱脈、暖色ランタン、羊皮紙と真鍮のUI。明るさ・深さ・接地を読み取りやすくする。

- モックの複数人物・手動戦闘コマンド・ミニマップ・サンプル数値は実装仕様ではない。完全自動戦闘と「潜る／帰還」を維持する。
- 既存作品の固有造形をコピーせず、宗教・種族・歴史などの新しい世界設定を勝手に追加しない。重要な造形／世界観／採否はユーザーが判断する。

## 現在の表示寸法（候補実装値、固定の美術規格ではない）

固定の要件は「比率維持・nearest・人物を切らず・実際の足元で接地・主要1280×720で読めること」。次は現コードの調整可能な値。

| 部分 | 原稿と実装 |
| --- | --- |
| 全画面 | 1280×720。背景は1672×941 PNGを比率維持で全面表示 |
| 探索／戦闘の絵領域 | 1280×720時は612×270実測。リサイズ時は幅可変。背景を覆う倍率で表示し、はみ出しだけクリップ |
| 通常／中／深層 | 通常背景を再利用し静的な色調と深度名を変更。10Fは門背景。各階10枚の制作は不要 |
| 戦闘キャラ | 主人公の透過領域矩形は高さ165px、E04は145px、B10は205pxを上限とし、幅は絵領域の34%以下。余白や薄いアルファを含む矩形寸法で、実体の見える高さとは異なる |
| キャラ配置 | 足元xは主人公75%、敵24%。背景原稿の地面y=705を表示倍率・縦クリップへ変換し、両者の足元yを揃える |
| ステータス／装備 | 同じ主人公静止画像を比率維持で84px／62px高の表示枠へ収める。別ポーズや新しい能力表示を追加しない |
