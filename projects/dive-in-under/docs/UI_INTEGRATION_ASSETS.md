# 0.6.0 UI素材の適用と残り

今回の添付で、準備・倉庫・タイトルの完成参考と、それぞれの独立背景が揃った。洞窟背景・人物・敵の再制作は不要。

| 素材 | 適用 |
| --- | --- |
| 地上町3背景 | タイトル／冒険準備／倉庫に別々のTextureRect |
| UIシート | 羊皮紙・石・真鍮四隅・ボタン状態を共用。文字と操作はGodot |
| 能力と状態シート | HP/SP/EXP、攻撃・防御・速度、毒・暗闇・麻痺・防御のアイコン領域 |
| 収納シート | 上段のバッグ・風呂敷・倉庫。発光状態は既存選択枠で描画 |
| 既存装備 | 青い冒険者のマント（頭）、既存I01〜I09/I11。性能や種類の追加なし |

追加制作が有効な独立素材を以下にまとめる。現行の実装を止める必須条件ではない。

| 用途 | 推奨サイズ・枚数 | 透過・分割 | 参考 |
| --- | --- | --- | --- |
| タイトルロゴ | 768×240、1枚 | RGBA、周囲16px以上透過。町背景・操作ボタンを含めない | 最新タイトル参考 |
| 細い共通パネル枠 | 128×128、石／羊皮紙2種 | 9-slice、四辺16px、文字なし。中央は透過／別タイル | PX-03、最新倉庫 |
| タブ状態 | 160×48、通常／選択／hover／disabled各1 | RGBA、9-slice各辺8px、文字なし | ステータス4タブ |
| 装備部位の空枠ピクト | 32×32、11種 | RGBA、右左手・頭・上半身・下半身・足・首・耳・目・指・腕 | ユーザー装備仕様 |
| ゲージ端の宝石＋外枠 | 32×32赤青黄各1、外枠256×24×1 | RGBA。充填は別にGodotで実値を描画 | 準備参考 |
| スクロール部品 | 上下16×16各1、つまみ16×32×1、レール16×32×1 | RGBA、縦方向に反復可 | 倉庫・詳細 |
| 地図ノード・接続 | 24×24通常／現在／訪問各1、線16×8×1 | RGBA。未知の出来事を示す実体種別なし | DUNGEON_MAP |

高解像度の一枚絵をUI操作面として貼らない。全素材は1点ずつ使える余白、黒背景ではなくアルファ透過、ピクセルの輪郭、文字なしを条件にする。収納下段のように隣の発光が重なった素材は採用しない。
