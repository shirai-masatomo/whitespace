# Dive In Under — ダンジョン・層域・分岐ルート命名規則（2026-10-19 採用）

[全体仕様](../SPEC.md) ｜ [階層分岐とマップ](DUNGEON_MAP.md) ｜ [階層台帳](FLOORS.md) ｜ [探索UI参考](UI_MOCKS.md)

> **確定したのは命名構造**。「大深淵」「翠簾層」「青滝の洞道」「苔守の隠し道」など先に提示した固有名は**説明用候補であり、採用確定ではない**。名前を選ぶときは個別に決定する。資料更新はゲームコード・EXEへの反映を意味しない。

## 1. 3階層の命名構造（確定）

| 階層 | 対象 | 命名・表示規則 |
| --- | --- | --- |
| **1. ダンジョン全体名** | 本洞も支洞も含む**一つの巨大な地下ダンジョン** | 全区域を通じて共通の固有名を**一つ**持つ。分岐ごとに別ダンジョン扱いにしない |
| **2. 層域名** | 基本的に **1〜10F、11〜20F、21〜30F…** の階層帯 | **「第N層域」＋固有の区域名（○○層、○○の回廊等）**。10F刻みの区域番号と固有名を組にして管理 |
| **3. ルート名** | 同じ層域内のメイン経路・条件付き分岐 | 主経路は **本洞**、枝は **支洞** を分類名とし、地形に応じ **洞道・回廊・沢筋・尾根筋等**を固有名・通称へ使える。分岐先も一つのダンジョン内の道として扱う |

- 固有名は世界観・景観の異なる層域やルートを区別するために付ける。単に「1F」「分岐A」とだけ呼ぶより、地理的広がりを伝える。
- **階層番号（F）と固有名は別の情報**。同じ3Fに本洞と支洞があっても、内部のノードID／ルートIDはそれぞれ異なる。表示するF番号は階層を指し、経路を決めるキーにはしない。
- 隠し分岐に入れるかどうかは[分岐条件](DUNGEON_MAP.md)のアイテム所持で判定する。**名前が付いたこと自体は解放・発見の証拠ではない**。
- ルート名・地形名からBOSS・敵・宝・イベントの固定種別を推測させる表示ルールは、特段の設計判断がない限り加えない。ミニマップの種別非公開と矛盾させない。

## 2. 表示例（全て未採用の仮名）

```text
ダンジョン全体：大深淵（仮）
└─ 第1層域「翠簾層」（仮） / 地下1〜10F
    ├─ 本洞：「青滝の洞道」（仮） / 通常ルート
    └─ 支洞：「苔守の隠し道」（仮） / アイテム条件を満たすと分岐
└─ 第2層域「名称未決」（仮） / 地下11〜20F
    ├─ 本洞：「名称未決」
    └─ 支洞：「名称未決」
```

※サンプルに出る分岐場所・内容・「隠し道」への実際の進入条件は未確定。**3F分岐は例であり設計済みではない**。第1層域の採用区域名も未確定。

### 想定するUIの表示

- **探索HUD**：`第1層域 〔層域名〕｜本洞／〔ルート名〕｜3F` のように、必要な情報を画面サイズに応じて簡潔に表示する。
- **全景マップ**：上部にダンジョン全体名／層域名、接続線のまとまりにルート名を表示できる。未発見・未解放の枝の名前や表示範囲は、ゲーム側の解放ルールが決まってから表示を確定する。
- **結果画面**：到達した層域とルートを深度記録に併記できる。ただし同一10F帯の複数枝を別の「到達階」扱いにしない。

## 3. 台帳化するときの推奨項目（内部設計案）

| 種類 | 推奨フィールド | 備考 |
| --- | --- | --- |
| ダンジョン | `dungeon_id`, `dungeon_name` | ひとつのダンジョンを識別 |
| 層域 | `region_id`, `region_index`, `floor_start`, `floor_end`, `region_name` | 1〜10Fのような階層帯と固有名 |
| 経路 | `route_id`, `region_id`, `route_kind`, `route_name` | `route_kind` は `main`／`branch`、経路の通称は別項目 |
| ノード | `node_id`, `route_id`, `display_floor` | [DUNGEON_MAP](DUNGEON_MAP.md) にある接続・ノード種別・条件と連携 |

**フィールド名は設計上の例**であり、Godotの保存形式や既存実装を今すぐ変更しない。既存の10F固定ボス・11Fからの開始解放・分岐条件を維持する。

## 4. 固有名の決定待ち

- ダンジョン全体の正式固有名
- 第1層域（1〜10F：青い滝・苔・水辺洞窟）の正式名称
- 以後の第2・第3層域などの名前
- 各層域の本洞・支洞の名前と接続位置・固有ルート演出

**現段階は命名体系のみ正式採用し、固有名は自動確定しない。**
