> **基本設計**：ここには敵種ごとの**Lv1相当の基礎能力値と基礎報酬**、勝利時の**ドロップ率**、固有AIをまとめる。出現率・出現レベルは階層台帳が正本。個別数値・ドロップ率は**試作バランス用の仮値**。

- 全て**基礎値**。実際の敵レベルを[FLOORS.md](FLOORS.md)から取得し、[COMBAT.md](COMBAT.md)の共通Lv補正を適用する。
- **SPDは素早さ**。行動順に使用する。現時点の試案では**敵LvによるSPD補正なし**（固有・状態異常による補正は別）。
- **SPはスキルポイント**。スキル使用に消費する方式を暫定想定する。共通ルール・SPの回復は[COMBAT.md](COMBAT.md)、個別の消費SPは[SKILLS.md](SKILLS.md)。
- **基礎EXP／基礎Gold**は敵1体を倒した際の報酬の元値。**敵Lvに応じて増加**する。階層や味方Lvによる報酬倍率を重複適用しない（追加補正は未決定）。

## 撃破時のアイテムドロップ（仮）

| 敵ID | 落とすアイテム（ID・名称・ドロップ率） |
| --- | --- |
| E01 | I01 皮の帽子 **12%** / I04 古いブーツ **4%** |
| E02 | I10 補修石 **7%** / I01 皮の帽子 **6%** |
| E03 | I04 古いブーツ **9%** / I08 火花の耳飾り **3%** |
| E04 | I05 鉄の指輪 **12%** / I06 守りの腕輪 **5%** / I10 補修石 **8%** |
| E05 | I06 守りの腕輪 **14%** / I07 煤けた首飾り **6%** / I10 補修石 **12%** |
| B10 | I11 深層の指輪 **35%** / I10 補修石 **50%** |

- **撃破した敵1体ごと**に、ドロップアイテムのそれぞれを**独立判定**する。複数種類を落とす場合も、何も落とさない場合もある。ドロップ率の合計は100%でなくてよい。
- 上記ドロップ率は**敵レベルで変化しない（仮）**。敵の出現率や宝箱の抽選率とは別。
- EXP／Goldは撃破時に**獲得**、アイテムの有無とは独立。敵の基礎値×敵Lv補正の詳細は共通戦闘仕様を参照。
- 宝箱の入手確率は[FLOORS.md](FLOORS.md)、イベント報酬は[EVENTS.md](EVENTS.md)、黄金像の抽選は[SHRINE.md](SHRINE.md)で管理。

## 敵固有の行動パターン（候補）

- **E01 / E02**：汎用AIで通常攻撃主体。
- **E03**：高い素早さで先行し、目くらましを使用する候補。
- **E04**：攻撃優先。強打を使用する候補。
- **E05**：HPが減ったら守りの構えを使う候補。
- **B10**：強打を周期的に使う案。行動周期・優先目標・個別状態耐性は本台帳に追加する。

汎用AI・命中・ダメージ・状態異常は[COMBAT.md](COMBAT.md)、**スキルの効果・消費SPは[SKILLS.md](SKILLS.md)のみ**に書く。将来、個別敵の行動表・敵グループ・ドロップ条件を追加する。**旧ブラウザ版とは別の設計データであり、現在はコード未反映。**
