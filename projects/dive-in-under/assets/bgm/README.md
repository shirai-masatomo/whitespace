- **音源配置先**：`projects/dive-in-under/assets/bgm/adventure_preparation_loop.ogg`

## 0.6.2への実装

- 起動中のゲームルートが保持する `ui/preparation_music.gd` と単一AudioStreamPlayerを利用。
- `AudioStreamOggVorbis.loop=true`、`loop_offset=0`。`finished`通知による再生し直しを使わず、Godot内蔵ループを使用。音源そのものは変更しない。
- 冒険準備／ステータス4タブ／倉庫／装備は同じ再生を継続。町でのアイテム操作・表示更新でも再開しない。
- 専用BGMバス初期値 **−16 dB**。Master・効果音の音量は変更しない。`set_gain_db`で将来の設定UIから調整可能。
- 開始時0.35秒フェードイン。出発／タイトルへ移動時0.7秒で無音までフェードアウトし停止。帰還後の準備画面で再開。フェード途中に戻っても古い停止処理を取り消す。
- クラウドの隔離Windows EXEで変更箇所のみ確認する。結果と試聴用の実ゲームPCMを [BGM導入レビュー](../../review/bgm-0.6.2/README.md) に記録済み（CI39236684696成功、最終隔離EXE15.483秒）。通常入口／ZIPへ0.6.2を反映済み。通常プレイから検証処理へ入らない。
- 実装確認と利用者の聴感・採用評価は分けて記録する。実PCの音声機器／既存効果音との聴感バランスは利用者の確認待ち。

## Dive In Under 実装担当への依頼

1. 指定されたOggファイルを、上記パスに配置しGodot側のインポートを確認する。既存のBGM配置慣習があればそれに従い、本書の参照パスも更新する。
2. 地上の「冒険準備」ハブで繰り返し再生する。ステータス／倉庫／装備など同一ハブ内の切替では頭から再生し直さない。
3. ダンジョンへ出発した際はBGMを停止または短くフェードアウトし、ダンジョン用曲（未制作）を勝手に作って差し替えない。
4. OGGの途切れないループ再生を確認する。二重再生・画面遷移時の重複AudioStreamPlayerを防ぐ。
5. SFXや操作音より大きすぎないように音量を調整し、BGM音量は将来調整可能にする。
6. Windows実行時に音が鳴ることを確認し、採用・未実装・未検証の状態と確認内容を報告する。

作業範囲は `projects/dive-in-under/` のみ。既存の工程1の実装、確定仕様、他のWhiteSpaceゲームには影響させないこと。
