## Dive In Under 実装担当への依頼

1. 指定されたOggファイルを、上記パスに配置しGodot側のインポートを確認する。既存のBGM配置慣習があればそれに従い、本書の参照パスも更新する。
2. 地上の「冒険準備」ハブで繰り返し再生する。ステータス／倉庫／装備など同一ハブ内の切替では頭から再生し直さない。
3. ダンジョンへ出発した際はBGMを停止または短くフェードアウトし、ダンジョン用曲（未制作）を勝手に作って差し替えない。
4. OGGの途切れないループ再生を確認する。二重再生・画面遷移時の重複AudioStreamPlayerを防ぐ。
5. SFXや操作音より大きすぎないように音量を調整し、BGM音量は将来調整可能にする。
6. Windows実行時に音が鳴ることを確認し、採用・未実装・未検証の状態と確認内容を報告する。

作業範囲は `projects/dive-in-under/` のみ。既存の工程1の実装、確定仕様、他のWhiteSpaceゲームには影響させないこと。
