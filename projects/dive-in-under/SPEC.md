# Dive In Under — 全体仕様 v0.1

> **この1本が入口。** 確定事項はユーザー指定に基づく。数値・主人公死亡時の扱い等は「試作案」であり、決定事項ではない。

## ゲームの核
地上で準備 → 地下を1階ずつ降りる → 戦闘・宝・イベント → 続行か帰還 → 戦利品と育成を次の探索へ。**地下では基本「潜る」「地上に戻る」の2択**。引き際・装備・仲間・成長が判断の中心。マップ探索は将来拡張。

## 地上
- **倉庫**: 所持品と保管品を出し入れして整理。
- **支給所**: 探索用物資を支給。支給品は倉庫へ保存できない。
- **黄金像**: 探索に潜るたび祈りを1回行え、アイテム／装備品／動物・魔物の仲間を獲得。候補は到達深度で変化。
- 将来: 町・施設・探索と連動する地上イベント・仲間の加入。

## 地下
- フロアの遭遇種別: 戦闘 / 宝 / イベント。**「ランダム」はそれらを抽選する枠**として試作し、意図との違いは確認する。
- 階層ごとに遭遇候補と重みを設定。原則は戦闘が最大比率。完全な三等分ではない。
- **10F、20F、30F…にボス**。地下1F、11F、21F…はその地点に**一度到達したら開始地点として解放**（初期は1F）。
- 地下へ進むほど敵の強さ・経験値・取得報酬の水準が上がる。低レベルの仲間を深く連れると早く育つが死亡リスクが高い。
- 将来: 特定フロアを自由に探索する機能。

## 仲間・戦闘・成長
- **戦闘は全自動**。装備、アイテム、スキル、仲間構成が重要。方式の詳細は検討中。
- 仲間は**人 / 動物 / 魔物**。死亡は基本的に永久離脱、例外的に戻る者もいる。
- 全員にレベルあり。主人公はレベルに応じ選択可能なスキルが増え、地上で自由に構成変更できる。仲間は固有スキルまたはランダムなスキル構成。
- **人間の装備枠9つ**: 頭・上半身・下半身・足 / 首・耳・目・指・腕。動物・魔物は当面装備・装飾品なし。
- 装備には耐久値。減ると性能低下、0で破損表示・性能0。修復手段あり。
- **武器の専用枠は未指定**。試作では基本攻撃力＋9枠の能力補正で成立させ、武器枠追加は後で検討。

## 管理と区切り
- 最初の制作目標は**地下1〜10Fを実際に試せる小さなプロトタイプ**。ゲームデザインと数値の調整を優先し、本格的なグラフィック・大量データは後回し。
- [階層](docs/FLOORS.md)から[敵](docs/ENEMIES.md)・[仲間](docs/ALLIES.md)・[アイテム](docs/ITEMS.md)・[イベント](docs/EVENTS.md)のIDへ参照する。
- [戦闘](docs/COMBAT.md) / [黄金像](docs/SHRINE.md) / [10F試作](docs/PROTOTYPE_10F.md)を分離。
