## ブランド方針

- **WhiteSpace**: 一般向けを含むゲーム・実験作品の制作母体。
- 将来、成人向け等でブランドを分ける必要が生じた場合は **BlackSpace（仮）** など別ブランドを検討する。
- ブランド名と法的な会社・販売者名は別問題として扱い、必要になった時点で整理する。

## リポジトリ方針

当面はモノレポとして `whitespace` 内に複数プロジェクトを置く。

各ゲームが次のいずれかに到達したら、別repoへの切り出しを検討する。

- 独自のゲームエンジン/依存関係が大きくなる
- CIやビルド時間が他作品に影響する
- Steam等の公開・保守を独立管理したい
- 外部コラボや権限分離が必要
- 成人向け等でブランド/公開範囲を明確に分けたい

切り出す場合もWhiteSpace側には索引と方針だけ残す。
