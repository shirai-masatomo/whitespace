# IDEAS — DIVE DIVE

下方向へ進むOnly Up系。海上から飛び込み、自然沈降・E急降下・Space浮上で足場と酸素を狙う。足場で下降停止、補給は接触で瞬時に満タン。失敗しても世界を切らず深度を失う。圧力・待機回復・円筒ステージは現行仕様ではない。

現在案は泡化して浅い訪問済み地点へ高速浮上。別案は身体を保ったまま緊急浮上。まず移動の連続性と失う深度を検証し、見た目だけの別案を大量実装しない。

横に動くコンテナは実装済み。次は足場を経由する価値と上下操作の感覚を [REVIEW_PACKET](REVIEW_PACKET.md) で評価し、1区間の光・着地・素材を磨く。海流や回転足場はその後の候補。敵・魚・装備・Steam SDKはまだ入れない。

ビジュアル目標はOnly Up級の3Dインディー。照明 → 水/Fog/Post Process → スケール → 足場/ランドマーク → マテリアル → 環境アセット → 演出。現在は初期の方向試作。Godotの具体的な制約が出たときだけUE5移行を検討する。
