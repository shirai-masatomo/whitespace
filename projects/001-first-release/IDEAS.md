# IDEAS — DIVE DIVE

## 今検証する核

下方向へ進むOnly Up系。何もしなければ沈み、足場で止まる。酸素があるうちに次の補給地点へ到達する。失敗すると深度を失うが、ゲームの流れは切れない。
2026-09-19の人間レビューで、この核へ変更済み。圧力・待機回復・円筒ステージは現行仕様ではない。

## 失敗表現

- 現在案: 酸素0 → 泡化して高速浮上 → 最後の補給地点で再形成。その地点と深度が近すぎる場合は一つ前へ。
- 別案: 身体を保ったまま緊急浮上し、安全地点に着地。損失ルールは共通で、移動の連続性を優先。
