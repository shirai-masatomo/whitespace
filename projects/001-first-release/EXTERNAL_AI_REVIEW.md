## P0-1. L1-P1: 岩橋が「自然な場所」より「作った橋」に寄る

`l1_landforms.gd` の `BrokenSkyBridge` は単調さを崩す操作差として有効。一方、同じ `PROFILE` をspineに沿って掃引する `mass()` 生成で、実装者自己批評にも「人工的な角張り」が残る。

次はルートを増やさず、**橋に見える形を侵食された岩棚/隆起の欠け/アンダーカットへ寄せる**。

- 上ルートは連続する自然な岩棚として読ませ、端部を左右非対称に崩す
- 下側の湾は単なる橋の裏ではなく、海藻・魚・泡・視界変化など最低1つの観察理由を持たせる
- 入水後の通常視点から、正面/横/下の2〜3個の「気になる場所」が読めるようにする。ただし全部を別ルートにしない
- 岩橋だけが主役になりすぎず、遠景/中景/近景の層を作る

対応: **DD-068 / DD-069 / DD-055**。

## P0-2. L1-P2/P3: 断層・隆起は増えたが、生成則が共通で反復感が残りやすい

`l1_landforms.gd::mass()` は同一PROFILEを各spineへ掃引し、幅/高さもsin/cosで変形する方式。`ocean_geometry.gd::fault_block()` もloftベース。大きさと位置は変わったが、**異なる地質が同じ生成家系に見える危険**がある。

約160m以降で欲しいのは「岩が増えた」ではなく、岸壁に包まれ、上下/横/内部の遊び方が変わる場所。

- 160m前後を左右/奥/一部頭上の2〜4個の独立した巨大岩体で囲む
- 同じ掃引輪郭を連続させず、片側は断層面、片側は崩落、別側は張り出し/棚など主形状を変える
- 岩階段・段丘・狭棚は**実際に歩く→見渡す→泳ぐ**操作差へ接続する
- 見える棚/穴/張り出しのうち高い割合が実際に到達・通過・回り込み可能であること
- 小物で大面を隠すのではなく、シルエットと大形状から直す

対応: **DD-065 / DD-070 / DD-084 / DD-067**。

## P0-3. L1-P4: 盆地への収束は正しいが、数式的なボウル/線に見える危険

`biology_layout.gd::sand_height()` はゲートからの距離で最大約125m持ち上げるshoulderと、1本のgully式で収束を作る。導線は強くなったが、実装者自己批評の通り砂の筋が「演出的な線」に見えやすい。

- 放射状の大きなボウル1面ではなく、砂丘・侵食溝・露出岩盤・崩落塊・海藻帯の2〜4場所へ分ける
- ゲート方向は直線模様で示すより、地形の低まり＋砂リップル＋浮遊粒子＋海藻の向き＋泡を組み合わせる
- 歩く砂地 / 岩肩を回る / 谷へ泳ぐ、の行為差を画面から読ませる
- L1-P4では選択肢を増やさず、自然にL1-Gへ収束させる

対応: **DD-081 / DD-067**。
