## P0-1. L1-P1: 「岩窓」がまだ人工アーチへ寄りやすい

`l1_landforms.gd` の `WindowAboveGarden` は seed 53 の時だけspineをcubic補間するが、断面は他の大岩と同じ `PROFILE` を閉じたまま掃引している。魚群を通す目的地は良い一方、形の生成家系が同じなので、自然侵食より「作った輪/アーチ」に見える危険が残る。実装者自身も模型感を認めている。

次:

- 完全な輪を見せるより、**片側が岸壁へ根付き、屋根の一部が崩れた非対称な岩窓**へ寄せる
- 端部を左右で異なる崩れ方にし、同じ断面が一周していることを見せない
- 正面/横/下に2〜3の「気になる場所」は維持。ただし全部を別ルートへしない
- 岩窓単体を主役にしすぎず、近景の岩・中景の生物/藻・遠景の岸壁で奥行きを作る

対応: **DD-055 / DD-068 / DD-069**。

## P0-2. L1-P2/P3: 可遊棚は前進、しかし6枚の棚が「地層プレート列」へ寄る危険

新規 `cliff_shelves.gd` の6つの `bed()` は、同じ24×18格子、同じ `point()` 生成則、同系統のscallop/tiltで作られている。足場を岸壁へ接続したことは明確な前進だが、**生成則が共通なので上/中/下の棚が平行な層板の反復に見えやすい**。

約160m以降で必要なのは「棚の枚数」ではなく、周囲を包む異なる巨大主形状と、その中に埋め込まれた移動差。

次:

- 2〜4の独立巨大形状へ整理し、**片側=断層面 / 別側=崩落楔 / 別側=張り出し・アンダーカット / 奥=根付いた隆起**のように生成家系を変える
- 6枚すべてを残す前提にしない。似た棚は削る/統合し、シルエット差を優先
- 棚同士を平行に積まず、角度・根元・端部・厚み・天井の抜け方を大きく変える
- 岩階段/段丘は **歩く → 見渡す → 泳ぐ** のリズムへ繋げ、見える穴/棚/張り出しの高い割合を実際に到達・通過可能にする
- 小物で大平面を隠さず、大形状と輪郭から直す

対応: **DD-065 / DD-070 / DD-084 / DD-067**。

## P0-3. L1-P4→L1-G: 導線は良くなったが、まだ数式的な盆地＋線配置

`biology_layout.gd::sand_height()` は前回同様、ゲートからの距離で持ち上げる大きな `shoulder` と1本の `gully` が中心。さらに `biology_world.gd` の露出岩盤15個は `x=-16+i*4.8` / `z=-94-i*2.3...` の規則列で置かれるため、自然地形ではなく「誘導用に並べた列」へ見える危険がある。`mouth_outline()` も波打たせた楕円が基本形で、形としての割れ目はまだ弱い。

次:

- 一枚ボウルではなく、**砂丘 / 侵食溝 / 露出岩盤肩 / 崩落塊 / 海藻帯**から2〜4の異なる場所へ分ける
- 露出岩盤を直線配列せず、大小・角度・密度・欠けを塊ごとに変える
- L1-G入口はノイズ付き楕円穴ではなく、**2〜4個の岩盤が噛み合って生じた最深の隙間**として構成する
- 地形の低まり＋床を走る砂粒＋海藻の向き＋泡＋実潮流で収束を読ませ、一本道UIや一直線の目印にしない
- 選択肢は増やさず、海底到達→最深部の発見→隙間へ吸い寄せられる流れを強くする

対応: **DD-081 / DD-078 / DD-067**。

## P0-4. L1-G / L2-P0: 「管」問題は未解消で最優先のまま

入口の輪郭と潮流は改善したが、`biology_world.gd::make_throat()` は依然として100段×32断面の**連続した閉じた環状メッシュ**。`throat_point()` も同じ断面をPATHへ沿わせ、outside側は一定量膨らませる方式。これは前回レビューで指摘した「岩盤の隙間」より「作られた管」に見える根本原因そのもの。

次:

- 連続管をやめ、左右壁/天井/床を **2〜4個の独立した巨大岩体** へ分解
- 区間ごとに幅・高さ・傾き・片側の開き・低い天井・短い空洞を大きく変える
- **狭い → さらに狭い → 短い抜けの予感 → L2の暗闇** を段階化
- 潮流は方向を感じさせる程度にし、現状のSpace離脱を維持。自動搬送だけで通過させない

対応: **DD-078 / DD-082**。
