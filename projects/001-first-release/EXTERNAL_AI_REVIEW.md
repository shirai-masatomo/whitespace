## 最優先の修正

1. **真下に進むだけのマクロ構造を壊す**
   - 足場やギミックを縦に追加するだけでは不足。0〜300mを上から見た時に、主要ルートが同じXZ付近へ積まれていないかを確認する。
   - 岸壁沿い / 沖 / 洞窟内部 / 岩礁上 / 縦穴の途中横穴など、数十m単位で横方向に分岐し、しばらく別の景色・操作を体験してから再合流する経路を作る。
   - 「一番速いから真下へE」が常時最適にならないよう、未知・酸素・潮流・安全・発見の価値を別方向へ置く。

2. **入水直後の『海！』を一段作り直す**
   - 最初の15〜30秒を独立した品質ゲートとして扱う。水面を割る瞬間、上の揺れる光、海面の反射/透過、細かな泡、浮遊粒子、魚群の反応、浅海の色、遠近の岩礁、音の切替を一体で見直す。
   - 現在の巨大泡はゲームギミックとしては有望だが、それが最初に強く見えることで「自然の海へ飛び込んだ」感覚を弱めないかも比較する。最初は自然の豊かさ、その後に少しずつ異物感を混ぜる案を試す。

3. **景観密度ではなくプレイアブル密度を上げる**
   - 現状は大きな海・岸壁・岩景観に対して、実際に歩く/入る/通る/利用する場所が少なく、背景の中に少数の遊び場がある構図に見える。
   - 目立つ前景・中景の岩礁、棚、裂け目、アーチ、海藻帯、洞窟の多くを「行ける / 入れる / 回り込める / 上に立てる / 別出口がある」のいずれかへ変える。
   - 全背景をコリジョン化する必要はないが、**行けそうに見える主要地形が実際に遊べる割合**を増やす。レビュー時は代表カメラごとに「見える主要ランドマークのうち何個が探索可能か」を記録する。

4. **実際の自然を構造の参考に使う**
   - 岩礁海岸、海中アーチ、海食洞、ケルプフォレスト、サンゴ礁の通路、海底谷、崖下のオーバーハング、浅海の光芒などの実写真を参考にしてよい。画像資産を無断流用するのではなく、自然の不規則さ・密度・重なり・視線の抜け方・スケール感をゲーム用3Dへ翻訳する。
   - 「自然よりゲーム空間の方が単純」ならCHANGESとする。岩を増やすだけでなく、穴・庇・割れ目・段差・枝分かれ・内外ルートを持つ複合地形にする。

5. **面白さ仮説の自律駆動を止めない**
   - DD-054を完了報告で止めず、最低3つの異なるマクロ空間仮説を短く比較する。例: A 開けた浅海→複雑な岩礁迷路、B 岸壁と洞窟の内外を往復、C 青い外洋とプレイ可能な巨大リーフ壁。
   - 各案で「どこを見た / なぜ横へ行った / 何を発見した / 酸素で何を諦めた / 直前30秒と何が変わった」を記録し、弱い案を削除する。
   - 現在の泡・潮流・アーチ・巨大影も既得権にしない。海の体験を弱めるなら作り直すか捨てる。
