# DIVE DIVE — EXTERNAL AI REVIEW

更新: 2026-09-20
対象: 最新の探索試作（巨大泡 / 曲がる潮流 / 岩の穴 / 巨大生物）と最新人間方針

## 判定: **CHANGES / SELF_CONTINUE**

現在は機能追加量に対して、**画面・空間・場所としてのクオリティー向上が弱い**。人間レビューへ戻さない。

### P0-1. クオリティー停滞を止める
泡・潮流・穴・生物などの機能数を増やすだけでは改善とみなさない。
各改善サイクルで代表画面を比較し、以下が前版より明確に良くなっていることを要求する。

- 構図
- 地形の複雑さ
- シルエット
- 自然な密度差
- 背景とプレイ領域の一体感
- 生物の存在感
- 足場/地形の意味の読みやすさ
- 「ここへ行ってみたい」と感じる場所の数

見た目がまだプロトタイプ然としている場合はCHANGESのまま続ける。

### P0-2. 160m付近から地形に包まれる
海面〜序盤は広大な「海！」を優先する。
約160m付近から岸壁・岩礁が徐々に近づき、左右/奥に地形が入り、海そのものがプレイ空間へ変わる構成を試す。
いきなり狭い通路にせず、
**開放海 → 岸壁の気配 → 半囲い → 岩礁/峡谷 → 複雑な内部**
という段階を作る。
深度160mは目安で、画面と遊びを見て調整可。

### P0-3. 足場の形を根本的に増やす
平たい単岩の反復を禁止。
少なくとも次の異なる地形表現を比較試作する。

- 岩の階段
- 段丘状の連続棚
- 歩ける岸壁
- 傾斜面
- 狭い岩棚
- 割れ目を跨ぐ地形
- アーチ上下
- 岩壁内部/外側

「岩の種類が違う」ではなく、**移動の仕方が違う**ことを基準にする。

### P0-4. 景観とプレイアブル領域を一致させる
見えている岸壁・岩棚・穴・裂け目の相当部分へ実際に行けるようにする。
大きな背景の中に小さな足場だけが浮く構図を避ける。
160m以降は特に、岸壁そのものを歩く/入る/回り込む/飛び降りる対象にする。

### P0-5. 不要ファイル・古い試作を整理
現行開発に不要な一時成果物、重複した古いレビュー画像、使われていない試作資産、不要な生成物を監査して削除する。
ただし以下は残す:
- 現行コードから参照される資産
- 最新REVIEW_PACKETから参照される証跡
- 再現/回帰検証に必要なデータ
- Git履歴で十分に追跡できない必須資料
削除後にリンク切れ・参照切れ・build/check失敗がないことを検証する。

### P0-6. ギミックを点ではなく場所へ統合
巨大泡・潮流・穴・生物を順番に置くだけでは新しい岩→岩。
一つの場所の中で複数の要素が交差する設計を試す。
例: 岩階段→岸壁棚→泡で上側横穴→潮流を途中離脱→別の棚へ、など。

## 自己レビューの追加質問

1. 前版と比べ、スクリーンショット1枚だけでも品質向上が分かるか。
2. 足場の形ではなく、移動体験が何種類あるか。
3. 160m以降に「地形へ入り込んだ」感覚があるか。
4. 見えている岸壁のどこまで遊べるか。
5. 新しい機能を消しても、その場所自体に魅力があるか。
6. 不要な試作資産が残っていないか。
7. 今回の変更は「機能追加」なのか「品質向上」なのか。後者が弱ければ続行。

## 次回HUMAN_REVIEW条件

まだ不要。

次に上げるには最低でも:
- 入水直後の「海！」が明確に強化
- 160m前後から岸壁に囲まれていく空間変化が成立
- 岩階段など足場/地形の移動バリエーションが複数成立
- 景観に対するプレイアブル密度が上昇
- 代表画面で前版よりクオリティー向上が明確
- 140m以降の岩反復から脱却
- 不要ファイル/古い試作が整理済み
- 実衝突/CI/PC非干渉を維持

それまでは **CHANGES / SELF_CONTINUE**。
