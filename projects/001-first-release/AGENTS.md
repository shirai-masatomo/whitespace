# DIVE DIVEの作業開始

このディレクトリに適用する。他作品の自律ルールは変更しない。

現在は**面白い空間・地形・探索構造を速く発見する試作フェーズ**。完成保証やテスト網の拡大を目的にしない。30分の自動再開はPAUSEDのまま。

1. セッション開始時にSTATE/TASKS/AUTONOMYと人間・AIレビューを読む。Git状態と最新mainの正本2文書を確認し、未反映指示を既存P0/P1へ具体化。他の変更を上書きしない。
2. 前回の検証結果と今回の差分から必要な確認を選ぶ。開始時に毎回フルcheckを実行しない。
3. 通常は「実装 → 軽い起動 → 変更箇所の操作 → 代表画面1〜3枚 → 自己批評 → 次の試作」。弱い案はすぐ修正/破棄する。
4. 大きな地形、移動/physics、collision、酸素/救助など中核変更、人間レビュー候補、merge前、Release候補では重い検証をまとめる。詳細はAUTONOMYの検証選択表。既知の不具合は隠さない。
5. 関連する数回の試作を1制作サイクルとして、必要なcheck/衝突/GPU確認、最小限のSTATE/TASKS更新、commit/push、CI確認をまとめる。小変更ごとにCI待ちで制作を止めない。
6. AI_REVIEW/REVIEW_PACKETの詳細更新と多数の画像保存は節目だけ。通常は既存結果を上書きし、文書を日記にしない。

品質基準とHUMAN_REVIEW条件は維持。テスト成功や物量だけで完成・面白さを認定しない。制作時間を優先し、最新ユーザーの指定範囲内で進める。

PC非干渉: 通常headless/background、GPUは必要箇所だけ画面外・無音・非捕捉。人間のアプリ/ゲームを終了しない。定期開発は人間の再開連絡まで停止。
