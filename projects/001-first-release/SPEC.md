# DIVE DIVE — 世界観とゲーム仕様

> この1冊がプレイヤー向けの企画・仕様の入口。今動いていることと、構想・未実装を分ける。過去3D版の詳細や検証ログは開発者用資料へ。

更新：2026-10-15（基準は2026-09-28の2D通し試作）。

## 1. 世界・体験

海へ飛び込み、より深い層へ潜っていく2D探索アクション。海中の広大さ、徐々に狭まる岩の裂け目、暗闇、生物、人工物、神話、星々、最深部へと景色が変わる。「さらに先へ進みたい」と思わせる発見と、進路選択・酸素管理を核とする。

死や頻繁なリセット画面ではなく、酸素切れ時に泡となり、最後に通った補給地点へ戻る**連続再挑戦**を採用する。物理的なリアリティより、独自の景観と発見を優先する。

**現在の主開発は2D**。かつての3D版は凍結保存。2Dの地形・キャラクターは読みやすいピクセルアート。光、泡、藻、生物などに限定して質感を深め、全面のぼかしや過度な高解像化はしない。

## 2. ゲームの進み方（現行）

海上の陸から始まり、右へ歩いて入水。最初は一本道、深く潜るにつれ複数のルートを選べるようになり、重要なゲートで再び合流する。酸素補給を探しつつ、岩、砂、段丘、空気の洞窟、沈没船、遺構などを通過して最深部へ。

| 層 | 体験（現行2D通し試作の実移動深度の目安） |
|---|---|
| L1：浅海・リアル層 | 入水から岩棚・泡・酸素藻・分岐、砂の海底と裂け目へ。約0〜450m |
| L2：生物層 | 暗い狭路、水球の光、開けた巨大空間、影・触手・巨大タコ。約480〜720m |
| L3：人工物層 | 沈没船の内部、折れた通路、空気の船室。約730〜960m |
| L4：神話層 | 発光する庭、柱や屋根、玉手箱。約960〜1390m |
| L5：宇宙層 | 紫の星海、惑星、上昇流、動くクラゲ。約1390〜1820m |
| L6：深淵 | 再び狭くなる最深部、最後の光とエンディング。約1820〜1960m |

構想上の「約11,000m」は未実装の目標であり、現在の2D版は圧縮された**約1960mの通し試作**。9つの「海の記憶」は任意収集。巨大タコは遭遇演出で、ボス戦ではない。

## 3. 操作と共通ルール

| 操作 | 効果 |
|---|---|
| A / D または左右キー | 横へ歩く・泳ぐ |
| Space長押し | 浮上／空気中ではジャンプ |
| E長押し | 急降下。酸素消費2.5倍 |
| 左クリック | クリック位置へ移動（壁は自動迂回しない） |
| Shift＋左クリック長押し | 近くの岩・砂を採掘 |
| 右クリック | 掘った岩の配置 |
| Esc | 一時停止 |
| R | 最初からやり直し（停止時・到達後） |
| M | 音の切替 |

自然沈降・浮上・急降下を使い、岩階段・足場・潮流を越える。藻・大泡・光る水球に触れると酸素が100%へ戻る。空気の洞窟では呼吸と歩行が可能。酸素切れで泡となり経路を戻って安全地点から再挑戦。硬い岩盤や船体等は掘れない。進路を助ける右上の深度マップは6層と現在位置・到達率を表示し、ワープや最適経路を自動表示しない。

## 4. 景観とレベル設計原則

- 序盤は目的が分かる一本道。段階的に開けて複数ルート・探索の自由を出し、海底で一度収束。
- 「広大→狭い→開放→人工物→幻想→宇宙→深淵」という空間リズム。
- 掘る・岩を置く・寄り道する自由を残し、単なる真下移動の連続を避ける。
- 進路目印は光る藻・泡・水球・景観の形。目立つが邪魔にならない。
- Godot Editorで動かした地形・ランドマーク位置を正本として扱い、起動時にコードで元の座標へ戻さない。

## 5. 現在できること／未完成

**現行**：6層通し・エンディング・救助・採掘と配置・クリック移動・深度マップ・一部の演出が動く。

**未完成**：製品品質の本格的な地形・後半アート、戦闘／ボス戦、セーブ、クラフト、Steam SDK、オンライン。3D開発は停止中であり、2Dの自動定期開発再開も一時停止。
