# AUTONOMY — DIVE DIVE

共通方針は[WhiteSpace 自律運用](../../docs/AUTONOMY.md)。現在は高速試作、**定期自動再開はPAUSED**。過去の常設許可より最新の停止・指定範囲を優先する。

## 開始と対象選択

1. `git fetch origin main`。mainのHUMAN_DIRECTION / EXTERNAL_AI_REVIEWを読み、作業ブランチの内容と比較する。新しい会話指示を古いmainで上書きしない。
2. PROJECT_STATE → TASKS → AI_REVIEW / REVIEW_PACKET → Git/CI。他セッションの実行・未commit変更を上書きしない。
3. 空間構成の正本は[HUMAN_DIRECTION](HUMAN_DIRECTION.md)。**L=層、P=層内フェーズ、G=層間ゲート**。作業対象を1つ選ぶ。ユーザー指定を優先し、隣接接続に必要な修正以外へ広げない。
4. 最新方針の未反映部分を対象ID付きタスクへ具体化。DD番号はタスク識別子として維持し、優先度は最優先/高/通常と書く（層内P番号と区別）。深度は可変、試作の実深度と計画目安を分ける。

## 通常サイクル

実装 → 軽い起動/対象操作 → 自己批評 → 次案。何を見て何を選ぶか、直前区間との変化、地形と可遊域の一致を評価する。複数案を小さく試し、弱い案を削除・修正する。機能数・完走率で面白さを判定しない。

| 変更 | 検証 |
| --- | --- |
| 文書/レビュー資産整理 | 差分・リンク・コード/テストからの参照。ゲーム変更がなければ起動/build不要 |
| 小物・材質・局所地形 | 軽い起動、対象操作、必要なら変更面の接触だけ。毎回全経路/全renderer/全画像を回さない |
| 大地形・physics・collision・酸素/救助 | 関連案をまとめた節目にcheck・影響経路/衝突・必要なbuild/CI |
| merge前・レビュー候補・Release候補 | full check、必要なGPU/Windows build、対象SHAのCI成功 |
| 性能に疑い | 対象箇所の測定。全benchmarkは通常サイクルに含めない |

数案を1制作サイクルへまとめ、TASKS状態とSTATEの重要変化だけ更新してcommit/通常push。詳細なAI_REVIEW/REVIEW_PACKETは節目だけ。既知のCI失敗・操作不能・すり抜けは放置しない。

## スクリーンショット

ユーザー/外部AIから特定L/P/Gの画面確認依頼が来た時だけ、原則2〜4枚（入口/中間/出口/問題）を撮る。通常の確認は画像保存なし。既存GPUテストは撮影対象を明示した時だけPNG保存、連続JPGは明示オプション時のみ。全visualを毎回実行しない。

保存先は `review/<対象ID>/entry.png` / `middle.png` / `exit.png` / `issue.png`。必要なものだけ使い、修正後は同じファイルを更新。REVIEW_PACKETに対象commit・対象ID・実深度・撮影条件を短く記載する。未撮影のフェーズを撮影済みと扱わない。

古い画像はコード/README/REVIEW_PACKET/検証/回帰テストの参照を調べ、リンクを更新して削除。古い連続画像ビューアとマニフェストも用途がなくなれば一緒に整理。生成テスト/ゲーム素材は保持し、履歴はGitを正本とする。削除前に対象パスがプロジェクト内であることを確認する。

## 自律判断と停止境界

技術選定、小規模機能、地形/演出の可逆な試作、数値、バグ修正、リファクタリング、テスト/CI、文書整理、通常commit/pushは再承認不要。2026-09-20の常設許可は保持するが、**30分再開は停止中**。指定作業の完了は自動再開の許可ではない。

人間が必要: 核そのものの変更、成立案の好み、AIでは判定困難なプレイ感、重要な創作判断、有料サービス、権利/ライセンス重大判断、実公開/契約/販売、秘密情報操作、不可逆な重要データ大量削除。force push/履歴書換え/人間のプロセス強制終了は常設許可外。

外部AIレビューは毎回読む。過去の全区間分岐/後続層禁止/毎回撮影という指摘は最新HUMAN_DIRECTIONで更新済み。外部レビュー原文を書き換えて合格を捏造しない。同一実装者の自己レビューを独立レビューと呼ばない。品質はCHANGESで保持し、実装終了だけでHUMAN_REVIEWへ移らない。

GPUは画面外・無音・非捕捉、通常headless。終了できるのは自分が開始し所有を確認した検証プロセスのみ。人間のゲーム/アプリを妨げない。
