# AUTONOMY — 001 First Release

## 原則

人間へ細かく確認するより、可逆で小さい変更はCodexが自分で進める。

開始時:

1. `PROJECT_STATE.md`
2. `TASKS.md`
3. Git状態
4. テスト/ビルド状態

を確認し、依存が解決済みの最優先タスクを選ぶ。

作業後:

1. テスト
2. 自己レビュー
3. PROJECT_STATE更新
4. TASKS更新
5. Git記録

まで行う。

## Codexだけで進めてよい

- 小規模実装
- 試作
- テスト追加
- lint/format
- CI
- バグ修正
- 小規模リファクタ
- 技術調査
- 文書整理
- タスク分割

## 人間確認が必要

- どのゲームを正式に作るか
- ゲームの核を変える変更
- 有料サービス/API
- 外部アカウント作成
- Steam等の契約/支払い/公開操作
- ライセンスや成人向け区分に影響する判断
- 大規模削除・不可逆な移行

## ドキュメント

人間が読む資料は短くする。新規文書は、既存文書へ統合できない場合のみ作る。
