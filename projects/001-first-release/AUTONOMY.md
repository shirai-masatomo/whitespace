# AUTONOMY — DIVE DIVE

**運用モード: 完全自律型**

共通ルールは [WhiteSpace 自律運用](../../docs/AUTONOMY.md) を正本とする。このファイルにはDIVE DIVE固有の例外・判断境界だけを書く。

## 毎回のループ

PROJECT_STATE → TASKS → Git状態/最新main → build/test → 依存が解決した最優先タスク → 実装 → 自動テスト/可能なら画面・入力確認 → 自己レビュー/修正 → STATE/TASKS更新 → commit → GitHub更新/CI確認。

開始・終了の品質ゲートは `./dev.ps1 check`。見た目・入力を変えたら `./dev.ps1 visual` と画面確認を加える。CI失敗をmainの通常状態にしない。別セッションの変更は上書きしない。

## Codexが判断する

技術選定、実装、テスト、リファクタリング、CI、バグ修正、タスク分割、GitHub更新、環境改善、可逆な仮の数値調整。合理的な仮定を記録して進め、細かい許可待ちにしない。

仕様は可変。酸素・泡化・移動・ステージ・ゴール等が変わったら、既存コードを守ることよりゲームの核への適合を優先する。重要なデザイン判断では必要に応じ現在案と別案を2〜3案だけ示す。

## 人間が判断する

- ゲームの核・面白さ・世界観・大きな方向転換。
- 契約・支払い・有料API・外部アカウント・秘密情報・ストアへの実公開。
- ライセンス上の重大リスク、成人向け区分、不可逆な大規模削除。

DIVE DIVEの開始は承認済み。中核ループをWindowsで触れる初回試作が完成したら一度止まり、人間にプレイ感をレビューしてもらう。

## 文書と報告

新規説明文書は既存文書へ統合できない場合だけ。重要な環境問題はPROJECT_STATEの再実行メモ、過去の詳細はGit履歴。
報告は「作ったもの / 今どう遊べるか / Codexの判断 / 次3タスク」。重大な判断があるときだけ人間への項目を追加する。
