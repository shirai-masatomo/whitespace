DIVE DIVE / Windowsリアル層制作版

「DIVE DIVE.exe」をダブルクリック → 「潜りはじめる」。
WASDで桟橋の端から海へ飛び込んでください。
WASD: 水平移動 / マウス: 視点 / E長押し: 急降下（酸素消費2.5倍）
Space長押し: 水中で浮上 / Q長押し: 沈降を減速
F長押し: 俯瞰 / H: 道案内ON・OFF / Tab: 案内候補を切替 / V: 三人称・一人称切替
Esc: 一時停止 / M: 音のON・OFF / ウィンドウの×: 終了

水中では自然に沈み、足場に着地すると止まります。
泡を出す光る藻に触れると瞬時に酸素100%。補給中の待ち時間はありません。
普通の水中足場では酸素が減ります。酸素0で泡になって浅い安全地点へ。
死亡画面もロードもなく、戻った場所から再挑戦できます。
450mの「裂け目の先」に着地するとクリア。
岸壁を歩く道、沖のクラゲと流木、補給を省く近道を選べます。
300mより下は狭い裂け目と、外側を回る経路。道案内は初期OFFです。
俯瞰中も時間は進みます。見渡すなら補給地点へ。

セーブなし / オフライン / 日本語 / Windows x64 / Vulkan対応GPU（標準Forward+）。
起動できない場合は Play-Compatibility.ps1 でOpenGL 3.3版を起動できます。
景観と操作の方向を確かめるための試作で、完成ビジュアルではありません。
