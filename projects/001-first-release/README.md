# DIVE DIVE

**横視点で海中地形を探索し、海底の隙間から未知の生物層へ潜る2Dゲーム。** 現在は2Dが主開発対象。3D版は凍結保存、30分ごとの自動再開はPAUSEDです。

## 今すぐ遊ぶ

1. `build/windows-2d/DIVE DIVE.exe` をダブルクリック（通常起動が2Dになりました）。`Play-2D.cmd` でも同じ版を起動できます。
2. Enterまたは「海へ潜る」。右へ歩いて岸から飛び込む。
3. 序盤は共通の海路。約130mから岸壁内側・沖側の進み方を選べます。光る藻や大きな泡で酸素補給。岩・砂は掘れて、掘った岩を置くこともできます。
4. 岩階段・段丘・空気の洞窟を経て、約450mの砂の海底へ。砂と泡の流れを追い、最深部の裂け目へ入る。
5. 暗い狭路で青い水球を追う。約580mで巨大空間へ抜け、影→触手→巨大タコの順に遭遇。約680mの最後の光へ触れると今回の制作範囲に到達。

| 操作 | 動作 |
| --- | --- |
| A / D・左右矢印 | 横へ泳ぐ・歩く |
| Space長押し | 浮上。空気中ではジャンプ |
| E長押し | 急降下。酸素消費2.5倍。上昇流を突破できる |
| 左クリック長押し | 近くの岩・砂を掘る（硬い岩盤は不可） |
| 右クリック | 集めた岩を置く |
| Esc | 一時停止・再開 |
| R | 一時停止中または到達後、最初からやり直す |
| M | 音のON/OFF |

酸素藻・巨大泡・水球は接触で即100%。空気洞窟内は呼吸と歩行が可能。酸素0では泡になり、直前に通った道を戻って最後の補給点で再挑戦。死亡/ロード画面はありません。金色の「海の記憶」3つは任意の寄り道です。

**試作段階**。セーブ、戦闘/ボス戦、クラフト、Steam SDKは未実装。3D版もそれらは未完成でした。3Dと同じ到達範囲になっても、面白さ・製品品質が完成したという意味ではありません。

## 自分でレベルを編集する

`./dev.ps1 editor` → `game/two_d/ocean_layout.tscn` を開きます。

- `Landmarks` 内の酸素藻、水球、遺物、流木、クラゲ、潮流、タコ、最後の光を選んで移動。保存Transformを起動時に初期値へ戻しません。
- クラゲの `travel` は保存位置からの移動幅。流木・クラゲの回転/大きさは衝突と描画へ反映します。
- 潮流は `extent` が範囲、`flow` が向きと強さ。酸素藻と水球は移動先で補給でき、その周囲を生成時に空けます。
- `Passages` 内のPath2Dを選択し、Curve2Dの点を動かすと洞窟経路を変更できます。`radius` はタイル単位の幅。水色の帯はEditor上の掘り抜き範囲の目安です。
- 保存して `game/two_d/main.tscn` をF6、またはF5でゲーム全体を起動。

海面・初期岸・砂盆地・岩階段・巨大空間の補助生成は `terrain.gd` に残っています。OceanLayout全体の移動や、海底/巨大空間を大幅に移設する場合はこれらも調整が必要です。大移動後は経路の接続と補給位置を確認してください。完全な手作業タイルマップ化は未対応です。

## 開発と検証

- `./dev.ps1 play` / `play-2d`: 2Dを起動
- `./dev.ps1 test-2d` / `test`: headlessで2Dの連続操作・内外経路・衝突・救助・Editor配置を確認
- `./dev.ps1 lint`: formatter/lint/依存チェック
- `./dev.ps1 build`: Windows export、通常起動・2D起動smoke、ZIP作成
- `./dev.ps1 check`: lint → import → 2D検証 → build。CIもこの範囲
- 出力: `build/windows-2d/` / `build/DIVE-DIVE-windows.zip`

通常の試作は対象だけ軽量確認。全3D回帰は2D変更のたびには実行しません。GPU検証は画面外・無音・非捕捉。Godot 4.7.2とツールは `./tools/setup.ps1` でセットアップ。素材はオリジナルのコード描画と合成音、文字は同梱Noto Sans JP。Terrariaの素材は使っていません。
