# DIVE DIVE

**[世界観・ゲーム仕様（ここだけ読めばOK）](SPEC.md)**

現在の主開発は2D。海から最深部・エンディングまで遊べる圧縮試作です。3D版は凍結保存中。

ゲームの起動入口：`build/windows-2d/DIVE DIVE.exe` または `Play-2D.cmd`。Godot Editorからの編集は `game/two_d/ocean_layout.tscn`。

以下は開発者向けです：[開発状態](PROJECT_STATE.md) ／ [検証・旧タスク](docs/internal/README.md)。ユーザーが決める世界観・遊びの仕様は新しいファイルを増やさず、`SPEC.md` に集約して更新してください。
