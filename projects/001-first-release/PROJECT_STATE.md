アートはピクセル輪郭を維持し、水の深度色・薄い光芒・浮遊粒子、藻/水球の局所グロー、泡の反射、クラゲの半透明、タコの段階陰影を改善。物理・ルート・酸素ルールは変更していない。今回の4枚は[REVIEW_PACKET](REVIEW_PACKET.md)。
