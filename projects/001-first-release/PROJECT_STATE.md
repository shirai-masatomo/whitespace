- 約160mから段丘/狭棚/西の張り出し/東の崩落湾。入り江の既存藻を内岸へ移し、元の西岸の歩行面も保持。80%では内外どちらも補給できるが、70%では内側のみ到達し、外回りは同じ世界で救助となる。
- 入り江→岩窓→24m/sの潮→既存流木の経路。途中で岸へ戻る通し操作は22.45秒/最低15.07%。流木再合流は25.07秒/最低3.40%で、初見の安全路とは呼べない。
