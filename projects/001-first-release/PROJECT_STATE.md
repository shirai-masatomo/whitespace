## 再実行メモ

- `./tools/setup.ps1` → `./dev.ps1 check` → `./dev.ps1 visual`。ログ・生成画像はartifacts、配布物はbuild、レビュー用の選別画像はreview。
- Godotは終了コード0でもERRORを出す場合があるため、dev.ps1はログも検査する。権限制限下ではユーザーデータの作成に実行許可が必要な場合がある。
- 起動したままの配布EXEは再exportを妨げる。パス/プロセスを確認して、そのテストEXEだけ終了してからbuildする。
- 可変フォントのウェイトは整数のOpenTypeタグで指定。全ゲーム資産をexportし、tests/tools/build/artifacts/reviewは除外する。
- 足場の装飾上面と本体上面を同じ高さに重ねるとちらつく。装飾面だけを最上面に置く。
