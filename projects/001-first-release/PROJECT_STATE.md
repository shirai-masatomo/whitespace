## 現在動くもの

- 海上から入水、自然沈降5m/s、E15m/s・酸素2.5倍、Space6m/s。藻で即補給、酸素切れは同じ世界で救助。450mの既存経路。
- 浅海の藻庭から横へ入り縦穴へ抜ける裂け目。補給地点の先の縁を侵食斜面へ変え、内部を覗ける構図にした。縁の格子状の角を除き、内部の壁に窪みを追加。従来の岩礁歩行・空気洞・屋根/外側・泡上昇流も維持。
- 160〜240mは段丘/西岸の張り出し/下側の藻庭と、侵食された連続岸壁の内外経路。岩柱の反復を層状の欠けへ置換。125mから連続操作で歩行/遊泳できる。
- 張り出しからエイ/魚群を見に沖へ寄り、同じ藻へ戻る試作。満タンで約19.9秒、沖で酸素61.73%、35%開始では救助。生物接近を酸素以外の見返りとして比較中。近景のエイは紙状から曲面へ再制作。
- 通常の開始視点でも水面裏が平らな帯にならず揺らいで見える。左の20m巨大泡と右の藻庭が寄り道先。泡の奥のアーチを浅く奥へ再配置し、穴と支柱を予告。泡→潮流→アーチ→補給は実入力で約29.2秒。
- 最新ビルド出力は `build/windows-agent/DIVE DIVE.exe`。人間の `windows-preview` 等は置換しない。[起動方法](README.md) / [比較と測定](REVIEW_PACKET.md)。
