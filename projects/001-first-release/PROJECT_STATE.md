## 再実行と環境メモ

`./tools/setup.ps1` → `./dev.ps1 check`。画面変更は`visual`と`visual-reef`、描画比較は`benchmark -Renderer forward_plus/gl_compatibility`。詳細ログはartifacts、選別画像/測定はreview。Actionsはheadless、GPU画質はローカルで確認する。

使用中のEXEは上書きしない。未使用のBuildFolderへexportし、人間のプロセスを停止しない。外部--scriptによる配布EXE撮影は不採用、ソース実画面と配布EXE起動を分ける。Godotのexit 0でもERRORログを失敗扱いにする。

Dummy音声ドライバーでは再生を開始しない（headless終了時のWAV/playback残存を防止）。PCMとイベントはテストし、通常ドライバーは再生する。三人称で上を見る際はカメラを床下へ回さない。実プレイヤーは連続掃引カプセル、軽量モデルの上面計算を全方向衝突の証明に使わない。

以前の外部テクスチャ取得は承認待ちのため未実施。現在の独自素材には依存しない。
