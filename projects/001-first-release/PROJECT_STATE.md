## 現在動くもの

- 浅海では左の巨大泡/アーチと右の魚群/藻庭。群れは同一直線上で反転せず、庭へ湾曲して往復する。藻庭から横穴・縦穴へ入れる。岩礁の内側/屋根/外側、空気洞で歩行、泡上昇流を利用できる。
- 約160mから段丘、狭棚、西の張り出しと切れ込み、東の崩落湾。125mから連続操作で44.73秒。生物に寄り道して下側の藻へ22.40秒。80%酸素では早期内側16.47秒で到達、長い外回りは救助。
- 下側の細長い棚を、歩ける岸と潜れる穴/沖の横口がある入り江へ置換。藻から歩行→穴へ潜る→沖へ12.43秒。初案の穴を塞ぐ旧景観岩を撤去し、均一な輪を南岸の崩落/内壁の段へ修正。岸の大面と通常視線で穴の底が読みにくい点は未合格。
- 入り江の南岸に岩窓を試作。通常歩行の視線で見え、内部/上側を実操作できる。窓を抜けると24m/sの潮が既存の流木藻へ繋がる。満タン22.77秒/最低12.60%、藻を離れて80%では再合流前に救助。上側は9.28秒で到達するが見返りがまだ弱い。
- 最新成果物: `build/windows-agent/DIVE DIVE.exe`。[起動方法](README.md) / [画像・測定](REVIEW_PACKET.md)。人間が使うwindows-preview等は置換しない。

- 魚/海藻が三人称カメラの直前を塞ぐ問題を、近距離のみの描画抑制で修正。通常の進行方向カメラで海上→藻庭→裂け目を連続撮影する検査を追加。新横穴の試作は棄却し、既存の歩行面を保持。
- 潮の均一な白線100本を細泡34/大小の浮遊片66へ変更。18/21/24m/sの2地点で横/E/Space離脱を実確認。24m/sは暫定維持。独立した満タンfixtureから、岸へ戻る13.33秒/既存流木へ9.47秒を確認したが、通しの残酸素を持つ離脱は未合格。
