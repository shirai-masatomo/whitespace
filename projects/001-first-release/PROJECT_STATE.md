## 再実行メモ

- `./tools/setup.ps1` → `./dev.ps1 check` → `./dev.ps1 visual`。測定のみならevaluate。ログ/JSON/生成画像はartifacts、配布物はbuild、選別画像はreview。
- Godotは終了コード0でもERRORを出す場合があるためログも検査する。権限制限下でのユーザーデータ作成には実行許可が必要な場合がある。
- 配布EXEが起動中だと再exportできない。実行パスを確認して該当テストプロセスのみ終了する。
- exportは全ゲーム資産を対象にtests/tools/build/artifacts/reviewを除外。評価画像は.gdignoreでも除外する。
- 可変フォントは整数OpenTypeタグを使用。足場の装飾面は本体と同じ高さへ重ねない。俯瞰カメラは水面より下に保つ。
