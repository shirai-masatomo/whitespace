## 現在動くもの

- 海上から入水、自然沈降5m/s、E15m/s・酸素2.5倍、Space6m/s。藻で即補給、酸素切れは同じ世界で救助。450mの既存経路。
- 浅海の藻庭から横へ入り縦穴へ抜ける裂け目。縁の格子状の角を除き、内部の壁に窪みを追加。従来の岩礁歩行・空気洞・屋根/外側・泡上昇流も維持。
- 160〜240mの東側に岩段差・狭棚・段丘・斜面・削れた岩橋・橋の下の藻庭・壁を横断する内外経路。125mの既存補給地点から連続試走。歩いて下降/登り返し、泳いで横断、橋の下へ潜れる。
- 通常の開始視点でも水面裏が平らな帯にならず揺らいで見える。左の20m巨大泡と右の藻庭が寄り道先。泡→潮流→アーチ→補給も実入力で接続。
- 最新ビルド出力は `build/windows-agent/DIVE DIVE.exe`。人間の `windows-preview` 等は置換しない。[起動方法](README.md) / [比較と測定](REVIEW_PACKET.md)。
