## 現在遊べる範囲

海上→岩棚→海藻の泉→流木→約125mのクラゲまでを共通の導入に整理。入水直後の寄り道誘導を後ろへ移し、P1/P2移行帯で左の泡/岸壁と右の岩礁/洞窟が開く。約160mから既存の断層・隆起した岸壁へ。約450mの砂海底→隙間→狭い暗闇→約585mで巨大空間→約680mの水球まで接続。一本道は主進行を意味し、自由遊泳を不可視壁で禁止する構造ではない。

水球は通過可能で触れると即補給。自然沈降5m/s、E15m/s・酸素2.5倍、Space6.6m/s、水平7m/s。酸素0の救助は訪問済みの浅い安全地点へ戻る。水球帰還後も泳ぎ続けられ、見えない足場は作らない。

出力: `build/windows-agent/DIVE DIVE.exe` / `build/DIVE-DIVE-windows.zip`。[起動方法](README.md) / [フェーズ別の代表画面](REVIEW_PACKET.md)。
