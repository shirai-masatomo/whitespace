## 1. 層 / フェーズ管理

今後は **L = Layer / P = Phase / G = Gate** で指示・レビューする。深度はゲームプレイ上の目安で、実装スケールを機械的に引き延ばす必要はない。

- **L1 現実海層 / 0〜1000m目安**
  - L1-P0 海上・入水 / 0〜30m
  - L1-P1 開放浅海 / 30〜160m
  - L1-P2 岩礁・岸壁 / 160〜500m
  - L1-P3 深部海域 / 500〜800m
  - L1-P4 海底・収束 / 800〜950m
  - L1-G 岩盤隙間ゲート / 950〜1000m
- **L2 生物層 / 1000〜3000m目安**
  - L2-P0 暗闇・狭窄 / 1000〜1300m
  - L2-P1 巨大空間・解放 / 1300〜2500m
  - L2-P2 巨大生物遭遇 / 2500〜3000m
  - L2-G 沈没船ゲート / 3000〜4000m候補
- **L3 人工物層 / 3000〜6000m目安**
- **L4 神話層 / 6000〜9000m目安**
- **L5 宇宙層 / 9000〜11000m目安**
- **L6 最深部 / 約11000m**

現在の制作対象は **L1-P0〜L1-Gの品質向上 + L2-P0〜L2-P1、必要ならL2-P2の遭遇まで**。L3以降や本格ボス戦は先回りして作らない。

## 2. 空間リズムとルート

探索性 = 大量分岐ではない。L1前半は2〜3程度の意味ある選択でよく、深くなるほど選択肢を減らす。

**L1: 広い → 少数の選択 → 岸壁に包まれる → 砂の海底 → 狭い岩盤の隙間をかいくぐる → 1ルートへ収束**。

L1-Gは自然地形として1ルートでよい。明示ゲートUI/ロード/ワープは使わない。

**L2-P0: 狭い + 暗い + 発光する水球を追って下降**。すぐ開けず圧迫感を引っ張る。

**L2-P1: 狭い空間から突然巨大な暗い空間へ解放**。影・泡・逃げる生物・触手などで「何かいる」→「巨大」→「タコ」と段階的に認識させる。L2-P2は遭遇まででよく、戦闘は不要。

## 3. L1の品質優先

後半を増やしてL1の弱さを隠さない。以下は継続P0。

- 入水直後から「海！」と感じる第一印象を強くする。
- 小足場の列ではなく、**大きな岩盤・岸壁・段丘・崩落・穴・張り出し・アーチ・斜面**を先に作り、その中を遊べるようにする。
- 約160mから左右/奥/頭上の岸壁・岩礁が近づき、開放海から地形内部へ入る感覚を作る。
- 岩階段、段丘、連続棚、狭棚、裂け目、歩ける岸壁など、形そのものが移動を変える。
- 画面上の景観と実際の可遊域を一致させる。見える場所を歩ける/泳げる/入れる/回り込める比率を上げる。
- 大岩盤の板状輪郭、規則反復、均一な散布、模型的な生物を完成扱いしない。
- オブジェクトは数ではなく役割で置く。藻=補給/安全/視界変化、崩落=方向、魚/クラゲ=穴/流れ/未知の予告など。
- 通常視線で「どこを見て、何を試したいか」が読めること。機能数・テスト数だけを品質改善と数えない。

## 4. 高速試作

現在は完成保証より**面白い空間を速く見つけるフェーズ**。

通常は `実装 → 軽い起動 → 対象操作 → 代表1〜3画面 → 自己批評 → 次案`。小変更ごとに全経路/全renderer/export/benchmarkを繰り返さない。大地形、physics/collision、中核ロジック、人間レビュー候補、merge/Release候補などの節目だけ重い検証をまとめる。

品質基準、実衝突の信頼性、既存経路を壊したまま進めないことは維持する。

## 5. スクリーンショット運用

古いレビュー画像を現行repoへ蓄積し続けない。

- 現行レビュー、再現、意図的な前後比較に不要な古いPNG/JPGは参照監査後に削除する。Git履歴を保存庫とする。
- 通常開発では大量撮影しない。
- ユーザー/外部AIが `L1-P2を確認` などと求めた時だけ、**入口/中間/出口/問題箇所から2〜4枚**を出す。
- 修正後は原則として新しい画像へ置換し、古い確認画像を残し続けない。
- 品質ゲートで前版比較が必要な時だけ、同条件の旧1枚+新1枚程度を意図的に残す。

## 6. PC非干渉

通常はheadless/background。GPU確認はまとめて画面外・no_focus・マウス非捕捉・無音。人間が起動したゲーム/エディタ/アプリを終了しない。終了してよいのは自分が開始し所有を確認した検証プロセスだけ。

## 7. HUMAN_REVIEW条件

少し改善しただけで人間へ戻さない。AIで検出できる模型感、空虚さ、単純面、管状/反復形状、入口の読みにくさ、見えるのに行けない景観、衝突問題が残る間は **SELF_CONTINUE**。

人間へ渡すのは、少なくともL1の代表フェーズが前版より一目で自然・密・遊べる場所になり、L1-G→L2-P0→L2-P1の「収束→暗闇→解放」が通常プレイで成立した候補ができた時。
