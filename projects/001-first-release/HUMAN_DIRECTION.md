## 現在の制作範囲と空間リズム

**L1-P0〜L1-Gの完成度を上げ、L2-P0〜L2-P1、可能ならL2-P2の遭遇まで。** 現在の680m版はこの体験を圧縮した接続試作。数字を合わせるためだけに地形を引き伸ばさない。L2-G以降・本格ボス戦・Steam SDKは今回対象外。

- L1: 広い → 少し自由 → 岩礁/岸壁が迫る → 密な地形 → 砂海底 → 狭い岩盤隙間。
- L2: ゲート後も狭い・暗い → 水球 → さらに狭い → 巨大空間へ解放 → 生物の気配 → 遭遇。
- L1-P1〜P3は岸壁沿い/沖側/危険な近道など少数の選択でよい。深くなるほど合流し、L1-P4で絞り、L1-Gは基本1つ。探索性をルート数で評価しない。
- 人工的なゲート、層名を説明するUI、ロード/ワープを用いず、地形・光・音・生物で移る。

## 継続するゲーム方針

自然沈降、E急降下（酸素消費増）、Space長押し浮上、水平移動、地形で下降停止。酸素藻/泡/水球への接触で即補給。酸素切れは同じ世界で救助・深度損失・再挑戦。速度/配置/酸素量は調整可能。

足場を散らすより大きな地形の中に歩く/泳ぐ/回り込む場所を作る。岸壁・岩棚・穴は実際に利用でき、見える世界と遊べる世界を近づける。リアルさより探索・好奇心・未知への怖さを優先して誇張してよい。生物や植物は場所の手掛かり、酸素は経路判断になるよう使う。Only Upは構造のみ参考にし、素材・具体的なステージを模倣しない。

## フェーズへ集中する

「L1-P2の岸壁」「L2-P0の暗闇」の指示には、そのIDの体験と隣接接続だけへ集中する。全体バックログへ拡散しない。作業開始時に対象ID・現在の問題・試す仮説を決め、少数案を比較し弱い案は捨てる。指定がなければTASKS先頭から**1フェーズ**を選ぶ。

現在は高速試作。通常は実装→軽い確認→少しプレイ→自己批評→次案。全経路/full check/collision/build/CIは大きな地形・中核変更、merge、制作サイクルの節目にまとめる。小変更ごとの詳細な文書・大量撮影は不要。
