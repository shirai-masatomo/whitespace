# Local AI Image Lab — Project State

更新: 2026-10-19（日本時間）

- 目的: ローカル画像生成モデルの出力と利用条件をGitHub上で見比べる。
- 核となる問い: 同じ文章・シードで、モデルによって顔・輪郭線・塗り・色がどう変わるか。
- 自律モード: ユーザー指定範囲をCodexが実行。定期監視・継続課金・アカウント登録は設定しない。
- 完了: 3モデル×2枚を実機生成し、PNGのメタデータとハッシュを確認。GitHub確認用の独立フォルダーに整理。
- 人間の判断: 好みの画風、採用する素材、販売用素材の仕上げと最終的な権利・販売規定確認。
- 公開方針: 一般向け試作の確認用。既存の公開リポジトリへ収録する。ゲーム販売・モデル配布は今回の対象外。
- 実行環境: ローカルの tools/local-ai-foundation に隔離済み。この確認フォルダーには巨大な実行環境を複製しない。
