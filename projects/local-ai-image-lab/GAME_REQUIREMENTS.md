# 現在想定するノベルゲームの要件

更新: 2026-10-20。ユーザーの最新説明を制作方針として扱う。初期の環境構築案は、作品の実装条件を確定したものではない。

## 中心となる画面と機能

- 背景絵とキャラクター絵を配置する。
- 画面下部のテキスト欄へ、あらかじめ決めた台詞とナレーションを表示する。
- 場面に応じてBGMとSEを再生する。
- セーブとロードができる。
- バックログで既読の文章を確認できる。
- 回想で、見たイベントやCGを後から再生できる。「階層」は回想の意味とユーザーが確認済み。
- 必要に応じて選択肢、好感度、フラグ、条件分岐を扱う。

## 後から追加する可能性があるもの

- マップから移動先やイベントを選択する。
- 作品固有のゲーム性を加える。内容は未確定。

この可能性だけを理由に、最初から汎用エンジンの利用を必須にしない。ノベル部分を中心に制作し、追加要素の具体的な規模を見てエンジンを比較する。

## エンジンと編集方法

最終ゲームエンジンは未選定。Godotは既存の独立したデータ読込・分岐検証デモとして残す。Ren’Pyやティラノ系を含む専用エンジンも比較候補で、現在は未導入。既存のGodotデモを作ったという理由だけで本編の採用を固定しない。

ユーザー自身が台詞、選択肢、好感度、画像、イベント条件を修正できる制作方法を重視する。JSONの直接編集が最終的に最も使いやすい方法かは未確定。専用エンジンの編集方法や、必要に応じた入力画面を比較する。

## ローカル文章生成は利用しない

Qwen3とllama.cppは不要との指示により、2026-10-20にアンインストールした。モデル、専用ランタイムと同梱CUDA DLL、取得済みZIP、専用起動ファイル、ローカルAPIキー、文章生成スクリプトを削除。通常セットアップの取得対象からも外した。

ゲームは固定台詞を再生する構成を基本とし、プレイ中のLLM会話生成を要件に含めない。作成済みの台詞・会話JSONと過去の検証記録は残す。画像制作環境は継続して利用できる。

## 現在の実装と今後の要件を区別する

| 項目 | 現状 |
| --- | --- |
| 画像・固定JSON・選択肢・簡易好感度とフラグ | 独立したGodotデモで検証済み |
| BGM・SE・セーブ・ロード・バックログ・回想 | このデモには未実装。本編の要件 |
| マップ選択・独自ゲーム性 | 追加候補。未実装 |
| 本編エンジンの選定・専用制作ツールの導入 | 未実施 |

この更新では新しいゲームエンジンの導入や既存ゲームへの組み込みは行っていない。
