## お金や契約について

| 項目 | 今回の扱い |
| --- | --- |
| ComfyUI | 既存PC内で実行。新たな有料契約なし |
| 画像モデル | 無料公開の公式重みを取得。有料モデル購入・サブスクリプション・無料体験登録なし |
| 画像生成 | ローカル実行。外部の有料推論API・クラウドGPUは使っていない。画像ごとの課金や生成回数に応じたロイヤリティなし |
| 生成枚数 | ローカル実行にサービス側の枚数枠はない。時間、GPUメモリ、保存容量には限界がある |
| 電気・通信 | PCの電気代と、契約に応じた通信費は別。モデル2個の追加取得は合計約13.88GB |
| Codex | 既存の契約・利用枠は別。この作業で新しいプランやAPI課金を申し込んでいない |
| GitHub | 既存リポジトリへ通常の画像・JSON・説明を追加。Git LFS・Actions・有料ストレージ・追加契約は設定しない |

「新しい有料契約をしていない」ことと「利用条件がない」ことは別。モデルやツールは公開ライセンスの条件に従って利用する。
