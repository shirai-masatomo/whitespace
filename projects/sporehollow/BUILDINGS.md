# 建築

数値と下記の補足は初版の仮設定。確定バランスではない。

| 建築 | 資源/費用 | HP | 工期 |
| --- | --- | ---: | ---: |
| 土壁 / 木壁 / 石壁 | 土10 / 木10 / 石10 | 8 / 16 / 28 | 1 / 2 / 3秒 |
| 土タイル / 木タイル / 石タイル | 土2 / 木2 / 石2 | 8 / 16 / 28 | 1秒 |
| ドア / ロック付きドア | 木10 / 木20 | 16 | 2秒 |
| ロック | ドアと別耐久 | 8 | 修理で回復 |
| 犬小屋 | 木20・設計図 | 12 | 2秒 |
| 鶏小屋 | 木30 | 12 | 2秒 |

- 床と構造物は別層。同じ場所の床上へ施設を建てられる。
- 土→木→石へ直接改築。新素材を消費し旧素材返却なし。作業中は旧機能を保持し、完成時に耐久率を引き継ぐ。同等/下位は不可。
- 未着工取消は確保素材を返却。新設着工後の取消は既存の半額返却。改築の取消は旧建築を残し、着工後は新素材半額（仮）。
- 閉じたドアは視線遮蔽。牧場主/許可味方は開けて通れる。敵は通常ドアを開け、正常なロックは壊す必要がある。ロックだけ壊れても本体は残る。閉めても復活しない。
- 屋内は完成した壁/ドア本体で囲い、縦横接続の内側すべてを施工床で覆った領域。外周柵/マップ端/予約は囲いに数えない。開いたドアも囲いとして有効。
- 動物・主人公・敵のいるマスへ施工不可。最後の施工で屋外専用動物を屋内へ囲い込む場合も不可。予約/着工/完成直前に確認し、進捗と資材を保持して理由を表示。
- 床は自然物生成を抑える。卵・羽・設計図は許可。既存落ち物は回収してから施工する。
- 旧建築門は位置/本体耐久/開閉を保って通常ドアへ移行する。
