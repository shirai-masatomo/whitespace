# 建築

数値と下記の補足は初版の仮設定。確定バランスではない。

| 建築 | 資源/費用 | HP | 工期 |
| --- | --- | ---: | ---: |
| 土壁 / 木壁 / 石壁 | 土10 / 木10 / 石10 | 8 / 16 / 28 | 1 / 2 / 3秒 |
| 土タイル / 木タイル / 石タイル | 土2 / 木2 / 石2 | 8 / 16 / 28 | 1秒 |
| ドア / ロック付きドア | 木10 / 木20 | 16 | 2秒 |
| ロック | ドアと別耐久 | 8 | 修理で回復 |

- 床と構造物は別層。同じ場所の床上へ施設を建てられる。
- 土→木→石へ直接改築。新素材を消費し旧素材返却なし。作業中は旧機能を保持し、完成時に耐久率を引き継ぐ。同等/下位は不可。
- 未着工取消は確保素材を返却。新設着工後の取消は既存の半額返却。改築の取消は旧建築を残し、着工後は新素材半額（仮）。
- 閉じたドアは視線遮蔽。牧場主/許可味方は開けて通れる。敵は通常ドアを開け、正常なロックは壊す必要がある。ロックだけ壊れても本体は残る。閉めても復活しない。
- 屋内は完成した壁/ドア本体で囲い、縦横接続の内側すべてを施工床で覆った領域。外周柵/マップ端/予約は囲いに数えない。開いたドアも囲いとして有効。
- 動物・主人公・敵のいるマスへ施工不可。最後の施工で屋外専用動物を屋内へ囲い込む場合も不可。予約/着工/完成直前に確認し、進捗と資材を保持して理由を表示。
- 床は自然物生成を抑える。卵・羽・設計図は許可。既存落ち物は回収してから施工する。
- 旧建築門は位置/本体耐久/開閉を保って通常ドアへ移行する。

## 床の現地解体（補足仮仕様）

- 土/木/石タイル→未舗装。床を選び「タイルを解体」。停止中は予約のみ、隣接してから実行。
- 選択/修理/解体/取消は層・ID・種類を照合。同座標の建物と混同しない。建物のある床は先に上の建物を解体する。
- 動物/敵/主人公の占有中は実行しない。主人公が対象床上なら隣へ移動する。施工後に現れた障害も再確認し、通行待ちはその仕事だけを止める。
- 8対象の同層選択、8件の仕事。二重予約不可。完了時に支払済み最新素材×耐久率×80%（切捨て）を一度だけ返却。旧素材の累積返却なし、無料デバッグ施工は返却0、取消は返却なし。
- 卵/羽/巻物は残す。屋内・経路・隣接表示を更新し、自然物は次回の通常抽選から。屋外化後も既に入眠した状態は維持して回復速度だけを変える。

## 小屋の一時停止

待機小屋・犬小屋・鶏小屋は表示/建築/専用AI/回復/卵保護/専用通行禁止を停止。購入動物は既存入口から受け入れる。犬小屋設計図の新規入手も停止し、既存の取得/習得履歴は残す。

旧完成小屋は記録を退役建物として保存して無効化、返金なし（仮）。旧未完了工事の確保素材は一度だけ全額返却して仕事を終了。再構成で再返金しない。通常の建築を上書きしても退役記録は残る。

## 森と重要オブジェクト（初版仮設定）

| 対象 | 現地作業 | 占有・保存 |
|---|---|---|
| 開拓できる木 | 4秒、木材8、斧不要 | TreeIDを予約/完了時に照合。移動と視線を遮るが屋内の壁にはならない |
| 黄金像 | 調査2秒・祈り3秒 | 2×2、HP180。床・通常施設とは別の重要物。通常解体/売却不可 |
| 像の修理 | 現地2秒、土1個→HP1／木1個→HP2／石1個→HP3 | 満タン不可、端数は1個消費で最大HPまで。祈りによる無料修理なし |
| 像の再固定 | 2秒 | 牽引を止めた現在地に再固定。瞬間帰還なし |

像の占有地は施工済みの基盤として屋内の床条件を満たす。周囲の床・壁・ドアは別途必要。開拓は予約・停止・並べ替え・取消・翌朝持越しに対応。旧キャンペーン移行では既存の施設/床/個体を避けた中央候補へ像を設置し、安全な候補がなければ新キャンペーンが必要と表示する。

像の安全な中央候補をすべて旧建築が使っている場合は、元データを消さず移行理由を表示して昼開始を止める。新キャンペーンが必要。像の移動時も屋内判定を更新する。

壁の見た目は施工済み床から外周側へ最大9px寄せる。描画のみの変更で、占有セル・通行・屋内判定・費用は維持（2026-10-10ユーザー指定）。

## 修理の指定と反映範囲

素材1個で土HP1・木HP2・石HP3という指定は黄金像の修理に反映済み。通常建物・床・錠は `world.gd: repair_quote` の既存式（建築費×REPAIR_FACTOR÷最大HPから必要素材を計算）で、同じ回復率ではない。全建築へ共通適用したとは扱わず、範囲の追加確定または実装変更を待つ。
