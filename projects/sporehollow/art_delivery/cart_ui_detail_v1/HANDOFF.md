# 荷車だけのUI精細版
ユーザー要望：アップ表示時の荷車の粗さを改善。本は現状維持。
完成：cart.png、768×512、基準(384,496)、静止1枚。旧merchant_cart_v2のUI荷車と同じキャンバス／基準点で置換可能。元の採用原画から細部を残して再加工し、商人の顔や荷車のデザインを再生成していない。

朝メニュー・市場UI用。盤面用merchant_board_v1/cart_idle_00.png、本の静止／見開き／開閉、主人公・柴犬・商人の単体スプライトは変更しない。商人込みの絵なので別商人を重ねない。

通常RGBA、二値alpha、nearest、等比表示、透明余白保持。768px全体を固定表示寸法にせず、既存の枠へfitする。最新実装の朝枠318×246へ等比で置いた比較を作成。UI素材の白い布・袋・光を透過せず、最終画素の輪郭を暗茶に整形した。外部の接地影は焼き込んでいない。
動作は静止、frame0を状態変更まで保持、duration=null、loop=false。歩行・車輪回転を完成した扱いにしない。

寸法・alpha・SHA256をmanifest.jsonへ記録。reviewは実装寸法を再現した素材比較でありゲーム内検証ではない。原画の出典と加工手順は../../art-production/cart-ui-detail-v1/。
未実施：実装担当によるUI参照の置換と隔離描画確認。ゲームロジック・本番シーン・UIDの編集なし。
