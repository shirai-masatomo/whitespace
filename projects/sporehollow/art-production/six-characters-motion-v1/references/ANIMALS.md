# 動物図鑑

実装対象：柴犬・鶏・猫・ドーベルマン・ウシガエル・ハリネズミ・乳牛・闘牛。以下の他種は将来設計で、購入・生成不可。素材の納品/取り込み状況はART_SPECを参照。

動物の設計正本。数値・価格は「仮」とあるものは調整前提。

## 共通

装備は1個体1枠（仮）。基礎忠誠と装備補正/一時低下は別。死亡/連れ去りは履歴へ移し、装備も失う。売却/交換/解除では装備を持ち物へ戻す。死亡時の死体は今回は残さず、生態系・蘇生は未実装。柴犬の療養だけ従来どおり。
個体追加スキルの初版は「丈夫」（Uncommon、最大HP+4、全実装動物対象・仮）。種族固定の救出本能は抽選外。

- 所有個体は園内で生活する。任意出撃・自由収納はしない。指示は主人公の接近後に届く。ホイッスルでも猫は従わない。
- **HP0**：柴犬だけは死亡せず気絶する。**柴犬以外の動物はHP0で死亡**。死体・回収・蘇生の扱いは種別/後続仕様で定める。
- 名前：所有・仲間化した動物は原則命名可。野生・敵所有・ネズミ・カラス等は不可。
- 親密度：一部動物のみ。将来、親密度ボーナスを実装。
- Lv：最大5。共通EXPプールを購入・育成フェーズで消費して任意Lvアップ。
- **レアリティ**：動物・スキル・アイテム・敵で共通分類を持つ。初期ラベルは Common / Uncommon / Rare / Epic / Legendary（仮）。確率と表示色は調整前。
- **種族スキル**：種ごとにLvで解放する固定スキル。
- **個体追加スキル**：購入・黄金像などの入手時に低確率で付く個体差。珍しいスキルほど高レアリティ。黄金像はショップより高レア個体/追加スキルの抽選率が高い。
- **防御**：共通ステータスとして持てるようにする。初版は max(0, 攻撃−防御)（仮）。
- 対物攻撃：全動物が内部値として持つ。未使用なら0。
- **検知範囲**：自分で敵を発見できる距離。
- **攻撃対象範囲**：検知済みの敵を「攻撃対象」として選べる距離。検知範囲とは別。
- 他動物から共有された敵も「検知済み」にできる。攻撃対象範囲外なら、検知していても攻撃対象にはしない。

### 迎撃特性

| 型 | 行動 |
| --- | --- |
| **自律迎撃型** | 自分の検知範囲で敵を認識すると迎撃モードへ入る。犬など。 |
| **受動迎撃型** | 自分からは迎撃開始しない。攻撃される、または他個体から敵情報を共有されると敵を認識して迎撃モードへ入る。ハリネズミなど。 |
| **非迎撃型** | 迎撃モードを持たない。逃走・生産・索敵共有・支援などを行う。 |

「敵を検知済み」と「攻撃できる」は別。共有を受けても攻撃対象範囲や種別能力に従う。

### スキル

- **発動スキル**：条件成立時に使用。原則CTあり。
- **パッシブスキル**：条件を満たすと常時/自動で機能。原則CTなし。
- 各スキルに**解放Lv**を持つ。
- Lvアップ画面で、使用可能スキルと今後解放されるスキルを確認できる。

### 吠える
**発動 / Lv1 / CT6秒**  
敵検知時。周囲4マスの敵の移動を1秒停止。ダメージなし。

### 救出本能
**パッシブ / Lv1**  
主人公被弾後6秒間（仮）はその攻撃者、気絶時は近くの敵へ救出に向かう。拘束者・運搬者は最優先。「狙う」の指定よりも救出が優先。移動速度1.5倍、判断の揺れを大幅低下。「休む」中は発動しない。屋内へは入らず、到達できる屋外出口付近で運搬者を待ち、外へ出たら迎撃する。

屋内での救出待機は、把握している主人公/運搬者の部屋につながる出口に限る。他個体のいるマスは待機先に選ばず、壁の破損や運搬者の屋外移動に応じて見直す。

### 休む
その場で5秒ごとHP1回復。小屋へは向かわない。

### 犬小屋（保留）
現在は使用しない。通常の休む指示と自主休養を利用する。

## 森・黄金像との関係

柴犬の救出本能は引き続き主人公を最優先とし、像の運び手は通常の発見・迎撃対象。森の中でも通れる経路を使う。像の危機を理由に屋内制限・視認・明示休息の抑制を無視しない。大人数の誘導は到着マスの間に通路を残し、密集した時は仲間が通常速度で一マスずつ道を空ける（仮）。

## 今回の指示・戦闘補足（仮）

犬「狙う」は検知済み・攻撃対象範囲内のEnemyIDを優先。主人公の現地指示後に応答し、救出を上書きする完全固定ではない。死亡/退散/5秒見失い/経路閉塞で通常AIへ戻る。猫・鶏へ犬命令を適用しない。
ウシガエルの舌拘束は人間のスタミナを20低下させる。has_stamina=falseの対象は拘束だけ。個体別技ゲージは共通CombatEventで増え、現在の種の必殺技は未設定。

## 乳牛・闘牛（仮調整）

- **乳牛**：現地の「搾乳」を1日1回予約し、ミルク1個を得る。誘導可・屋内可・非戦闘。HP60。将来のメイド懐柔は保留。
- **闘牛**：HP80/攻撃12。「突撃」は指定セルへ直進し、最初の敵に20ダメージ、CT8秒。壁・閉扉・味方で止まり、迂回やすり抜けをしない。「根性」はHP50%以下で移動/攻撃速度1.5倍、回復すると解除。屋内可。
- 牛2種も常駐個体。HP0は死亡し、再収納や翌朝復活はしない。数値は初版の仮値。
