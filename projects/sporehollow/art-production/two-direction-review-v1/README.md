# 左右方向確認用の制作原本

2026-10-08のユーザー指定を適用。6対象（商人・荷車、メイド、舞姫、盗賊、乳牛、闘牛）、各1枚の方向確認シート。左右のみ、正面背面や別デザインA/B/Cは制作しない。正式連番は方向確認採用後。

- `originals/`: 内蔵image_genによる不足姿勢の原画4点。
- `generation-records.json`: 完全なプロンプト、採用参照画像、出力元。
- `references/`: 最新仕様の読取コピーとゲーム画面参照。原本のゲーム文書は変更しない。
- `existing-png-hashes.json`: 作業開始前の既存1095PNGの保全検査用ハッシュ。
- `build.py`: 採用原画のalpha連結成分抽出、姿勢切り出し、原寸整形、右の複製、左の反転、方向シート作成。色キー透過はしない。
- `validate.py`: build後に実行。既存画像不変・寸法・方向・透過・足元・ハッシュ検査と背景比較。
- `extraction.json`: 使用原画と切り出し範囲。

成果物: `../../art_delivery/two_direction_review_v1/`。方向確認に限る。既存v1/v2やmotionの制作スクリプトをimportしない。元ファイルを上書きしない。新規姿勢は採用衣装を基に生成した代表姿勢で、正式モーションの最終ピクセル修正・接触・保持点・時間は未確定。

作業時参照の実装版: f6a60ee525cbe63d962a06280a7d7a9533d69d66。最新ART_SPECでは新5体は静止/キーポーズで既に表示されるが、今回の新方向シートがゲーム統合済みであることは意味しない。新しい外部API・有料サービスは利用していない。
