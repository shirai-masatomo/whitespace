# アイテム図鑑

アイテム・装備の設計正本。数値は特記がなければ仮。装備時の見た目差分は当面作らない。

## 共通

### レアリティ

スキル・アイテム・動物・敵で共通分類を持つ。

**Common / Uncommon / Rare / Epic / Legendary（仮）**

色、排出率、価格補正は後で調整する。レアリティは強さだけでなく、珍しさ・特殊性を表せる。

### アイテム種別

| 種別 | 扱い |
| --- | --- |
| 消耗品 | 使用時に1個消費 |
| 条件消耗装備 | 動物に持たせ、条件成立時に自動消費 |
| 耐久装備 | 装備中に効果。耐久0で壊れる |
| 非消耗装備 | 装備解除まで効果。耐久を持たない |
| 設計図／巻物 | 取得時に建築・装備・スキル等を解放し、巻物自体は消費 |

各装備に EquipTargets を持ち、装備可能な種／カテゴリを限定する。全動物へ無条件装備できる設計にはしない。

### 装備操作

指示モードから「装備」を行えるようにする。

初期案：
動物を選択 → 装備 → 所持アイテムを選択 → 主人公が対象へ近づく → 装備成立。

物理的に渡すアイテムなので、ホイッスルだけで遠距離装備は行わない（仮）。PAUSE中は予約のみ。装備対象・在庫・耐久を実行直前にも再確認する。

装備中のアイテムは個体IDと紐付ける。売却・死亡・仲間化解除・装備交換時の返却／消失はアイテム種ごとに定義する。二重装備・二重消費を防ぐ。

ゲーム内キャラクター画像へ首輪や実などを重ねる見た目差分は当面不要。UI／図鑑で装備状態を確認できればよい。

## 首輪

**種別**：装備  
**装備対象**：犬系  
**Rarity**：未定  
**耐久**：未定

犬につけると：
- 忠誠度を**大幅に上昇**
- 防御を**少し上昇**

具体値、耐久制か非消耗か、外した時に忠誠補正をどう戻すかは要精査。

---

## きのみ

**種別**：条件消耗装備  
**装備対象**：原則動物。種別制限は要精査  
**Rarity**：Common～（仮）

持たせた動物のHPが**最大HPの50%以下**になったとき自動消費し、**最大HPの1/4を回復**する。

- 1回発動すると1個消費。
- 同じダメージで複数個を同時消費しない。
- HP0で死亡した後に発動して蘇生するアイテムにはしない。
- 柴犬がHP0で気絶した後に自動発動するかは別途決める。

---

## 巻物

**種別**：取得時消費  
**主な入手**：忍者の撃退など  
**Rarity**：巻物／中身それぞれに設定可能

中身候補：
- 建物の設計図
- 装備アイテムの設計図
- スキル
- その他の解放要素

取得時に一度だけ内容を解決する。建築の設計図と同様、巻物自体は消費して取得・習得記録を残す。

## アイデア候補（未採用）

以下は検討用。実装・ショップ・黄金像の抽選には、採用されるまで入れない。

- **鈴付き首輪**：犬系。検知／警報共有を少し強化。
- **胴当て**：犬・ヤギ・イノシシ等。防御上昇、移動を少し下げる案。
- **夜光札**：索敵役向け。夜だけ検知範囲を増やす案。
- **お守り**：一度だけ状態異常を防ぐ条件消耗装備。
- **薬草袋**：HP一定以下で小回復。きのみとの差別化が必要。

装備の面白さは「単純な数値上昇」だけでなく、動物の役割や迎撃特性を少し変える方向も検討する。
