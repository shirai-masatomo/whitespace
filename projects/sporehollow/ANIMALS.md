# 動物図鑑

動物の設計はこの文書を正本とする。新しい動物・スキル・特徴は、実装前にここへ追加する。

## 共通ルール

- **HP0**：特記がなければ死亡せず**気絶**。気絶した動物は**翌日は出撃不可**。翌々日に最大HPの半分で復帰（仮）。
- **死亡**：死亡する種類は各動物欄に明記する。死亡した場合は死体が残る場合がある。
- **名前**：所有・仲間化した動物は原則命名可能。野犬、他人の動物、ネズミ・カラス等は命名不可。
- **親密度**：一部動物のみ所持。親密度に応じたボーナスを将来実装する。
- **Lv**：最大5。Lvアップは自動ではなく、購入・育成フェーズで**共通EXPプール**を消費して任意に行う。
- **対物攻撃**：全動物が内部ステータスとして保持できる。未使用の動物は0。将来、施設・障害物への攻撃に使用可能。

---

育成の仮値：Lvが1上がるごとに最大HP+4。柴犬は攻撃+2。種ごとの成長特徴は今後調整。

## 柴犬

**役割**：愛犬 / 警戒 / 迎撃 / 主人公救出  
**指示**：おまかせ・待機・徘徊・休む  
**死亡**：しない（HP0で気絶）  
**名前**：可  
**親密度**：将来対象候補  
**売買（仮）**：買42G / 売15G

| 基礎値 | 値 |
| --- | ---: |
| HP | 40 |
| 攻撃 | 10 |
| 対物攻撃 | 0（未使用） |
| 攻撃間隔 | 1.2秒 |
| 移動 | 2マス/秒 |
| 敵検知 | 4マス |
| 忠誠度 | 75（仮） |

### 吠える
- 敵検知時に使用
- CT 6秒
- 周囲4マス
- 敵の**移動を1秒停止**
- ダメージなし
- 「休む」中は使わない

### 救出本能
主人公が連れ去られると運搬者を最優先。
- 移動速度1.5倍
- 判断のランダム性を大幅に下げる
- 「休む」中のみ発動しない

### おまかせ
徘徊・警戒・戦闘・吠える・自主休養・犬小屋利用・主人公救出を状況に応じて自律判断。

### 休む
- 戦闘・警戒・吠える・救出をしない
- 5秒ごとHP1回復
- 空き犬小屋が近ければ向かう
- 犬小屋内では犬小屋の回復と重複

### 犬小屋
- 1棟につき1匹
- 毎秒HP1回復
- 設計図を回収すると建築解放
- 建築費：木材20

## 鶏

**役割**：愛玩 / 生産  
**指示**：不可  
**攻撃**：しない  
**死亡**：しない（HP0で気絶）  
**名前**：可  
**親密度**：将来対象候補  
**売買（仮）**：買30G / 売10G

基礎HP20（仮）。

### 卵
夜明け時、生存して出撃中の鶏が現在位置へ1個産卵。未出撃・気絶中は産まない。
- 回収・売却・将来の加工に利用
- 放置1日 → ひよこ
- ひよこのまま1日 → 鶏

### 羽
夜明けに低確率で羽を落とす（出撃中・生存個体あたり15%の仮値）。地面で回収でき、将来、矢などの素材に使用。

### 鶏小屋
- 木材30・HP12・建築2秒（仮）
- 中の鶏を毎秒HP1回復（仮）
- 中で産まれた卵は敵に発見されにくい
- 卵を奪うには敵が小屋を壊す必要がある
