# ホイッスル牧場 — 動物仕様正本

この文書は、動物の基礎値・スキル・習性・成長・実装状況をまとめる専用の正本。

## 運用ルール

- 新しい動物・スキル・特徴を追加/変更するときは、原則として**先にこの文書を更新**する。
- 実装レビューでは、この文書とコード/ゲーム挙動の差を確認する。
- 数値は **確定 / 仮調整 / 将来候補** を区別する。
- 「設計済み」でも未実装なら、実装済みのように書かない。
- README はゲーム全体、PROJECT_STATE は現在実装、TASKS は作業順、この文書は動物仕様を担当する。

# 動物一覧

## 柴犬

### 状態
**実装済み + 一部仮調整**

### 役割
最初から主人公といる愛犬。警戒・迎撃・主人公救出の中心。

### 基礎値

| 項目 | 値 | 状態 |
| --- | ---: | --- |
| MaxHP | 40 | 仮調整 |
| AttackPower | 10 | 確定基準 |
| AttackInterval | 1.2秒設定（固定tick上は約1.25秒） | 仮調整 |
| MoveSpeed | 2マス/秒 | 仮調整 |
| DetectionRange | 4マス | 確定 |
| 基礎忠誠度 | 75 | 仮調整 |
| 最大Lv | 5 | 確定方針 |

### 指示
- おまかせ
- 待機
- 徘徊
- 休む

配置後の移動は指示/自律AIのみ。配置モードでの再配置・回収は不可。

### おまかせ
便利な標準自律状態。

- 周囲を徘徊
- 敵を警戒
- 敵を検知すると対応
- 吠える
- 戦闘
- HP低下時に自主休養を検討
- 空いている犬小屋を利用可能
- 主人公連れ去り時は救出本能

### 固有スキル：吠える
- 発動条件：敵を検知
- クールタイム：6秒
- 効果範囲：周囲4マス
- 効果：範囲内の敵の**移動を1秒停止**
- ダメージなし
- 「休む」指示中は使用しない

### 固有特性：救出本能
主人公が連れ去り状態になると発動。

- 運搬者を最優先
- 移動速度1.5倍
- 通常より判断ノイズを大幅に低下
- 救出/撃退後は通常AIまたは有効な指示へ復帰
- 明示的な「休む」指示中だけは発動しない

### 休む
- 敵を警戒しない
- 追跡/攻撃/吠える/救出を行わない
- 別指示まで継続
- 近くに空き犬小屋があれば向かう
- 犬小屋がなければその場で休む
- 5秒ごとにHP1回復
- 犬小屋の毎秒HP1回復と重複

### 施設相性：犬小屋
- 1犬小屋につき1犬
- 使用中は他犬のおまかせ休養候補から除外
- 毎秒HP1回復
- 犬小屋設計図で解放
- 建築費：木材20

### Lv成長
最大Lv5。具体的な成長配分は未確定。
単純な攻撃力だけの成長にはしない。

## 鶏

### 状態
**設計更新中 / 現行実装との差あり**

### 役割
愛玩・生産動物。戦闘要員ではない。

### 基本方針
- プレイヤーから直接指示を出さない
- 敵へ攻撃しない
- 危険時の自律逃走等は可能
- 夜明け時に条件を満たせば卵を産む
- たまに羽を落とす

### 卵
夜明け時にフィールド内へ産卵。

- 回収可能
- 売却可能
- 将来、餌/加工/その他用途へ拡張可能
- フィールドに1日放置 → ひよこ
- ひよこのままさらに1日経過 → 鶏

孵化・成長の詳細条件は未実装。

### 羽
たまに落とす生産物。

将来用途：
- 矢の素材
- 自動吹き矢トラップ等

### 施設相性：鶏小屋
将来施設。

- 中にいる鶏のHP回復
- 中で産まれた卵は敵から発見されにくい
- 敵が中の卵を奪うには鶏小屋を破壊する必要がある

### 現行実装との差
現行コードには鶏の旧試作挙動（恐怖・産卵等）が存在する。
本項の最新設計を正本とし、今後実装との差を解消する。

## 猫

### 状態
**設計のみ / 未実装**

### 役割
愛玩・懐柔支援。

### 基本方針
- プレイヤーから直接指示を出さない
- 敵へ直接攻撃しない
- 自律行動中心

### 固有特性：懐柔支援
敵側の動物に対する「懐柔値」を上昇させる。

目的：
- 敵が連れている動物を仲間にできる確率を高める

具体式・範囲・速度は未確定。

### 固有スキル：鳴く
猫が鳴くと周囲の敵へ一時的な弱体化。

- 周囲の敵のAttackPowerを数秒間少し低下
- 効果量/範囲/クールタイムは未確定
- 直接ダメージは与えない

# 経験値とLv

## 最新方針

動物のLvアップは**自動ではなく任意**。

Stage中に動物が活躍して得た経験値は、
個体へ即時投入せず**共通EXPプール**へ蓄積する。

購入/育成フェーズでEXPプールを消費し、

- どの動物をLvアップするか
- EXPを温存するか

をプレイヤーが選択する。

これは購入フェーズにおけるビルド構築の一部とする。

### 実装状況
**未実装。**
現行コードの自動Lvアップ処理は最新設計と齟齬があるため、今後修正対象。
