# ホイッスル牧場 — 試遊の確認項目

この文書は通常プレイで確認する操作チェックリスト。**自動起動・負荷試験の指示ではない**。PC停止の経緯があるためユーザーの許可なくゲームを起動しない。現在のEXE版は [PROJECT_STATE.md](PROJECT_STATE.md) と [review/current/PACKET.md](review/current/PACKET.md) を参照。

1. 通常入口 `確認入口/最新開発版.lnk` からユーザーが自分で起動する。保存・読込は現在無効（毎回新しい牧場）。
2. アーキテクトで壁を指定し、カーソル・ボタンの選択状態、連続ドラッグ、建築予定の表示・搬入→施工を確認。
3. 備蓄・居住ゾーンを指定。物資は命令→回収で備蓄へ運ぶ。受入カテゴリの変更で、既存物資が消失しないか確認。
4. 人物を選び、HP・眠気・満腹・現在行動、休息・食事後の仕事復帰を確認。
5. 動物の指示・調教・採掘・伐採・現物回収を確認。
6. 商人・図鑑・夜の襲撃・黄金像の祈り・連行・救出を確認。
7. 大量建築のドラッグ中のカクつきやUI停止を確認。異常がある場合は繰り返し起動せず、その時点で停止する。

新しい繊維、製作台、料理バフ、衣服、満腹度・スタミナ統合は **現在の試遊対象外**（[企画案](CRAFTING_NEEDS_DESIGN.md)）。
