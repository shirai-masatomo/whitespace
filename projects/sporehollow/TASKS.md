# 現在の作業

## 開発ルール

- **一度に進めるのは原則1段階。** K6→確認→K7→確認→K8の順。複数段階をまとめて実装しない。
- 普段は対象機能のテストだけ。フル回帰・AI192・Windows export・大量の隔離GPU撮影は行わない。
- review/currentは毎コミット更新しない。
- 定点レビューは、各K段階の完成時または試遊可能な縦切り完成時にまとめて行う。
- 定点では全回帰、AI評価、Windows版、必要最小限の代表スクリーン／動作、残課題を確認する。
- UIだけの変更ならUI関連、AIだけならAI関連というように、変更に無関係な検証を常時回さない。
- 中間証拠はartifactsへ。Gitのreview/currentにはレビュー判断に必要な代表証拠だけを残す。
- 新しい抽象化・共通基盤は、現在使う2〜3ケースで必要になった時点で追加する。将来候補だけのために先行実装しない。

### 次の定点

1. **K6定点**：黄金像の動物／お金／アイテム抽選が翌朝まで一周する。
2. **K7定点**：カルマが報酬Rarityと敵出現条件へ実際につながる。
3. **K8定点**：仲間化を採用する場合、その最小1ケースが一周する。
4. その後、カルマ0ルートとカルマ利用ルートを人間が数日試遊して比較する。
