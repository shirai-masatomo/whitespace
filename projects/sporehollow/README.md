# ホイッスル牧場 — コロニー開発版

Godot 4.7.2 の牧場防衛ゲームです。50×34マスの牧場で人へ作業を割り当て、動物と黄金像を守ります。開発中のソース公開であり、ゲーム全体の完成や人間試遊による面白さの確認を意味しません。

## 起動

Godot 4.7.2 でこのフォルダの `project.godot` を開いて実行してください。Windows用の開発ツールを取得する場合は PowerShell 7 で `./tools/setup.ps1` を実行します。

セーブは Godot の専用ユーザーフォルダ `WhistleResearchAutonomy` に保存します。ゲーム内の新規開始は現在の開発版セーブを置き換えます。

## 操作と実装範囲

- 地図の空白を左ドラッグして移動、ホイールで拡大縮小。ドラッグ中は握った手になります。
- Architectで建築とゾーンを指定します。右クリックで選択・未確定の範囲を解除します。
- 役割表で人ごとの作業優先度を1～4または空欄に切り替えます。同順位は左の作業が優先です。
- 住人を選択し、通常状態で商人を左クリックして「交渉」を選ぶと、その本人が商人へ向かいます。到着後に既存の店を開き、閉じると中断した仕事を再評価します。建築や範囲指定中の右クリックは操作解除が優先です。
- 保管ゾーンは置き先です。物の運搬は「命令→回収」で単体または範囲を明示します。建築と食事は必要な実物を取りに行きます。
- 資材の運搬、空腹・栄養不足、採掘、訓練、家畜の屠殺、徴兵時の攻撃と装備を実装しています。数値と装備の種類は暫定です。
- 地図の端のマスまで移動・建築・指示が可能です。人と動物は自分が端の1歩外へ出ると連れ去り確定、黄金像は2×2全体が外へ出ると失われます。不可視の外森での救出区間はありません。
- 昼夜は継続し、夜明けに敵が残っていても時間は進みます。通常の終了・再開では作業、物資、敵、時計の状態を復元します。

## 素材

実際に参照する画像は `art_delivery/` と `assets/` に収録しています。採用済み人物・動物のフレーム、UI、建築物、黄金像を含みます。`ASSETS.md` に主な場所と出典を記載しています。

ローカル試遊用に提供された昼BGMのMP3は配布条件が未確認のため含めていません。音源がなくても合成環境音と効果音で動作します。利用権のある同名ファイルを `assets/audio/Porch_Swing_Serenade.mp3` に置くと昼BGMを読み込みます。

## 検証

PowerShell 7 で `./tools/verify.ps1` を実行すると、専用のデータフォルダを使い、境界・保存移行・明示回収・本人の交渉指示と作業復帰をheadlessで確認します。通常のデスクトップや既存セーブは操作しません。

GPU上の入力・描画とWindows EXEの終了／再開もローカルで確認しています。これらは合成入力と制御したシミュレーションによる確認です。人間による長時間試遊や楽しさの評価は別です。
