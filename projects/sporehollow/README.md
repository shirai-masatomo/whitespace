# ホイッスル牧場（仮）

**動物を育て、まかせて、ときどき手を貸す。** 育成 × 小さな経営 × 間接防衛のWindows向け2D試作。

[Play.cmd](Play.cmd) をダブルクリック、または `build/WhistleRanch.exe` を起動。ブラウザ・通信・Godot Editorの起動は不要。Stage 1 → 評価・購入 → Stage 2まで約2〜4分。

以前の「胞庭」は今回の人間方針で置き換えた。技術的なフォルダ名 `sporehollow` はリンク維持のため残す。旧ブラウザ試作はcommit `f3d5968` のGit履歴にあり、現行版に混在させない。DIVE DIVEとは独立したコード・TASKS・ビルド・CI。

## 遊び方

1. 最初の仲間は **柴犬 Lv1 ×1**。準備中に柵の内側をクリックして見張り場所を決める。輪はおおよその警戒範囲。
2. 「朝をはじめる」。上下から来る泥棒に柴犬が自律反応する。飼料・卵を合計2個持ち出される前に追い返す。
3. 道具を選び、盤面を左クリック。柴犬の元気と指示力を見ながら介入する。
4. 成功後はEXP・Goldを受け取り、鶏・餌・施設を購入。「Stage 2へ進む」で所有・Lv・Gold・餌・卵・施設を引き継ぐ。
5. Stage 2では斥候が加わる。鶏は落ち着くと卵を産むが、近くの敵から逃げ、しばらく産卵が止まる。卵も盗まれる。

| 操作 | 効果と代償 |
| --- | --- |
| 1 / ホイッスル | 指定地点へ犬を呼ぶ・見張り位置を変える。指示力2。近い侵入者への反応は犬が優先 |
| 2 / 餌 | 餌1・指示力3で設置。疲れた犬が自分で向かい元気48回復。防衛地点から離れることもある |
| 3 / 門 | 金色の門をクリック。指示力1。犬も通れなくなり、泥棒は閉じた門を壊せる |
| Space / 一時停止 | 考える時間を確保。停止中も指示可能 |
| 速度 ×1 / ×2 | 時間の進行を変更 |
| この日の最初から | 当日開始時へ戻る。失敗で購入資産を失わず、結果報酬を重複獲得できない |

指示力は最大10、約3.6秒で1回復。直接攻撃はない。プレイヤーが動かす人物もいない。動物や泥棒は死亡せず、吠えて追い返す表現。

## ゲームデザイン（人間・AI共通の正本）

### 確定する軸

- 開始は柴犬Lv1だけ。各個体にカテゴリー・種類・Lv・EXPを持たせる。
- 動物の自律行動と、配置・指示・餌・施設による間接介入が中核。攻撃塔の設置ゲームにはしない。
- ステージ制。所有動物・育成・経済・施設を引き継ぐ。単純な動物の上位互換は作らない。
- 畜産物は守る資源であると同時に経済・育成に使う。今回は卵だけ。
- オフライン試作。既存作品の名称・ステージ・キャラクター・アートを使用しない。

### 今回の実装と仮数値

| 項目 | 試作上の扱い |
| --- | --- |
| 犬 / 柴犬 | 狭い範囲を警戒、追跡、吠える。走る・吠えると疲れ、休む・食べると回復。Lvで警戒・疲労効率が伸びる |
| 鳥 / 鶏 | 接近した侵入者を怖がって逃げる。安全が続くと産卵、Lvで周期短縮。攻撃しない |
| 侵入者 | 泥棒とStage 2の速い斥候。卵があれば巣、なければ飼料庫を狙い、盗んで出口へ戻る |
| 評価 | 防衛35・残した資源25・犬の元気20・門の被害10・指示効率10。時間は記録のみで報酬加算しない |
| EXP | 成功時16＋評価÷10。参加個体全てに付与。必要EXPはLv×20 |
| Gold | 初期12。成功32＋評価÷5＋追返人数×3。Stage中の回収分も成功時に精算 |
| 購入 | 鶏30G、餌3個8G、休憩小屋28G、補強門24G。試作は犬1＋鶏1まで |
| 卵 | 売却9G / 餌2個への交換。次の日へ持ち越す |
| 小屋 | 盤上に休憩場所を設置。近くで見張り中の犬の回復が速くなる。笛・配置との組合せ |
| 門補強 | 次の日の門耐久6→10。途中の破損は日替わりで修復 |
| 日替わり | 動物は元気を戻し、門・飼料は補充。育成・購入資産は引継ぎ。アプリ終了後の保存は未実装 |

### 試作仮説と未確定事項

「全部を指示する」より、**別方向への侵入を知らせる / 疲れた犬を食べさせる / 門で到着をずらす**判断を試す。Stage 1は配置学習、Stage 2は産卵と複数方向の防衛。

現時点ではStage 1の良い配置だけでも勝てる。Stage 2は餌と門を含む介入で成績が変わるが、これを面白さの合格とはしない。次は、早すぎる笛・餌・閉門がどんな失敗を招いたかを短いプレイで確かめる。

牧場か動物園か、外敵の正式設定、犬種追加、生産加工の深さ、繁殖、土地拡張は未確定。オンライン・非対称対戦・Steam・セーブ・Stage 3以降は今回作らない。大きな方向転換と遊びの好みは人間が判断する。

## 開発・AI検証

Godot 4.7.2 / GDScript / Compatibility描画。通常はheadless。プロジェクトフォルダから:

```powershell
./tools/setup.ps1       # 公式Godot・export templateをSHA512検証して取得
./dev.ps1 test          # ルール、育成、経済、引継ぎ
./dev.ps1 evaluate      # 2ステージ × 5介入方法 × 8 seeds
./dev.ps1 build         # Windows exe + headless起動
./dev.ps1 check         # 制作サイクルの節目に一括
./dev.ps1 visual        # 画面外・非捕捉・無音の実GPUとGodot入力テスト
./dev.ps1 editor        # Godot Editor
```

- `game/world.gd`: 固定刻みルール、キャンペーン、コマンド、数値状態。
- `game/raider_ai.gd`: 侵入者の目標を選ぶController。将来人間の目標入力へ交換可能。通信はない。
- `game/main.gd`: 描画・UI・入力。ゲームルールを二重実装しない。
- `tests/evaluate.gd`: 放置・初期配置・笛・餌併用・門併用を同条件比較。結果は `artifacts/evaluation.json`。
- 画面の「観察JSON」は `%APPDATA%/Godot/app_userdata/ホイッスル牧場/observations/latest.json` へ保存。個体の種類/Lv/経路、侵入経路と目的、盗難、Gold、指示量、評価、時間、操作履歴を取得できる。ゲーム進行のセーブではない。
- CIはWindowsで公式ツール準備→headlessテスト→比較→export→exe起動。画像の良さ・面白さはCIで合格にしない。
