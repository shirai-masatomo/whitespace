# ホイッスル牧場（仮）

**牧場経営 × 育成 × リアルタイム構築 × 間接防衛。**  
主人公は牧場を経営し、夜に襲う野盗から牧場・動物・自分自身を守る。

## 1日の流れ

**購入・育成 → 夜の防衛 → 夜明け → 生産・成長 → 次の購入・育成**

- Campaign開始も**購入フェーズから**。初期所有動物は愛犬の柴犬1匹。
- 初期軍資金を使い、動物・素材・アイテム等を選んで最初の夜へ備える。
- 序盤ショップはある程度固定。鶏・猫も買えるが、買うと素材購入が厳しくなる程度の価格にする。
- 夜開始前に主人公の初期位置を決める。配置すると夜が始まる。
- 夜は一旦**3分**。
- **夜明けまで耐える**、または**その夜の野盗を全員撃退**すると防衛成功。
- 早期全滅後は、夜明けまで牧場内で活動を続けてもよい。
- 早期全滅後に活動を終了した場合は、残り時間が多いほどボーナス。
- 夜明け時に産卵・孵化・成長等の日次処理を行う。
- 夜明け後、商人が来て購入・売却・育成を行う。

## 敗北

- 主人公が牧場外へ連れ去られる。
- 牧場耐久0は第2敗北条件候補。詳細は今後調整。

## プレイヤー操作

プレイヤー自身は攻撃しない。

- 動物の配置・指示
- 壁・門・施設の建築
- 修理・解体
- 資源・アイテム回収
- 施設操作
- 時間操作

### 時間

- PAUSE / 0.5x / 1x / 2x
- PAUSE中は動物への指示予約のみ。建築・修理・回収等は不可。
- WASD：カメラ移動
- Ctrl+ホイール：ズーム
- Space：PAUSE
- **速度変更のキーボードショートカットは未実装。**

### モード

- 建設
- 動物
- 回収

盤面上の対象を直接クリックすると対応モードへ切り替える。

**動物モード開始時は個体未選択。**  
未配置動物を明示的に選んだ時だけ配置プレビューへ入る。

Tabはモード内の候補選択に使う。  
**動物モードでは、未配置の所有動物を壁・門と同じ感覚で順番に選べるようにする。**

## 動物

動物の個別仕様は **[ANIMALS.md](ANIMALS.md)** を正本とする。

共通：
- HP0は特記がなければ気絶。翌日は出撃不可。
- 所有・仲間化した動物は原則命名可能。
- 一部動物に親密度を持たせ、将来ボーナスへ使用。
- Lv上限5。
- EXPは共通プールへ蓄積し、購入・育成フェーズで任意の動物へ使用する。

## 資源

| 資源 | 主用途 |
| --- | --- |
| 土 | 壁・門・修理 |
| 木材 | 犬小屋等 |
| 石 | 将来施設 |
| Gold | ショップ |

HUDでは土・木・石・Goldを別アイコンで表示する。

## 建築

### 壁 Lv1
- HP8
- 土10
- 建築1秒
- 動物・敵の通常通行不可
- 敵が破壊可能

### 門
- 開閉可能
- 敵の侵入口は外周の明確なゲートとして表示
- コスト等は仮調整

### 犬小屋
- **犬小屋設計図をフィールドで回収して解放**
- 木材20
- 1棟1犬
- 毎秒HP1回復

### 解体
返却量は仮に  
**floor(建築費 × 現在HP/最大HP × 0.8)**。  
複数施設を一括解体可能。

施設の配置・損傷・破壊状態は翌日へ持ち越す。

## 自然物

ゲーム内時間**1秒ごとに抽選**。PAUSE中は進まない。

現在のStage1仮値：
- 発生抽選：20%
- 種類weight：雑草80 / キノコ15 / 切り株5
- 1夜上限：雑草10 / キノコ3 / 切り株1

| 自然物 | 回収 |
| --- | --- |
| 雑草 | +1 Gold |
| キノコ | 夜終了時、HP割合が低い出撃動物からHP5回復 |
| 切り株 | 木材20 |

確率・上限はバランス調整対象。

## 購入・育成フェーズ

最上位は **買う / 売る**。

カテゴリ：
- 動物
- 素材
- 施設
- アイテム

畜産物はアイテム扱い。

- 動物はStageに応じた候補からランダム入荷。
- 序盤は方向性を選べるよう、ある程度の商品を固定/保証する。
- 設計図を回収・購入すると建築種類が増える。
- 買値 > 売値。転売だけで利益が出ない。
- 動物Lvアップは**共通EXPプールを消費して任意**。自動Lvアップしない。

## 卵・日次成長

詳細は [ANIMALS.md](ANIMALS.md) の鶏を参照。

- 夜明け時に鶏が卵を産む。
- 卵を1日放置 → ひよこ。
- ひよこを1日放置 → 鶏。
- 卵は回収して売却・加工等に使える。

## Stage1

- 初回購入・育成フェーズから開始。
- 夜は3分。
- 最初の誘拐者Lv1は夜開始10秒後に1体。
- 誘拐者Lv1：HP50 / 対動物攻撃5 / 対施設攻撃2。
- 初期建築素材：土100を基準。初期軍資金はショップ構成と合わせて再調整。
- 誘拐者撃退時、**犬小屋設計図をその場にドロップ**。
- 設計図を回収すると犬小屋を建築可能になる。

## 敵・将来拡張

敵の個別仕様は **[ENEMIES.md](ENEMIES.md)** を正本とする。

敵は視界距離と視認状態を持つ。主人公を視認できれば直接狙えるが、見えていなければ園内を探す必要がある。

敵Role候補：
- 誘拐
- 施設破壊
- 動物攻撃
- バランサー
- 支援
- 妨害

敵が動物を連れてくる場合があり、条件次第で仲間化できる。

中盤以降は通常の動物に加え、変わった生物・卵も購入/入手可能にする。

## 昼夜演出

- 昼/夕方/夜/夜明けで盤面の色・環境音を変える。
- 夜開始：太陽→月の短いカットイン。
- 夜明け：月→太陽、鳥声の復帰、生産・成長処理。
- 夜は門灯・月明かり・虫/コオロギ等で雰囲気を出す。
- 夜明け後に商人が来る演出を候補とする。
