# ホイッスル牧場（WhiteSpace）

**普段読むのは [世界観・ゲーム仕様](SPEC.md) だけです。** ゲームの問い、マップ生成、資材・建築・製作、動物・敵、商人、操作、採用済みの今後の仕様までこの1冊にまとめています。

起動入口はこれまでと同じ `確認入口/最新開発版.lnk`。Godot 4.7.2のプロジェクトはこのフォルダの `project.godot`。PC全体フリーズがあったため、ユーザーの通常デスクトップでゲームを勝手に起動しません。

**数が増える一覧だけ別資料**： [動物](docs/catalog/ANIMALS.md) ／ [敵](docs/catalog/ENEMIES.md) ／ [アイテム](docs/catalog/ITEMS.md)

開発担当が使う資料： [実装・配布状態](PROJECT_STATE.md) ／ [技術詳細と旧仕様](docs/internal/README.md) ／ [検証原本](review/current/README.md) ／ [画像納品](art_delivery/)

**企画を更新する場合は `SPEC.md` を更新してください。** 新規の長文仕様ファイルをユーザー向けに増やさず、実装済みと未反映を区別します。
