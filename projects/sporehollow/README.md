# ホイッスル牧場（仮）

UI荷車・土木石金の資源アイコン・既存誘拐者の左右動作/運搬・小演出を正式納品素材へ置換。本と盤面荷車、取引・戦闘ルールは維持。

**牧場経営 × 育成 × リアルタイム構築 × 間接防衛。**  
主人公は牧場を経営し、夜に襲う野盗から牧場・動物・自分自身を守る。

設計正本： [世界観](WORLD_STORY.md) / [黄金像・森・世界システム](WORLD_SYSTEMS.md) / [動物図鑑](ANIMALS.md) / [敵図鑑](ENEMIES.md) / [アイテム図鑑](ITEMS.md) / [建築](BUILDINGS.md)。

**起動は [Play.cmd](Play.cmd) をダブルクリック。** `build/WhistleRanch.exe` が通常版です。検証フォルダのEXEを探す必要はありません。
`Play.cmd` はWindows用のCRLF改行で管理します。起動しない場合の非起動検査は `./tests/test_launcher.ps1`。ゲーム画面を開かず、起動先の有無とcmdの読み取りを検査します。
開発時は `./dev.ps1 build` が検証成功後に通常版を更新します（起動中は更新を拒否）。`check` は検証のみ。ビルド番号はESCメニューと `build/BUILD.json` で確認できます。

## 1日の流れ

**朝の市 → 昼の牧場仕事 → 夜の仕事と防衛 → 夜明け・生産・成長 → 次の朝**

- Campaign開始は**朝の牧場・主人公と愛犬・商人の到着**を短く見せてから購入・育成へ。ショップをいきなり開かない。初期所有動物は愛犬の柴犬1匹。
- 初期軍資金を使い、動物・素材・アイテム等を選んで最初の夜へ備える。
- 序盤ショップはある程度固定。鶏・猫も買えるが、買うと素材購入が厳しくなる程度の価格にする。
- 商人を見送ると、同じ牧場で昼の時計が進む。昼は仮に90秒。主人公の別途配置は不要。
- 昼も夜も主人公は歩いて仕事をする。日暮れに位置・動物・施設・予定をリセットしない。夜だけ外敵が襲来する。
- 夜は一旦**3分**。
- **夜明けまで耐える**、または**その夜の野盗を全員撃退**すると防衛成功。
- 早期全滅時は**「今夜の襲撃を退けた」ことを画面中央で明確に知らせる**。その後、夜明けまで牧場内で活動を続けてもよい。
- 早期全滅後は「朝まで休む」で残り時間を通常の休息として過ごせる。選択時点の floor(残り秒数 / 10) Gold を夜明けに一度だけ加算（仮）。途中中断では受け取らない。通常の夜明けはボーナス0。
- 夜明け時に産卵・孵化・成長等の日次処理を行う。
- 夜明けは牧場を見せたまま報酬と生産を短く伝え、少し落ち着いた後に商人の荷車が来る。到着してから購入・売却・育成を行う。
- 「支度を終える」で商人を見送り、昼の牧場仕事へ。日暮れは同じ盤面の光が変わる。昼→夜の間も操作を止めない。夜明けの短い演出と商人の到着は維持する。

## 敗北

- 主人公が牧場外へ連れ去られる。
- 牧場耐久0は第2敗北条件候補。詳細は今後調整。

## プレイヤー操作

ESCメニューから「昼からやり直す」に加え、**購入・育成フェーズ開始時点からやり直す**操作を用意する。同じ商品の抽選結果/seedへ戻す。


主人公は隣接する敵へ弱く抵抗する。本格的な迎撃は動物と牧場の構造を頼る。

- 園内の動物への現地指示・誘導
- 壁・床・ドア・施設の建築
- 修理・解体
- 資源・アイテム回収
- 施設操作
- 時間操作

### 時間

- PAUSE / 0.5x / 1x / 2x。休息中のみ4xも選べる。敵襲・発見・接近・被弾・動物の危険・運搬で自動的に1xへ戻る。
- PAUSE中は計画する時間。作業・移動・時計・回復は止まるが、仕事/移動/動物指示の予約、未実行予定の取消、並べ替え、対象選択は可能。実作業は再開後。着工済み工事の中断も再開後に処理する。
- WASD：カメラ移動
- Ctrl+ホイール：ズーム
- Space：PAUSE
- - / +（=キー・テンキーも可）：0.5x / 1x / 2xを一段階ずつ変更。休息中は4xまで。速度ボタンのホバーとESCの操作説明でも確認できる。残り時間を休む時間送り中は倍率変更を使わず、先に時間送りを中断する。

### 仕事の予定

- 初期状態はどのモードも選ばないニュートラル。空き地のクリックでは何もしない。牧場主を直接クリック、「牧場主」タブ、またはホイールで選び、**地面を左クリックして移動**する。人物・動物・施設・回収物の操作が地面移動より優先。物のない施工床は地面と同じく移動先にできる。旗は到着・失効で消える。仕事は実行中を含め最大8件。
- 建築・改築・回収・修理・解体・ドア開閉・動物指示は **予約 → 主人公が隣接マスへ移動 → 現地で実行**。指示も主人公の接近後に実行する。
- 建築予定は薄い杭と小さな木札で表示。予定そのものは通行を妨げず、完成した壁は通行を妨げる。ドアは権限に応じて開けて通る。工期は建築表に従う。
- 建築資材は予約時に確保。着工前の取り消しでは全額を戻す。着工後の取り消しは既存の中断返却率（仮50%）を使う。
- 右上の札と盤面は同じ順番番号。×または予約を選んだ近くの「取消」で1件だけ取り消す。後続札をドラッグすると浮き、元の空き枠・挿入線・周囲の移動で位置を示す。離すと短く収まり、範囲外なら元へ戻る。移動/作業中の先頭は固定。施工不能で待っている札は並べ替えられ、犬の誘導などを先に実行できる。表示番号と不変のJobIDは別管理。
- **牧場主選択＋地面左クリック**は仕事を消さず保留し、直接移動する。既存作業を中断した避難なら到着後も「作業再開」まで保留。仕事なしの通常移動後は新しい依頼を開始できる。移動中の新規予約も、到達不能・強制休息で移動が終了した場合は、その移動だけの保留を解いて続けられる。起床は休息前の保留理由へ戻し、避難/救出の保留を勝手に解かない。
- **盤面右クリックは選択解除だけ**。ニュートラルへ戻り、未確定プレビューを消す。登録済みの仕事・移動・休息は継続。ドラッグ中は未確定のドラッグだけを取り消す。
- 主人公は仮に毎秒2.5マス。回収などの到達不能な仕事は取り消して後続へ進む。建築は進捗/素材を保って理由を表示し、取消や順番変更で対応する。誘導は閉塞が合計20秒続くと終了（仮）。対象や資源の状態は到着時に再確認する。
- 牧場主選択中/キュー編集中の赤い経路は、実移動と同じ経路探索で壁を避け、味方が開けられるドアを通り、隣接作業地点、動物への接近→誘導先を順番に示す。同じ区間の往復はずらした点線と矢印で区別し、重複は2本まで。保留計画も点線。通れない区間は終端印にする。動く個体/後で完成する壁は先読みしない。
- 保留理由はキュー見出しに短く示す。手動避難・休息・救出/被弾・通路/配置先閉塞を区別し、保留時にはキュー直下にも再開ボタンを出す。
- 気絶/運搬/休息中は作業を停止。救出後も仕事を保留する。
- 昼→夜では予定を維持。夜明けも建築/改築の予定・確保素材・進捗を残し、翌日の現地作業で続ける。その他の仕事は夜明けに終了する。

### 直接回収と選択

落ちた物を1回クリックすると現地回収を予約する。重複予約はしない。回収専用タブは使わない。ドラッグした場合は単体クリックを発火させず、回収物の選択後だけ「回収」を表示する。一括予約は近い順に空き枠まで、未登録の選択を残して件数を伝える。選択は動物・回収物・建物・床とも最大8対象（ドラッグ/Ctrl追加共通）。ドラッグへ入った順、同時なら開始点からの距離と固定識別子で決める。仕事の空き枠とは別で、仕事5件＋回収物8対象なら3件予約・5件未登録。動物への指示も現地仕事として最大8件の枠を使う。

選択対象付近に必要な「修理」「解体」「回収」「開閉」「取消」を表示する。予約済みは無効表示や取消へ。修理不要なら修理を出さない。費用/返却はホバー。ボタンはすべて現地仕事の予約で、停止中は計画だけを変える。解体はボタンのみ（Del・右クリック解体なし）。

入力優先順は **UI → 有効な建設ツールの設置判定 → 対象の選択/操作 → 牧場主選択時の地面左クリック移動**。建設プレビュー中は落とし物・動物を押しても回収や選択へ切り替えず、建設不可の理由を表示する。無効ボタンも押下から解放まで盤面入力を遮断する。牧場主選択中と「連れていく」の行き先指定中は、物のない床を選択せず移動/誘導先にする。通常選択では床を選び、近くの修理/解体を使える。この優先順は停止中も同じ。右クリックは移動・解体・登録済み予約取消を行わない。

### モード

- 建設
- 指示
- 牧場主

初回・やり直し・選択解除後はニュートラル（タブ強調なし、通常カーソル）。ホイール下で **建設→指示→牧場主→建設**、上は逆。ニュートラルからは下で建設、上で牧場主へ入る。スクロール可能UI・市場・図鑑はUI優先、装飾やスクロール用途のない余白は巡回を妨げない。Ctrl+ホイールはズーム。建設/指示へ入っただけでは対象を選ばない。牧場主は盤面選択でもタブ強調が同期する。Qは使わない。カーソルは通常/工具/ホイッスル/行き先旗。矢印先端が共通のクリック位置。選択・モード変更自体は移動/仕事/休息を止めない。
**指示モード**は園内の個体をクリックして使う。柴犬は既存の指示と移動誘導、鶏は移動誘導のみ（仮）、猫は情報確認のみ。初期の愛犬も購入個体も園内で生活し、朝昼夜で収納し直さない。購入個体は既存の牧場入口から通れる近傍の空き場所へ加わる（仮に入口から4マス以内）。入口が塞がっている時は受入待ちとし、無関係な部屋へ出現させない。待機小屋・犬小屋・鶏小屋は通常プレイから外す。気絶個体は園内の現在地で翌日療養する。有効な空きがなければ受入待ちとして知らせる。

指示はAnimalIDを持つ仕事。主人公が動いている相手へ近づいて発令し、移動誘導では実在個体を連れて歩く。到着後は元の指示へ戻す（仮）。取消・主人公被弾/気絶/運搬で誘導を終え、その場で通常AIへ戻る。個体を収納・複製・瞬間移動しない。非対応・療養・到達不能は理由を示す。

ホイッスルは非消耗の所持効果。仮に買18G/売6G、距離6（縦横マス距離）、音は壁を通る。未所持は隣接・1匹。所持時は最大8匹を1仕事で段階的に呼び、到達可能な別々のマスへ誘導する。忠誠度・通行・屋内制限は無効化しない。初版の指示受諾率は柴犬90%＋忠誠度×0.1%、鶏100%（仮）。拒否は1回で終わる。

Tab/Shift+Tabは**現在モードのサブタスクを順/逆に選ぶだけ**。建設は表示中の有効な候補、指示は選択個体に対応する命令、牧場主は表示中の有効な操作を巡回。ニュートラルでは何もしない。指示モードで未選択なら、最初のTabは牧場主からマス距離が近い活動可能・指示対応動物を選ぶ（同距離は固定ID順、仮ルール）。次のTabから命令を選ぶ。命令発行はボタンクリック、誘導は行き先指定で確定する。Tabだけで休息・飲料使用・仕事追加はしない。Ctrl追加/ドラッグ選択は最大8対象。

建設・指示の**操作ボタン自体をドラッグ**すると表示順を変更する。7px以上の移動でドラッグ、浮く札・元の空き枠・挿入線を表示。範囲外、Esc、右クリックで並べ替えだけ取消。固定操作IDで順序を保持し、Tabもその順を使う。種別で一時非表示の操作は順序を保ち、新規操作は末尾へ追加。`user://ui-settings.cfg`へUI順序だけ保存する。仕事キューの順序変更とは独立し、キャンペーン全体の永続セーブではない。

朝の入口は「朝の市／牧場の仲間／支度を終える」。市場は**買う・売る→カテゴリ→一覧→詳細**。右上の「戻る」または右クリックで一階層戻る。「メニューへ」は朝の入口へ直接戻る。昼へ進むのは「支度を終える」だけ。図鑑の右クリックは本を閉じ、前ページにはしない。命名入力では盤面ショートカットを処理しない。

市場の商品列は左揃えの共通カード。購入できない品も詳細は開け、一覧に「あと○G／売り切れ」を表示する。資材は「木材 ×20」「店の在庫：3セット」「所持：木材20」で取引単位と個数を区別。売却可能なセット数に足りない手持ちも確認できる。詳細に次の取引後の所持金、取引結果には今回の増減と前後の所持金を表示する。結果はその詳細を離れるまで残し、連続取引では最新の1件に置き換える。朝の入口にも所持金を表示する。価格・販売単位・在庫生成は変更しない。

本は納品表紙→開く→本文→紙と本文のページ送り→閉じる。仮のUI時間は開閉0.54秒、送り0.42秒。世界の停止/倍率と独立し、演出中の送り連打は蓄積しない。Esc/右クリック/メニューへで安全に閉じられる。

### 残り時間を休む

昼は「夜まで休む」、襲来予定を消化し脅威が残っていない夜は「朝まで休む」。現在地で仕事を保留し、既存の固定tickを仮24倍で進める。屋外5秒/屋内3秒は眠気回復待ち、既に休息中なら待ち時間を引き継ぐ。HP・動物・自然・施設・日次処理も通常進行と同じ。停止中に押した場合は予定だけ。

時間送りは中断可能。危険時と昼→夜で1xへ戻し、夜開始は自主休息から起床する。強制休息は80%未満という解除条件を維持。既存仕事は「作業再開」まで保留。気絶/運搬や動物誘導中は使用不可。朝の市の滞在時間は世界時間に含めない。

## 主人公の体調（試作値）

- HP30、自己防衛の攻撃2、間隔1.5秒。敵は隣接攻撃し、健康な主人公を即運搬しない。
- HP0は気絶。行動不能だが即敗北ではない。敵は気絶後に担ぎ、牧場外へ運ぶと敗北。柴犬は気絶付近の敵/運搬者を優先する。「休む」中の犬は救出しない。
- 運搬されていない気絶は12秒後にHP8で目覚め、休息する。救出直後はHP0のまま。夜明けを越す場合は最低HP8で朝を迎える。
- 眠気は起きている270秒（昼90＋夜180を1日相当）で0→100%。朝の市では時間が進まない。眠気とHPは日をまたいで維持する。
- 見た目は50%以下で通常、50%超～80%で重い目と小さな月、80%超で傾いた姿勢・月と下向き矢印・少量の落ちるもや。未選択でも見え、現在の値へ即座に追従する。60/80/90/100%の警告は維持。能力低下は従来どおり80%以上で、移動・建築・回収などの仕事速度が60%。100%はその場で強制休息し、80%未満まで起きられない。
- することがない安全な状態で5ゲーム秒待機すると自動休息を始め、その後に屋外5秒／屋内3秒の入眠待ちを行う（仮）。仕事・指示・移動・閉塞待ち・明示保留・近距離3マス以内の敵・被弾後2秒・気絶/運搬中は対象外。PAUSE/朝/メニュー中は待機時計も停止。自動休息は新しい有効仕事・移動・危険で起床し、選択やカメラ操作では起きない。眠気0でも新たな用事まで休息を続け、寝起きの反復を防ぐ。倍率は変更しない。手動/強制休息とは区別する。
- 「休息」は現在地で自主休息。自主/強制とも屋外はゲーム内5秒後から毎秒2ポイント、屋内は3秒後から毎秒4ポイント眠気を減らす（仮）。HP回復は共通。囲い破損後は屋外速度へ戻るが、既に入眠した状態や休息経過時間は戻さない。中断で待ち時間をリセットし、継続したままの日暮れではリセットしない。HPは既存どおり5秒に1回復。世界と動物は進む。通常の休息は「起きる」や牧場主選択中の地面左クリック移動でいつでも中断できる。
- コーヒーは眠気12、活力ドリンクは25軽減。各朝1本ずつ入荷、飲み物合計1日2本まで。眠気を帳消しにし続ける代替睡眠にはしない。
- 入眠待ちの間は座って待つ「…」、睡眠は横になる「Zzz」、気絶は「!」、運搬は敵の肩の姿で区別。起きている眠気にZzzは出さない。
- HP/眠気/今の行動/先の仕事は主人公選択時の小さなカードへ。被弾時は足元近くのHP、眠気は小さな眠そうな表示で知らせる。
- 数値・回復・昼夜換算は仮調整。空腹、病気、寝床設備等は今回の範囲外。

## 動物

動物の個別仕様は **[ANIMALS.md](ANIMALS.md)** を正本とする。

共通：
- HP0は特記がなければ気絶。翌日は療養で活動不可。
- 所有・仲間化した動物は原則命名可能。
- 一部動物に親密度を持たせ、将来ボーナスへ使用。
- 検知範囲と攻撃対象範囲は別ステータス。共有された敵情報でも、攻撃対象範囲外なら攻撃対象にはしない。
- スキルは発動/パッシブに分類し、解放Lvを持つ。Lvアップ画面で現在/将来スキルを確認できる。
- Lv上限5。
- EXPは共通プールへ蓄積し、購入・育成フェーズで任意の動物へ使用する。

## 建築

壁・床・ドア・施錠・屋内条件は [BUILDINGS.md](BUILDINGS.md) を参照。床は構造物とは別の層。重なっている場所は対象付近の「床を見る／建物を見る」で切り替え、床は「タイルを解体」で現地解体を予約する。床上の建物は先に解体する（仮）。床だけを除去し、落とし物は残す。層ごとの複数選択は8対象まで。返却は支払済みの最新素材×耐久率×80%の切捨てで、完了時一度だけ。施工も改築も現地仕事で、動物のいるマスや屋外専用種を囲い込む完成は許可しない。予約・着工・完成時に再確認する。

柴犬は救出・追跡でも屋内へ入らない。屋内で運搬される主人公の部屋に接続する出口から、到達可能な屋外待機地点を選ぶ。無関係な部屋のドアは対象にしない。

## 自然物

ゲーム内時間**1秒ごとに抽選**。PAUSE中は進まない。

- 種類weight：雑草80 / キノコ15 / 切り株5
- 1日（昼＋夜）上限：雑草10 / キノコ3 / 切り株1

| 自然物 | 回収 |
| --- | --- |
| 雑草 | +1 Gold |
| キノコ | 夜終了時、HP割合が低い園内の動物からHP5回復 |

確率・上限はバランス調整対象。

## 購入・育成フェーズ

朝の場面から **朝の市 / 動物図鑑** を別々に開く。閉じると朝の場面へ戻り、昼へ進む「支度を終える」と区別する。朝の市は減光した牧場を背景に木枠・布の前景を置き、最上位は **買う / 売る**。

- 買う：商品カテゴリへ進む
- 売る：所持品カテゴリへ進む
動物図鑑は市場とは別。見開きの個体ページで育成・命名する。開閉0.4秒、ページ送り0.3秒（仮）。設定済みスキルの発動/パッシブ・解放Lv・CTを確認できる。

買う / 売るのカテゴリ：
- 動物
- 素材
- 施設
- アイテム

畜産物はアイテム扱い。

品の種類（絵付き2×2）→商品一覧→商品詳細→購入/売却の順。商品カードを見ただけでは取引しない。「← 戻る」は一階層だけ戻り、「閉じる」は朝の場面へ。朝の「支度を終える」でのみ昼へ進む。売り切れ・資金不足では取引ボタンを無効にする。

指定された柴犬ドットを盤面・予約姿・図鑑で共通使用する。素材の出典は [assets/ui/SOURCES.md](assets/ui/SOURCES.md)。

画面の共通表現は木の縁・生成りの札・落ち着いた緑。選択中は緑の縁、押下は沈む陰影、無効は灰草色、危険は赤土色。HPはゲージ、報酬は小さな絵と数値を使う。市場・図鑑では牧場を減光して奥へ置き、前景の文字や商品は鮮明にする。動物は姿・名前・元気さを先に見せ、数値や特技はその次に置く。

- 愛犬の柴犬は初期所有のみで、ショップには並ばない。
- 動物はStageに応じた候補からランダム入荷。
- 序盤は方向性を選べるよう、ある程度の商品を固定/保証する。
- 設計図の巻物は現地回収時に消費し、取得記録と習得状態を別に保持する。「○○の設計図を手に入れた。」と、初習得時だけ「○○の作り方を覚えた。」を通知。重複取得で再習得・在庫増殖しない。翌朝/キャンペーン再構成で維持するが、ファイルへの永続セーブは未実装。
- 買値 > 売値。転売だけで利益が出ない。
- 動物Lvアップは**共通EXPプールを消費して任意**。自動Lvアップしない。仮に現在Lv×20 EXPを消費。
- 「犬用餌」「鶏用餌」等の個別餌は一旦ショップ/基本ループから外す。
- 育成・命名で個体を選ぶ。名前は12文字まで、空欄なら種類名。

## 昼夜演出

- 昼/夕方/夜/夜明けで盤面の色・環境音を変える。
- 日暮れは同じ牧場が徐々に夜色へ変わる。主人公の位置・作業予定・操作を維持し、夜専用の配置画面へ切り替えない。
- 夜明け：月→太陽を**大きく見せる**切替演出、鳥声の復帰、生産・成長処理。
- 夜は門灯・月明かり・虫/コオロギ等で雰囲気を出す。
- 夜明け後、門付近に商人と荷車が来る。
- 商人到着・見送り・夜明けの短い演出中は通常UIを隠す。昼から夜への移行は操作を止めず、作業UIも維持する。
- ショップは荷車・木箱・商品台を背景に、商人の短い言葉で迎える。恒常的な手順説明を増やさない。
- 動物の選択情報は顔/姿・HPゲージ・短い状態を中心にし、具体HPは必要時に確認できる。クリック・誘導・発見・撃退へ小さく反応する。
- 撃退した敵の選択と生存中の状態表示は解除する。

## 検証用操作

F3でデバッグ表示を切り替える（通常OFF）。DEBUG表示中は素材無制限、実装済み3種の追加、ホイッスル付与、選択対象のHP±10、選択した正常なロック付きドアのロック耐久−4を使える。HP/耐久0も通常の気絶/退散/破壊へ進む。屋内は薄く色分けする。無制限で確保した素材は取消でも返却されない。F8は観察JSON出力。通常プレイの売買在庫は無制限化しない。床/建物の選択層ごとに耐久を変更し、ロック操作は他の対象では無効。素材∞のON/OFFも表示する。ESCメニューはビルド元コミットと未コミット変更を表示する。
