# ホイッスル牧場 — コロニー開発版

Godot 4.7.2。50×34マスの牧場で現地作業を指定し、動物と黄金像を守る開発版です。UI・AIレビュー02の不一致修正を反映しています。旧仕様の資料はGit履歴で参照してください。

## 起動・保存

ローカル試遊の入口は、通常プロジェクトの `確認入口/最新開発版.lnk` です。開発元は `colony-structure-01-work/projects/sporehollow`。Godotではこのフォルダのproject.godotを開きます。旧Play.cmdや旧試遊リンクとの版の対応はPROJECT_STATEを参照してください。

途中状態は専用ユーザーフォルダWhistleResearchAutonomyのcolony.snapshotへ保存します。通常終了後は時計・仕事・物資・敵を保持して再開します。ESCメニューは保存／読込／保存して終了。操作ガイドと版情報は別ページです。「新しく始める」は確認後、現在の牧場を復元履歴へ保存してから1日目05:00へ戻します。検証用セーブは通常データと分離します。

## 基本操作

- 空白を左ドラッグしてパン。未選択時のホイールはズーム。モード内では操作選択、Ctrl＋ホイールはズーム。
- Tab：モード。Shift：指示対象。左クリック：選択／指定。牧場の右クリック：選択・未確定範囲を解除。登録済みの仕事は一覧の×で取消。
- アーキテクト：壁・床・ドア・備蓄／居住ゾーンを指定。壁を選んでドラッグすると連続予約。
- 命令：回収／禁止／禁止解除。単体クリックと範囲ドラッグが可能。備蓄は置き先の設定であり、自動運搬の指示ではありません。
- 物資の回収は同じ予約で残量まで運びます。途中で備蓄を削除して降ろした物資も、その予約から再開できます。建築・食事・装備は必要な現物を取りに行きます。
- 人物選択：HP・眠気・満腹・現在行動、休息、図鑑、持ち物、徴兵と装備。徴兵中の牧場主は地面クリックで移動、敵クリックで指定攻撃。徴兵中は休息・作業再開・装備変更を受け付けず、図鑑／持ち物の確認は可能です。徴兵解除で作業を再評価します。
- 役割表：建築／採集／回収／動物／その他／運搬の優先度を1〜4または空欄で設定。小さい数優先。同順位は左のカテゴリ、同カテゴリでは距離・実行条件・予約状況で選択。登録順は実行順ではなく、並替操作は提供しません。通常の予定一覧は仕事名・件数・状態を表示し、内部IDはDEBUGだけで確認します。
- 採掘は採集、調教・と殺・搾乳・動物指示／装備は動物の優先度。旧優先度の値は維持して移行します。
- Space：停止／再開。1：0.5倍、2：1倍、3：2倍、4：4倍（休息中のみ）。＋／＝／テンキー＋：速く、−／テンキー−：遅く。危険時は1倍。停止中も選択・指定・取消は可能です。

## 物資と生活

HUDの土・木材・石は総所有数。利用可と異なる場合は「使える数」を小さく併記します。ホバーで所有／利用可／備蓄／運搬中／工事現場／禁止／予約を確認します。利用可は未禁止・未予約で、到達できる経路の保証ではありません。施工済み建材は在庫に含めません。

空腹時は物理的に食料を取り、食事後に仕事を再評価します。禁止物資は建設・食事・装備・運搬・売却に利用しません。栄養不足は段階的に進行・回復します。休息は到達可能な居住ゾーンを利用し、未指定／到達不能なら理由を表示して現在地で休みます。犬の調教と家畜のと殺は現地仕事で、取消・禁止・保存に対応します。と殺後の肉も現物として回収・保管・食事に使います。数値は仮設定です。

## 商人・図鑑・一日の流れ

朝5秒後に商人が来訪、30秒滞在。通常状態の住人を選択→商人を左クリック→交渉→その本人が接近→買い物／図鑑。接近予約中は商人が待ち、会話中は世界時間が止まります。閉じると既存作業を再評価します。

牧場主の図鑑ボタンでも本を開き、動物／敵を確認できます。正式な本と肖像、8枠の未発見表示を維持。登録・発見数とページを表示し、詳細のスキルはホバーで条件・効果・CTを確認します。育成は共通EXP、命名は個体IDを維持します。

朝・昼・夜は連続し、残敵がいても翌朝と次の襲撃へ進みます。残敵数は時計の横へ表示し、押すと近い敵の位置を確認します。「夜まで休む／朝まで休む」は時計に合わせて切替。残敵・未消化襲撃・徴兵・誘導などで使えないときは理由を表示します。生産・祈り報酬は日次の一度だけ。見える端のマスまで操作可能で、個体の連れ去りは端の1歩外、黄金像は2×2全体の外への搬出で成立します。

## 制約と検証

二人以上の作業エンジンと役割設定は制御した登録作業者で検証しています。通常プレイの追加作業者募集・全員共通の直接移動／攻撃／装備UIは未完成です。メイド等の固有支援人物を一般作業者へ自動変更しません。

関連headless、GPUのGodot入力イベント、通常起動／終了／別プロセス再開は区別して記録します。人間の通し試遊・実音・IME・各敵AIの長時間評価は別です。今回の外部レビュー資料は[review/current/PACKET.md](review/current/PACKET.md)にあります。ローカルでは `確認入口/23_UI_AIレビュー02`。非対話デスクトップでのGPU描画・入力・終了再開が成功しています。GPUを共有するため30fpsで直列実行し、音と通常セーブを分離します。

個体仕様：ANIMALS.md／ENEMIES.md。建築：BUILDINGS.md。世界：WORLD_SYSTEMS.md。採用素材：ART_SPEC.md。BGM・正式素材は既存参照を維持し、新しい画像は生成していません。

バイオーム01は通常の最新版入口へ反映済み。ESCのバージョンで428e568を確認できます。[配布確認と前後画像](review/current/biome01/DELIVERY.md)。既存の続きは物資・住人を再配置せず景観を追加します。

開発共通ルールは[AGENTS.md](AGENTS.md)と[DEVELOPMENT.md](DEVELOPMENT.md)。固定作業領域の再利用、配布前の隔離終了再開確認、結果保存後の自動整理を工程へ接続。旧EXE23本・重複ツール36ファイルを個別削除。作業フォルダ全体と古い確認入口の削除は自動承認審査で保留。未保存ソース3か所は保持。
