# ホイッスル牧場 — コロニー開発版

Godot 4.7.2。新規100×68マス（既存セーブは元の50×34）の牧場で現地作業を指定し、動物と黄金像を守る開発版です。総合品質改善の不一致修正を反映しています。旧仕様の資料はGit履歴で参照してください。

## 起動・保存

ローカル試遊の入口は、通常プロジェクトの `確認入口/最新開発版.lnk` です。開発元は `colony-structure-01-work/projects/sporehollow`。Godotではこのフォルダのproject.godotを開きます。Play.cmdも同じ1本のEXEを起動します。配布版のSHAはreview/current/map_expansion/DELIVERY.jsonとESCの版情報で確認します。

途中状態は専用ユーザーフォルダWhistleResearchAutonomyのcolony.snapshotへ保存します。通常終了後は時計・仕事・物資・敵を保持して再開します。ESCメニューは保存／読込／保存して終了。操作ガイドと版情報は別ページです。「新しく始める」は確認後、現在の牧場を復元履歴へ保存してから1日目05:00へ戻します。検証用セーブは通常データと分離します。

## 基本操作

- 空白を左ドラッグしてパン。未選択時のホイールはズーム。モード内では操作選択、Ctrl＋ホイールはズーム。
- Tab：モード。Shift：指示対象。左クリック：選択／指定。牧場の右クリック：選択・未確定範囲を解除。登録済みの仕事は命令の「キャンセル」または対象付近の取消で取り消します。右上の仕事一覧は非表示ですが、仕事と保存は維持します。
- アーキテクト：壁・床・ドア・備蓄／居住ゾーンを指定。壁を選んでドラッグすると連続予約。
- 命令：回収／禁止／許可／キャンセル／採掘／伐採を一行表示。ホイール上下で前後の命令を選択し、選択だけでは予約しません。Ctrl＋ホイールはズーム。単体クリックと範囲ドラッグが可能。許可は使用禁止を解除し、キャンセルは仕事指定を取り消します。通常クリックは物資の選択だけ。備蓄は置き先の設定であり、自動運搬の指示ではありません。
- 物資の回収は同じ予約で残量まで運びます。途中で備蓄を削除して降ろした物資も、その予約から再開できます。建築材料と自律食事は備蓄へ搬入済みの現物だけを利用します。建築予定の材料は運搬担当が近隣の複数現場へまとめて届け、建築担当が組み立てます。1人でも両工程を実行できます。
- 人物選択：HP・眠気・満腹・現在行動、休息、図鑑、持ち物、徴兵と装備。徴兵中の牧場主は地面クリックで移動、敵クリックで指定攻撃。徴兵中は休息・作業再開・装備変更を受け付けず、図鑑／持ち物の確認は可能です。徴兵解除で作業を再評価します。
- 役割表：建築／採集／回収／動物／その他／運搬の優先度を1〜4または空欄で設定。小さい数優先。同順位はカテゴリの左右に関係なく、実経路・資材・予約・工程・待ち時間で選択。登録順は実行順ではなく、並替操作は提供しません。通常の仕事一覧は非表示です。人物選択で作業と停止理由を確認できます。
- 採掘は採集、調教・と殺・搾乳・動物指示／装備は動物の優先度。旧優先度の値は維持して移行します。
- Space：停止／再開。1：0.5倍、2：1倍、3：2倍、4：4倍（休息中のみ）。＋／＝／テンキー＋：速く、−／テンキー−：遅く。危険時は1倍。停止中も選択・指定・取消は可能です。

## 物資と生活

HUDの土・木材・石は総所有数。利用可と異なる場合は「使える数」を小さく併記します。ホバーで所有／利用可／備蓄／運搬中／工事現場／禁止／予約を確認します。素材・食料の利用可は備蓄へ搬入済みかつ未禁止・未予約で、到達できる経路の保証ではありません。新規開始の物資は初期備蓄内の別セルへ置きます。既存セーブの物資ID・座標・数量は維持し、ゾーンを塗るだけでは未回収品を搬入済みにしません。施工済み建材は在庫に含めません。

空腹時は物理的に食料を取り、食事後に仕事を再評価します。禁止物資は建設・食事・装備・運搬・売却に利用しません。栄養不足は段階的に進行・回復します。休息は到達可能な居住ゾーンを利用し、未指定／到達不能なら理由を表示して現在地で休みます。犬の調教と家畜のと殺は現地仕事で、取消・禁止・保存に対応します。と殺後の肉も現物として回収・保管・食事に使います。数値は仮設定です。

## 商人・図鑑・一日の流れ

朝5秒後に商人が来訪、30秒滞在。通常状態の住人を選択→商人を左クリック→交渉→その本人が接近→買い物／図鑑。接近予約中は商人が待ち、会話中は世界時間が止まります。閉じると既存作業を再評価します。

牧場主の図鑑ボタンでも本を開き、動物／敵を確認できます。正式な本と肖像、8枠の未発見表示を維持。登録・発見数とページを表示し、詳細のスキルはホバーで条件・効果・CTを確認します。育成は共通EXP、命名は個体IDを維持します。

朝・昼・夜は連続し、残敵がいても翌朝と次の襲撃へ進みます。残敵数は時計の横へ表示し、押すと近い敵の位置を確認します。「夜まで休む／朝まで休む」は時計に合わせて切替。残敵・未消化襲撃・徴兵・誘導などで使えないときは理由を表示します。生産・祈り報酬は日次の一度だけ。見える端のマスまで操作可能で、個体の連れ去りは端の1歩外、黄金像は2×2全体の外への搬出で成立します。

## 制約と検証

二人以上の作業エンジンと役割設定は制御した登録作業者で検証しています。役割表の登録住人は共通状態カードからHP・満腹・眠気・スタミナ・装備・仕事状態と徴兵を確認できます。通常プレイの追加作業者募集・全員共通の直接移動／攻撃／装備操作は未完成です。メイド等の固有支援人物を一般作業者へ自動変更しません。

関連headless、GPUのGodot入力イベント、通常起動／終了／別プロセス再開は区別して記録します。人間の通し試遊・実音・IME・各敵AIの長時間評価は別です。今回の外部レビュー資料は[review/current/PACKET.md](review/current/PACKET.md)にあります。現行のレビュー入口は `review/current/quality/README.md`。非対話デスクトップでのGPU描画・入力・終了再開が成功しています。GPUを共有するため30fpsで直列実行し、音と通常セーブを分離します。

個体仕様：ANIMALS.md／ENEMIES.md。建築：BUILDINGS.md。仕事・物流：WORK_SYSTEMS.md。世界：WORLD_SYSTEMS.md。採用素材：ART_SPEC.md。BGM・正式素材は既存参照を維持し、新しい画像は生成していません。

## 岩山の採掘

新しく始めた牧場には、連続岩壁に加えて大岩山・小岩山が現れます。岩山をクリックして残量を確認し、「採掘を予約」または命令の採掘範囲で指定します。採集担当が継続して掘り、大岩山は4段階、小岩山は3段階で減っていきます。石材は現地に残り、回収指定で備蓄へ運べます。禁止・取消・保存でも途中の進捗は残ります。以前のセーブの地形を勝手に作り直さないため、新しい岩山の確認は「新しく始める」で行ってください。

## 情報表示

ショップの「所持」と持ち物の「所持」は同じ現物台帳の総所有数です。備蓄外・携行・工事現場・装備も含み、盗まれた物と施工済み建材は含みません。「予約」は内数で、所持へ加算しません。購入物資は入口へ到着し、回収して備蓄へ搬入するまでは建築・通常食事に使えません。栄養失調で動けない場合は手元の食事用携行品か隣接する利用可能な備蓄食料だけを使い、遠方の食料へは歩きません。

動物を直接クリックすると、その個体の状態と「指示」だけを表示します。「指示」で種別・状態に対応する共通メニューを開きます。動物タブは小型一覧で、各行から同じメニューへ進めます。9匹以上でもスクロールできます。HP・管理アイコンにはホバー説明があります。無名個体は図鑑に種名を表示します。小屋と旧餌は通常メニューから外していますが、保存データを削除しません。像の近くの固定3段は調査／祈り／修理です。材料不足でも建築予定は置け、必要数と利用可能数はボタンのホバーで確認します。

## マップ・備蓄

新規牧場は100×68、1マス48×42。保存された旧牧場は50×34のまま継続し、地形を再生成しません。新規開始はESC → 新しく始める。現在の保存は既存の復元履歴へ保管します。

WASDは毎秒1050画面pxを基準に移動（旧630）。斜めは正規化、ズームに応じて換算します。ニュートラルの空白ドラッグで地図をつかみ、全景から四隅まで操作できます。

備蓄は40個/マス、携行8個。同種のある有効セルを優先し、搬入予定数を仕事に予約します。残り1個なら1個だけ拾い、満杯なら現地に物資を残して待機。ゾーン拡張・消費・許可変更で再評価します。所有数と備蓄数・携行数は別表示です。物資の完全名と個数はホバー・選択で確認できます。
