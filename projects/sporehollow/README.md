# ホイッスル牧場（仮）

**牧場経営 × 育成 × リアルタイム構築 × 間接防衛。**  
主人公は牧場を経営し、夜に襲う野盗から牧場・動物・自分自身を守る。

## 1日の流れ

**朝の市 → 昼の牧場仕事 → 夜の仕事と防衛 → 夜明け・生産・成長 → 次の朝**

- Campaign開始は**朝の牧場・主人公と愛犬・商人の到着**を短く見せてから購入・育成へ。ショップをいきなり開かない。初期所有動物は愛犬の柴犬1匹。
- 初期軍資金を使い、動物・素材・アイテム等を選んで最初の夜へ備える。
- 序盤ショップはある程度固定。鶏・猫も買えるが、買うと素材購入が厳しくなる程度の価格にする。
- 商人を見送ると、同じ牧場で昼の時計が進む。昼は仮に90秒。主人公の別途配置は不要。
- 昼も夜も主人公は歩いて仕事をする。日暮れに位置・動物・施設・予定をリセットしない。夜だけ外敵が襲来する。
- 夜は一旦**3分**。
- **夜明けまで耐える**、または**その夜の野盗を全員撃退**すると防衛成功。
- 早期全滅時は**「今夜の襲撃を退けた」ことを画面中央で明確に知らせる**。その後、夜明けまで牧場内で活動を続けてもよい。
- 早期全滅後は「朝まで休む」で残り時間を通常の休息として過ごせる。選択時点の floor(残り秒数 / 10) Gold を夜明けに一度だけ加算（仮）。途中中断では受け取らない。通常の夜明けはボーナス0。
- 夜明け時に産卵・孵化・成長等の日次処理を行う。
- 夜明けは牧場を見せたまま報酬と生産を短く伝え、少し落ち着いた後に商人の荷車が来る。到着してから購入・売却・育成を行う。
- 「支度を終える」で商人を見送り、昼の牧場仕事へ。日暮れは同じ盤面の光が変わる。昼→夜の間も操作を止めない。夜明けの短い演出と商人の到着は維持する。

## 敗北

- 主人公が牧場外へ連れ去られる。
- 牧場耐久0は第2敗北条件候補。詳細は今後調整。

### 時間

- PAUSE / 0.5x / 1x / 2x。休息中のみ4xも選べる。敵襲・発見・接近・被弾・動物の危険・運搬で自動的に1xへ戻る。
- PAUSE中は計画する時間。作業・移動・時計・回復は止まるが、仕事/移動/動物指示の予約、未実行予定の取消、並べ替え、対象選択は可能。実作業は再開後。着工済み工事の中断も再開後に処理する。
- WASD：カメラ移動
- Ctrl+ホイール：ズーム
- Space：PAUSE
- - / +（=キー・テンキーも可）：0.5x / 1x / 2xを一段階ずつ変更。休息中は4xまで。速度ボタンのホバーでも確認できる。

### 仕事の予定

- 初期状態はどのモードも選ばないニュートラル。空き地のクリックでは何もしない。牧場主を直接クリック、「牧場主」タブ、またはホイールで選び、**地面を左クリックして移動**する。人物・動物・施設・回収物の操作が地面移動より優先。旗は到着・失効で消える。仕事は実行中を含め最大8件。
- 建築・回収・修理・解体・門開閉・未出撃動物の投入は **予約 → 主人公が隣接マスへ移動 → 現地で実行**。動物への指示は従来どおり動物AIへ伝える。
- 建築予定は薄い杭と小さな木札で表示。予定そのものは通行を妨げず、完成した壁・閉じた門が通行を妨げる。着工後の建築時間は従来の値を使う。
- 建築資材は予約時に確保。着工前の取り消し・到達不能では全額を戻す。着工後の取り消しは既存の中断返却率（仮50%）を使う。
- 右上の札と盤面は同じ順番番号。×または予約を選んだ近くの「取消」で1件だけ取り消す。後続札をドラッグすると浮き、元の空き枠・挿入線・周囲の移動で位置を示す。離すと短く収まり、範囲外なら元へ戻る。実行中の先頭は固定。表示番号と不変のJobIDは別管理。
- **牧場主選択＋地面左クリック**は仕事を消さず保留し、直接移動する。既存作業を中断した避難なら到着後も「作業再開」まで保留。仕事なしの通常移動後は新しい依頼を開始できる。起床は休息前の保留理由へ戻し、避難/救出の保留を勝手に解かない。
- **盤面右クリックは選択解除だけ**。ニュートラルへ戻り、未確定プレビューを消す。登録済みの仕事・移動・休息は継続。ドラッグ中は未確定のドラッグだけを取り消す。
- 主人公は仮に毎秒2.5マス。通れない仕事は短く知らせて取り消し、後続へ進む。対象や資源の状態は到着時に再確認する。
- 牧場主選択中/キュー編集中の赤い経路は、実移動と同じ経路探索で壁・閉門・小屋本体を避け、隣接作業地点、小屋受取→配置/返却を順番に示す。同じ区間の往復はずらした点線と矢印で区別し、重複は2本まで。保留計画も点線。通れない区間は終端印にする。動く個体/後で完成する壁は先読みしない。
- 保留理由はキュー見出しに短く示す。手動避難・休息・救出/被弾・通路/配置先閉塞を区別し、保留時にはキュー直下にも再開ボタンを出す。
- 気絶/運搬/休息中は作業を停止。救出後も仕事を保留する。
- 昼→夜では予定を維持。夜明けには未着工分を払い戻し、着工済みの未完成施設は進捗を残して翌日の現地作業で続ける。

### 直接回収と選択

落ちた物を1回クリックすると現地回収を予約する。重複予約はしない。回収専用タブは使わない。ドラッグした場合は単体クリックを発火させず、回収物の選択後だけ「回収」を表示する。一括予約は近い順に空き枠まで、未登録の選択を残して件数を伝える。選択は動物・回収物・施設とも最大8対象（ドラッグ/Ctrl追加共通）。ドラッグへ入った順、同時なら開始点からの距離と固定識別子で決める。仕事の空き枠とは別で、仕事5件＋回収物8対象なら3件予約・5件未登録。動物への指示は仕事枠を使わない。

選択対象付近に必要な「修理」「解体」「回収」「開閉」「取消」を表示する。予約済みは無効表示や取消へ。修理不要なら修理を出さない。費用/返却はホバー。ボタンはすべて現地仕事の予約で、停止中は計画だけを変える。解体はボタンのみ（Del・右クリック解体なし）。

入力優先順は **UI → 対象の選択/操作 → 牧場主選択時の地面左クリック移動**。無効ボタンも押下から解放まで盤面入力を遮断する。右クリックは移動・解体・登録済み予約取消を行わない。

### モード

- 建設
- 動物
- 牧場主

初回・やり直し・選択解除後はニュートラル（タブ強調なし、通常カーソル）。ホイール下で **ニュートラル→建設→動物→牧場主→ニュートラル**、上は逆。UI上ではUI優先、Ctrl+ホイールはズーム。建設/動物へ入っただけでは置く物を選ばない。牧場主は盤面選択でもタブ強調が同期する。Qは使わない。カーソルは通常/工具/ホイッスル/行き先旗。矢印先端が共通のクリック位置。選択・モード変更自体は移動/仕事/休息を止めない。
**動物モード開始時は個体未選択。**  
未配置動物を明示的に選んだ時だけ配置プレビューへ入る。予約後は番号付きの半透明の姿が残る。主人公は牧場内右下の初期設備・待機小屋へ歩き、動物を連れて配置先へ向かう。全工程で1件の仕事。未配置→予約済み→搬送中→配置済みを管理し、同じ個体の二重予約・配置後の回収/再配置は禁止。受取前の取消は予約解除、受取後は同じ仕事を小屋への帰還に切り替える。避難・自主休息では搬送個体を保持して再開後に続行する。搬送/返却中に主人公が被弾した場合は、隣接する通行可能・無占有マスへ降ろして配置済みにし、配置仕事を完了する（仮）。柴犬は既存の自律防衛、鶏/猫は既存の非戦闘AIへ移る。周囲に空きがなければ同じ1件で個体を保持し、空き次第降ろす。気絶/運搬中もこの確認を続ける。別個体や追加キューは生成しない。降ろした個体も回収/再配置不可。行き先が塞がれた時は待機して知らせる。夜明けの未配置個体は小屋の所有個体へ戻す。

Tab/Shift+Tabは建設中なら候補を順逆に巡回、それ以外は牧場主を選ぶ。動物の個体選択は**クリック**で行う。動物モードで個体未選択なら、未出撃個体をアイコン＋名前で表示する。配置済み個体の選択後は、その種が受け付ける指示だけを表示する。鶏・猫は情報確認のみ。Ctrl+クリックの追加選択・通常の左ドラッグの範囲選択・一括指示を利用できる。ドラッグ中に最初に入った分類（仲間/回収物/施設）に固定し、同時なら開始点から近い順。鶏・猫には犬の指示を適用しない。

### 残り時間を休む

昼は「夜まで休む」、襲来予定を消化し脅威が残っていない夜は「朝まで休む」。現在地で仕事を保留し、既存の固定tickを仮24倍で進める。最初の5秒は眠気回復待ち、既に休息中なら待ち時間を引き継ぐ。HP・動物・自然・施設・日次処理も通常進行と同じ。停止中に押した場合は予定だけ。

時間送りは中断可能。危険時と昼→夜で1xへ戻し、夜開始は自主休息から起床する。強制休息は80%未満という解除条件を維持。既存仕事は「作業再開」まで保留。気絶/運搬や動物搬送/返却中は使用不可。朝の市の滞在時間は世界時間に含めない。

## 主人公の体調（試作値）

- HP30、自己防衛の攻撃2、間隔1.5秒。敵は隣接攻撃し、健康な主人公を即運搬しない。
- HP0は気絶。行動不能だが即敗北ではない。敵は気絶後に担ぎ、牧場外へ運ぶと敗北。柴犬は気絶付近の敵/運搬者を優先する。「休む」中の犬は救出しない。
- 運搬されていない気絶は12秒後にHP8で目覚め、休息する。救出直後はHP0のまま。夜明けを越す場合は最低HP8で朝を迎える。
- 眠気は起きている270秒（昼90＋夜180を1日相当）で0→100%。朝の市では時間が進まない。眠気とHPは日をまたいで維持する。
- 見た目は50%以下で通常、50%超～80%で重い目と小さな月、80%超で傾いた姿勢・月と下向き矢印・少量の落ちるもや。未選択でも見え、現在の値へ即座に追従する。60/80/90/100%の警告は維持。能力低下は従来どおり80%以上で、移動・建築・回収などの仕事速度が60%。100%はその場で強制休息し、80%未満まで起きられない。
- 「休息」は現在地で自主休息。自主/強制とも休息開始後のゲーム内5秒は眠気を減らさず、その後毎秒2ポイント減らす。中断で待ち時間をリセットし、継続したままの日暮れではリセットしない。HPは既存どおり5秒に1回復。世界と動物は進む。通常の休息は「起きる」や牧場主選択中の地面左クリック移動でいつでも中断できる。
- コーヒーは眠気12、活力ドリンクは25軽減。各朝1本ずつ入荷、飲み物合計1日2本まで。眠気を帳消しにし続ける代替睡眠にはしない。
- 休息開始5秒は座って待つ「…」、睡眠は横になる「Zzz」、気絶は「!」、運搬は敵の肩の姿で区別。起きている眠気にZzzは出さない。
- HP/眠気/今の行動/先の仕事は主人公選択時の小さなカードへ。被弾時は足元近くのHP、眠気は小さな眠そうな表示で知らせる。
- 数値・回復・昼夜換算は仮調整。空腹、病気、寝床設備等は今回の範囲外。

## 購入・育成フェーズ

朝の場面から **朝の市 / 動物図鑑** を別々に開く。閉じると朝の場面へ戻り、昼へ進む「支度を終える」と区別する。朝の市は減光した牧場を背景に木枠・布の前景を置き、最上位は **買う / 売る**。

- 買う：商品カテゴリへ進む
- 売る：所持品カテゴリへ進む
動物図鑑は市場とは別。見開きの個体ページで育成・命名する。開閉0.4秒、ページ送り0.3秒（仮）。設定済みスキルの発動/パッシブ・解放Lv・CTを確認できる。

買う / 売るのカテゴリ：
- 動物
- 素材
- 施設
- アイテム

畜産物はアイテム扱い。

品の種類（絵付き2×2）→商品一覧→商品詳細→購入/売却の順。商品カードを見ただけでは取引しない。「← 戻る」は一階層だけ戻り、「閉じる」は朝の場面へ。朝の「支度を終える」でのみ昼へ進む。売り切れ・資金不足では取引ボタンを無効にする。

指定された柴犬ドットを盤面・予約姿・図鑑で共通使用する。素材の出典は [assets/ui/SOURCES.md](assets/ui/SOURCES.md)。

画面の共通表現は木の縁・生成りの札・落ち着いた緑。選択中は緑の縁、押下は沈む陰影、無効は灰草色、危険は赤土色。HPはゲージ、報酬は小さな絵と数値を使う。市場・図鑑では牧場を減光して奥へ置き、前景の文字や商品は鮮明にする。動物は姿・名前・元気さを先に見せ、数値や特技はその次に置く。

- 愛犬の柴犬は初期所有のみで、ショップには並ばない。
- 動物はStageに応じた候補からランダム入荷。
- 序盤は方向性を選べるよう、ある程度の商品を固定/保証する。
- 設計図はフィールド回収等で建築種類を増やす。購入画面に説明文を常時出さない。
- 買値 > 売値。転売だけで利益が出ない。
- 動物Lvアップは**共通EXPプールを消費して任意**。自動Lvアップしない。仮に現在Lv×20 EXPを消費。
- 「犬用餌」「鶏用餌」等の個別餌は一旦ショップ/基本ループから外す。
- 育成・命名で個体を選ぶ。名前は12文字まで、空欄なら種類名。

## 昼夜演出

- 昼/夕方/夜/夜明けで盤面の色・環境音を変える。
- 日暮れは同じ牧場が徐々に夜色へ変わる。主人公の位置・作業予定・操作を維持し、夜専用の配置画面へ切り替えない。
- 夜明け：月→太陽を**大きく見せる**切替演出、鳥声の復帰、生産・成長処理。
- 夜は門灯・月明かり・虫/コオロギ等で雰囲気を出す。
- 夜明け後、門付近に商人と荷車が来る。
- 商人到着・見送り・夜明けの短い演出中は通常UIを隠す。昼から夜への移行は操作を止めず、作業UIも維持する。
- ショップは荷車・木箱・商品台を背景に、商人の短い言葉で迎える。恒常的な手順説明を増やさない。
- 動物の選択情報は顔/姿・HPゲージ・短い状態を中心にし、具体HPは必要時に確認できる。クリック・出撃・発見・撃退へ小さく反応する。
- 撃退した敵の選択と生存中の状態表示は解除する。
