# ホイッスル牧場（仮）

**牧場経営 × 育成 × リアルタイム構築 × 間接防衛。**  
主人公は牧場を経営し、夜に襲う野盗から牧場・動物・自分自身を守る。

## 1日の流れ

**購入・育成 → 夜の防衛 → 夜明け → 生産・成長 → 次の購入・育成**

- Campaign開始は**朝の牧場・主人公と愛犬・商人の到着**を短く見せてから購入・育成へ。ショップをいきなり開かない。初期所有動物は愛犬の柴犬1匹。
- 初期軍資金を使い、動物・素材・アイテム等を選んで最初の夜へ備える。
- 序盤ショップはある程度固定。鶏・猫も買えるが、買うと素材購入が厳しくなる程度の価格にする。
- 夜開始前に主人公の初期位置を決める。配置すると夜が始まる。
- 夜は一旦**3分**。
- **夜明けまで耐える**、または**その夜の野盗を全員撃退**すると防衛成功。
- 早期全滅時は**「今夜の襲撃を退けた」ことを画面中央で明確に知らせる**。その後、夜明けまで牧場内で活動を続けてもよい。
- 早期全滅後に活動を終了した場合は、残り時間が多いほどボーナス。仮に floor(残り秒数 / 10) Gold。待って自然な夜明けを迎える場合は0。
- 夜明け時に産卵・孵化・成長等の日次処理を行う。
- 夜明けは牧場を見せたまま報酬と生産を短く伝え、少し落ち着いた後に商人の荷車が来る。到着してから購入・売却・育成を行う。
- 購入フェーズ終了は「主人公を配置して夜へ」のようなシステム文言を使わない。**商人を見送る → 夕暮れ演出 → 今夜の居場所を盤面で選ぶ**流れを基本とする。

## プレイヤー操作

ESCメニューから「今夜をやり直す」に加え、**購入・育成フェーズ開始時点からやり直す**操作を用意する。同じ商品の抽選結果/seedへ戻す。


プレイヤー自身は攻撃しない。

- 動物の配置・指示
- 壁・門・施設の建築
- 修理・解体
- 資源・アイテム回収
- 施設操作
- 時間操作

### 時間

- PAUSE / 0.5x / 1x / 2x
- PAUSE中は動物への指示予約のみ。建築・修理・回収等は不可。
- WASD：カメラ移動
- Ctrl+ホイール：ズーム
- Space：PAUSE
- - / +（テンキーも可）：0.5x / 1x / 2xを一段階ずつ変更

### モード

- 建設
- 動物
- 回収

盤面上の対象を直接クリックすると対応モードへ切り替える。

**動物モード開始時は個体未選択。**  
未配置動物を明示的に選んだ時だけ配置プレビューへ入る。

Tab/Shift+Tabは建設候補だけを巡回する。動物の個体選択は**クリック**で行う。動物モードで個体未選択なら、未出撃個体をアイコン＋名前で表示する。配置済み個体の選択後は、その種が受け付ける指示だけを表示する。鶏・猫は情報確認のみ。Ctrl+クリックの追加選択・Shift+ドラッグの範囲選択・一括指示を利用できる。

## 動物

動物の個別仕様は **[ANIMALS.md](ANIMALS.md)** を正本とする。

共通：
- HP0は特記がなければ気絶。翌日は出撃不可。
- 所有・仲間化した動物は原則命名可能。
- 一部動物に親密度を持たせ、将来ボーナスへ使用。
- 検知範囲と攻撃対象範囲は別ステータス。共有された敵情報でも、攻撃対象範囲外なら攻撃対象にはしない。
- スキルは発動/パッシブに分類し、解放Lvを持つ。Lvアップ画面で現在/将来スキルを確認できる。
- Lv上限5。
- EXPは共通プールへ蓄積し、購入・育成フェーズで任意の動物へ使用する。

## 建築

### 壁 Lv1
- HP8
- 土10
- 建築1秒
- 動物・敵の通常通行不可
- 敵が破壊可能

### 門
- 開閉可能
- 敵の侵入口は外周の明確なゲートとして表示
- コスト等は仮調整

### 犬小屋
- **犬小屋設計図をフィールドで回収して解放**
- 木材20
- 1棟1犬
- 毎秒HP1回復

### 解体
返却量は仮に  
**floor(建築費 × 現在HP/最大HP × 0.8)**。  
複数施設を一括解体可能。

施設の配置・損傷・破壊状態は翌日へ持ち越す。

## 自然物

ゲーム内時間**1秒ごとに抽選**。PAUSE中は進まない。

現在のStage1仮値：
- 発生抽選：20%
- 種類weight：雑草80 / キノコ15 / 切り株5
- 1夜上限：雑草10 / キノコ3 / 切り株1

| 自然物 | 回収 |
| --- | --- |
| 雑草 | +1 Gold |
| キノコ | 夜終了時、HP割合が低い出撃動物からHP5回復 |
| 切り株 | 木材20 |

確率・上限はバランス調整対象。

## 購入・育成フェーズ

最上位は **買う / 売る / 動物**。

- 買う：商品カテゴリへ進む
- 売る：所持品カテゴリへ進む
- 動物：個体一覧から育成・命名。個体アイコンを表示する

買う / 売るのカテゴリ：
- 動物
- 素材
- 施設
- アイテム

畜産物はアイテム扱い。

- 愛犬の柴犬は初期所有のみで、ショップには並ばない。
- 動物はStageに応じた候補からランダム入荷。
- 序盤は方向性を選べるよう、ある程度の商品を固定/保証する。
- 設計図はフィールド回収等で建築種類を増やす。購入画面に説明文を常時出さない。
- 買値 > 売値。転売だけで利益が出ない。
- 動物Lvアップは**共通EXPプールを消費して任意**。自動Lvアップしない。仮に現在Lv×20 EXPを消費。
- 「犬用餌」「鶏用餌」等の個別餌は一旦ショップ/基本ループから外す。
- 育成・命名で個体を選ぶ。名前は12文字まで、空欄なら種類名。

## Stage1

- 朝の牧場へ商人が到着してから初回購入・育成を開始。
- 夜は3分。
- 最初の誘拐者Lv1は夜開始10秒後に1体。
- 誘拐者Lv1：HP50 / 対動物攻撃5 / 対施設攻撃2。
- 初期建築素材：土100・木材0・石0。軍資金40G、鶏30G・猫38G（仮）。
- 誘拐者撃退時、**犬小屋設計図をその場にドロップ**。
- 設計図を回収すると犬小屋を建築可能になる。未回収なら地面に翌日まで残す。
- Stage1の同じ襲来設定を翌日も使用。新Stageへは進めない。

## 敵・将来拡張

敵の個別仕様は **[ENEMIES.md](ENEMIES.md)** を正本とする。

敵は視界距離と視認状態を持つ。主人公を視認できれば直接狙えるが、見えていなければ園内を探す必要がある。

敵Role候補：
- 誘拐
- 施設破壊
- 動物攻撃
- バランサー
- 支援
- 妨害

敵が動物を連れてくる場合があり、条件次第で仲間化できる。

中盤以降は通常の動物に加え、変わった生物・卵も購入/入手可能にする。

## 昼夜演出

- 昼/夕方/夜/夜明けで盤面の色・環境音を変える。
- 夜開始：太陽→月を**画面全体で大きく見せる**切替演出。
- 夜明け：月→太陽を**大きく見せる**切替演出、鳥声の復帰、生産・成長処理。
- 夜は門灯・月明かり・虫/コオロギ等で雰囲気を出す。
- 夜明け後、門付近に商人と荷車が来る。
- 昼夜切替中は通常UI・案内・配置プレビューを隠す。到着・見送り・昼夜は短い演出でつなぎ、演出中に誤操作させない。
- ショップは荷車・木箱・商品台を背景に、商人の短い言葉で迎える。恒常的な手順説明を増やさない。
- 動物の選択情報は顔/姿・HPゲージ・短い状態を中心にし、具体HPは必要時に確認できる。クリック・出撃・発見・撃退へ小さく反応する。
- 撃退した敵の選択と生存中の状態表示は解除する。
