# ホイッスル牧場（仮）

**育成 × 牧場経営 × リアルタイム構築 × 間接防衛。** 牧場を作り、動物の習性とプレイヤーの介入で侵入者に対抗するWindows向け2Dゲーム。

このREADMEは人間・AI共通の**ゲームデザイン正本**。以下の【確定仕様】は実装済み一覧ではない。実装との差は [PROJECT_STATE](PROJECT_STATE.md)、実装・検証の順番は [TASKS](TASKS.md) を参照する。文書はこの3つを基本とし、試作値と将来案を確定ルールへ混ぜない。

## 【確定仕様】

### 中核とステージ進行

**Campaign開始時のほぼ空の四角い牧場 → 主人公を一度配置 → 時計が自動開始（動物出撃は任意） → 敵がいない間に建築 → 襲来 → 建築・指示・施設操作・回収を続けて防衛 → 結果・EXP/Gold → 購入・育成 → 同じ牧場の状態を引き継いで次Stage。**

- 開始時の所有動物は **柴犬 Lv1 ×1**。Campaign初回は入口を定めた空き地から、プレイヤー自身が牧場構造を作る。次Stageでは施設配置・現在耐久・破壊状態を維持し、空き地へリセットしない。
- プレイヤーは直接攻撃しない。動物育成・動物指示・牧場構築・施設操作・餌・畜産物・資源管理で間接介入する。
- 準備と防衛を完全分離しない。襲来前から同じ時計が進み、侵攻中も牧場を作り替えられる。
- 主人公は盤上の主要標的。開始前に主人公を一度だけ配置すると、動物が0匹でも時計が自動で進み始める。開始ボタンは設けない。初期操作モードは動物配置。所有と出撃済みを区別し、未配置個体は時計進行中にいつでも投入できる。PAUSE中は一覧・選択・位置プレビューまで。主人公配置前は通常UIを隠す。配置済み個体はそのStage中、回収・再配置・瞬間移動不可。配置後の移動は指示で行う。**拘束だけでは敗北せず、牧場外へ連れ去られた時点で敗北**。移送中に動物などが救出できる。
- 動物は警戒・追跡・待機・徘徊・餌へ寄る・怖がる・生産・疲労などの習性で自律行動する。すべてを最初から実装する必要はない。
- 目指す因果は「牧場構築 → 動物の自律行動 → 敵の目的に沿う侵攻 → リアルタイム介入 → 動物・施設・生態系の相互作用による結果」。動物を攻撃塔として扱うだけのタワーディフェンスにはしない。

### 建築・侵入者・損失

| 項目 | 方針 |
| --- | --- |
| 壁 | 資材制、耐久あり。動物・敵とも通常通過不可。敵の攻撃で破壊される |
| 門 | 資材制、開閉可能。開いていれば移動経路、閉じていれば遮断・破壊対象。将来強化可能 |
| 動的経路 | 建築・開閉・破壊後の盤面で再判断。敵は通常経路、長い迂回、門/壁を壊す近道のコストを比較できるようにする |
| 最初の敵 | 主人公を優先して拘束し、入口へ連れ去る基本誘拐型。敵の役割拡張は段階的に行う |
| 迷路対策 | 長大な迷路だけを必勝にしない。資材制限・耐久・迂回/破壊比較を基本に、追加対策は試作する |
| 損失 | 動物死亡、畜産物盗難、個別施設破壊、Gold損失は原則即敗北ではない。「勝ったが大きな被害」も成立させる。損失システムの未実装分は現在地で区別する |

### 動物と忠誠度

動物データは **Category → Species → Individual → Runtime State** を分離して扱う。カテゴリー共通の行動・役割、種類固有の特徴、個体の育成、ステージ中の状態を混同しない。柴犬以外の追加種類は候補であり、単純な上位互換を作らない。

- **個体Lvの最大は5**。Lvを攻撃力だけの増加にしない。Lv1基本／Lv2基礎性能／Lv3特徴／Lv4基礎性能／Lv5種固有能力強化、という成長配分は試作案。
- 忠誠度は「戦闘能力」ではなく「戦術に組み込みやすさ」。低忠誠＝弱い、にはしない。低忠誠の猫が自律的なネズミ処理で役立つ、といった価値も作れる。
- 忠誠の設計は **種の基礎値＋個体差＋現在値/状態補正**。具体式・変動幅・効果量は準確定。
- 基本指示の試作対象は、おまかせ／お座り・待機／徘徊（現在地を中心に1クリック）。個別敵指定は現行UIから外す。「おまかせ」では固有AIと習性を活かす。

### 停止と侵攻中の操作

**停止＝判断、進行＝実行。** 侵攻中も速度切替・PAUSEを可能にする。倍率の具体値は試作扱い。

| 状態 | できること |
| --- | --- |
| PAUSE | 世界時間を完全停止。動物一覧・選択・配置プレビュー、おまかせ、待機、徘徊などの指示予約のみ。命令による行動は再開後 |
| 時間進行中 | 未配置動物の投入、動物指示、リアルタイム建築、施設・オブジェクト操作、餌設置、畜産物/資源回収、速度操作 |
| PAUSEで禁止 | 動物の投入、壁/門建築、撤去、修理、門開閉、餌設置、回収、施設稼働、その他世界状態を直接変える行為 |

### 育成・経営・引継ぎ

- クリア評価によって参加動物のEXPとGold報酬を変える。時間だけを最重要にせず、死亡・損失があっても別の成果で高評価を得る余地を残す。
- ステージ間に購入・育成フェーズを設ける。**ショップの動物はランダム陳列で、全種類から自由購入する形式にしない**。種類ごとに価格を持つ。抽選方式・保証の詳細は準確定、現行の固定販売は仮実装。
- 所有動物、個体Lv/EXP、Gold、所持品、畜産物、施設、牧場強化を次Stageへ引き継ぐ。**施設の配置・現在耐久値・破壊済み状態は回復/リセットせず維持する**。次Stageでは敵を強くする。
- 勝利による資産増加だけで永遠に有利／敗北による損失だけで永遠に不利、という雪だるま問題を避ける。救済策は今後検討する。
- 畜産物は売却だけでなく餌・加工など複数用途を持たせる。初期試作は少数種類から。牧場強化もHP増加だけにせず、土地・建築範囲・施設・地形など**盤そのものの成長**を重視する。
- 最初は完全オフライン。オンライン通信・Steam SDKは現段階で実装しない。既存作品の具体的キャラクター・名称・ステージ・アート・数値・ルールをコピーしない。

## Stage1制作仕様（今回の最優先）

以下がStage1の正本。基本ルールは今回実装済み。仮の速度・価格・反撃条件は最終バランスではなく、後から変更できる設定として分離する。

### 確定する数値とルール

| 対象 | 確定内容 |
| --- | --- |
| 開始・襲来 | 主人公を一度配置→「敵の襲来に備えよ」→時計自動開始。動物の出撃は任意、進行中のみ。**ゲーム時間10秒後**に誘拐者Lv1を**1体だけ**出現。追加Wave・増援・継続襲来なし。PAUSEの実時間は10秒に含めない |
| 初期建築資材 | **土100のみ**。壁/門の建築・修理に使用。Gold等を直接建築資材に使わない。初期所持Gold額を0と確定する指示ではなく、通貨と建築資材を区別する |
| 柴犬Lv1 | **AttackPower = 10**。ひるみシステムは使わない |
| 固有特性「救出本能」 | 主人公が連れ去り状態になると発動。**救出中の移動速度は通常の1.5倍**。運搬中の敵を最優先で追跡・撃退し、救出後は通常AI/指示へ戻る |
| 誘拐者Lv1 | **MaxHP = 50、AttackPower = 5（対動物）、ObjectAttackPower = 2（対オブジェクト）**。目的は主人公の連れ去り。壁/門を破壊可能 |
| 壁Lv1 | **MaxDurability / MaxHP = 8、建築費 = 土10、建設時間 = 1秒**。完成後は動物・敵の通常通行を遮断。敵から攻撃され破壊される |
| 施設永続化 | 壁・門・その他永続施設の**配置・現在耐久値・破壊状態をStage間で回復/リセットしない**。Campaignを通して同じ牧場を育てる |
| 購入・資材 | 購入フェーズで資材を購入可能にする。動物購入、施設投資、資材購入、修復用資材確保を競合する経済判断にする。販売価格は未確定 |

「壁の防御力8」と呼ばない。8は耐久の上限であり、ダメージ軽減を担う **Armorとは別パラメータ**。敵の対動物/対施設の攻撃力も別々に管理し、壁の経路破壊コストは対オブジェクト攻撃に応じて見積もる。

| 誘拐者の判断 | Lv1なので移動・経路判断に多少の無駄を持たせる。攻撃を受けると反撃候補を持ち、判断時に反撃/迷い/誘拐続行を選ぶ。対象離脱/一定時間/判断変更で誘拐へ復帰。条件と各行動速度・攻撃間隔は試作する。反撃はAIの判断変更であり、ひるみではない |

### 時間のある建設・修理

- 壁は建設開始直後に完成しない。**進行中のゲーム時間1秒**で完成させ、建設中の見た目/進捗を示す。PAUSEでは工事時間も進まない。
- 初期案では建設中の地点へ侵入でき、その際に工事を中断する。完成と侵入が同tickになった場合の優先順位も定義する。敵の目前へ壁を連打する完全封鎖を必勝にしない。
- 建設モードで侵攻中の施設を左クリックして選択し、E（または修理ボタン）で土を消費して耐久を回復。**建築費・最大耐久・回復耐久**から、回復量に比例する消費を計算できるようにする。係数・端数処理は設定へ分離し、確定式にしない。
- 土不足は可能量だけの部分修理、または修理不可のどちらかを試作で選ぶ。現在耐久が最大を超えないこと、土が負にならないこと、少量修理の繰り返しで無料化しないことを確認する。
- **PAUSE中の修理は禁止**。破壊済み施設の再建を通常修理と同一扱いにするかは未確定。

### Campaignに残る牧場

例：Stage終了時に壁Aが8/8、壁Bが3/8、壁Cが破壊済みなら、次StageもAは8/8、Bは3/8、Cは破壊済み。配置も維持し、自動修復・自動再設置をしない。初回だけ空き地で開始するという原則に更新する。購入画面への移行で施設が回復しないことも同じ条件で確認する。

Campaign内の状態維持と、アプリ終了後のセーブは別件。今回は永続セーブ実装を要求しない。建設途中でクリアした場合や門の開閉状態の引継ぎ方法は試作で決める。

### 配置・侵攻中の操作とUI

- 配置前は木柵のある空き地、主人公プレビュー、「主人公を配置してください」「クリックで配置・開始」だけ。通常HUDを隠す。適切なセルを一度クリックすると中央に短く「敵の襲来に備えよ」、時計が自動開始する。
- 開始後の初期モードは動物配置。柴犬は任意投入、未配置の個体のみ時間進行中に一度出撃できる。配置済み個体を移動するのは指示だけ。
- **ホイールは3分類（建設／動物／回収）**。数字1〜3は補助。左クリックで選択中の操作、右クリックで選択解除。PAUSE中は動物指示の予約だけ。
- 建設モードの施設クリックは、空き地への建築より選択を優先。選択枠と耐久・修理見積りを表示し、**Eで修理、Delで撤去**。門の開閉は選択後のボタン。工事中は半透明＋進捗、損傷はヒビ、破壊は瓦礫。
- 動物は個体選択→おまかせ／待機／徘徊。徘徊は現在地を中心に即予約し目的地クリック不要。個別敵指定・呼び戻しは現行パレットから外す（旧試走用のモデル命令は保持）。
- **WASDはCamera2D移動、Ctrl＋ホイールで0.65〜1.8倍の拡縮**。HUDは固定。Home/中央で位置・倍率を復帰。Spaceで停止、Tabで1x→2x→0.5x。速度は世界時計にのみ作用する。
- 常時HUDはStage・土/Gold/キノコのアイコンと数・経過時間・速度/停止。資源アイコンはホバーで意味を説明。対象詳細は選択時だけ。F3でAI状態、F8で観察JSON。
- 襲来、拘束、連れ去り、救出、HP30%以下は短い通知と自作短音。誘拐/低HP対象が画面外なら方向警告。動物HP50%以下や近接戦闘でHPバー。大型右パネルは復活させない。

### 吠える・自然資源

- 柴犬の自動スキル「吠える」：生存侵入者を**4マス（現在の縦横距離）**内で検知し、クールダウン**6秒**なら発動。範囲内の敵の**移動だけを1秒停止**。ダメージ0、攻撃・反撃・拘束処理を停止するひるみではない。救出中も発動する。
- 通常AIの受動的な「吠える」抽選を置換。音波・「ワン！」・短音、敵側の足止め表示。発動tick、対象ID、次使用可能tickをskill logへ記録。
- 雑草とキノコは進行時間に応じてseed付きで生成する。仮値は4秒ごとに空きセルへ1個、キノコ20%、盤上16個まで。生成RNGはAI判断と分離。PAUSE中は生成も回収も進まない。
- 回収モードで雑草をクリックすると**Gold +1**。キノコは在庫へ入れ、**Stage終了時に1個につきHP5回復**。その場では回復しない。参加個体のID順に不足HPへ使用し、上限を超えず、余りは次Stageへ残す（配分は試作）。建築した場所の草は除去され、収穫報酬にはならない。
- キノコ回復は評価後に処理し、評価用残HPを水増ししない。次Stageで動物を自動全快する旧仮処理は撤回し、回復後の残HPを引き継ぐ。HP0は現行の当日休養扱いでキノコ回復対象。死亡システムは未実装。

### Stage1の成立確認

**フルHPで正面1対1なら柴犬が勝つが、無傷にはならない。** 誘拐される要因は配置・距離・壁/門・指示・救出の遅れに置く。以前の「標準配置の放置は必ず負ける」という評価を置換する。

攻撃10/敵HP50/敵攻撃5、反撃間隔1.0秒は維持。Lv1のseed付き判断を追加し、seed1〜32の近い正面配置では32勝、残HP10〜35。同じ遠めの配置では無指示25勝7敗、早めの待機地点指示で32勝。勝率だけで面白さや最終バランスを確定しない。

### Stage1の判断AI【試作中 / 準確定】

- 判断は `game/decision_ai.gd`、仮重みは `game/rules.gd` の `AI`。通常0.6〜1.4秒で次判断を決める（固定0.25秒tickでは0.75〜1.5秒）。判断後は行動を維持し、毎tickの再抽選はしない。新しい標的との遭遇/攻撃距離への移行/指示の受理/救出開始は文脈変更として再判断する。
- 柴犬：接近/攻撃を主行動に、様子見・位置調整。受け付けた待機は優先する。受動行動を連続抽選しない。吠えるは独立した自動スキル。様子見は小さい「…」で認識中と示す。旧呼び戻し/対象指定は検証用APIに残すが現行UIには出さない。
- 誘拐者：主人公への進行/迂回/迷い。被攻撃中は反撃/迷い/誘拐へ戻る。経路は施設を迂回する移動費と破壊費を比較し、時々余計な一歩を選ぶ。目的は常に誘拐。`?` は短い迷い。Lv2以降の精度段階は将来案で、今回は作らない。
- 救出本能の発動・運搬者最優先は確実。通常randomness1.0、救出0.12を仮採用し、救出では接近/攻撃だけを選ぶ。行動の迷いはなく、判断間隔0.5〜0.75秒だけわずかに揺れる。救出速度1.5倍、攻撃間隔は維持。判断間隔は攻撃/移動の実行間隔とは別。
- 新規起動時にseedを選び、再挑戦では同seedを維持。F3でseed、F8で初期Campaign・seed・配置/投入時刻・操作履歴・判断logを出力。同一ビルド/設定・seed・初期状態・tick付き操作履歴で再現する。描画フレームや演出用時刻をAI乱数へ使わない。
- decision logは冒頭/末尾を最大96件保持し、行動別回数は全判断を集計。レビューJSONは重複するactor/state/actionを除いた抜粋＋末尾を最大28件/試走に縮め、省略件数を明記。確率・判断間隔・救出noiseは最終確定値ではない。
- 見た目の踏込み/被弾反動は描画のみ。ゲームルールのひるみを追加しない。侵攻中の誘拐者は生存動物のセルへ進入せず、描画でも双方を離して見せる。運搬中の主人公は敵の横上へ持ち上げて横向きで描く。

### 襲来設定

Stage別に初回襲来時間、Wave数/開始時刻、間隔/ランダム幅、敵種類/数、侵入口、継続の有無、一度だけの大群を設定する。長い準備後の一斉襲来、短い準備と小侵入、継続襲来、複数方向の時間差、最後の大規模Waveを作れる方向にする。

現行では既に [game/stages.gd](game/stages.gd) へ分離済み。`first_attack_seconds`＝初襲来、`waves`の件数＝Wave数、`start_seconds`＝初襲来からの開始オフセット、`count`＝人数、`interval_seconds`＋`jitter_seconds`＝間隔と幅、`role`＝敵種類、`entries`＝入口。`repeat_waves` と `repeat_interval_seconds` で継続、継続時は `time_limit_seconds` まで守れば成功。一度だけの大群は1 Waveと人数/間隔で表現できるが、現行2Stageのプレイ内容には未採用。

## 現行試作の起動・操作

[Play.cmd](Play.cmd) をダブルクリック、または `build/WhistleRanch.exe` を起動。ブラウザ・Editor不要。

1. 空き地をクリックして主人公を置くと、その場で時計開始。10秒の準備時間が始まる。
2. 初期は動物配置モード。進行中にクリックで柴犬を任意出撃、右で選択取消。
3. 時計開始から10秒後に誘拐者1人。ホイール/数字1〜3で建設・動物・回収。建設中に施設を選びE修理／Del撤去。
4. Spaceで止めて指示を考え、再開して実行。WASDでマップ移動、Ctrl＋ホイールで拡縮、Homeで中央へ。
5. 勝利後は購入→施設の損傷も残ったStage2へ。結果画面から当日開始状態へ再挑戦可能。

通常侵攻時の固定HUDは上下計101px。1280×800で、盤面の外枠を含む投影面積は旧800×544（42.5%）→1200×714（83.7%）。パレット/対象詳細は選択時だけ重なる。これはプレイ可能なマス数を増やしたという意味ではない。

### 現在採用した仮の処理（変更可能）

- 数値の正本コードは [game/rules.gd](game/rules.gd)、襲来は [game/stages.gd](game/stages.gd)。25×17マス、Stage1は左1入口。Stage2は14秒後から2 Wave・計5人で、今回の調整対象外。
- 柴犬HP40、攻撃10/1.25秒（設定1.2秒を0.25秒tickへ切上げ）、通常速度2マス/秒、救出中3マス/秒。HP0は当日休養で即敗北ではない。終了時にキノコで回復後のHPを次Stageへ維持（元気は回復する仮仕様）。**施設は回復しない**。救出優先中も元の指示を保存し、救出後は有効な指示へ、期限切れなら自律へ戻る。
- 誘拐者は攻撃を受け、判断で反撃を選ぶと最大4秒反撃し、1.0秒間隔で対動物5。反撃終了後2秒は誘拐に戻る。移送中も反撃し、移動/運搬は約0.75/1秒に1マス。Lv1は判断間隔ごとに迷い/迂回/反撃の打切りがある。ひるみ・確率による攻撃無効化なし。
- 建設中は通行可能。侵入は完成より優先し中断、土を半分返却、残りは消費。中断後は再建を選ぶ。右キャンセルは選択解除のみ。手動撤去はHP比例の返却なので工事中は返却なし。
- 修理は `ceil(建築費 × 回復HP / 最大HP × 仮係数1.0)`。予算内の整数HPだけ回復し、全快・建設中・破壊済みは修理不可。破壊済みは再建する。壁3/8→8/8には仮に土7、土4なら3HP回復して土0残る。
- 完成施設のID/配置/HP/開閉/Armor、破壊・中断・撤去状態、工事の残り時間、土を持越す。購入した門補強は**新設門のみ**で、既存門を回復・書換えしない。アプリ終了後のセーブは未実装。
- 忠誠75は反応0.5秒・維持47.5秒、鶏は0。現行指示は無料、連打は反応待ちをやり直す。指示力は餌用（最大10、約3.6秒で1回復）。
- 評価は防衛35・拘束防止25・犬の残HP20・施設損害10・指示力効率10。時間ボーナスなし。EXP16＋評価÷10、Gold32＋評価÷5＋追返数×3。Lv上限5は設計上確定だが実装は次タスク。
- 店は固定販売の仮実装：鶏30G、餌3個8G、休憩所28G、新設門補強24G、**土50を15G（仮）**。卵は売却9G/餌2個へ交換。未回収卵は成功時回収。ランダム動物陳列は未実装。

## 開発・検証

Godot 4.7.2 / GDScript / Compatibility。`sporehollow` はリンク維持用のフォルダ名。DIVE DIVEとはコード・TASKS・ビルド・CIを分離する。

```powershell
./tools/setup.ps1       # 公式GodotとtemplatesをSHA512検証して取得
./dev.ps1 test          # ルール回帰
./dev.ps1 evaluate      # seed1〜32 × 6条件のAI比較（192試走）
./dev.ps1 check         # import → test → evaluate → Windows export → exe起動
./dev.ps1 visual        # 画面外・非捕捉・無音のGPU/入力試走
./dev.ps1 editor        # Godot Editor
```

`game/rules.gd` は確定数値と仮調整値、`game/world.gd` は固定tick（0.25秒）とルール、`game/stages.gd` は襲来設定、`game/raider_ai.gd` は目標Controller、`game/decision_ai.gd` はseed付き意思決定、`game/main.gd` はCamera2D・CanvasLayerの小HUD・日本語UI・描画・入力。状態JSONには個体経路、侵入経路、拘束/救出、双方HP/攻撃履歴、建築/中断/損壊、施設ID/残工事時間、土、評価、操作履歴を残す。開発用F8の「観察JSON」は `%APPDATA%/Godot/app_userdata/ホイッスル牧場/observations/latest.json` へ保存（ゲームセーブではない）。

通常は変更に対応する軽い検査、制作サイクルの節目にcheck/CI。**文書だけの更新はリンク・Markdown・整合性確認だけ**。自動シミュレーションの勝率を面白さの合格にしない。動物やStage追加で核の不足を隠さず、小さな仮説→実装→プレイ→批評→修正で進める。定期自動再開は停止のまま。フォントは[OFL](assets/fonts/OFL.txt)、エンジン等は[Godot notices](assets/GODOT_COPYRIGHT.txt)。
