# 胞庭（ほうてい）— SPOREHOLLOW

**地下を掘り、餌場と生物の関係で採掘隊から地脈を守る**、1画面・約90秒の独立2D試作。DIVE DIVEとはコード・依存関係・タスクを共有しない。

## 遊ぶ

Windowsでは **[Play.cmd](Play.cmd) をダブルクリック**。または [index.html](index.html) をブラウザで開く。インストール・サーバー・通信は不要。

1. 「庭をひらく」を押す。
2. 左クリック／ドラッグで通路に隣接する岩を掘る。桃色の眠り卵へつなぐとツノイモリが目覚める。
3. **灯苔 → 胞虫 → ツノイモリ**の食物連鎖を観察。部屋や横道、餌場を作り、生物と採掘隊の出会い方を変える。
4. 40秒後から採掘隊が3人侵入。地脈が1つでも残れば勝利。採掘隊も壁を掘るため、閉じ込めるだけでは守れない。

| 操作 | 効果 |
| --- | --- |
| 1 / 道具「掘る」 | 地脈力1で岩を掘る |
| 2 / 「岩を戻す」 | 地脈力3で空いた通路を塞ぐ。生物のいる場所は不可 |
| 3 / 「苔をまく」 | 地脈力3で餌場を作る |
| 一時停止 / 再開 | 時間を止めて地形を考えられる |
| 速度 ×1 / ×2 | シミュレーション速度切替 |
| 同じ種でやり直す | 地形と生態系を初期化。同条件で別の掘り方を試す |
| 別の種 | 同じ地形で生物のランダムな行動を変える |

直接攻撃・生物への移動命令はない。苔は岩肌の有限な養分で育ち、食べ尽くされても胞子と養分が残れば再発芽する。捕食者を増やしすぎると餌不足になる。隣り合った命の振る舞いが防衛結果を決める。

## 開発・数値評価

Node.js 20以上。外部パッケージ・外部アセットなし。Canvasの表示と、固定刻み・seed付きシミュレーションを分離。ブラウザとNodeで **同じ `src/sim.js`** を動かす。

プロジェクトフォルダで実行:

```powershell
npm ci --ignore-scripts --no-audit --no-fund
npm run lint
npm test
npm run build
npm run evaluate
# より多く比較: 5戦略 × 100 seeds
node tools/evaluate.cjs 100
# 任意のローカル開発サーバー
npm start
```

`lint` はJavaScript構文検査。`build/index.html` が通信不要の配布用入口。`npm start` は `http://127.0.0.1:4174`。GitHub Actionsもこのプロジェクトだけを検証する。

ゲームの「観察記録を保存」で、種類別個体数、捕食・繁殖・餓死、侵入者の経路と生存時間、勝敗、全地形、時刻付き操作履歴をJSON化する。次で同じ状態を再現し、保存記録との完全一致を検査できる:

```powershell
node tools/replay.cjs "観察記録のパス.json"
```

これは再現・分析用で、ゲーム内の続きから遊ぶセーブではない。ブラウザには読み取り用 `sporeSnapshot()` もある。戦略の追加は `tools/evaluate.cjs`。大量試行の勝率は固定手順の比較値であり、人間の面白さを保証しない。
