# ホイッスル牧場 — 現在地

設計正本：[README](README.md) / [ANIMALS](ANIMALS.md)

## 実装済み

- Stage1を繰り返す1日ループ：初日から購入・育成→主人公配置→夜180秒→夜明け・生産→翌朝の購入。全敵撃退後は活動継続/残り時間ボーナスで終了を選べる。
- 初期45Gと柴犬1匹。鶏34G・猫36Gの保証入荷、素材・カテゴリー別餌との支出選択（価格は仮）。
- 犬小屋設計図は撃退位置へ落ち、手動回収で解放。未回収品は翌夜にも残る。木材20で建築。
- Tab/逆Tabは未配置かつ出撃可能な個体と選択なしを巡回。初期動物カテゴリは未選択。Space停止、-/+・テンキーで0.5/1/2倍。
- EXPは共通プール。朝だけ任意Lvアップ、上限5。命名・種類ごとの任意親密度フィールド。
- 柴犬/鶏/猫は気絶し翌日出撃不可、翌々日に半HPで復帰（仮）。設置施設・損傷・所持資源は持越し。
- 出撃鶏の夜明け産卵、未回収卵1日→ひよこ1日→所有鶏、羽の発生/回収。回収済み卵は孵化しない。
- 鶏小屋の建築・自主利用・HP回復と卵の保護元記録。猫は命名/親密度/自律歩行/逃走のみ。両種とも指示・攻撃不可。
- 昼夜色、短い太陽/月切替、門灯、昼/夜環境音、朝の商人と生産報告。
- 夜の再挑戦は購入後の開始状態・同seedへ戻る。

## 未実装・設計との差

- 猫の懐柔/鳴くは能力定義のみ。数値・戦闘効果は未確定。
- 鶏小屋の卵を発見/破壊/盗難する敵AIは未実装。現在の敵は主人公を狙う誘拐者。
- 野犬等の死亡種・死体、親密度の増加条件/ボーナスは未実装。
- 複数動物を含むStage評価方式の全面見直しは保留。今回、旧評価式は変えずEXPの行先と別枠の早期終了ボーナスだけ変更。
- 朝の資金・産卵/増殖量・活動継続と早期終了の価値は仮バランス。大量個体の一覧スクロールと音の実スピーカー聴感も今後の課題。
