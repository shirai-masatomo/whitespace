# 胞庭 — 現在地

## 現在何が遊べるか

- 2026-10-02 / 中核試作。`Play.cmd` または `index.html` からオフライン起動。
- 1画面で掘削・埋戻し・播種。灯苔、胞虫、ツノイモリの繁殖・捕食・餓死、侵入者3人、勝敗と即再挑戦まで動作。直接攻撃なし。
- 15自動テスト、構文検査、静的build成功。ブラウザの実操作で掘削・播種・埋戻し・勝利・放置敗北・即再挑戦を確認。保存した実プレイJSONをNodeで完全再現できた。
- 5戦略×100 seedsの固定手順比較：放置0勝／封鎖のみ0勝／3巣を開く97勝／大部屋93勝／迂回餌場99勝。最初の「放置で勝つ」案を廃棄し、餌の全滅には有限養分による再発芽を追加した。

## まだ何が面白くないか

- **面白さの合格ではない。** 同じ1枚の地形で迂回餌場が強い。上記は開始時に一括施工する自動戦略で、人間の勝率ではない。
- 勝利しても胞虫を食べ尽くす庭がある。短期防衛と生態系の持続の葛藤はあるが、回復を待つ価値や結果の違いはまだ弱い。
- 生物を選んで状態を読む機能がなく、どこで餌不足になったかが画面だけでは追いにくい。

## 次に試すこと

1. 捕食密度・逃げ場・餌の再生周期を小さく比較し、捕食者一択と餌の全滅を減らす。
2. 餌場の位置を変える少数の地形条件で、同じ掘り方が毎回最良にならないか試す。
3. 生物の空腹と直近の行動が分かる最小の観察表示を試す。
