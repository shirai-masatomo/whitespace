# ホイッスル牧場 — 現在地

正本：[README](README.md) / [ANIMALS](ANIMALS.md) / [ENEMIES](ENEMIES.md)

## 実装済み

- 朝の市は絵付き2×2の種類選び→商品一覧→詳細→取引。戻るは一階層ずつ、商人の見送りは別ボタン。売り切れ/資金不足を明示し、見るだけの誤購入を防ぐ。
- 木枠/生成り/草色の共通UI、hover/押下/無効/選択の統一。商品棚と小さな札で牧場を残す。動物詳細は姿/名前/元気さを主役にし、未設定の将来スキル欄は表示しない。夜の選択情報、報酬、配置の可否/短い操作案内も同じ表現へ。
- 時間ショートカットは防衛中だけ。買い物や夜明けで、表示のない停止状態に入らない。
- 初日40G・柴犬1匹。朝の牧場へ荷車が到着（2.6秒）→朝の市→商人の見送り→夕暮れ/夜→今夜の居場所選択→180秒夜→夜明け/生産→余韻→翌朝の荷車。任意の早期終了・共通EXPによる朝の育成・命名。
- 動物の個体選択はクリックのみ。未選択時は出撃可能な未配置個体、配置済み選択時は指示だけ。鶏/猫には指示を表示しない。Tabは建設候補だけ。
- 誘拐者の視界6マス（仮）・壁/閉門の遮蔽・未視認探索・最後に見た位置の捜索。発見/見失い時の短い反応、選択時のHP/視界/状態。
- 柴犬/鶏/猫の汎用ステータス、検知と攻撃対象範囲の分離、スキル種別/解放Lv/CT/条件/効果。柴犬の吠える/救出、猫Lv2の鳴く（4秒攻撃低下）、鶏Lv2の羽。未実装種は図鑑だけ。
- 柴犬・カテゴリー別餌を店と操作UIから除外。動物一覧は4個体ずつ、商品は6品ずつのカード。朝の再挑戦は購入/育成前の資源・個体・EXP・同seed/入荷を復元する。
- 昼夜演出中の通常UI/配置プレビュー/入力を遮断。夜明けは牧場を残した小さな報酬表示から自動で商人の到着へ。朝の再挑戦も到着から再生。
- 木箱/荷車/露店の朝の市、姿アイコン+HPゲージの動物情報、クリック/出撃/発見/撃退に応じた柴犬の顔向き/しっぽ/短い跳ね。待機の座り姿、鶏のついばみ、猫の伸び。数値HPは選択カードへポインターを重ねて確認。
- 撃退済み敵は選択・発見リアクションを解除。侵入時は警鐘と門/動物の反応を中心にし、通常の侵入/夜開始/夜明け説明バナーを削減。
- 侵入は低い木質警鐘、拘束は短音、運搬は2打の警告。昼の鳥声は独立した8～20秒間隔、危険音優先・環境音減衰。
- 建築/修理/解体、施設損傷持越し、設計図の地面ドロップ/手動回収/持越し、気絶翌日出撃不可、産卵/孵化/成長、鶏小屋基盤を維持。

## 未実装・設計との差

- 猫の懐柔はスキル定義のみ。敵側動物がなく、仲間化の実効果は未実装。対物攻撃は値のみ（現行3種は0）、施設への攻撃行動は未実装。
- 鶏小屋の卵保護は記録まで。盗難AI、野犬など死亡種、親密度の上昇/ボーナス、各種の将来スキルは未実装。
- 複数動物を含むStage評価の全面見直しは保留。今回評価式は変更なし。
- 探索は少数の巡回候補を使う初期案。探索の読みやすさと待ち時間、朝の経済・早期終了の価値は仮調整。
- 音は合成波形を改修・無音ドライバで発火を確認。実スピーカーでの音色/音量の聴感は未確認。
- 初夜の反応は実際の検知に合わせる。未出撃/遠方/休む状態の柴犬に強制反応・自動出撃はさせない。初見で危険を読めるか、短い夜明け報酬を読み取れるかは人間試遊で確認が必要。
