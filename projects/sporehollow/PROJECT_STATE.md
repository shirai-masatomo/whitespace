# ホイッスル牧場 — 現在地

## 実装済み

- 初期・購入個体が園内で生活し、位置/HP/指示を翌朝へ保存。任意出撃・小屋搬送を廃止。受入待ちと翌日療養を区別。
- 指示モード。個体IDを追って接近し発令する仕事、既存個体の物理的誘導。取消/牧場主被弾で元のAIへ戻る。猫は不可、鶏は誘導のみ。
- 非消耗ホイッスル。6マス・最大8匹を1仕事で段階的に呼び、異なる到着マスへ誘導。牧場主の進路を空ける小移動と発令音。
- 床/構造物の別層、土/木/石の新設・改築。旧機能/耐久率・確保素材・進捗を保持。建築/改築は夜明けを越して継続。
- 通常/ロック付きドア、独立したロック耐久・修理、旧門データの移行。外周入口は維持。
- 完成した囲い＋全面施工床の屋内判定。開閉/ロック破損は囲いを維持、本体破損で屋外へ。床は自然物だけ抑制。
- 柴犬の屋内進入禁止をAI/誘導/休養/救出へ共通適用。囲い込み施工は予約/着工/完成時に拒否。停止理由を表示し、停止した札を後ろへ回して先に犬を誘導できる。
- 屋内睡眠3秒/毎秒4、屋外5秒/毎秒2。HP回復は共通。囲い破損で回復速度が変わり、睡眠表示は現在状態に追従。
- 既存F3へ無限素材、HP/ロック耐久、実装済み種追加、ホイッスル、屋内表示を統合。通常OFF、DEBUG表示。
- 朝昼夜、停止中計画、8件/8対象、左クリック行動/右クリック解除、札並べ替え/番号/赤線、近傍ボタン、市場/図鑑、主人公生存、探索/戦闘/救出、EXP/育成/生産を維持。

## 仮決定・残る差

- ホイッスル買18/売6G、音は壁を通る。柴犬の受諾率90%＋忠誠度×0.1%、鶏100%。誘導の閉塞は合計20秒で終了。価格・工期・耐久は調整前。
- 右下小屋は受入口。療養個体は現在地で休み、療養室へ運ぶ仕組みは追加していない。
- 複数誘導は現在地形の経路予測。混雑する狭い通路では待機/終了があり、人間試遊で間隔と待ち時間を調整する。
- 猫の懐柔、鶏小屋の盗難AI、親密度の成長/効果、将来種/スキルは保留。Stage評価式は変更しない。
- 牧場主/鶏/猫/地形は既存の簡易ドット。音の実スピーカー聴感と数日間のバランスは未確認。
