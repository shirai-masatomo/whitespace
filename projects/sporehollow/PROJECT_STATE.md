# ホイッスル牧場 — 現在地

## 開発運用：軽量反復＋定点レビュー（2026-10-06）

今後は**K0〜K8のような複数段階を一気に完成させない**。1機能または1段階ずつ実装し、通常変更では関連テストだけを実行する。

- 通常変更：変更箇所の関連テストのみ。原則としてWindows export、AI192、隔離GPU大量撮影、review/current更新を行わない。
- 機能単位：必要な関連回帰と、見た目を変えた場合のみ代表1〜3画面を確認する。
- **定点**：K6完了、K7完了、K8完了、または人間試遊へ渡す縦切り完成時に、まとめて全回帰・AI評価・Windows出力・必要な隔離GPU・人間レビューを行う。
- review/currentは定点でだけ更新し、代表的な証拠を中心にする。中間の大量画像・ログは原則artifactsへ置き、Gitへ蓄積しない。
- TASKSは「今やること／次」だけ、PROJECT_STATEは「現在できていること／できていないこと」だけを保つ。過去の完了履歴はGit履歴へ任せる。
- 将来用の汎用基盤を先回りして完成させず、現在使う機能に必要な最小構造から拡張する。
