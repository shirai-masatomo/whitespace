# ホイッスル牧場 — 現在地

## 現在遊べるもの

- Stage1：主人公を一度クリックで配置→自動開始→10秒後に誘拐者1人。柴犬の投入は任意、進行中のみ。再配置は禁止。
- 建設／動物／回収の3分類。施設を選んでE修理・Del撤去・門開閉。Ctrl＋ホイールで拡縮、0.5x/1x/2x。PAUSEでは動物指示予約のみ。
- 柴犬の吠える：4マス検知・6秒CD・敵移動1秒停止、ダメージ/攻撃停止なし。救出優先は維持。
- 壁10土/耐久8/1秒。草回収で1Gold、少数のキノコは終了時5HP回復。残HP・余りキノコを次Stageへ維持。
- 木柵の外周と開いた入口、草・踏み跡・小物。配置画面は主人公プレビューと短文のみ。
