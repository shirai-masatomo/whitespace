# ホイッスル牧場 — 現在地

## 現在遊べるもの

- 主人公クリック配置→自動開始、10秒後に誘拐者1人、柴犬Lv1を任意出撃するStage1を維持。
- 盤面の動物・資源・施設を直接クリックしてモードと対象を自動選択。資源は選択枠→同じ対象をもう一度クリックで回収。停止中の回収/建設等は禁止。
- Tab/Shift+Tabでサブ操作を選び、空き地クリックで実行。速度は右上ボタン。Ctrlクリック複数選択、Shiftドラッグ範囲選択、一括指示。
- 休むは解除まで継続し、吠え・攻撃・救出を抑制。おまかせなら負傷時は自主休養、敵や誘拐で戦闘へ戻る。
- 配置型犬小屋は1犬専用。接近中も予約。休むHP1/5秒＋犬小屋HP1/秒、5秒合計HP6。小屋なし/満員/到達不可ならその場で休む。
