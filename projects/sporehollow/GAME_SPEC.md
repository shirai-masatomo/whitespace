## 1. ゲームの核と進行（現行＋仮）

- ジャンル：牧場運営・資源採取・建築・自律作業・夜間防衛。牧場主と動物、中央の黄金像を守る。
- 主人公は父から牧場と謎の黄金像を引き継いだ。父の生死・像の由来・物語の結末は未確定。
- **昼**：採掘／伐採／資材回収／建築／動物世話／行商人との取引／図鑑・装備／必要に応じて祈りの準備。
- **夜**：複数方向から敵が来襲。人・動物・施設・黄金像を守る。2夜目以降は夜間に黄金像への祈りが可能（動物／お金／アイテムのカテゴリ選択、後から反作用）。
- **夜明け**：日次生産・祈り報酬・進行更新。敵が残っても時計は次の日へ継続。10夜目をひとまずの目標とする仮ロードマップ。
- 主人公の連れ去り、黄金像の破壊／持ち出しなどが敗北条件。主人公や動物のHP・捕縛、黄金像HP・修理、救護や蘇生の詳細は個別資料へ。

## 2. マップ生成と土地（現行の主な仕組み）

| 項目 | 現行内容 |
|---|---|
| 新規マップ寸法 | **100×68マス**。1マス **48×42px** |
| 生成条件 | 新規開始でseedに基づく手続き生成。現行地形データは **version7**（game/biome_map.gd） |
| 地域（5種類） | open（開けた土地）／lush（草の多い土地）／woodland（森林）／dry（乾燥地）／rocky（岩質地） |
| 基礎地面 | 土を基本に草の密度・茶砂・低彩度青灰粘土・砕石・岩盤を重ねる |
| 地域の形 | 複数の広域中心点＋seedノイズで地域境界を歪める。共有頂点の地表重みにより隣接マスの地面をつなぐ |
| 密度 | 中央は建築・通行の余白を確保、森林・岩盤・散在資源は外側で増え、まばらな小木立・小岩も生成 |
| 描画 | 固定の粒状地面模様と連続岩盤、8×8セル単位の保持チャンク。スクロールごとの地面全再生成を避ける |
| 操作 | WASDでカメラ移動（基準1050px/秒）、未選択時ホイールズーム。横縦四隅へ移動可能 |

**地表と資源を混同しない**：
- 土／砂／粘土／砕石／背景岩盤は主に地表種・質感。表面が砂や粘土だから自動的に採掘在庫が増えるわけではない。
- **採掘可能な連結岩壁**は地面とは別の障害物。上下左右の接続状態と採掘による消失・通行解放を持つ。
- 独立した大岩山（4×4から段階縮小）と小岩山（1×1）、木、自然物は別のオブジェクト／資源として配置する。
- 完成建築、施工中の設備、床、備蓄ゾーン、自然物、採掘後の資材などは地表とは別の占有・現物として管理する。
- 岩盤の分布・通行可能性・中央への道は生成時の保護規則に従う。地表の種類そのものに新たな移動速度・採掘効果は原則付けていない。

**連結岩塊・地層表現（現行／資源ルールは未設定）**：
- 大規模な連結岩塊を岩盤バイオームの中心に形成し、岩場区画は全体の約1/4〜1/3を目安とする。
- 土→砂・粘土→岩盤→中心の鉄鉱層という分布。通常岩盤・鉄模様・粘土・砂は正式素材を使用。**鉄・粘土・砂の採取物化、採掘量／用途は別設計**。地表の見た目だけでゲーム内の鉄採取実装済みとは扱わない。
- 地質・岩盤の現状ソース：game/biome_map.gd、game/soil_surface.gdshader、game/rock_view.gd、game/mining_mountains.gd。採用素材は [ART_SPEC.md](ART_SPEC.md)。

ログは常設の縦スクロールバーでホイール／ドラッグ操作可能。最下部で新着追従、過去閲覧中は同じ行を保持。最大120件。地形v7は主岩塊を維持して長い直線の外縁を自然化する。

## 3. 建築・施工・物流（現行）

- アーキテクトで土／木／石の壁・床、ドア、設置物、備蓄・居住ゾーンを指定。壁は1マスごとの接続表示。**土壁・木壁・石壁の素材費は各5／マス**（HP・工期・修理は [BUILDINGS.md](BUILDINGS.md)）。
- 予約は1現場1件。1回のドラッグで指定した建築群は同じ施工グループに入る。
- 建築の仕事は **①必要資材の現場搬入 → ②グループの搬入が揃った現場から施工**。現場全体が搬入不能なら揃った現場から施工可能にして停滞を避ける。中断・追加予約で既に着工した仕事を無理に戻さない。
- 搬入途中・一部搬入・搬入完了・施工中は、建築予定の現場表示やクリック情報で区別する。
- **仕事指定上限100件、1人の全種類合計携行20個、備蓄容量40個／セル**。物資の所有・利用可・現場搬入・携行・予約は同一の現物台帳から算出。
- 必要素材は備蓄にある未禁止・未予約品。地面に落ちた採掘・伐採物は回収を指示して搬入する。ゾーンを塗るだけでは自動搬入しない。
- 建築・採集・回収・動物・その他・運搬に仕事優先度（1〜4または無効）。作業者は経路／資材／優先度／待ち時間により自律選択し、原則として一度引き受けた仕事を続ける。空腹・危険・休息・閉塞などで中断する。
- 岩山採掘・伐採・素材の所有権・取消・再試行・手持ち上限の詳細は [WORK_SYSTEMS.md](WORK_SYSTEMS.md) と [BUILDINGS.md](BUILDINGS.md) を参照。
- 追加の作業者募集や全員共通の直接戦闘指示、長時間の多人数負荷は開発中／未検証。

## 4. 人物・動物と生活（現行／企画案の区別）

- **現行**：人物にはHP・満腹度・眠気・休息・栄養不足・一部スタミナが存在。食料は現物から消費し、仕事より空腹・休息・危険を優先する。動物には種別ごとにHP・忠誠・Lv・個体スキル・装備・行動指示・生産などを持つ。数値は調整前。
- **現行**：柴犬はHP0で気絶、その他の飼育動物は種ごとの死亡規則に従う。一般住人と動物を同じ死亡ルールへ無断統一しない。
- **企画案**：人と動物に満腹度0〜100、スタミナ初期100を統一し、満腹度が下がると最大スタミナと回復速度を下げる。50%時の最大80、25%以下で最大60、0で飢餓ペナルティと猶予後HPダメージ。仕事・継続移動で消費、待機・徘徊・休息で回復。詳細表と食性は [CRAFTING_NEEDS_DESIGN.md](CRAFTING_NEEDS_DESIGN.md)。
- 眠気・栄養失調・戦闘スタミナとの二重ペナルティは避け、既存処理を統合する計画とする。
- 動物種ごとの仕様・実装対象と未実装候補：[ANIMALS.md](ANIMALS.md)。敵の目的・索敵・状態・固有技能：[ENEMIES.md](ENEMIES.md)。

## 6. UI・行商人・成長・戦闘（現行の概要）

- ニュートラルでドラッグすると最初に囲んだ分類を最大8対象選択。建築のドラッグと別。各モードの操作、命令ホイール切替、取消・禁止・許可、動物の共通指示は [README.md](README.md)。
- 役割表で住人の優先度を調整。キャラや建築予定をクリックすると状態カードと理由を表示。図鑑は動物と敵の一覧・個体詳細・命名・Lvとスキル。詳細は [ANIMALS.md](ANIMALS.md)、[ENEMIES.md](ENEMIES.md)。
- 行商人は原則2日目以降、現地で話しかけて売買・図鑑へ進む。商品購入後の現物は受入口へ入り、搬入しなければ通常は作業素材に使えない。
- 祈りは2夜目以降の夜、カテゴリから選んだ報酬とカルマ・遅延反作用が核。初期襲撃は祈りのせいではない。世界観・敵AIの詳細は [WORLD_STORY.md](WORLD_STORY.md)、[WORLD_SYSTEMS.md](WORLD_SYSTEMS.md)、[ENEMIES.md](ENEMIES.md)。
- 装備・消耗品・スキル・レアリティ・素材の参照は [ITEMS.md](ITEMS.md) と [ANIMALS.md](ANIMALS.md)。

## 7. 実装範囲と運用上の制約

- **現行の保存／読込／自動保存は停止**。起動するたびに新しい牧場が始まる。過去のセーブ原本は削除しない。古いドキュメントの「保存済み」は過去時点の記録であり、現行プレイ機能ではない。
- 現在はGUI/GPUの自動起動・高負荷試験を行わず、コード確認／安全なロジック検証を優先。過去のPC全体フリーズとの因果は未特定。
- 実装の完了判定はGitHubのコード・検査・実際のEXE反映・見た目の評価を分離する。企画案を記載しただけで「実装済み」にしない。
- この総合仕様は広域の見取り図。細部を変更したときは該当する正本を更新し、ここに短く反映する。
