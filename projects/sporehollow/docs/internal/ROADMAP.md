# ホイッスル牧場 — 次に考えること

更新：2026-10-14。最新の実装版・確認結果は [PROJECT_STATE.md](../../PROJECT_STATE.md)、ゲームの全体仕様は [GAME_SPEC.md](GAME_SPEC.md) を参照。本書は今後の方向を短く示すもので、旧実装の「保存有効」を正当化しない。

## 現在ある基盤

- 牧場の新規100×68マップ、土・砂・粘土・連結岩盤・一部鉄の視覚表現。資源採取・現地物資・建築・拠点防衛。
- 建築の一括資材搬入→施工、仕事指定100件、携行20、備蓄40/マス、現行6分類の備蓄ゾーン許可設定。
- 人・動物の状態、祈りと黄金像の反作用、敵・商人・図鑑。未実装・試遊未確認箇所は PROJECT_STATE と個別仕様に従う。
- セーブ／ロードは現在撤去。ユーザーの許可なしに通常PCでゲームの自動起動や高負荷GPU試験はしない。

## 次の企画候補（**未実装**）

1. **植物繊維を導入**：雑草からゴールドは得ない。代わりに植物繊維を現地に生成し、一部衣服へ利用（数量仮）。
2. **備蓄の分類を拡張**：主・サブカテゴリと用途タグを分け、各ゾーンで保管可否と優先度を設定。自動再配置の有無は後で決定。
3. **共通の製作エンジン**：最初に調理台・木工作業台・裁縫台。備蓄の素材確保→搬入→製作→現物生成→回収。
4. **満腹度とスタミナの再設計**：住人・動物に共通値を持たせ、料理バフ・飢餓ペナルティに接続。既存の栄養失調・戦闘スタミナと二重化しない。
5. **安定性・操作感**：長時間の履歴・資源蓄積、大量予約・経路探索のCPU負荷、実画面での操作感を順次検証。

詳細レシピ・バランス・生活ルール：[CRAFTING_NEEDS_DESIGN.md](CRAFTING_NEEDS_DESIGN.md)。
