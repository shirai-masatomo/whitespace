# 建築

数値と下記の補足は初版の仮設定。確定バランスではない。

| 建築 | 資源/費用 | HP | 工期 |
| --- | --- | ---: | ---: |
| 土壁 / 木壁 / 石壁 | 土5 / 木材5 / 石材5 | 8 / 16 / 28 | 1 / 2 / 3秒 |
| 土タイル / 木タイル / 石タイル | 土2 / 木2 / 石2 | 8 / 16 / 28 | 1秒 |
| ドア / ロック付きドア | 木10 / 木20 | 16 | 2秒 |
| ロック | ドアと別耐久 | 8 | 修理で回復 |
| 調理台 / 木工作業台 / 裁縫台 | 木材12 / 14 / 10 | 16 | 4秒 |

- 床と構造物は別層。同じ場所の床上へ施設を建てられる。
- 土→木→石へ直接改築。新素材を消費し旧素材返却なし。作業中は旧機能を保持し、完成時に耐久率を引き継ぐ。同等/下位は不可。
- 未着工取消は確保素材を返却。新設着工後の取消は既存の半額返却。改築の取消は旧建築を残し、着工後は新素材半額（仮）。
- 閉じたドアは視線遮蔽。牧場主/許可味方は開けて通れる。敵は通常ドアを開け、正常なロックは壊す必要がある。ロックだけ壊れても本体は残る。閉めても復活しない。
- 屋内は完成した壁/ドア本体で囲い、縦横接続の内側すべてを施工床で覆った領域。外周柵/マップ端/予約は囲いに数えない。開いたドアも囲いとして有効。
- 動物・主人公・敵のいるマスへ施工不可。最後の施工で屋外専用動物を屋内へ囲い込む場合も不可。予約/着工/完成直前に確認し、進捗と資材を保持して理由を表示。
- 床は自然物生成を抑える。卵・羽・設計図は許可。既存落ち物は回収してから施工する。
- 旧建築門は位置/本体耐久/開閉を保って通常ドアへ移行する。

## 床の現地解体（補足仮仕様）

- 土/木/石タイル→未舗装。床を選び「タイルを解体」。停止中は予約のみ、隣接してから実行。
- 選択/修理/解体/取消は層・ID・種類を照合。同座標の建物と混同しない。建物のある床は先に上の建物を解体する。
- 動物/敵/主人公の占有中は実行しない。主人公が対象床上なら隣へ移動する。施工後に現れた障害も再確認し、通行待ちはその仕事だけを止める。
- 8対象の同層選択、8件の仕事。二重予約不可。完了時に支払済み最新素材×耐久率×80%（切捨て）を一度だけ返却。旧素材の累積返却なし、旧無料デバッグ施工の記録は返却0（現在の素材無限は廃止）、取消は返却なし。
- 卵/羽/巻物は残す。屋内・経路・隣接表示を更新し、自然物は次回の通常抽選から。屋外化後も既に入眠した状態は維持して回復速度だけを変える。

## 小屋の一時停止

待機小屋・犬小屋・鶏小屋は表示/建築/専用AI/回復/卵保護/専用通行禁止を停止。購入動物は既存入口から受け入れる。犬小屋設計図の新規入手も停止し、既存の取得/習得履歴は残す。

旧完成小屋は記録を退役建物として保存して無効化、返金なし（仮）。旧未完了工事の確保素材は一度だけ全額返却して仕事を終了。再構成で再返金しない。通常の建築を上書きしても退役記録は残る。

## 森と重要オブジェクト（初版仮設定）

| 対象 | 現地作業 | 占有・保存 |
|---|---|---|
| 開拓できる木 | 4秒、木材8、斧不要 | TreeIDを予約/完了時に照合。移動と視線を遮るが屋内の壁にはならない |
| 黄金像 | 調査2秒・祈り3秒 | 2×2、HP180。床・通常施設とは別の重要物。通常解体/売却不可 |
| 像の修理 | 現地2秒、土1個→HP1／木1個→HP2／石1個→HP3 | 満タン不可、端数は1個消費で最大HPまで。祈りによる無料修理なし |
| 像の再固定 | 2秒 | 牽引を止めた現在地に再固定。瞬間帰還なし |

像の占有地は施工済みの基盤として屋内の床条件を満たす。周囲の床・壁・ドアは別途必要。開拓は予約・停止・並べ替え・取消・翌朝持越しに対応。旧キャンペーン移行では既存の施設/床/個体を避けた中央候補へ像を設置し、安全な候補がなければ新キャンペーンが必要と表示する。

像の安全な中央候補をすべて旧建築が使っている場合は、元データを消さず移行理由を表示して昼開始を止める。新キャンペーンが必要。像の移動時も屋内判定を更新する。

過去の外周側へ最大9px寄せる表示は廃止。現在は下記の1マス接続表示を使用する。

## 修理の指定と反映範囲

素材1個で土HP1・木HP2・石HP3という指定は黄金像の修理に反映済み。通常建物・床・錠は `world.gd: repair_quote` の既存式（建築費×REPAIR_FACTOR÷最大HPから必要素材を計算）で、同じ回復率ではない。全建築へ共通適用したとは扱わず、範囲の追加確定または実装変更を待つ。

## 建築材料と施工

建築予定は1件のまま、内部で搬入と組み立てを分離。運搬優先度を持つ人が備蓄から合計容量20以内で近隣の複数予定へ配送し、同じドラッグの全搬入対象が揃ってから建築担当が施工する。残りに搬入可能な対象がない場合は揃った現場から施工し、後の予約で巻き戻さない。1人でも両担当を行う。禁止・未回収の資材は使わず、携行/現場資材と材料予約は中断・徴兵・保存/再開で保持する。通常クリックは物資情報、回収は明示命令。詳細は[WORK_SYSTEMS](WORK_SYSTEMS.md)。

通常アーキテクトは上段の品目スクロールと下段固定の「壁と扉／床／設置／ゾーン」。初期は壁と扉、「すべて」は廃止。犬小屋／鶏小屋は停止中で表示しない（旧セーブ移行は保持）。資材不足の新規予約は受け付けない。備蓄にある未禁止・未予約の現物から予約時に必要数を確保する。既存の予定は後の資材不足で取り消さない。ボタンの「不足」とホバーの必要数／利用可能数を参照。

## 連結表示

土・木・石壁は1マス単位の正式16接続PNGを同じ接地点へ描画する。旧外周方向への画像変形は使用しない。縦横・角・交差・異素材・ドアの接続は完成した近傍から毎回決まり、費用・HP・占有・屋内判定・保存は変更しない。床も48×42の連続面を維持する。

横壁の量感改善：正式16接続PNGの上面を32×28px相当へ再配分し、縦横ともマスの2/3の厚みで表示。角・交差・ドアも共有形状へ接続。48×42の接続ピッチと足元、ゲーム上の壁性能は維持。実画面は未確認（2026-10-14）。

## 建築予定の現場表示（2026-10-14）

- 未搬入から施工中まで完成画像を45%のゴーストとして表示。一部搬入は正式な資材アイコン、搬入完了はチェック付き施工待ち枠、施工中は足場と進捗バーを重ねる。完成時のみ通常の不透明表示になる。
- 未完成現場をクリックすると既存の情報欄に名称・工程・必要素材・搬入数・不足数・施工率・待機理由を表示。同グループの搬入待ちと施工担当待ちを区別する。
- 土／木／石壁は各5個。ドア・床の費用、HP、工期、占有・屋内判定は変更なし。未着工取消は全数、着工後は既存の50%切捨て返却（5個なら2個）。
- 旧10個予約を読み込む内部互換経路では5個へ移行。余剰は建築予定を避けた近くの通行可能地へ現物で返す。着工進捗と施工グループの解放状態は保持。通常版の保存機能は追加していない。

## 製作台・家具（現行実装）

3作業台は各1セル。既存の搬入→施工を使用し、完成後に台を選択して「製作」から共通指示を登録する。
設備費は単一素材建築に合わせた仮木材費。複数素材費の旧案を確定値と扱わない。
木箱・木製棚は製作した現物から既存の設置物へ接続する。収納能力は付与していない。
台の解体・破壊で未使用の製作材料を失わない。詳細は [製作・生活設計](CRAFTING_NEEDS_DESIGN.md)。

## 完成予想ゴースト・予約時の資材確保（現行・2026-10-15）

- 完成時と同じ素材・アンカー・壁変形を共有。通常45%、不可は赤色48%＋丸斜線。壁は完成／予定／ドラッグ候補の上下左右16接続、床は共有辺を除いた外周。建築中は旧矩形の仮本体を二重描画しない。
- 建築ドラッグは壁だけでなく床・扉・作業台にも共通の連続マス指定を使用。条件不適合セルを除き、資材予算と上限100の範囲で受理。確認ログは操作単位で同じ理由をまとめ、予約／未登録件数を出す。カーソル移動ではログを出さない。
- 予約時のplan claimを搬入claimへ移し、施工完了まで現物ID・数を追跡。取消は未消費の確保を解放。代替の備蓄を使う場合、古い確保を重ねて残さない。搬入優先→施工、運搬20、備蓄40は維持。
- 木箱・棚など既存の設置物も備蓄の完成品を1個確保する。既存の設置工程を維持し、重複指定による同一物品の二重消費を防ぐ。
- 3作業台・木箱・木製棚は素材ブランチf7c521eの正式world/UIを採用。48×48、アンカー(24,44)、接地点はセル中心+(0,21)。正式静止画以外の施工足場・破壊表示は従来処理。衣服・料理などは今回の対象外。
