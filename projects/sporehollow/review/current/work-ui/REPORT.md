# 作業モーション・アーキテクト・ゾーン・動物UI

2026-10-15。基点は最新リモートと一致した `dce550f2`（試作 `c88c1fc2` を含む）。今回のコード・EXEの対応は [DELIVERY.json](DELIVERY.json) に記録する。

## 実装した内容

- 採掘・伐採の正式接触4枚は無加工のまま使用。仮道具は手元を支点とする弧、緩い振り上げ・加速する打撃・戻り、柄と連動する刃／ハンマーの向きに変更。全身画像の足元、打撃イベント、接触保持0.18秒、施工限定ハンマー、休止・中断・歩行復帰は維持。
- アーキテクトは壁と扉／床／設置／ゾーンの4分類。初期は壁と扉。「すべて」は廃止。停止中の犬小屋／鶏小屋を含む既存ツールの所属を照合し、利用条件は維持。
- 上段は112pxのスクロール領域、下段4カテゴリは論理座標y=706に固定。メインモードの位置は従来どおり。選択色はhoverでも保持。スクロール位置は更新時に保持し、画面外にクリップされたボタンはマップ入力を遮らない。
- ゾーン作成欄は基本4操作のみ。既存ゾーンの空き部分を左クリックして独立詳細を開く。物資・建築のあるマスは従来の対象選択を優先し、同じ対象をもう一度クリックするとゾーンを選択できる。ゾーンカテゴリで指定を解除した状態ではゾーンを優先。描画中のドラッグは詳細を開かない。
- 独立詳細にゾーン切替一覧、32文字までの名前編集、範囲、優先度、分類／サブ分類／個別品目、全許可／禁止、範囲変更、削除、閉じるを配置。居住は短いパネル。IDと名前を分離し、備蓄1／居住1などを自動付与。名前は同じゾーンデータとセッション内campaignに保持。セーブUI・ディスク保存は復活していない。
- 動物は一覧／個体を排他表示。一覧は内容量に合わせ下端へ配置。マップクリックも個体へ切替。「指示」「一覧に戻る」を維持し、一覧へ戻るだけでは複数選択を失わない。選択済みの別個体の指示を押した場合も正しい個体を表示する。

## 性能・残課題

- ゲームの作業時間、収量、当たり判定、AI、料理・資源ルールは変更していない。名前変更は物流の再評価を呼ばず、UIの配置計算は更新時だけ。モーションは少数ベクトル演算で、テクスチャの読戻しや毎フレーム画像合成は行わない。
- 正式接触と既存idleの全身姿勢は離散的に切り替わる。今回の改善は道具の軌跡・加減速と向き。滑らかな全身動作には採掘・伐採それぞれ左右の振りかぶり／戻り計8枚、建築左右の接触・振りかぶり・戻り計6枚が次候補。現行80×64、足元右(28,56)／左(52,56)、顔・帽子・比率を維持する。新規制作は今回していない。
- 実機の操作感、GPU描画、EXEの実起動は安全制約により未検証。技術テスト合格と人間による快適さを同一視しない。
- headless終了時のObjectDB警告（今回1410前後）は以前からの警告（前回1409）と別途監査が必要。今回の資料でメモリリーク解消を主張しない。
- 未保存の既存.import／.uid変更を巻き戻していない。候補EXEと今回の一時検証領域は反映後に整理し、通常EXEは1本を維持する。
