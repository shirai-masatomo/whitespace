# マップ・操作・物流の統合修正

実装：`260923924abe952f4ff2befe61831c80f8ab6e77` / `codex/sporehollow-biome01`。基準はef67bc4。素材納品 `3229d2655e35e82d178577cdd8acbbe66e9be4f8` を維持。ロードマップ0〜11は未着手。

## 変更結果

- 新規牧場は100×68、48×42px/セル。像・牧場主・柴犬・初期物資は中央。商人・襲来口・退却先・連れ去り境界も保存された寸法へ追従。
- 旧保存は50×34のまま継続。保存地形へ新生成マップを重ねず、地形・物資・建築・仕事を復元。大マップで遊ぶ場合はESCの「新しく始める」。既存牧場の復元履歴を保持する既存手順を使用。
- 5地域をマップ比率で広域生成。設定はbiome_map.gdのSETTINGS（領域スケール・閾値・境界幅・樹木密度・岩場群数）。31/73/109の3seedで確認。移動速度・仕事時間は変更していない。
- カメラ1050px/秒（従来630の約1.67倍）。斜めを正規化、deltaとズームを考慮、ドラッグは押下時の位置基準。地面を8×8セル区画で保持し、頂点色の地面を区画ごとのmeshへまとめ、見えない区画と描画対象を除外。地形変更のある区画だけ描画を更新。
- 岩山はIDで全体選択・外周枠・1件予約。採掘の縮小と残り資源・進捗に追従。
- 命令6種類は一行。ホイール上/下で前/次、Ctrlでズーム。「キャンセル」は予約取消、「許可」は使用禁止解除。右クリックで登録仕事を消さずニュートラル。
- 動物の直接選択はその個体の状態＋「指示」。クリックした猫が物資や別個体に化けないよう選択優先を修正。一覧は小型・スクロール式、各行から同じ指示メニューへ接続。種別・禁止・調教条件を維持。
- 右上のキュー描画と入力領域を停止。仕事データ・AI・保存・進行は維持。
- 備蓄/居住は内部罫線を除いた連続面。地面物資は名前・数量を選択/ホバーで表示。同セルの異種も全種類を確認可能。
- 備蓄40/運搬8を維持。全備蓄から同種優先で空きを探し、予約量を差し引いて部分搬入。空きなしでは拾わず理由付き待機、再評価で再開。
- 壁は正式16接続PNGをセル位置へ描画。外周への位置補正を撤去し、土・木・石・ドアの接続を再確認。費用・HP・占有・屋内・保存単位は変更なし。

一部の移動では単発の長いフレームが残っています。地面全景の継続的な重さは改善しましたが、全フレームの安定を保証する結果ではありません。原因の追加切り分けは残課題です。

## 残る差・未検証

- 人間による長時間試遊、物理入力の感触、多人数/大量敵の負荷、全PCのGPU性能は未検証。単発のフレーム遅延も残課題。
- 岩壁と立体岩山の描き込み密度の差、全品の正式アイコンなど従来の素材課題は今回の範囲外。今回の壁接続に追加PNGは不要と判断。既存正式素材のみ使用。
- 旧牧場を100×68へ拡張する移行は行わず、保全優先の旧サイズ互換。新規開始時だけ大マップ。
- Godotの再生成.import/.uidに開始前から差分があるためビルド表示はdirty。今回のソースは実装コミットに記録し、別作業の差分を破棄していない。
