# 操作・設備・選択表示の改善（2026-10-16）

赤い×は表示されていたが地面へ埋もれていた。形は維持し、暗い外縁・明るい内縁・鮮明な赤を重ね、画面上の太さをズームに左右されないようにした。物資・自然物・木・岩・岩山・動物は共通描画を使用。一部禁止は補助点、操作結果は固定HUD。

併せて添付の統合修正を実装：ホイールはズーム、Ctrl＋ホイールは操作切替。1〜3倍速、E主要作業／X取消・解体。作業台3種は2×2占有で外周搬入・施工・製作。設備をクリックすると個別状態、木の樹冠選択、完成建築と予定の混在選択、明暗の選択枠、ゾーン色と画面内名称。ドアは既存の開閉・施錠PNGを壁用変形なしで表示。施工時の退避位置と、商人の隣接予定からの退避を接続。

## 検証

- `TEST_SUMMARY.json` と各JSONが正本。関連ロジック／UI試験を直列実行。通常画面の自動起動なし、headless・Dummy音声・30fps上限・低優先度・1プロセス120秒制限。
- 作業台を実際の仕事AIで資材搬入→完成→木箱製作まで進め、費用・出力数・外周作業位置を確認。1予約1設備、4セル重複拒否、子セル選択・解体、搬入20・備蓄40・仕事100を維持。
- 実入力ハンドラーでホイール／Ctrl、1〜3、E/X、文字入力中抑止、完成＋予定の範囲選択を確認。既存UI試験は1280×800／1600×1000を含む。
- 閉じ込め判定は単独住人・別住人・商人・ドアを検証。最終出口の施工を内側から行わず、影響する施工のみ保留。商人は近接予定追加で安全な地点へ移動し、帰還の上限で永久滞在を防ぐ。
- 新設した退避判定の初回CPU時間が91.551msだったため、2回の全マップ探索を廃止。接続候補の周辺を先に調べ、必要な接続成分だけ探索する方式へ変更。同じ小部屋の最終壁ケースは6.038ms、キャッシュ時平均0.0305ms。2×2設備の搬入・施工49tick合計42.416ms、商人再配置0.736ms。単一ケースのCPU時間であり、実GPUフレーム時間や全マップ最悪値の保証ではない。

## 残課題・未検証

- 通常デスクトップ／実GPUでの操作感、夜間を含む実画面の見やすさ、長時間負荷は未検証。headless成功だけでPCフリーズ解消や実機快適性を断言しない。
- headless UI試験終了時にObjectDB残存警告（最大1,420件）がある。今回の3D/GPU動作や通常プレイ中の継続的蓄積を示す測定ではないが、リークなしとも判定していない。生ログを保持。
- 2×2作業台は既存48px素材を96×88で拡大した仮表示。専用画像なら3種・透過PNG96×88、足元アンカー(48,88)、2×2占有左上から地面アンカー(48,84)、完成・ゴースト共通。現画像は幅が十分でも奥行きの絵が浅く、正式な描き込み改善の余地がある。現段階で新規画像待ちにしていない。
- ドアは現行素材の横スライド表現をそのまま利用。新規差分は必須と判定していない。
