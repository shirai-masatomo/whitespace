# 最新レビュー — 働く・休む・逃げる主人公

実装: 503320ddbe24dcb971e559522776a02e8693fa86 / codex/sporehollow-prototype
実GPU 1280×800、画面外・非フォーカス・Dummy音声。現行画像を上書き。

## 実装

朝の市→昼→夜→翌朝、現地作業FIFO8件、既存動物/敵AIを維持。主人公HP・眠気・休息を同じ固定tickへ統合。敵は攻撃→HP0気絶→運搬。主人公は弱い隣接反撃。犬の救出後も、主人公は気絶から回復して休む。

主人公を選んで右クリックすると仕事を消さず保留して移動。到着後は「仕事へ戻る」まで再開しない。旧Ctrl＋右クリックは廃止。Shift＋右クリックは移動を末尾に予約。休息中4x、危険時1x。仕事札は工具アイコン、予定位置は木杭と小さな札に変更。常時の操作文を除去。

## 検証と撮影条件

- 市場購入→3件建築→途中取消/追加→動物投入→右クリック移動→夜持越し→迎撃→設計図の現地回収→夜明け→翌朝の育成まで、Inputイベントで操作。
- 主人公の遭遇画面は**別の制御した初期配置**。主人公19,8・眠気70、休む犬19,10、敵18,8へ接近させる。撮影時点のHPや救出結果を作らず、実際の攻撃/気絶/運搬/指示/AIで進めた。一本の自然プレイの別時刻とは扱わない。
- 主人公検査49項目：0→80→100%・強制/任意休息、減速、キュー保留/再開、飲料制限、気絶→運搬→救出/敗北、3種＋建築＋戦闘の8seed占有検査。
- 現地仕事98項目、既存ルール241項目を確認。旧拘束の期待値を気絶へ更新。既存試験の盤面準備はfixture、本番の仕事/生存検査はproduction world。
- 固定戦闘32seed×6条件：犬なし32敗、正面の犬32勝、救出配置32勝（運搬31件すべて救出）。数値を面白さの合格とは扱わない。
- Windows export・生成exe headless起動。[観察JSON](stage1-observation.json)へHP/眠気/休息/保留/手動目的地/危険/戦闘を記録。音は無音で発火確認のみ。

## 仮値・自己批評

HP30・反撃2/1.5秒。起きて270秒で眠気100%、80%以上で移動/仕事60%。休息は眠気-2/秒、HP+1/5秒。強制休息は80%未満で解除。非運搬の気絶12秒→HP8で休息、夜明けを越す気絶も最低HP8。自主休息だけはいつでも中断可能。

コーヒー-12/8G、活力ドリンク-25/15G、各朝1本・合計使用2本/日。日数強化は最大6段階、HP+4/段階、攻撃+1/2段階、速度+0.27/段階（7日目は主人公より速い）。全て仮調整。

自律判断で、救出後と直接移動後は仕事を保留し、着工済みの進捗を残すようにした。建築周囲の占有を再検査し、犬・鶏・猫の移動も通行可能な空きマスへ揃えた。運搬だけは意図した同セル。

実プレイでは「休む→敵襲で減速→起きて逃げる→犬へ頼る」が操作としてつながった。一方、休息時間・HP回復・日数強化は数日間の忙しさ調整が必要。主人公の回復はかなり遅い。寝床/快適度、右クリックの対象別メニュー、食料/農業/新種は未実装。ファイルセーブは従来どおり未実装。
