# 常駐動物・現地指示・建築と屋内

検証対象実装：`823f876de93700cdfda1a2cd8377250e8c4ec4b9`
対象：`codex/sporehollow-prototype` / Stage1。

## 変更

- 任意出撃と小屋からの搬送を廃止。所有個体は園内に常駐し、購入時に右下の受入口から加わる。空きなしは受入待ち。位置・HP・指示を翌朝へ保存し、気絶翌日は現在地で療養。
- 指示は既存8件キューで主人公が接近して発令。AnimalIDの現在位置を追う。柴犬は既存指示＋誘導、鶏は誘導のみ、猫は情報確認のみ。
- ホイッスルで6マス・最大8匹を1仕事として段階的に呼ぶ。行き先は重ならず、実際に歩いて到着。取消/被弾/気絶で誘導を終え、個体はその場のAIへ戻る。
- 土/木/石の壁・別層の床、現地改築、通常/ロック付きドア、独立したロック耐久。旧門の位置・本体耐久・開閉を移行。
- 完成した囲いと全面施工床で屋内。ドア開閉/ロック破損では維持、本体破壊で屋外。床は自然物を抑制し、生産物/敵ドロップを許可。
- 柴犬は通常AI/休養/救出でも屋内へ入らない。屋内の運搬者は屋外出口で待つ。囲い込み施工は予約/着工/完成前に拒否し、進捗を維持。停止札を後ろへ回して犬の誘導を先に実行できる。
- 屋内は入眠3秒・眠気毎秒4、屋外は5秒・毎秒2。HP回復は共通。囲い破損後も入眠状態を戻さず、回復速度だけ変更。
- F3へ素材無制限・HP/ロック耐久・実装3種追加・ホイッスル・屋内表示を統合。通常OFF、DEBUG明示。通常売買の所持資材は無制限化しない。
- 実入力で再現した「次の施工マスに牧場主が立っているため進まない」を修正。朝の演出用個体の二重描画、屋内入眠後も寝入り表示が残る点も修正。

## 仮決定

- ホイッスル：買18G/売6G、非消耗、縦横距離6、音は壁を通る。通行・屋内制限は別。
- 柴犬の受諾率90%＋忠誠度×0.1%、鶏100%。拒否は一度だけ。誘導終了後は元の指示と残り有効時間へ戻る。
- 複数頭の混雑では小さく道を空ける。閉塞が合計20秒続く誘導は理由を示して終了。安全な別地点への瞬間配置はしない。
- 建築/改築は夜明けを越して保持。新素材を確保し旧素材返却なし、耐久率を引継ぐ。着工後取消は新素材50%返却。詳細は [BUILDINGS](../../BUILDINGS.md)。
- 受入口は購入個体のための設備。療養室への運搬は新設せず、気絶個体は園内で休む。

## 検証

- **358項目通過**：今回76、世界56、仕事95、主人公64、計画43、休息送り24。192試行のAI評価、Windows export、出力EXEのheadless起動も通過。
- 旧配置/遠隔即時操作の専用fixtureを削除し、本番world・現地仕事APIによる回帰へ移行した。旧990項目をそのまま通したという意味ではない。Stage評価式は変更なし。
- A/B：近接1マス・ホイッスル6マス、猫拒否、鶏の犬命令拒否、8匹の異なる地点への到着、犬を連れる主人公も屋内の近道を避けること。
- C/D：床欠損/壁欠損は屋外、ドア開閉/ロック破損は屋内維持、本体破壊で屋外。犬のいる囲いの最後の床を拒否し、着工後に犬が入った場合も進捗を維持。誘導を先に実行すると施工再開。
- E/F：屋内運搬者を犬が屋外で待ち、外へ出たら救出。同条件6秒休息で眠気70→屋外68/屋内58、壁破損後1秒で56。HP回復は同じ。停止中は経過/回復なし。
- G/H/I：土→木→石の床/壁改築、耐久率・資材・取消・旧門移行、床上の自然発生なし/設計図保持、誘導取消/被弾/気絶時の個体維持、空きなし受入待ち/空き発生後の受入。
- **通常入力**：GPUの画面外ウィンドウへInputEventを送り、市場購入/戻る/売る/閉じる、図鑑連打/命名、停止中建築・札並べ替え・近傍取消、園内柴犬の指示/誘導/取消、左クリック行動/右クリック解除を確認。
- **デバッグ入力**：F3の付与/個体追加/無限素材、部屋fixture上の左クリック移動・屋内休息・ロック損傷/現地修理、その後の防衛成功・翌朝まで確認。部屋自体の配置はfixture。施工・囲い込み・改築は別の本番APIテストで検証。
