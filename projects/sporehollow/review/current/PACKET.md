# 朝の市・動物手帳・牧場の予定

検証対象実装：`db140d1263b34c0b9fbbbb3573e2a79ec1f86f7a`
対象：`codex/sporehollow-prototype` / Stage1。ゲーム数値・評価式・動物種は追加変更していない。

## 変えたこと

- 朝の市と動物手帳を分離。市の買う/売る、カテゴリ、一覧、詳細の「戻る」と、朝へ「閉じる」、昼へ「朝の準備を終える」は別操作。
- 市場は減光した牧場の手前に木枠・商品台。手帳は見開きと短い開閉/ページ送り、個体名・HP・実際のスキル、既存の命名/育成。
- PAUSE中の予約・取消・並べ替え。実作業・移動・回復は止まる。最大8件、不変JobIDと表示番号を分離。
- 回収タブを廃止。単体クリックで予約、通常ドラッグは最初の分類へ固定。複数回収は空き枠まで。盤面右クリック取消を直接移動より優先。
- 行き先旗、番号付き動物ゴースト、待機小屋への受取→見える搬送→現地配置。受取後の取消は同じ仕事を帰還へ変更し、元の配置ゴーストを消す。
- 自主/強制休息とも5ゲーム秒の待ち時間。睡眠・気絶・運搬・起きている疲労は現在状態から表示する。

## 確認

- 実入力：市の売買/戻る/閉じる、手帳開閉/ページ送り中連打、命名中ショートカット抑止、翌朝の共通EXP育成。
- 停止中に5件予約→ドラッグ並べ替え→盤面取消→旗→再開→小屋受取と現地作業。停止中の世界tick/位置/取得資源が不変。
- 動物/自然物混在の通常ドラッグ、クリックとの二重発火なし。既存5件＋回収6対象から3件のみ追加、未登録3件は選択を維持。
- 休息5秒待機→回復→直接移動で起床、昼→夜→防衛→夜明け→翌朝→育成まで完走。
- 関連44項目を含む432項目の回帰、既存192戦闘試行、Windows export・EXE headless起動が通過。搬送取消・行き先閉塞・休息/気絶/運搬/救出を挟む個体保持、強制休息解除は数値検証も実施。
- [観察JSON](stage1-observation.json)：JobID/番号、予約・取消・並べ替え、搬送状態、休息開始/回復開始、入力確認。短い表示補正（帰還時の札位置）は最終Windows出力へ反映。

## 仮決定・残る確認

- 手帳開閉0.4秒・ページ送り0.3秒。小屋は通行可能な受取口を持つ初期設備。搬送は主人公に付随する描画で、独立した追従AIや戦闘実体にはしない。
- 搬送先/帰還路が塞がると待機。避難や休息で仕事を保留した場合は「仕事へ戻る」で再開。夜明けは既存の予定清算に合わせて未配置個体を小屋へ戻す。
- 撮影は画面外・フォーカス不可の実GPU、InputEventの実入力再生。選択/休息の一部はJSONに明記した配置・眠気fixtureを使う。人間の初見操作感・長期の経済バランス・実スピーカーの聴感は未確認。
- 今回の画像だけを残し、不要になった旧固定画像は削除。ANIMALS/ENEMIESの個体設計とStage評価式は維持。
