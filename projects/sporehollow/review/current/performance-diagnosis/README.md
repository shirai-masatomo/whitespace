# 起動・地面描画の比較診断

診断と限定修正の結果は [REPORT.md](REPORT.md)、最終配布は DELIVERY.json。単色化、装飾停止、旧式頂点色は診断専用で、採用案ではない。

## 操作

診断対応ビルドでは F9 で開始、再度 F9 で保存。通常はOFF。120秒または30,000フレームで自動保存。保存先はゲーム画面にも表示する `user://diagnostics/play-*.json`。最新5件を保持。CPU区間は入れ子で、足し合わせない。frame_msは描画後コールバックの間隔で、Windowsの実Present間隔そのものではない。

起動から記録する入口は `tools/diagnose_play.ps1`。同じEXEを使い、専用の `artifacts/diagnostics/user-data` で起動する。セーブのコピーは作らず、新規診断データで起動する。比較の各起動は独立したプロセス。F9保存後も手動版ではプレイを続けられる。終了してから次の条件を実行する。

例（プロジェクトフォルダのPowerShell）：

```powershell
./tools/diagnose_play.ps1
./tools/diagnose_play.ps1 -Case simple_ground
./tools/diagnose_play.ps1 -Case no_decor
```

現行→簡易地面→粒子のみ→ノイズ追加→砂利追加→岩盤追加の条件は `baseline / simple_ground / grain / noise / gravel / baseline`。`legacy_color` は現行地形データの頂点色だけを表示し、過去コミット全体を再現したものではない。`manual_chunks` は修正前の表示切替を再現し、`all_chunks` は修正後と同じ、`no_occupancy` は建築等の変更検出のみ停止。後者は診断中に建築しない。

その他の独立条件：`no_scene`（地面とUIのみ）、`no_world`（シミュレーション停止）、`no_hud`（HUD描画のみ停止。Control更新は継続）、`no_audio`（合成・再生停止）。`-NoVSync / -MaxFps 60 / -Fullscreen / -ShaderCache on` はそれぞれ単独で比較する。ShaderCacheの比較中は設定overrideを一時使用するため別の通常ゲームを同時起動しない。終了後に除去する。

## 同じ操作順

1. 新規開始し、操作せず30秒。導入画面が出たら閉じる。
2. WASDで未表示の土地へ移動し、戻る。
3. 広域ズームで同じ経路を往復。
4. F9保存、終了。条件を一つだけ変えて再起動。
5. 普段の保存状態は通常EXEを開いてF9で計測する。コピーは不要。

自動経路 `-Route` は seed 731、0–30秒静止、30–40秒右、40–50秒左、50–60秒右上、60秒に0.35倍、70–80秒下へ移動、以後静止。速度1050を維持。端で停止したフレームはmoving=falseで記録し、実際に動いた区間と区別する。これはOSのWASD押下や人間の快適さの検証ではない。
