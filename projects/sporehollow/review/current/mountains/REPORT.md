# 独立した岩山の採掘 — 実装・配布

実装 `9624a291a35fd73046c1df51dd6e5fb11f73cd45` / 素材 `3229d2655e35e82d178577cdd8acbbe66e9be4f8`。通常EXE更新済み。既存の「確認入口 → 最新開発版.lnk」から起動できます。**新しい岩山は新規ゲームに生成します。既存セーブへは追加しません。**

## 実装

- 大岩山は4×4を一つのID・資源・仕事として管理。小岩山は1×1。既存の16接続岩壁は従来どおり1マス採掘。
- 通常クリックは選択のみ。「採掘」ボタン／範囲命令で予約。占有内のどのマスも同じ対象を選び、重複仕事・複数住人の同時確保を防止。
- 大岩山は4段階、小岩山は3段階で縮小。接地点・共通キャンバスを固定し、正式RGBA9枚をnearest・等比で描画。納品SHA256は9枚一致。
- 占有は画像から推測せずデータ定義。大16→12→6→2→0セル。縮小のたびに通行・建築・経路を更新。
- 打撃・石片・粉塵・音は既存作業イベントを共用し、住人が接する岩のマスで発生。段階移行時に短い崩壊表現。
- 石材は現地に生成。明示的な回収で備蓄へ入れるまで建築用共有在庫へ加算しない。岩山の残骸と石材は別管理。
- 空腹・休息・徴兵・禁止・担当変更・取消で資源や進捗を消さず、再開・保存復元に対応。旧セーブには新規生成しない。
- 5seedの配置・到達性を確認。中央、初期物資、商人、侵入口を保護し、岩山の周囲を後から木・岩で塞がない。

## 検証中に修正した問題

- 段階変化後の選択カードが旧残量のまま：選択中の岩山もUI更新対象にした。
- 採掘予定の印が解放済みの旧原点に残る：現在の占有範囲へ追従。
- 回収先の途中に別住人が立つと運搬者が往復し続ける：通常作業の経路全体で住人を回避。動物誘導の既存譲り合いは維持。

## 仮設定・残る確認

- 大64石（16石×4、1段階8秒）、小12石（4石×3、1段階2秒）。作業速度補正前。バランスは仮設定。
- 残骸は通行を妨げず12ゲーム秒で薄れて消える。
- 人体の正式つるはし動作PNGは不足。既存の腕・工具描画と作業FXを流用。新しい画像の無断生成はしていません。
- 各方向からの前後関係、長時間の多人数作業、採掘量の遊び心地は人間レビューで確認が必要です。

検証後に候補EXE・生フレーム・合成セーブ・再生成キャッシュを削除。通常EXEは1本、入口も1本を維持。正式素材と原本PNG10枚・WebPは保存しています。
