# 採掘・伐採の作業演出

実装/撮影ca21a14。通常EXE反映は進行中。[画面・動き・音](SCREENS.md)。

- 採集担当が歩き、隣接して現地作業。既存4秒/成果8個を維持。伐採の「道具未実装」停止を廃止。斧/つるはしは新しい販売品ではなく仮描画。
- 固定tickの打撃通知と道具先端/木屑/葉/石片/粉塵/音を接続。進捗に亀裂/切口が追従。完了の崩壊/倒木は0.65秒（仮）の表示だけで数値処理と分離。
- 岩は1セルだけ消え、隣接maskを描き直す。岩が歩行判定へ反映されていなかった既存漏れも修正。木も当該TreeIDだけ消える。
- 成果は現地の物理アイテム、回収/備蓄搬入まで利用可0。数量/ID/進捗は中断/禁止/取消再指定/保存で維持。
- 命令の採掘/伐採は単体/範囲指定、禁止/許可、解除で取消。選択した木の近くにも操作あり。分類は既存の採集。

関連7スイート成功。新規28項目（中断/保存/部分消失/回収/分類/音、12人同時採掘/100音要求）、岩51、景観60、物流30、入力29、音楽22、作業食事4グループ。[原本](../verification/harvest-tests.json)。

実GPUでPNG8枚、128サンプルから8秒の連続画像2本を取得・画素確認。開始/打撃の道具位置差、亀裂、残る岩、倒木後の木材を確認。仮描画なので正式な全身作業ポーズ/自然な岩の細部の完成とは扱わない。人間の快適さ/実音/多数住人の実GPU FPSは未評価。

制限：通知履歴64、描画参照24、同フレーム音候補2、共通最短0.18秒、距離減衰。既存粉塵も32まで。
