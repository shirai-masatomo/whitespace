# 建築選択hover・連続岩塊

2026-10-14。開始HEAD: 71bff54、対象: codex/sporehollow-biome01。

## 原因と修正

- 選択色はnormalだけに設定され、hoverの紙色で上書きされていた。アーキテクト内のnormal/hover/pressed/hover_pressedを明示設定。選択中のnormalとhoverは同一の薄緑、未選択hoverは生成り色。配置候補マスの既存薄緑は変更なし。
- 白い岩セルの生成は、中心を7マス以上離して小棚を4個作っていた。地面色だけの修正では対象物自体はつながらない。新規生成時に元の岩数を予算として、広い空き領域から密集した連結領域を成長させる。外縁には固定seedのゆらぎを使用。小孤立岩は最大4個。
- 通路を密閉する追加は局所8セルで拒否。既存の通路修復で岩資源が削られることを防ぐ。配置計算は新規生成時のみ。毎フレームの計算追加なし。
- 既存16接続PNG、内角PNG、砕石・土の外縁表示を再利用。地面シェーダー、4×4／1×1大型岩山の選択・縮小、1セル8石の採掘、採掘時間は変更なし。既存の進行中マップは再配置しない。

## 安全な検証

ゲームの自動起動・GPU描画試験・OS入力操作は未実施。Dummy音声、headless、30fps上限、低優先度、テストごとの時間上限で実施。

- 新規3seed＋選択スタイル: 22項目。
- 実際のmain UIツリーでViewport.push_inputによるhover、選択切替、refresh、予約増加なし、壁5個: 18項目。
- 既存の岩採掘・接続・囲まれた中心への進入・物理資源生成・内部snapshot・48損傷マスク: 83項目。
- 岩描画と周囲の表現・更新範囲: 58項目。
