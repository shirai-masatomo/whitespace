# 建築現場の資材表示・壁コスト5（2026-10-14）

基準：987d1a9 / codex/sporehollow-biome01。既存の施工グループと物理資材を継続使用。

## 変更

- 未搬入の半透明予定表示に、搬入済みの正式資材アイコンを追加。全数搬入後はチェック＋枠、施工中は足場＋進捗バー。完成時は予定マーカーを消し既存建物表示へ移る。
- 既存の現場クリック選択を情報パネルへ接続。名称、工程、必要素材、搬入数／必要数、不足、禁止中の現物、施工率、停止・通路・役割未設定・グループ搬入待ちを表示。パネルの入力遮断範囲は行数に合わせる。取消操作は既存ボタンを使用。
- 壁3種を各5個に統一し、アーキテクト表示も更新。ドア・床・HP・工期・当たり判定は不変。
- 旧10個コストの予約・搬入中・施工中データは内部復元時に5個へ移行。余剰は現物として近くへ返却。移行試験で、余剰を現場に置くと施工が塞がる問題を検出し、他の建築予定を避けた通行可能地へ返す処理に修正。完全密閉で返却先がなければ元の場所に保持し、無理に消失させない。
- 完成時は必要数だけ消費し、余剰を残す。取消の既存50%切捨て仕様を維持（未着工5個返却、着工後2個返却）。通常保存機能は復活させていない。
- 新規画像・独立UIは追加なし。素材納品SHAは game/art_provenance.json を継続使用。
