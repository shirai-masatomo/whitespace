# 総合品質改善：修正結果

ゲームの価格・襲撃・育成・祈り・地形生成は変更していません。明確な不一致とUIの重なり、運搬の往復を修正しました。正式な本・商人・動物・肖像・建材・岩山は継続使用。配布版と素材SHAはDELIVERY.jsonを参照。

## 修正と原因

| 項目 | 原因と修正 | 確認 |
|---|---|---|
| F-01 | 動物の整数IDと岩山の文字列IDを無条件比較。種別・型を先に判定。他の同種比較も種別ガードを点検 | 動物／牧場主／岩山／敵／施設／解除と不正型をGPUで切替。SCRIPT ERROR 0を必須化 |
| F-02 | 旧アイテム説明が現行の備蓄食事と不一致。持ち物の説明を訂正 | 備蓄外食料を消費せず、回収後に食事→仕事再開 |
| F-03 | 商品詳細が総所有数でなく利用可の旧集計を参照 | Stock.summaryへ統一。40所有→8予約→8携行→現場→消費、購入／売却、二人競合 |
| F-04 | 停止済み小屋が建設カテゴリと全項目に残存 | 両方から除外。旧データ・小屋ソースは保持 |
| F-05 | 固定スクロール高と個体カードが競合、行の実最小高と計算が不一致 | 3匹表示、9匹末尾への実ホイール、別枠カード。幅を536pxへ抑制 |
| F-06 | 像の操作を横一列に置いていた | 像の横の固定3段（調査／祈り／修理）。費用・回復・一晩一回と不可理由 |
| F-07 | 生活ゲージ・装備・命令が別領域だった | 下部左の共通カードへ集約。登録住人も役割表から選択、徴兵は本人へ適用 |
| F-08 | 居住ゾーンの盤面名が「休息」、凡例不足 | 居住に統一、用途凡例と編集中の輪郭、平常の塗りを薄く |
| F-09/10 | 汎用アイコンの巨大拡大、無名は空文字を返す | 拡大上限と48px枠、無名は種名。正式Icon不足はART_SPECへ |
| F-11 | 結果が商人側に離れていた | 売買ボタン直下、取引結果と現物受取案内を集約 |
| F-13 | 旧餌と仮注記、曖昧な仕事停止文字 | 通常メニューから旧餌を隠しデータ保持。実際の不足／経路／役割の理由を表示 |
| 新たに再現した運搬往復 | 住人が備蓄への通路を塞ぐと、落とした荷を隣から拾い直して移動を繰り返す | 配送先の動的占有を再確認し理由付きで待つ。足元の荷を無駄に取りに戻らない。解除後8個を自動搬入 |

通常食事は備蓄搬入済み・未禁止・未予約の食料。栄養失調で動けない場合も、既に携行した食事か手の届く利用可能な備蓄食料に限定し、未備蓄の食料を食べる例外は追加していません。

所有数は備蓄・備蓄外・携行・現場・装備の合計。予約は内数、盗品と完成建材は除外。物資の保存形式と取引単位は変更なし。

## 動作と画面の評価

関連テストの原本はTESTS.md。2人の分担建築、同順位の経路と待ち時間、二重予約防止、食事／徴兵中断、動物優先度の正逆を確認。四辺四隅の通行・建設・カメラ、5seed地形、岩山段階／資源／保存も確認。

InputEventによる単体クリック、範囲ドラッグ、禁止／許可／解除、ボタン上右クリック、役割変更を確認。OSのマウスを操作していません。GUIの見た目は非対話Window Station、OpenGL、30fps、Dummy音声で撮影。1280×800と1600×1000。静止画像を人間の操作快適性や音の証拠にはしません。

## 3日間の通常進行と面白さ

seed31、各5184固定tick＝3日間。通常初期資源・通常襲撃・通常HPのまま、「待つだけ」と「壁3件・採掘・伐採・調教・食料採集・明示回収」の2方針。日が変わるたび隔離保存／読込。強制勝利や資源補填はなし。quality-journey.jsonに原本。

最終ビルドでの再観測でも双方が4日目05:00まで生存、牧場主HP30・像HP180・136G。準備側は壁3件完成、木材30消費、食料5消費。待機側も食料5消費。準備側は物資を備蓄へ集め、待機側は備蓄外の支給品が蓄積しました。

**観測からの仮説**：序盤3日では準備しなくても同じ生存結果になり、建築投資の利益が伝わりにくい。1seedの自動方針だけで全体バランスの結論にはしません。次は別seed／5夜目で被害・消費・操作回数を比較し、敵強化より先に準備目標と成果の伝え方を試す。

動物育成と祈りの長期的利益、住人募集の楽しさ、熟練プレイヤーの戦術は今回未評価。二人目は登録fixtureで分担エンジンを検証したもので、通常募集を実装した証拠ではありません。

## 残るもの

- **素材不足／見た目**：木の長柄、キノコ、肉、救出・舌・産卵等の正式Icon。現在の汎用代替を最終品質とは扱わない。採掘・伐採の専用身体コマも別途。
- **F-12 継続**：中央の建築余白は維持。正式岩山と連結岩壁の密度差、夜の減光以外の光、地表の目印は未改修。生成・採掘・保存の技術確認と、景観の好みを区別。
- **実装不足**：通常募集、全住人の直接移動／攻撃／装備／手動休息の統一。登録住人の状態カード・徴兵・役割設定まで。
- **未検証**：物理OS操作、IME、実音、全商品／全Tooltip／全ズーム、全敵長期AI、多数人FPS。今回は変更画面中心。
- **今回の工程で解消**：一時的なフォント再インポートのUnicodeエラーは1回のみで次の実行は成功。検証fixtureの壁にopen項目がなく出た例外はfixtureを修正。最終GPUランではエラーを無視・除外せず0を確認。

## 整理

修正前64枚は比較原本として維持。撮影の失敗版は同じ品質フォルダ内で更新し、試行ごとのフォルダは作らない。候補EXE・生ログ・テスト用セーブ・生成キャッシュは既存dev工程で削除。開始902.8 MiBからの最終差分は配布記録へ。既存の別作業のimport/uid変更は今回のコミットへ混ぜない。

通常EXEは実装3fb97ffへ反映済み。起動・終了・再起動・保存復帰5確認を通過。最終容量906.6 MiB（開始902.8 MiB、+3.8 MiB：主に必要な22枚の比較証拠）。候補EXE・隔離セーブ・キャッシュは片付け済み、通常ゲームEXEは1本。
