# 地形生成 v2：統合結果

通常EXEは実装コミット `231b71fbbce0460b1ab05623faf4a936bbcdd0c8` へ更新済み。EXE本体の隔離起動・終了・再開5項目に合格し、既存の最新版入口を維持しました。撮影時の83ソースと納品ソースのハッシュは一致。EXEは1本、一時検証領域は削除済みです。

50×34の新規マップへ、岩場・疎林・草原・乾燥地がまとまって生成される構造を反映しました。既存の地形フィールドを拡張し、地域・地面の材質・障害物を分離しています。旧セーブの実体配置は保持します。

## 生成と開拓

楕円状領域＋低周波ノイズ＋境界の細かな揺らぎ＋中央減衰を継続利用。岩場は高強度領域の3×3芯から不規則な棚を作り、砂利・岩盤の歩行地と少数の孤立岩を残します。疎林は密度のまとまりと幹間隔を使い、木の壁を防ぎます。重要領域を保護し、閉鎖された歩行可能ポケットだけを局所修復します。

生成検証5シード（1/17/31/97/2026）では、5地域・3×3岩棚・全歩行地と四辺四隅の到達・中央保護・再現性・保存互換を確認。既存の分布検証では0〜15も確認しました。岩場・疎林・乾燥地はいずれもまとまった主領域です。緑地は複数の広い領域を許容し、9マス未満の細片が地域面積の5%以下であることを検査しています。

実ゲーム3シード（31/97/2026）では、自然生成3×3範囲の端→中央→角→残りを通常の作業指示で採掘しました。各9マスで石材72個、周囲の岩は不変。通常伐採で木材8個と非衝突の切株を残し、保存復元も一致。seed31では石材の禁止/許可→既存備蓄へ回収→元の岩マスに木床を施工しました。試験用に岩を追加したり、障害物を直接除去したり、仕事を強制完了させていません。[観測結果](terrain-observations.json)

## 正式素材と見た目

採用済み樹木、単独岩12種、16接続岩壁、内角、材質境界、草、切株、切込み、葉片・石片を再利用。新規PNGの生成・複製はしていません。必要な未納品素材はありません。

境界は一度だけ内側に重ね、8近傍を参照。地面に透明な穴を開けず、採掘時は隣接岩の露出面・角を現在の配置から選びます。生成時の景観データは固定し、採掘による地表の傷と障害物の変化を別に扱います。

初回GPU確認で乾燥地の小石が格子状に見えたため、密度を15%へ下げ、草と土パッチの位置を固定ハッシュで少しずらして再撮影しました。接続素材は動かしていません。代表的な全景・境界・中央採掘・伐採前後・乾燥地・角・床施工を目視確認しました。岩棚の上面には共通テクスチャの反復が残ります。人間による長時間の操作感評価は行っていません。

## テストと既存の失敗

合格した16スイートは合計 **770項目、失敗0**。生成130、旧生成60、分布126、旧形式互換21、岩接続83、岩描画51、採掘伐採28、仕事26、備蓄12、動物命令39、境界51、ゾーン17、仕事/食事34、経路29、畜産23、既存レビュー40。自律作業は同じ仕事/食事スイートへの別入口でも実行し、重複加算していません。

## 性能

30fps上限は隔離検証の運用条件です。合格の根拠にはせず、CPU計時とGPUのViewport実測を保存しました。

| 対象 | 標本数 | 平均 | p95 | 最大 |
|---|---:|---:|---:|---:|
| 新規World＋開始処理 | 3 | 494.0 ms | — | 500.7 ms |
| シミュレーション1刻み | 906 | 0.97 ms | 4.01 ms | 54.72 ms |
| 画面更新CPU | 1086 | 1.72 ms | 4.12 ms | 6.24 ms |
| Viewport描画CPU | 438 | 2.02 ms | 2.66 ms | 11.77 ms |
| Viewport描画GPU | 438 | 0.35 ms | 0.79 ms | 8.74 ms |

生成は新規作成時だけ、地面形状・装飾は初回キャッシュ、描画は可視範囲に限定。岩は各セルの近傍だけ参照し、採掘のたびに全地形を再生成しません。通常の描画処理はこの負荷内ですが、seed97の最初の採掘移動の刻みで54.72ms、seed31の運搬で19.35msを記録しています。瞬間的な引っかかりが全くないとは言えません。上限なしの全体FPS、最大戦闘負荷、他GPUは未評価です。

## 変更箇所と保全

`biome_map.gd`（分類/配置/安全補修）、`board_art.gd`（草と地面キャッシュ）、`rock_view.gd`（材質境界/採掘跡）、`story_view.gd`（切株/切込み）、`harvest_view.gd`（伐採演出）、`main.gd`（地面順の切株呼び出し1行）、`research_snapshot.gd`（旧分類の補完）。既存の通行・資源・仕事ロジックを利用し、採掘量や新規敵ルールは変更していません。

撮影は非対話デスクトップ・Dummy音声で直列実行。通常デスクトップのゲーム起動・OS入力・ユーザーセーブの操作はありません。撮影時の基点HEADと実際の83ソースのSHA256を[隔離記録](terrain-isolation.json)へ保存し、納品時に一致検査します。コミット前撮影のため、記録の基点HEADだけを完成コードの版と解釈しないでください。
