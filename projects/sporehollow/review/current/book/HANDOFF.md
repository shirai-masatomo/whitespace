## 撮影した操作

初期朝 → 図鑑を開く → 柴犬1匹（EXP不足・送り無効） → 命名「こむぎ」 → 確定 → メニューへ → 朝。

続いて検証用の150G・100EXPを用意 → 市場で鶏・猫を購入 → 図鑑 → 柴犬育成（Lv1→2、100→80EXP） → 鶏 → 猫 → 前ページで鶏 → 右クリックで閉じる → 朝。全工程で世界tick=0。新規開始部分と資源を用意した部分はobservations.jsonのfixtureで区別する。動物や本文は固定の合成画像ではない。

## UI改善時に見てほしい点

- 左ページの動物絵の大きさと余白、個体名・種類・HPのまとまり。
- 右ページのスキル見出しと説明行間。柴犬では前の説明末尾と次の見出しが近い。
- 育成／命名ボタンと、下端の名前入力欄の配置。入力欄は紙面の外へ張り出している。
- ページ送りボタンが本の外に離れていることと、現在ページ番号の見つけやすさ。
- めくり途中の紙の輪郭・厚み・本文の変形。新旧ページが同時に見える中間フレームも同梱したので、静止した見開きだけで判断しない。
- 朝の閉表紙と開いた本のつながり、背景の減光量。

今回は現状撮影のみ。上記を修正済み・最終デザイン合格とは扱わない。物理マウス／日本語IMEでの入力、個体0匹・最大Lv・療養中・演出中連打は今回の撮影範囲外。育成・命名は隔離された検証状態でのみ実行した。
