# 岩場接続・部分採掘の実装確認

素材だけの納品から、正式PNGを使う実ゲーム描画と通常採掘の検証まで実施しました。実装ブランチ `codex/sporehollow-biome01`。素材本体は `codex/sporehollow-art-assets` / `7b6e813`、境界配置の追記は `1bd24e0`。実装・EXEの確定版はDELIVERY.jsonを参照。

## 完成範囲

- 上下左右16接続のPNGを岩の存在から自動選択。内角は斜めも参照。採掘の次の描画で周囲を更新。
- 1セルごとの損傷は既存の進捗から表示し、岩のalpha内にクリップ。接続部分を損傷中に消さない。
- 単独岩12種類（3サイズ×4状態）を変更せず再利用。壁と単独岩のアンカーを区別。最後に孤立した壁も壁の基準点を保つ。
- 草→土→砂利→岩盤の境界を、採掘対象の有無と独立したバイオーム分布に配置。境界の勾配は岩場側の1セルで完結。
- 採掘後に露出した地面、短い瓦礫・破片、石材現物を表示。資源量、通行、保存処理は従来の採掘処理を利用。

## 実ゲーム検証

実際の main.tscn と World.step、採掘指定・経路探索・保存処理を使い、非対話デスクトップでGPU描画しました。ユーザーの通常デスクトップと実セーブは使用していません。seed31の実際の岩場バイオーム内に、検証用の3×3資源配置を設定しています。通常操作を人間がプレイした記録ではなく、ゲーム内処理を使う自動検証です。

|ケース|手順|残る岩|地面の石材|保存再開|
|---|---|---:|---:|---|
|端|南端中央1セルを通常採掘|8|8|一致|
|角|南西角1セルを通常採掘|8|8|一致|
|中央|南端を掘って進入し、中央を通常採掘|7|16（8個×2地点）|一致|

無傷3×3の中央へ瞬間移動せず、端を先に採掘して通路を開けました。*_drops_clear.pngは通常の移動仕事で主人公を退避した補足画面です。中央だけを直接消した状態を通常採掘の証拠にはしていません。

[採掘前後のPNG・動画](SCREENS.md)。13枚の最終画面、3本の13秒WebP。別に境界不具合の修正前PNGを1枚保存。画面の加工・画像合成なし。

## 視覚確認と修正

初回実画面では岩場内外両セルに同じ境界勾配が描かれ、草の後に岩盤が復活する縦帯・四角いパッチが出ました。外側セルへの再描画を除去し、同条件で再撮影。縦帯の解消、隣接面のつながり、露出地面、石材2地点の判読を確認しました。岩壁は通常PNGと分離パーツを二重描画していません。
