## ゲームの流れ・操作

50×34マスの牧場で、住人の仕事・生活と夜の敵襲を扱います。昼夜は連続した時計で進み、独立した朝の買い物フェーズはありません。1日は432ゲーム秒。05時が朝、10時が昼、19時が夜。翌朝も生存敵は残ります。主人公・柴犬・黄金像は中央付近から開始します。

## 仕事・役割・資材物流

仕事指定は**最大32件**、一覧は10件単位。古い8件の記述は現行値ではありません。対象選択の上限とは別です。仕事は役割優先順位、到達性、必要物資、作業段階などから自律選択し、登録番号順をプレイヤーが管理する方式ではありません。

| カテゴリ | 対象例 |
|---|---|
| 建築 | 新設、改築、修理、解体、設置 |
| 採集 | 採掘、伐採、自然物の採集 |
| 回収 | 自然物以外の既存回収仕事 |
| 動物 | 指示、調教、搾乳、動物装備、と殺 |
| その他 | 上記以外の仕事 |
| 運搬 | 現物の備蓄への運搬 |

優先順位は1が最優先、4まで、空欄は担当しない。調教・と殺は内部分類も表示も動物。徴兵すると通常仕事は保留し、休息・作業再開ボタンは無効。画面05・09・12・14・16・17。

物資は地面、携行中、建築現場などに実体を持ちます。**備蓄にある、禁止でも予約済みでもない物資を利用可能数として扱う**。備蓄ゾーンを塗っただけで、遠方の資材が共同在庫になるわけではありません。1回の携行上限8、備蓄1セル40。建築は資材搬入と現地組立を分けて進めます。買った資材や採掘・伐採の成果は現地生成し、必要に応じて回収・備蓄します。

総所有数＝地面（備蓄を含む）＋携行＋現場など。利用可能数はこの総数の部分集合。予約や運搬で総数が増えるわけではありません。**現状UIはこれらの名称を十分に区別できていません**（F-03）。

根拠：[work_policy.gd](../../../game/work_policy.gd)、[physical_stock.gd](../../../game/physical_stock.gd)、[construction_delivery.gd](../../../game/construction_delivery.gd)。

## 建築・地形・採掘

壁と床は別層。土→木→石への改築、ドアとロック付きドア、修理・解体を現地仕事として扱います。床を敷いて壁・ドア本体で囲った領域が屋内。ドアの開閉と屋内判定は分離し、本体破壊で更新します。屋外専用の犬の囲い込みは施工時に検査します。タイル上の自然物生成は抑止し、生産物・敵ドロップとは区別します。

4×4大岩山は1つの採掘対象として段階的に縮小。初期64石、8ゲーム秒ごとの作業段階で16石ずつ生成し、表示16→12→6→2→0。小岩山は初期12石、2秒段階で4石ずつ、3段階。地形・通行を更新し、進捗は保存します。既存の連続岩壁・1セル採掘も別途維持。伐採は採集担当が現地作業し、木材を現物で落とします。打撃・粉塵・木屑・音は既存演出で、今回の静止画のみから同期の品質合格とは判断していません。

**飼育メニューに鶏小屋が残る一方、建築判定は休止中として拒否**。現状の不一致であり、利用可能な完成機能には数えません。

根拠：[buildings.gd](../../../game/buildings.gd)、[mining_mountains.gd](../../../game/mining_mountains.gd)。画面06各種・17・18。動きの前回証拠は [岩山レビュー](../mountains/REPORT.md)（今回の新規テストとは別）。

## 住人の生活・動物

住人は満腹度低下に応じて備蓄のキノコ・卵・肉・ミルクを食べ、仕事へ戻ります。空腹時の自律食事は備蓄を必要とします。倒れた際の手元食料等の例外を、通常の遠方地面からの自動食事と混同しません。現行の持ち物説明には旧文言が残っています。

牧場主HP30。自主休息、強制休息、安全な待機後の自動休息は別状態。自動休息は現在**8秒**の安全待機。屋外は入眠5秒・眠気2/秒回復、屋内は3秒・4/秒。通常HPは5秒に1ずつ回復。昼夜を休んで送る操作は通常tickで進め、危険や予定襲撃などに応じて制限。夜は「朝まで休む」。画面47〜49。

動物は常駐し、任意出撃・自由収納はありません。柴犬、鶏、猫、ドーベルマン、ウシガエル、ハリネズミ、乳牛、闘牛をデータ化。味方メイドはHuman。現行の猫・鶏はおまかせ／誘導に対応し、犬専用戦闘命令とは区別。過去の「猫はすべての指示不可」を現行仕様として再掲しません。犬系の屋内禁止、忠誠、実移動による誘導、ホイッスルの距離6・最大8匹を維持。

家畜／ペット区分、調教、と殺、禁止・許可を動物一覧から扱います。今回、予約画面までを撮影しており、と殺完了や全種AIは再試験していません。

## 敵・戦闘・黄金像

| 敵 | 主な役割 |
|---|---|
| 誘拐者 | 主人公の拘束・運搬 |
| デストロイヤー | 建物へ鉄球攻撃 |
| 武闘家 | 礼と不殺、近接戦闘 |
| サラリーマン | 被弾時の応援要請 |
| 忍者 | 遠距離手裏剣と近接 |
| 動物使い | 動物の手懐け・連れ去り |
| ランナー／敵ドーベルマン | 走行と疲労／同行・迎撃 |
| 舞姫 | 支援と復活の舞 |
| 盗賊 | 毒、盗み、退却 |
| メイド | 味方追随・コーヒー。攻撃は激ギレ中のみ |

敵は死亡と生存退散を分離。死体は8秒保持、舞姫の蘇生は舞姫自身を除く有効な死体に一度だけ。復活HPは対象最大HPと舞姫現在HPの小さい方。誘拐者死亡時は運搬中の主人公を解放。

索敵は視認と最後の既知位置を使います。到着・経路不能・停滞で探索に切り替え、再訪しにくい探索点／経路コストを使います。常に主人公の現在位置を知る設計ではありません。夜明けは残敵を消す処理ではありません。

黄金像は調査・祈り・修理の対象。祈りは2夜目から一晩一回、現地完了時カルマ+3、翌朝報酬の現行調整。報酬種類を選べます。日次・襲撃編成は既存データを維持。今回は10日間通しプレイや全敵能力の再確認はしていません。

## 商人・図鑑・保存

開始5ゲーム秒後に来訪、30秒滞在。向かって交渉中なら待ち、到着後は「買い物／図鑑」の選択。ショップ・図鑑閲覧中は世界時間を止めます。買う／売る→カテゴリ→一覧→詳細の階層、右クリックで戻る。資材はセット単位、所持金と不足額、取引結果を表示。通常朝フェーズの「支度を終える」は使いません。

本型図鑑は動物／敵、未発見枠、Portrait、Rarity、スキル、命名・育成を備えます。表紙の開閉とページ送りは世界速度から独立したUI時間。画面33〜40は途中フレームも含みますが、動画での滑らかさは別確認です。

メニューから保存・読込・新規開始・保存して終了。現在は時計・仕事・現物・敵を含むスナップショットを保存します。古い「任意保存未対応」という文書は現行コードと一致しません。今回の保存・読込は隔離セーブを同一プロセスで確認。通常EXEの終了・再起動は前回記録と区別します。
