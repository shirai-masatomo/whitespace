# 大規模岩盤・地層 統合報告

## 変更

- 新規100×68の地形v6。地質ノイズの強い隣接セルへ広げ、岩場バイオームを29%とする。中央の建築空間と外周3セルの迂回路を保護し、岩塊は不規則な入り江・突出を持つ。大きな分離島を増やす旧配置から変更。
- 通常岩盤16接続・内角4・8×8広域岩肌・鉄鉱脈・4×4粘土/砂の正式素材を統合。原画は変更しない。土/砂/砕石/粘土/岩盤と、中心寄りの鉱脈を識別する。
- 接続は生成時に計算。採掘時は周辺3×3のみ更新し、関係する地面チャンクだけ再描画。画面外の岩は描画用ソートに入れない。上面画像の取得・合成はローディングで準備し、採掘後の新しい接続パターンだけ追加キャッシュする。
- A*の候補選択を全件走査から安定min-heapへ変更（候補選択O(F)→O(log F)）。旧方式と経路配列・同順位順が一致する比較試験を実施。ゲームの移動速度やルールは変更しない。
- 1セルの採掘時間・石8個・衝突・現地ドロップを維持。岩場拡張に伴いマップ全体の石総量は増える。鉄模様のセルも今回は石8個であり、鉄の価格・利用先・採掘量は未設定。独立4×4/1×1岩山の資源・選択・段階縮小は維持し、巨大岩塊の外縁へ配置する。
- 地形v5の既存データは変更しない。保存UIや診断機能は復活させない。仕事上限100・壁コスト5・運搬20・建築二段階は維持。
