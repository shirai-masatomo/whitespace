## 仕様として分かること

| 場面 | 確認した現行動作 |
|---|---|
| 電話開始 | 生存する正の被弾ごと15%、スタミナ12を払える場合。電話中・成功済みは再抽選しない |
| 成立前の死亡 | 2秒の電話を中断し、増援を予約しない |
| 中断後の蘇生 | 途中の電話は再開しない。成功歴がないため、次の生存する被弾で新しい電話を抽選できる |
| 電話成立 | 3秒後に外周へサラリーマン1体を予約。1個体の成功1回、夜の上限4人を維持 |
| 成立後の死亡・蘇生 | 予約は残り、蘇生しても成功歴は消えず二重予約しない |
| 夜明け前 | 予約中／電話中は早期全滅にならない。外周出現後も接近中の敵がいる間は早期全滅にならない |
| 制限時間を過ぎた夜明け | 電話中と予約中は待つ。外周へ出現した時点で、他の危機がなければ通常の生存勝利へ進む。増援の到着・撃破までは待たない |

READMEは「夜明けまで耐える、または全員撃退」を勝利条件にしている。電話の中断や個体1回はENEMIESと実装が一致する。一方、夜明け直前の予約増援をどこまで待つかという細部は旧設計で断定できない。今回は既存の生存勝利を維持し、必ず増援と戦うまで延長する設計へ変えていない。この体験上の判断は未確定事項として残す。

## 固定条件と実画面の結果

seed31、9日目の夜途中。柴犬Lv3 HP48・攻撃14、サラリーマンLv1 HP28、舞姫Lv1 HP38・ゲージ100。樹木・自然物・落ち物・通常の出現予定を除いた。一発目の電話だけ既存のテスト用確率100%で開始し、その後の自動再抽選は0%にして各境界を切り分けた。成立前に与える1ダメージもfixtureの設定。その後の戦闘は通常AI・通常ダメージ。初日からの自然通し、通常15%の出現頻度・難度の評価とは区別する。

- **電話中の撃破・蘇生**：主人公(7,8)、柴犬(10,10)、敵(11,10)と(12,11)。1秒で電話中、約2秒で「電話を中断→倒した→復活」が履歴に並ぶ。復活後は電話中でなく、予約もない。内部試験では旧期限を過ぎても予約されず、新たな被弾からのみ再抽選できることを追加確認した。
- **成立した増援**：柴犬を(9,10)へ離した同じ配置で、2秒で成立、5秒で森の外(12,40)へ出現。本人と舞姫を柴犬が自然に倒した後も増援は接近を続け、tick91＝22.75秒で牧場へ入り、到着通知が出た。成立から到着までは約20.75秒、外周出現からは17.75秒。2.267＋3.134＋21.166＝26.567実秒、26.25ゲーム秒の区切った等速観察。到着後の撃退まではこの描画ケースで確認していない。
- **夜明け境界**：別fixtureで夜の制限時間を1秒に短縮し、電話中→増援予約中→5秒の出現期限→10日目朝まで観察した。通常の夜は180秒。この短縮を本来の夜の長さや難度と扱わない。到着前に朝になる現行動作を再現し、旧敵・予約の翌朝への持越しがないことは内部試験でも確認した。

主レビューは通常main.tscnを非対話デスクトップで描画し、Viewportへ入力。observeは通常フレームdelta・1倍速、画像を読む間は時計停止、3秒以上の区間は3秒間隔の画像も保存。OS入力・通常画面・通常保存は使わず、音声はDummy。今回は「朝まで休む」の24倍送りを使っていない。画像による区切った観察であり、人間が連続操作する体験や実聴感の合格ではない。

## 修正した表示

1. 電話開始は「電話中（撃破で中断）」、成立は「応援要請が成立」、成立前の死亡は「電話を中断」。上限を超える電話では成立した増援があると誤表示しない。
2. 外周出現は「増援が森から接近」。増援本人が実際に牧場内へ入った時だけ「増援が牧場に到着」を一度表示する。移動・経路・出現時刻・戦力には変更なし。
3. 夜明け時計がゼロでも電話／予約で保留する時は、「夜明け待ち：電話中」「夜明け待ち：増援の準備中」と理由を表示。
4. 図鑑の電話説明で成立前の中断と森を歩く時間を明記し、改行を入れた。表示専用fixtureで実際のホバー表示を確認し、全文が画面内に収まった。英語レア度は維持。

通常の到着を待つ約18秒は調整候補。接近通知は改善したが、待つ間に準備や配置を判断できるか、長く感じるかは人間試遊で判断する。速度を上げたり出現場所を近づける変更はしていない。
