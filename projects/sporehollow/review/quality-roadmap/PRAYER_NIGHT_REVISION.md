# 夜の黄金像と祈り（2026-10-09）

## 今回の仕様

- 動物・お金・アイテムのどれを選んでも、**3秒の現地祈りが完了した時点でカルマ +3**。予約・移動・途中取消・被弾中断では増えない。
- **2日目の夜から**、夜（内部 phase `defend`）だけ受け付ける。初日の夜、朝、昼、夜明け、敗北画面では受け付けない。停止中の夜は従来どおり予約できる。
- 各カテゴリ別の回数ではなく、**全カテゴリで共有して1晩1回**。既存の `prayed_day` を使い、翌日になっても昼は受付せず、翌夜に再び利用可能になる。
- 夜の未祈願の黄金像は発光。祈りが完了したら、その夜の光は消える。予約や途中取消では消えない。像が壊れている、持ち去られている、搬出準備中・搬出中のときは発光しない。
- 既存の「2日目以降に像を調べる」条件は維持。調査前も夜の光は目印として出るが、祈る前に調査を終える必要がある。
- 贈り物は**翌朝**に届く。カテゴリのみを選び、内容は seed・日・祈り時のカルマから決める既存抽選を維持。動物の抽選から柴犬は除外。予約時には報酬を出さない。
- 夜明けまでに終わらなかった祈りだけを取消し、建設等の翌日へ持ち越せる予定は残す。取消しにカルマ・回数の消費はない。

## 暫定解釈と既存仕様との境界

「祈ったら消灯」は予約時ではなく祈りの完了時とする。「翌夜リセット」は既存の一日一回制限を夜へ限定し、カテゴリごとに3回祈れる意味にはしない。未完了の祈りを翌日の作業列へ持ち越すと昼に先頭を塞ぐため、夜明けで失効させる。これらは今回の指摘を既存ループに組み込む暫定解釈。

調査・贈り物の抽選内容・反応イベント（翌朝の経済、翌々朝の噂、3日後以降の役割別襲来）には新しい数値調整を入れていない。カルマ +3 により以後の動物レアリティ抽選に渡る値は増えるが、面白さ・長期難度の評価とは分ける。

## 保存互換

新しい保存キーやフォーマット変更はない。過去に +1 で成立した祈りの `karma_at_prayer`、現在のカルマ、既に確定した報酬は遡って変更しない。旧カテゴリ祈りの未確定報酬も保存された値で決定する。さらに古い固定60Gの約束は従来どおり一度だけ支払う。古い朝保存に未完了の昼の祈り予約が含まれる場合、その予定だけを取消す。通常の朝保存・元のユーザーデータは触らない。

## 実装窓口

`world_story_system.gd` の `prayer_night(w)` が時間条件、`idol_glowing(w)` が描画条件、`reason(w, kind, position)` が受付不可理由。描画・コンテキストの更新側は phase の変化も監視する必要がある。
