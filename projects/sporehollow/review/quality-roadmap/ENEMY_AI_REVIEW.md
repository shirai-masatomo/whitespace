# 敵の目的・経路と停止原因

2026-10-08。f96467aを基準に、ユーザーの停止報告を調査。能力値・出現数・攻撃間隔は変更せず、停止原因2件を分離して修正した。

## いま敵が考える順序

1. 遠い森の外では出現時の入口へ接近する。境界が見える距離になると、同じ側の近隣入口・見える開口を比較する（下記）。牧場に達した後、視界・射線内の相手と最後に見た位置を更新する。見えていない黄金像の位置を無条件には取得しない。
2. 役割固有の行動（配布・舞・盗み・電話・礼など）を優先する。通常攻撃は「主人公・動物・建築・像」のカテゴリ重みから選び、同カテゴリでは高精度の敵ほど近い相手を選ぶ。壁の数だけ建築カテゴリの抽選が増える方式ではない。
3. 現在の標的が有効なら保持し、`0.5 + (100−AI精度)×0.025` 秒ごとに再評価する（0.25秒刻みへ切上げ）。標的が見えなくなった・死んだ場合などは待たずに選び直す。主人公の最後の位置や未到達の探索地点は保持し、到着/到達不能で更新する。
4. 通常の接近は上下左右4方向のA*。歩数に壁を壊す概算コストを足し、動物・敵を避ける経路を先に探す。見つからなければ占有を除外しない経路も調べるが、実際の移動では重なりを拒否する。壁・ドアの破壊能力、屋内に入れない犬、地形、スタミナ、拘束時間も実行時に確認する。
5. 像には像本体のマスでなく、周囲の接触マスへ近づく。今回、その候補から生きたキャラが占有中のマスを除いた。接触候補・経路は次の移動判断で再計算する。

経路の壁コストは共有の誘拐者対物値による近似で、敵ごとの完全な最短時間ではない。また、通常敵全体に「N秒停止したら標的を禁止する」機構はない。今回は到達できる別候補を無視する確定不具合を直し、広範なAI書換えはしていない。

## 役割

| 敵 | 主な目的・待つ理由 |
|---|---|
| 誘拐者 | 主人公を攻撃し、倒れた主人公を担いで入口へ戻る。主人公が隠れた場合は、見えている像などへ圧力を移す。 |
| サラリーマン | 通常攻撃と増援。電話は2秒、成功後3秒で増援予定へ追加。増援は森の外から歩くので、3秒で戦場中央に瞬間出現するわけではない。夜の成功上限4回。 |
| デストロイヤー | 建築優先。主人公ダウン中は見える像へ集中し、像が見えなければ建築などを狙う。 |
| 武闘家 | 人・動物に0.75秒の礼をして挑む。HP1を残し、黄金像は攻撃しない。 |
| 忍者 | 射線内の相手へ手裏剣、近距離攻撃。主人公ダウン中は観測済みの像へ。 |
| ムッツゴロウ | 動物への呼びかけで忠誠を下げ、連れ出す。 |
| ランナー／敵ドーベルマン | 速度による圧力。ランナーは8秒走行後4秒間、毎秒1マスへ減速。犬は屋内に入らない。 |
| 舞姫 | 1秒の舞、効果3秒、再使用6秒。対象条件のある一度限りの蘇生。画像フレームで追加効果は起こさない。 |
| メイド | 味方へコーヒー。一体へ配った後1秒待ち、一巡後は10秒休む。通常時は像を攻撃しない。今回、初回入場時だけ入口を空けてからこの処理へ進む。 |
| 盗賊 | 毒と落とし物の窃盗、盗品を持って退場。盗品は別合成のまま。 |
| 像破壊役／搬出役 | 像周囲へ接近して破壊、または固定解除8秒→毎秒0.5マスで搬出。搬出経路を塞ぐ物体/キャラは別の停止要因。 |

攻撃クールダウン、スタミナ回復、礼、配布後待機、舞、搬出準備は意図された有限の待ち時間。経路の全閉塞や生きたキャラによる封鎖も合法的な足止めで、無条件のすり抜けや瞬間移動では解消しない。

## 確認した不具合と比較

### 画像に対応する入口の休息反復

実見画像は [CONTINUITY_REVIEW](CONTINUITY_REVIEW.md) の1枚。上の「休む」、後続の「森から接近」という組合せは、牧場境界でメイドの役割AIが早く始まる状態と対応する。入場前の味方を配布先に選ぶが、通常経路は牧場外の相手へ届かない。配布済み扱い→10秒休息→再判定を繰り返し、後続の直進を塞いでいた。これは休息10秒を長く感じるだけの問題ではない。

seed31、下入口、3体を連続配置。旧処理は3体とも**60秒間入場ゼロ**。最終修正は入場前に空いていて到達可能な入口隣接マスへ進む。**0.5／1.25／1.75秒で3体入場、最長連続静止0.75秒**。対照サラリーマンは前後とも0.75／1.5／2.25秒。4方向、占有中は待つ、開通後再開、配布後休息、退場も確認した。静止画だけではユーザーの個体IDや秒数は復元できず、同じ症状と実装条件を再現した比較である。

旧 `artifacts/balance-audit/20261008-224743-892`、最終 `20261008-225741-137`。後者20検査・失敗0、`user-data/Godot/app_userdata/ホイッスル牧場/forest-entry.json` に2秒刻み観察。初回の「境界から1マスだけ入れる」修正では先頭が入口の内側で休み後続が止まったため不採用。最終は入口そのものも空ける。

### 像の占有された接触先

これは上記画像とは別に見つけた不具合。像(12,8)、敵(10,8)、停止した生きた味方(11,8)、他の接触先は開いている条件。A*が「標的マスは占有可」として返した最短接触先を繰り返し選び、移動時に拒否されていた。

次はユーザー試遊で入口以外にも止まる場面があれば、敵名・状態文字・周囲の障害物・止まった時間を同じ観察列へ追加する。停止をすべて同じ理由と扱わず、調整値を増やす前に目的→目標→接触先→経路→占有→再計画の順で切り分ける。

## 続報：同じ入口へ集中する根本の選択

メイドだけを直した後、ユーザーから「他のルートもあるのに一点へ集まる」指摘を受け、`enemy_arrival.gd` を追加した。従来は12個の入口マーカーから出現時に1つを指定し、牧場外ではその方向へ直進するだけだった。A*を改善しても、この段階ではA*を呼んでいないため解決しない。

新方式は **森側の確認地点→牧場側の通過地点** を分ける。未確認の内部へ到達できると推測せず、必要なら先に見える入口マーカーの手前へ行って確認する。侵入完了は外周マスではなく内側2列目への到着とし、支援役が境界に座り込むことを防ぐ。

- 候補：同じ辺で本人の視界・射線内にある4方向マス。既存の入口マーカー位置は既知だが、見えない内部の壁・キャラ・標的は評価に使わない。木・像は通行不可。通常メイドのように壊せない役には施錠された障害物を通る候補を与えない。
- 採点：歩数＋その敵の対物能力から見積もる破壊回数＋生きた占有マス12＋見えている味方の割当先3＋見える周辺の狭さ。既に把握した目標への距離は小さい補助点だけ。数値は経路選択の仮重みで、敵の攻撃力や出現数は不変。
- 選択：乱数を追加せず、確定直後に個体へ割当を記録する。後続は先行個体の新しい割当を読み取る。距離が大きく不利なら、均等に分けるためだけに遠い入口へ回らない。
- 保持：進めている経路は到着まで保持。一時占有は0.75秒まで保持し、それ以上塞がる場合や新しい障害物では再評価。確認地点→通過地点の切替と、入口自体の変更を別々に数える。候補なしは0.75秒間隔で再確認する。
- 解除：到着済み・死亡・退場へ目的変更した個体は割当人数から除外。候補なしでも旧割当を残さない。壁やキャラをすり抜けず、拘束/スタミナ/攻撃間隔は既存の実移動処理を使う。

「道を選ぶ性格」は、戦闘役=既存の観測済み標的への接近、破壊役=破壊と迂回の費用比較、支援役=味方を支えつつ入口を空ける、誘拐/盗み役=目的達成後に退場へ切替、という優先関係。今回共通化したのは入口の候補比較と保持だけで、戦場内の標的抽選・盗み・救護を全面的に置き換えてはいない。

### 採用理由と次の範囲

Godot 4.7.2、25×17グリッド、0.25秒固定更新を維持し、新依存は追加しない。公式資料ではRVO局所回避は経路探索に影響せず、ナビメッシュ/物理衝突とは独立している。よって今回の「候補が1つしかない」問題への先行解ではない。[Godot NavigationAgents](https://docs.godotengine.org/en/stable/tutorials/navigation/navigation_using_navigationagents.html)

候補生成→不適合除外→採点という設計は実制作の位置選択技法を参照した。方式の着想として採用し、資料の大規模な仕組みを移植してはいない。[Tactical Position Selection](https://www.gameaipro.com/GameAIPro/GameAIPro_Chapter26_Tactical_Position_Selection.pdf)。頻繁な目標更新による往復の注意はGodot公式にもあり、今回の経路保持と再計画の境界を明示した。

AStarGrid2Dは将来の候補。採用時にはjumpingが重みを無視し、updateがsolid/weightを消す点を検証する。[AStarGrid2D](https://docs.godotengine.org/en/stable/classes/class_astargrid2d.html)。行動ツリー導入は入口選択の代わりにはならない。多数同目的地の探索負荷が実測で支配的になればflow field、対向通行の詰まりが残れば短期予約を次候補とする。今回は3体の局所fixtureと自然5日目再挑戦までであり、大群性能・勝率・面白さは未評価。
