# 敵図鑑

敵の設計はこの文書を正本とする。新しい敵・能力・基礎値は、実装前にここへ追加する。

## 共通ルール

- **視認**：敵は視界を持つ。主人公が視界内かつ見通せる場合は主人公を直接目標にできる。
- **未視認**：主人公が見えていない場合は、即座に正確な位置へ向かわず**探す**必要がある。
- **視界距離**：敵ごとに「何マス先まで見えるか」をステータスとして持つ。
- **視認状態**：内部的に「主人公が見えている / 見えていない」を判定できる。
- **対動物攻撃 / 対物攻撃**：別ステータスとして持つ。
- 完成した壁・閉じたドアが視線を遮る。ドアを開けた後・破壊後は見通せる。未発見時は園内を探索し、見失ったら最後に見た場所を調べ、見つからなければ探索へ戻る。

## 誘拐者 Lv1

**役割**：主人公の誘拐  
**撃退**：HP0で退散  
**AI**：Lv1のため判断に無駄・迷いあり

| 基礎値 | 値 |
| --- | ---: |
| HP | 50 |
| 対動物攻撃 | 5 |
| 対物攻撃 | 2 |
| 視界距離 | 6マス（仮、縦横の距離合計） |

### 行動
- 主人公を視認 → 主人公へ向かう
- 主人公を未視認 → 園内を探す
- 壁・ドアに阻まれる → 迂回または破壊
- 動物から攻撃される → 反撃することがある
- 主人公へ隣接 → 攻撃（初日は5） → HP0で気絶 → 担ぎ上げ → 牧場外へ連れ去る
- Lv1なので必ず最適行動を取るわけではない
- 日数による仮強化：翌日から最大6段階、HPは1段階+4、攻撃は2段階で+1、移動は毎秒1.33マスから1段階+0.27。7日目は元気な主人公の2.5マス/秒を上回る。運搬は毎秒1マス。数・入口・襲来時刻・役割はステージのWave設定で調整する。

| Role | 主目的 |

| 施設破壊 | 壁・ドア・施設を壊す |

## ドアと施錠

通常ドアは開けて通る。ロック付きドアは対物攻撃でロックを破壊してから開ける（仮）。ロックと本体の耐久は別。閉め直しても壊れたロックは戻らない。閉じたドアは視線を遮るが、本体がある限り開閉で屋内判定は変わらない。外周侵入口は建築ドアとは別。

## 外周からの侵入と黄金像への目的

最初の夜は黄金像と無関係の身代金目的の誘拐。四辺各3か所の候補からseed付きで侵入辺を選び、牧場外から歩いて入る。商人/購入動物の物流入口とは別。完成壁があれば経路比較・迂回・対物攻撃を使い、牧場内へ飛ばさない。退却は到達できる外周出口を調べる。木と像本体も通行・視認の障害。

| 目的 | 行動 | 初期仮値 |
|---|---|---|
| 像破壊 | 像に近づき、対物攻撃でHPを減らす | 既存野盗の基礎値を共用 |
| 像搬出 | 接近→固定解除→牽引→境界外へ | 1人・準備8秒・0.5マス/秒、2×2本体＋運び手の経路を検査 |

噂と治安の遅延イベントで候補へ入る。追加襲撃は最大2体（仮）。同じ日数でも祈り履歴がなければこの追加襲撃は発生しない。専用の敵外見は未制作で既存野盗絵を使用、担ぎ姿は像に使わない。運び手が撃退されると像はその場で中断。壁やドアは牽引路を妨げ、狭い1マスのドアへ2×2の像をすり抜けさせない。

搬出路は侵入側を優先し、2×2本体と運び手が通れる別の外周候補も調べる。木は迂回し、完成壁・ドア本体は対物攻撃で破壊して進む。1マスへ像を縮めない。誘拐の担ぎ上げ準備も朝への移行を保留する。
