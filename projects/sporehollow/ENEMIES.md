# 敵図鑑

敵の設計はこの文書を正本とする。新しい敵・能力・基礎値は、実装前にここへ追加する。

## 共通ルール

- **視認**：敵は視界を持つ。主人公が視界内かつ見通せる場合は主人公を直接目標にできる。
- **未視認**：主人公が見えていない場合は、即座に正確な位置へ向かわず**探す**必要がある。
- **視界距離**：敵ごとに「何マス先まで見えるか」をステータスとして持つ。
- **視認状態**：内部的に「主人公が見えている / 見えていない」を判定できる。
- **対動物攻撃 / 対物攻撃**：別ステータスとして持つ。
- 完成した壁・閉門が視線を遮る。開門・破壊後は見通せる。未発見時は園内を探索し、見失ったら最後に見た場所を調べ、見つからなければ探索へ戻る。

## 誘拐者 Lv1

**役割**：主人公の誘拐  
**撃退**：HP0で退散  
**AI**：Lv1のため判断に無駄・迷いあり

| 基礎値 | 値 |
| --- | ---: |
| HP | 50 |
| 対動物攻撃 | 5 |
| 対物攻撃 | 2 |
| 視界距離 | 6マス（仮、縦横の距離合計） |

### 行動
- 主人公を視認 → 主人公へ向かう
- 主人公を未視認 → 園内を探す
- 壁・門に阻まれる → 迂回または破壊
- 動物から攻撃される → 反撃することがある
- 主人公へ隣接 → 攻撃（初日は5） → HP0で気絶 → 担ぎ上げ → 牧場外へ連れ去る
- Lv1なので必ず最適行動を取るわけではない
- 日数による仮強化：翌日から最大6段階、HPは1段階+4、攻撃は2段階で+1、移動は毎秒1.33マスから1段階+0.27。7日目は元気な主人公の2.5マス/秒を上回る。運搬は毎秒1マス。数・入口・襲来時刻・役割はステージのWave設定で調整する。

## 敵Role候補

| Role | 主目的 |
| --- | --- |
| 誘拐 | 主人公を連れ去る |
| 施設破壊 | 壁・門・施設を壊す |
| 動物攻撃 | 動物を優先して狙う |
| バランサー | 状況で標的を変える |
| 支援 | 敵側を回復・強化する |
| 妨害 | 動物・施設・プレイヤー操作を妨害する |

具体的な敵を追加するときに個別項目をこの図鑑へ追記する。
