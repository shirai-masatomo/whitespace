# 敵図鑑

実装対象：誘拐者と以下6種のLv1、敵側ドーベルマン。共通データ・遭遇表・戦闘/図鑑へ統合。素材の納品/取り込み状況はART_SPECを参照。Lv2以降・仲間化は未実装。

敵の設計正本。新しい敵・能力・出現条件は実装前にここへ追加する。数値は特記がなければLv1の仮値。

## 共通

初版調整値：Day1誘拐者1、Day2サラリーマン2、Day3デストロイヤー1、Day4既知候補2。Day5武闘家/Day6忍者/Day7ムッツゴロウ/Day8ランナーは固定1＋抽選1。以後抽選3、Day10以降5日ごと固定ランナー＋抽選2。日程はEncounterデータ。朝の復元で再抽選しない。

サラリーマンの電話は被弾時15%、2秒の電話成立後3秒で外周から増援。1個体成功1回、無限連鎖防止で1夜最大4人（仮）。忍者の巻物は実装済みの「丈夫」スキルだけを出す。取得時に未習得の生存個体の固定ID順で1匹へ付け、取得/習得を記録（仮）。
ムッツゴロウは距離3/CT3秒で忠誠補正−30、毎秒2回復、実効忠誠25以下を搬出。柴犬は低下量半減（仮）。基礎忠誠は不変。境界まで物理移動し、撃退で同じ個体を解放。
敵ドーベルマンは共通AnimalDataの能力・屋外制限を使用。HP0で死亡。ランナー撃退後も敵対を維持し自動加入しない（仮）。

### 共通ステータス

敵は可能な範囲で次を共通化する。

| 項目 | 意味 |
| --- | --- |
| Lv | 同じ敵種の強さ。Lv上昇で基礎値・技・見た目の差分を追加できる |
| Rarity | Common / Uncommon / Rare / Epic / Legendary（仮） |
| HP | 撃退までの耐久 |
| MoveSpeed | 通常移動速度 |
| SightRange | 自分で対象を視認できる距離 |
| AttackRange | 攻撃できる距離。遠距離攻撃は別Rangeを持ってよい |
| AttackInterval / CT | 通常攻撃間隔・特殊技の再使用時間 |
| HumanAttack | 主人公への攻撃力 |
| AnimalAttack | 動物への攻撃力 |
| ObjectAttack | 壁・ドア・像などへの対物攻撃力 |
| AIAccuracy | 判断精度。高いほど無駄・迷い・判断遅延が少ない |
| TargetWeights | 主人公 / 動物 / 建築 / 黄金像を狙う相対重み |
| KarmaMin / Max | 出現可能なカルマ帯。未指定は制限なし |
| SpawnWeight | 抽選テーブル内の出やすさ |
| Recruitable | 仲間化可能か。条件は敵ごとに定義 |
| LootTable | Gold・巻物・アイテム等のドロップ |

TargetWeightsは内部用。固定確率ではなく、その時点で有効な対象だけを正規化して使う。0は「通常は自発的に狙わない」。攻撃された時の反撃、進路を塞ぐ壁、専用能力は別判定。

### 視認・探索

- 敵は視界を持つ。視界内かつ見通せる対象だけを直接認識する。
- 未視認の主人公・動物・黄金像の正確な位置を魔法のように知らない。
- 見失った場合は最後に見た位置を調べ、その後は探索へ戻る。
- 壁・閉じたドア・森の視線遮蔽を共通判定に使う。
- 発見「!」、見失い／探索「?」などの短い反応を使い、大きな視界円を常時表示しない。
- AIAccuracyは探索点の選び方、進路選択、標的変更、判断遅延などに影響できる。**既存の「Lv1は迷う」を共通数値へ拡張する。**

### 出現条件

敵ごとに TypeTag を持てる。初期候補は Human / Animal / Infected / Mutation / Cult / Military / Alien。

- **カルマが低い間は Human / Animal タイプだけを出現候補にする。**
- 高カルマほど高レアリティや異常系TypeTagの候補を解放できる。
- exact threshold は未確定。通常UIにカルマ閾値・SpawnWeightを表示しない。
- 序盤の数ステージは学習用に固定遭遇を優先する。
- その後は遭遇テーブルから抽選する夜を増やす。
- 定期的に固定の「節目遭遇」を挟める。
- 各夜は Fixed / Table / Hybrid のいずれかで定義できるようにする。
- テーブルは Stage/Day、Karma、TypeTag、Rarity、Weight、前提イベント、出現済み回数などで絞り込める。
- 固定遭遇もseed再現・朝やり直しとの整合を保つ。

### 敵Lv

以下の個別記載は**Lv1**。Lv上昇で次を追加できる。

- HP・攻撃・速度・AIAccuracy等の強化
- 新技／既存技の強化
- 装備や服装などの見た目差分
- TargetWeightsや出現行動の変化

単純な全能力倍率だけで済ませない。

### 仲間化

一部の敵は仲間にできる予定。Recruitableと条件を敵データに持たせる。

- 対象・条件・仲間化後の種別は敵ごとに決める。
- HP0にしたら全員自動加入、のような共通ルールにはしない。
- 敵側動物、忠誠低下、猫の懐柔など既存案と接続する。
- 具体対象は要精査。

### 敵図鑑（ゲーム内）

敵図鑑を追加する。設計正本はこのENEMIES.md、ゲーム内図鑑は観察済み情報を見せる。

初期案：
- 未遭遇：シルエット／不明
- 遭遇済み：名前、TypeTag、Rarity、役割、見た目
- 行動を確認：能力・狙いやすい対象・主なドロップ
- 撃退等で追加情報を解放してよい

AIAccuracy、TargetWeightsの生値、KarmaMin、SpawnWeight、乱数式などの内部情報は通常の図鑑へそのまま出さない。

**TargetWeights（仮）**：主人公70 / 動物10 / 建築10 / 黄金像10

### 行動
- 主人公を視認 → 追跡。
- 未視認 → 探索。
- 壁・ドアに阻まれる → 迂回または破壊。
- 攻撃される → 反撃することがある。
- 主人公をHP0にする → 拘束 → 担ぎ上げ → 行動範囲外へ運ぶ。
- 主人公が境界外へ出た時点で敗北。拘束・運搬開始では即敗北にしない。
- 初期の誘拐者は黄金像の正体を知らない。像狙いは世界イベント後の別目的として解放する。

### 礼
戦闘開始前と戦闘終了後に対象へ短くお辞儀する。礼の最中は演出時間を長くしすぎず、無敵化しない。

### 不殺
主人公・動物へ**トドメを刺さない**。攻撃で対象を1HP未満にしない（仮実装）。対象が戦闘不能相当になったら礼をして離脱／別対象へ移る。

Lv上昇候補：構え、反撃、連撃、達人風の外見差分。

### 手懐け
近くの動物の忠誠度を一時的に下げる。低下量・Range・CTは調整前。低下した忠誠度は時間経過で元へ戻る。

### 動物を連れ帰る
忠誠度が一定以下になった動物を搬出対象にする。外側の敗北境界を越えるまで途中救出可能。

柴犬には**持ち帰り耐性**があり、忠誠低下・搬出成立への抵抗補正を持つ。完全無効とは限らず、倍率は要調整。

Lv上昇候補：複数動物への声掛け、より強い懐柔、動物系の取り巻き。

| 施設破壊 | 壁・ドア・施設を壊す |
| 動物攻撃 | 動物を優先して狙う |
| 動物誘拐 | 忠誠等の条件を満たした動物を連れ去る |
| 黄金像破壊 | 像へ対物攻撃 |
| 黄金像搬出 | 像を準備・牽引して外へ持ち出す |

## ドアと施錠

通常ドアは開けて通る。ロック付きドアは対物攻撃でロックを破壊してから開ける（仮）。ロックと本体の耐久は別。閉め直しても壊れたロックは戻らない。閉じたドアは視線を遮るが、本体がある限り開閉で屋内判定は変わらない。外周の侵入／搬出候補は建築ドアとは別。

## 外周からの侵入と黄金像への目的

最初の夜は黄金像と無関係の身代金目的の誘拐。四辺各3か所の候補からseed付きで侵入辺を選び、牧場外から歩いて入る。商人/購入動物の物流入口とは別。完成壁があれば経路比較・迂回・対物攻撃を使い、牧場内へ飛ばさない。退却は到達できる外周出口を調べる。木と像本体も通行・視認の障害。

| 目的 | 行動 | 初期仮値 |
|---|---|---|
| 像破壊 | 像に近づき、対物攻撃でHPを減らす | 既存野盗の基礎値を共用 |
| 像搬出 | 接近→固定解除→牽引→境界外へ | 1人・準備8秒・0.5マス/秒、2×2本体＋運び手の経路を検査 |

噂と治安の遅延イベントで候補へ入る。追加襲撃は最大2体（仮）。同じ日数でも祈り履歴がなければこの追加襲撃は発生しない。専用の敵外見は未制作で既存野盗絵を使用、担ぎ姿は像に使わない。運び手が撃退されると像はその場で中断。壁やドアは牽引路を妨げ、狭い1マスのドアへ2×2の像をすり抜けさせない。

搬出路は侵入側を優先し、2×2本体と運び手が通れる別の外周候補も調べる。木は迂回し、完成壁・ドア本体は対物攻撃で破壊して進む。1マスへ像を縮めない。誘拐の担ぎ上げ準備も朝への移行を保留する。

## 共通戦闘補足

Humanに短期スタミナ、全戦闘個体に個体別技ゲージ。現在のLv1値は維持し、上位差分はBaseStats＋GrowthTable/LevelOverrides。必殺技はREADYだけでは使わず、条件とAI判断を要する。現行種への新しい必殺技効果は未設定。森の外側24セルの進入レーンを歩いて境界へ到達後、通常AIへ移る（距離は仮）。

## 舞姫・盗賊（仮調整）

- **舞姫**：Human、HP38/扇攻撃2。周囲3マスの見通せる敵軍の移動/攻撃速度を1.15倍。必殺技「復活の舞」はREADY時、3マス以内の復活可能な味方1体（自身不可、武闘家優先）。復活HP=min(対象最大HP,舞姫現在HP)。
- 生存した舞姫が6マス以内にいる人間の撃破は10秒の復活待ち。各個体の復活は1回。期限切れ/舞姫不在で通常の退散へ移り、報酬と撃破ゲージを重複させない。動物は復活対象外。
- **盗賊**：Human、HP32/短刀攻撃4。毒は見通せる5マスへ投げ、対象周囲1マスへ5秒間毎秒1ダメージ＋移動0.8倍、CT8秒。実在する落とし物・こけし・化石へ接近して拾い、既存の外周退却境界へ到達すると盗難成立。途中撃破なら元の品をその場へ一度だけ落とす。
- 初登場は舞姫9日目、盗賊10日目。その後は既存の低カルマ抽選へ入る。上位Lvの猛毒や追加強化は未設定。
